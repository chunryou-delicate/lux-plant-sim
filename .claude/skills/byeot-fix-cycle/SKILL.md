# 고치기 한 바퀴 — 빨강을 먼저 보고 고친다

## 1. 받은 것을 맞춘다

- 총괄 가름(무엇을 · 왜 · 값인가 아닌가)과 plan 글(화면에 쓸 문장)을 같이 본다. 글이 없으면 plan 에 청한다 — 문장을 지어내지 않는다.
- 값(돈 · 체력 · 빛 문턱 · 집값)이 바뀌면 총괄을 거쳐 박사님 몫인지 본다. 값은 `data/balance/*.json` 에서만 바꾼다.
- 규칙 탓을 올리기 전 정본 함수를 읽는다. 그 규칙을 말하는 대사도 grep 한다.

## 2. 작업 전 빨강

- 자를 먼저 쓴다(`tools/probe_*.mjs` 브라우저 · `tools/test_*.mjs` node). 단언마다 «무엇을 · 왜»를 한 줄로.
- 작업 전 판(지금 origin/main)에서 돌려 **빨강**이 나와야 그 자가 잰다. 빨강이 안 나오면 자를 다시 쓴다.
- 작업 전 판과 고친 판은 **고정 복사본 두 벌**로 나란히 잰다: `git archive HEAD -- src data tools vendor ':(glob)*.html' | tar -x -C <새 폴더>` 두 번 → 한 벌에만 고침 → `assets` 는 `mklink /J` 연결(시험마다 `assets/manifest.json` 읽히나 확인 · 없으면 다시 건다). 작업 트리에서 재지 않는다(남의 미완료가 섞인다). 폴더는 늘 새 이름 — 지우지 않는다.
- 한 자에서 세이브를 두 번 띄울 때는 **새 탭**(`launch` 다시)에 띄운다. 같은 탭에 두 번 부팅하면 멎는다. 판 하나로 못 세우는 갈래는 앞 판의 `localStorage['byeot/save/1']` 를 떠서 새 탭에 싣는다(그릴 때마다 저장된다).
- 자의 «탈»(오류 · 시간 초과 · 못 찾음)은 빨강이다. `catch {}` 로 삼키지 않는다. 게임 속 이름은 CDP eval 밖이라 `window.__*` 와 DOM 으로 잰다.
- 대사 · 카메라가 멎은 뒤 누른다(첫 탭이 화면 밖이면 기다림이 모자란 것).

## 3. 고친다

- 손가락 · 배너 · 할 일 · 몬이 말이 같은 말을 하게, 가르는 함수는 하나로 둔다(예: 원룸 짐 풀기 손가락과 씨앗 0 배너가 한 함수로 가른다 — 11-02 core 묶음).
- 이사 · 놓기 같은 게임 규칙을 바꾸면 하네스 숫자도 바뀐다 — 부르는 곳을 grep 하고 총괄에게 먼저 말한다(게임 + 하네스 한 push).
- CRLF·LF 섞인 파일은 덩이마다 줄끝을 맞춘다. 고칠 스크립트는 .py 로 쓰고 `newline=''`.

## 4. 고친 판 초록 + 회귀

- 시험 서버는 `python tools/serve.py <포트>` · `BYEOT_URL=http://127.0.0.1:<포트>`(localhost 금지).
- 고친 자 초록 → 회귀: node 묶음 · probe_branches 켬/끔(정렬 글자 같은지) · `CYCLES=3 probe_force5`(손가락 끊김 0) · 브라우저 묶음(총괄 `tools/master/walkfinal.sh` 목록과 같게).
- 사진 자는 사진을 직접 본다.
- 멎거나 시간이 넘으면 그 자만 따로 다시 돌려 가르고, 보고에 «따로 다시»로 적는다.
- 다른 창 크롬(총괄 끝 걸음 · 비판 판)과 겹친 때 난 빨강은 따로 다시 돌려 가르고, 보고에 겹친 시각을 적는다(11-01 d100_6 · 11-02 minor5_15m — 겹치면 렌더러가 멎거나 좌표가 한 점으로 나옴 · 따로 돌리면 통과).

## 5. 커밋 · push

- `git diff -- <파일>` 로 내 줄만인지 본다. 남의 미완료가 섞이면 임시 색인(GIT_INDEX_FILE)으로 내 덩이만.
- `git add -- <새 파일>` → `git commit -- <파일들>` → 바로 `git push origin main`. 거절되면 멈추고 총괄에게.
- ⛔ `git add .` · pull · stash · autostash · `checkout --` · reset --hard · push --force · 파일 삭제.
- 검사와 커밋을 한 명령에 엮지 않는다.
