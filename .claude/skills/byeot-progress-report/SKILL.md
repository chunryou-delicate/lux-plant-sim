# 진행 보고 — 박사님이 폰으로 보시는 한 장

11-01 박사님이 «진행보고 만들었어?»라고 물으셨다. 그때까지 안 만들었다. 물으시기 전에 나와 있어야 한다.

## 0. 언제

- 정기 점검(아침 · 저녁)에서 지난 보고 뒤 게임 push 가 하나라도 있으면.
- 박사님께 여쭐 것이 새로 생겼을 때(물음은 보고 맨 아래 «정하실 것»에도 건다).
- 큰 고침 묶음(BLOCKER/MAJOR)이 끝 걸음 초록을 받았을 때.

정기 점검은 총괄 창의 CronCreate 다(`47 8,20 * * *` · 세션에만 살고 7일 뒤 꺼진다). 총괄 창을 새로 열었거나 7일이 지났으면 CronList 로 보고 없으면 다시 건다. 점검 글은 «①시각 ②지난 보고 뒤 push ③있으면 보고 고쳐 올리고 박사님께 ④인계 파일 맨 위»다.

## 1. 모은다

- `git log --oneline origin/main` 지난 보고 해시 뒤로 · 캠페인 문서 기록 줄 · `core-to-master.md` · `plan-to-master.md` 맨 위 · 가장 새 비판 보고.
- 사진: 끝 걸음 `shots_<R>/` · 비판 판 사진에서 «고친 뒤»를 고른다. 고치기 전 사진이 있으면 나란히 둔다. 사진은 Read 로 직접 보고 고른다.
- 사진은 PIL 로 JPEG q82 · 폭 그대로(390 폰 판)로 줄여 `docs/handoff/img/master-progress-<날짜>/` 에 둔다.

## 2. 쓴다 — `docs/handoff/master-progress-<YYYYMMDD>.html`

틀은 `master-progress-20261101.html` 을 따른다(색 토큰 · 어두운 판 · 사진 누르면 크게).

1. **한눈에** — 세 줄: 무엇이 좋아졌나 · 지금 무엇이 도나 · 박사님이 정하실 것 몇 개.
2. **고친 것 — 사진으로** — 한 장에 한 줄 설명(무엇이 보이나 · 전에는 어땠나).
3. **고친 것 — 목록** — 표: 번호 · 무엇 · 해시 · 잰 자/사진.
4. **총괄이 정한 것** — D95 안(값 아님)만. 까닭 한 줄씩.
5. **다음** — 순서대로.
6. **박사님이 정하실 것** — 물음마다 추천 + 까닭 + 다른 길. 급한 것을 위로.

- 못 잰 것 · 따로 다시 돌린 것 · 창이 꺼져 있던 때는 숨기지 않고 적는다.
- 시각은 `date` 로 읽는다.
- 같은 날 두 번째 보고면 같은 파일을 고친다(날짜가 바뀌면 새 파일).

## 3. 올린다

- 경로 커밋(html + 사진 폴더 파일들) → 바로 push.
- Pages 주소: `https://chunryou-delicate.github.io/lux-plant-sim/docs/handoff/master-progress-<YYYYMMDD>.html` (push 뒤 1~2분).
- 박사님께 한국어 존댓말로 두세 줄 + 주소. 원격에서 보실 수 있게 SendUserFile 로도 보낸다.
- 캠페인 문서 기록 줄에 «진행 보고 <날짜> · 해시».
