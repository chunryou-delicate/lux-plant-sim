## ★ 이 판이 배운 것

1. **뷰는 «한 장 안에서» 뽑는다** — 따로 뽑으면 등신이 어긋나고, Meshy 는 그걸 «평균 내어» 뭉갠다.
   턴어라운드 시트 한 장 → `split_sheet.py` 로 가른다. 굽기 전에 키를 재어 8% 넘으면 막는다.
2. **리깅이 받는 것은 «포즈»가 아니라 «손»이다.**
   A포즈/T포즈 둘 다 422 였다. 손가락이 «갈라진» 원화로 구우니 그대로 통과했다.
   ⇒ 주걱 손(미튼)은 pose estimation 이 사람으로 못 읽는다 [셈].
3. **굽기를 다시 하면 «고친 것 말고 다른 것»이 흔들린다.**
   v8 은 가슴을 고쳤으나 얼굴을 잃었다. ⇒ 고칠 것이 하나면 **메시를 직접** 깎아라(크레딧 0).
4. **재질이 판정을 바꾼다.** `MeshToonMaterial` 이 굴곡을 뭉개 「귀·턱이 없다」로 잘못 물렸다.
   ⇒ `glb_shot.py` 는 재질 없이 «면의 기울기»만 칠한다. 그 자로 봐라.
5. **낼 파일 이름을 «짐작»하지 마라.** `g_front.png` 로 저장했다가 있던 파일 둘을 덮었다(67).
