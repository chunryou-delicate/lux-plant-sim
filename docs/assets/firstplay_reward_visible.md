# 첫 플레이의 «보상 잎»이 화면에서 보이나 (2026-08-29 · leaf → Plan)

⛔ **등급을 매기지 않는다. 「그러니 어떻게 하자」도 안 쓴다.** 잰 것만 적는다.

## 물음

첫 플레이는 등급이 못박혀 있다 — `prologueGrades { 1: plain, 2: sanban, 3: halfmoon }`.
그런데 **등급 «안»에서 어느 그림이 나오는가**는 굴림이다. 그 굴림이 「안 보이는 그림」을
집을 수 있나.

## ① 어느 그림이 나오나 — **굴림이다. 그리고 고르게 뽑힌다**

`shop.js §leafSkinsFor`:
```js
const pick = (arr, salt) => {
  const r = marketHash(seed, `LS${potId}#${leafBirth}`, salt);
  return arr[Math.min(arr.length - 1, Math.floor(r * arr.length))];
};
```
⇒ **세이브 씨앗으로 정해진다** — 한 판 안에서는 안 바뀌고, 판이 바뀌면 다시 뽑힌다.
⇒ ★ 그리고 **풀은 갈래마다 «세 판»(기본·쨍`_v1`·차분`_v2`)을 다 넣는다**
  (`skinKeysOfGrade`: `leaf_mat n`, `n+1`, `n+2`).

★ **고르게 뽑히는지 재 봤다** — `marketHash` 를 그대로 옮겨 씨앗 20,000개를 돌렸다:

```
하프문 풀 15칸 · 소금값 5가지   ⇒ 칸마다 1230~1444 (고르면 1333)
```
⇒ **고르다.** 그러니 아래 비율은 **짐작이 아니라 잰 값**이다.

## ② 등급마다 «무지와 구별 안 되는 판»이 몇인가

「무지(`monstera_leaf_mature`)와의 3px 평균색 거리」로 쟀다. 어두운 판은 실제 화면에서
잰 휘도비 0.380 을 걸었다(`arrival_room_before_fixed.png`).

| 등급 | 값 | 풀 크기 | **무지와 거의 같은 판** | 비율 |
|---|---|---|---|---|
| 산반 | 350,000 | 24 | 6 (`green_yellow` ×3 · `green_lemonpatch` ×3) | **25%** |
| **하프문** | **750,000** | 15 | **6** (`galaxy_tealgold` ×3 · `galaxy_darkteal` ×3) | ★ **40%** |
| 풀문 | 1,150,000 | 18 | 3 (`charcoal` ×3) | 17% |

★ 아슬아슬한 것 더: 산반 `zebra` ×3 (어두운 판 12.1~14.8) · 풀문 `mauve_v2` (14.9).
⇒ 아슬한 것까지 세면 산반 **37.5%**.

### ⚠ 그리고 이것은 **어둠 탓이 아니다**

```
galaxy_tealgold      밝은 판 5.8   어두운 판 2.2
galaxy_tealgold_v2   밝은 판 5.2   어두운 판 2.0
charcoal             밝은 판 11.9  어두운 판 4.5
```
⇒ ★★ **밝은 판에서도 무지와 구별이 안 된다.** 어두워지면 조금 더 나빠질 뿐이다.

## ③ ⇒ 그래서 **첫 플레이에서 이렇게 된다**

```
잎2 = 산반   ⇒ 안 보일 확률 25%
잎3 = 하프문 ⇒ 안 보일 확률 40%      ← ★ 이것이 첫 플레이의 «끝 보상»이다
```

| | 확률 |
|---|---|
| 둘 다 보인다 | 0.75 × 0.60 = **45%** |
| **적어도 하나가 안 보인다** | ★ **55%** |
| **둘 다 안 보인다** | **10%** |

> ## ⇒ ★★★ **두 판 중 한 판 이상에서 보상 잎 하나가 «화면에 안 나타난다».**
> ## ⇒ 열 판 중 한 판은 **둘 다** 안 나타난다.

⚠ 「안 나타난다」는 **그림이 안 그려진다는 뜻이 아니다.** 그려지는데 **45일 그루의 잎이
3 × 3 px** 이라([core] 실측), 그 크기에서 무지 잎과 **색이 같다**는 뜻이다.

## ④ 셈과 눈이 어긋난 자리 — 갈라 적는다

- **셈**: 어두워지면 거리도 흩어짐도 같이 줄어 **비율은 그대로**다(1.74 → 1.75)
- **눈**: 어두운 판 그림(`grade_dark.png`)을 보면 **더 나빠 보인다.**
  어두운 색끼리는 원래 갈리기 어렵다. ⇒ ★ **셈이 이 자리를 못 잡는다.**

## ⛔ 이 수가 못 하는 것

- **게임에서 안 봤다.** 썸네일 3px 평균색으로 잰 것이다
- **한 판에서 잰 휘도비 하나**다. 밤·흐림·다른 자리는 다를 수 있다
- 「거리 10 미만이면 구별 못 한다」의 **10 은 내가 정한 수다.** 사람 눈으로 재 본 값이 아니다
  ⇒ ★ 다만 `galaxy_tealgold` 는 **5.8** 이라 어느 문턱을 잡아도 걸린다
