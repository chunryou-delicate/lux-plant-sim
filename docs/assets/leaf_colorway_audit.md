## ★ 이 훑기에서 배운 것 — **숫자가 셋을 놓쳤다**

숫자로 먼저 좁혔다: 잎 픽셀의 **평균 색상**이 원본에서 갈색대(10~55도)로 옮겨간 것.

```
숫자가 고른 것          8 장
  그중 진짜였던 것      4 장   ← 눈으로 보니 넷은 멀쩡했다(원래 분홍·자주 품종)
숫자가 못 본 것         3 장   ← ★ 눈이 찾았다
```

**숫자가 놓친 셋** — `mon_green_yellow_v2` · `pothos_marble_greenyellow_v2` · `mon_green_lemonpatch_v2`.
⇒ **왜 놓쳤나**: 이 잎들은 **바탕이 짙은 초록**이고 **무늬만 작게** 붉어졌다.
  평균을 내면 **넓은 초록이 좁은 빨강을 덮는다.** 평균은 안 움직인다.
  ⇒ ★ **평균은 「작은 조각이 망가진 것」을 못 잡는다.**

**숫자가 헛으로 고른 넷** — 원본이 이미 분홍·자주인 품종이다.
⇒ 처음에 「초록 띠 밖」으로 걸렀더니 **자주 잎이 전부 걸렸다.** 자를 두 번 고쳐야 했다.

⇒ **총괄이 시킨 순서가 맞았다** — *"숫자로 좁히고, 눈으로 판정하라. 숫자만으로 「고칠 것」에 올리지 마라."*

## 진단 — **「차분(`_v2`)」이 연두·노랑을 갈색으로 민다**

못 쓰는 6장이 **전부 `_v2`** 이고, **전부 원본에 연두·노랑이 있다.**

| 원본 색상 | `_v2` 결과 |
|---|---|
| `mon_variegata_gold` 72도 | → 35도 (갈색대) |
| `monstera_leaf_mid2` 74도 | → 24도 |
| `mon_neon_lime` 75도 | → 23도 |
| `heart_lime_2672_0` 100도 | → 48도 |

⚠ **다만 「연두면 반드시 그렇다」는 아니다.** 연두대(60~110도) `_v2` 가 12장인데
그중 **4장만** 갈색이 됐다. 나머지 8장은 멀쩡하다(`pothos_whitegreen_29` 89→153 등).
⇒ **원인을 다 안다고 쓰지 않는다.** 아는 것은 **「못 쓰는 것은 전부 연두 계열의 차분판」**까지다.
