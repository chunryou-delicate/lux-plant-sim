# ② 속의 설정 — 어떻게 뽑고 어떻게 이름 짓나

## 흐름

```
원화(2D)  →  Meshy image-to-3d (GLB)  →  tools/glb_thumb.mjs 로 납작하게 찍기  →  게임
```

⚠ **썸네일은 원화가 아니라 GLB 에서 찍는다.** 그래서 원화에 광택이 남아도 최종엔 안 남는다.

## 이름 규약 — **두 벌이 있고 방식이 다르다**

| | **잎** `_v1`·`_v2` | **화분·조명** `_c1`·`_c2` |
|---|---|---|
| 뜻 | 쨍 / 차분 | 민트(151°) / 핑크(343°) |
| 하는 일 | 원래 색을 **그대로 두고 채도만** 뺀다 | **한 색으로 덮는다.** 밝기 무늬만 남는다 |
| 바탕을 따지나 | **딴다** | **안 딴다** — 테라코타든 회백이든 결과가 같다 |
| 도구 | `tools/leaf/recolor_calm.py` | `tools/leaf/tint_pot.py` · `tint_lamp.py` |

★ 잎 「차분」 조리법(재서 확정한 것): **색상은 안 건드리고 채도 ×0.55 · 밝기 ×0.96.
단 금(색상 40~70°·채도≥0.35)은 ×0.82 로 덜 뺀다.**
⚠ 처음엔 색상을 −40° 돌렸는데 **연두가 갈색이 됐다.** 그것이 「삭은 색」 사고의 뿌리다.

★ 칠하기에는 **예외 칸이 있어야 한다.** 텍스처 전체를 덮으므로 빼 둘 것을 적어 둔다.
  화분은 **흙**(색상 5~50·채도>0.15·밝기<0.60), 조명은 **켜진 안쪽**(25~70°·채도>0.35·밝기>0.65,
  그리고 9×9 안에서 절반 넘게 켜져 있어야 — 안 그러면 주근깨가 남는다).

## 크기 규약

```
manifest.json 의 real_max_m  = 실제 미터 (사람이 손으로 적는다)
thumbs/index.json 의 m       = GLB 자체 크기 (도구가 적는다)
실제 미터 = GLB 크기 × manifest.scale_to_real
```

⚠⚠ **라벨 없는 숫자가 이 저장소를 열 번 데였다.** Meshy 산출물은 긴 축이 1 또는 2 로
정규화돼 나온다 — 모종삽이 `x=2` 다.

## 폰 자 — **1 m ≈ 106 px** (390×844 dpr2)

`tools/leaf/phone_px.py`. ⚠ **「몇 px 인가」와 「읽히는가」는 다르다** — 중간잎 42px 에서
11갈래 중 5~6만 갈렸다. **크기가 아니라 대비가 정한다.**

## ㉠-2 ★★ **화분 색 판은 게임에서 «고를 길이 아예 없다»** (2026-08-29 저녁 · 재서 확인)

「화분 색이 폰에서 읽히나」를 재려다 **그 앞에서 막혀 있는 것**을 찾았다.

색은 `shop.js` 의 `POT_KINDS[].colors` 에 제대로 들어 있다:
```js
concrete_round.colors = [ {id:'base',ko:'회색'}, {id:'mint',ko:'민트'}, {id:'pink',ko:'핑크'} ]
```
⇒ ⛔ **그런데 그 `colors` 를 밖으로 내주는 함수 `potKindList()` 를 «부르는 곳이 하나도 없다».**
```bash
grep -rn "potKindList" --include=*.js --include=*.html .   # ⇒ shop.js 정의 말고 0줄
grep -rn "_c1.glb|_c2.glb" ... (shop.js 정의·문서 제외)    # ⇒ 0줄
```
⇒ ★ 화분에 실제로 물리는 값은 늘 **기본 에셋**이다 — `state.js:477 potAsset: potKind.asset`.
⇒ ⇒ ★★ **민트·핑크 화분은 플레이어가 «절대» 만날 수 없다.** 안 보이는 것이 아니라 **못 고르는 것**이다.

### ⚠ 그리고 내 짐작 하나를 물린다 — **「바깥벽이 안 보인다」는 틀렸다**

카메라에 안 보이는 것**이 아닌가 했다. 재 보니 **아니다**

| `pot_concrete_round` | 13.7% | 23.6% | **33.5%** | 29.2% |
