# ④ 조명 셋의 색 판 — **셋이 얽혀 있어 한 물음으로 묶는다**

대상: `lamp_desk_mint` · `lamp_clip` · `lamp_table` (GLB 장식 조명 3종)
그림: `assets/lighting/thumbs/` · `assets/lamps/thumbs/`

## ㉮ 배경 — 왜 물음이 됐나

이 저장소는 색 판에 `_c1` · `_c2` 라는 이름을 쓴다. **화분은 `_c1`=민트(151°)·`_c2`=핑크(343°)** 다.
그런데 조명 셋만 `_c1`=43°(크림)·`_c2`=7°(주황빛 빨강)이었다.
내가 「규약이 안 맞는다」고 올렸고 박사님이 **ⓐ 민트로 맞춘다**를 고르셨다. 그래서 칠했다.

⚠ **그런데 칠하고 나서 manifest 를 다시 읽다가 걸렸다:**

```
id 372  lamp_desk_mint_c1.glb  →  「조명-데스크램프-민트-★버터크림」
id 374  lamp_desk_mint_c2.glb  →  「조명-데스크램프-민트-★코랄」
id 376  lamp_clip_c1.glb       →  「클립형 식물등-★버터크림」
id 380  lamp_table_c1.glb      →  「조명-버섯테이블램프-★버터크림」
```

⇒ ★ **manifest 는 조명 `_c1` 을 «버터크림», `_c2` 를 «코랄»로 «일부러» 적어 두었다.**
⇒ ⇒ ★★ 그러니 「이름과 색이 어긋난 것」이 아니라 **조명은 애초에 «다른 색 짝»이었을 수 있다.**
  **내가 올린 전제가 반쪽이었다.**

## ㉯ 진짜 물음은 이것이라고 본다

> ## ★ **「색 판 이름 규약을 화분과 조명이 «같이 써야 하나»」**

같이 쓰면 — 이름만 보고 색을 안다. 새 물건을 만들 때 헷갈리지 않는다.
따로 쓰면 — 물건마다 어울리는 색을 고를 수 있다. **조명은 따뜻한 크림이 어울릴 수 있다.**

## ㉰ 안 넷

| | 무엇 | `_c1` | `_c2` |
|---|---|---|---|
| **ⓐ** | **지금 그대로** (민트로 칠한 채) | 민트 151° | 주황빛 빨강 7° ⚠ 짝이 안 맞는다 |
| **ⓑ** | **화분과 완전히 맞춘다** | 민트 151° | **핑크 343°** |
| **ⓒ** | **되돌린다** — 조명은 조명 규약으로 | 버터크림 43° | 코랄 7° |
| **ⓓ** | 되돌리되 **이름을 바꾼다** | `_w1`(버터크림) | `_w2`(코랄) ★ 규약이 둘이라고 «적는다» |

## ㉱ 각 안의 결과

| | 무엇이 바뀌나 | 품 | 크레딧 |
|---|---|---|---|
| ⓐ | 아무것도. 다만 **`_c1` 민트 / `_c2` 주황**이라 한 벌이 안 맞는 채로 남는다 | 0 | 0 |
| ⓑ | `_c2` 셋을 핑크로 다시 굽는다. 화분·조명이 한 규약이 된다 | **3분** | **0** |
| ⓒ | `_c1` 셋을 버터크림으로 다시 굽는다. 원래 의도대로 돌아간다 | **3분** | **0** |
| ⓓ | ⓒ + 파일 이름 6개 바꾸고 manifest 6줄 고친다 ⚠ **이름 바꾸기는 위험하다** | 20분 | 0 |

★ **넷 다 크레딧 0 이다.** 기본판이 남아 있어 언제든 다시 굽는다.

## ㉲ 되돌릴 수 있나 — **완전히 된다**

★★ 그리고 **지금 이 조명 셋은 «게임에 안 붙어 있다»** — `data/`·`src/`·`game.html` 어디에도
이름이 0줄이다. ⇒ **어느 안을 골라도 게임 화면은 한 픽셀도 안 바뀐다.** 급하지 않다.

# ⓪-㉢ 축복받은 잎을 «색»으로도 갈리게 그릴까

그림: `docs/handoff/img/gradecolor/grade_at_3px.png` · `grade_color_ifdone.png`

## ㉮ 배경

[core] 가 화면에 투영해서 쟀다 — **45일 그루의 잎이 3 × 3 px** 이다(성숙잎도 멀리서 14px).
그런데 첫 플레이의 **보상이 「둘째·셋째 잎에 무늬가 확정된다」**이다.
⇒ ★ **보상이 3 px 안에서 일어난다.**
⇒ 내가 잰 것 — **작아지면 무늬가 먼저 죽고 «색»이 남는다.** 그래서 [Plan] 이 물음을 냈다.

## ㉯ 안 정하면 — **지금 이렇다** (재서 확인)

3 px 에서 남는 것은 사실상 잎의 **평균색**이다. 등급별로 재면:

| 등급 | 값 | 3px 평균색 | 등급 **안** 흩어짐 |
|---|---|---|---|
| 무지 | 20,000 | R23 G52 B30 (아주 짙은 초록) | **0** (한 갈래뿐) |
| 산반 | 350,000 | R90 G114 B68 | **±32** |
| 하프문 | 750,000 | R85 G95 B90 | **±40** |
| 풀문 | 1,150,000 | R125 G92 B77 | **±41** |

등급 **사이** 거리:

```
무지 ↔ 산반    55.8      ⇒ ★ 갈린다 (무지는 흩어짐이 0 이라)
무지 ↔ 하프문  54.7      ⇒ ★ 갈린다
★ 산반 ↔ 하프문  15.6    ⇒ ⛔ 흩어짐(32~40)이 거리보다 «크다». 안 갈린다
★ 하프문 ↔ 풀문  18.5    ⇒ ⛔ 안 갈린다
```

> ## ⇒ ★★★ **「무늬가 생겼다」는 3px 에서도 보인다. 「무슨 무늬인가」는 안 보인다.**

⚠ 눈으로 봐도 그렇다 — `mon_charcoal`(풀문 1,150,000원)이 새까맣고 `mon_galaxy_darkteal`
(하프문 750,000원)도 거의 검다. **무지와 3px 에서 구별이 안 된다.**
반대로 `mon_neon_lime`(산반 350,000원)은 형광 연두다. **등급 안에서 색이 제각각이다.**

## ㉰ 안 셋 — **① 할 수 있나 · ② 하면 어떻게 되나** (시늉내 재 봤다)

### ⓐ 그대로 둔다
### ⓑ **색만** 등급마다 모은다 — 무늬(밝고 어두움)는 그대로
### ⓒ **색과 밝기를 둘 다** 등급마다 모은다

시늉낸 결과 (등급 **사이** 거리 / 등급 **안** 흩어짐):

| | 산반↔하프문 | 하프문↔풀문 | 등급 안 흩어짐 |
|---|---|---|---|
| ⓐ 지금 | 15.6 | 18.5 | ±32~41 |
| ⓑ 색만 | 21.4 | 18.7 | ±24~44 |
| **ⓒ 색+밝기** | **69.5** | **86.1** | **±7~19** |

> ## ⇒ ★★★★ **ⓑ(색만)로는 «안 된다».** 거리가 21 로 오르는데 흩어짐이 여전히 24~44 다.
> ## ⇒ ⇒ **밝기까지 모아야 갈린다.**

★ 할 수 있나 — **된다. GLB 텍스처만 손보면 된다. 크레딧 0 이다.**
  화분 `_c1` 칠하기(`tools/leaf/tint_pot.py`)와 **같은 방식**이고 도구가 이미 있다.
  19갈래 × 색 판 = **약 57장**. 굽는 데 **한 시간쯤**, 3D 로 찍어 보는 데 **10분** 더.

## ㉱ ③ 무엇을 잃나 — ★ **이것이 고르실 자리다**

```
등급 «안» 흩어짐이  ±32~41  →  ±7~19  로 떨어진다
⇒ ★★ 잎 색의 다양함이 «절반 넘게» 사라진다
```

눈으로 보면 (`grade_color_ifdone.png` 오른쪽 14px 칸):

- `mon_charcoal` 의 **새까만 것**이 풀문 분홍빛으로 눕는다
- `mon_neon_lime` 의 **형광 연두**가 산반 올리브로 눕는다
- `mon_galaxy_darkteal` 의 **짙은 청록**이 하프문 은회로 눕는다

⇒ ★ 즉 **「등급이 읽힌다」와 「잎이 저마다 다르다」가 «맞바꿈»이다.**
⇒ ⚠ 그리고 잃는 것은 **당겨 본 판(262 px)에서 가장 크게 보인다** — 거기서는 지금도 36갈래가
  다 갈리는데, 모으면 등급마다 비슷해진다.

## ㉲ 되돌릴 수 있나

**된다.** 원본이 `assets/monstera/skins/_orig/` 에 104장 그대로 있다. 다시 굽거나 되돌리는 데
크레딧이 안 든다. ⚠ 다만 **57장을 다시 굽는 한 시간**은 매번 든다.

- **「그러니 하자/말자」를 안 썼다**
