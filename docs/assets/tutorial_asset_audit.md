## 1. ★ 제일 센 검사 — **코드가 이름을 박아 부르는 파일 32개**

manifest 를 도는 것보다 이쪽이 세다. **화면이 비는 것은 코드가 부른 파일이 없을 때**다.

```
src/**/*.js · game.html 에서  assets/….(glb|png|jpg|webp|jfif)  를 전부 뽑았다
  이름을 통째로 박은 것        28개 → 26 있다 · 2 는 조립 경로
  조립 경로 2개               assets/crops/beansprout_${stage}.glb
                              assets/crops/sprout_radish_${stage}.glb
    stage 는 's' · 'm' · 'l' 셋뿐이다(room_view.js:2117·2188)  → 6개 다 있다
⇒ 합 32개, 없는 것 0개
```

## 3. ⚠ 판정 필드 — **manifest 가 게임에 닿는 자리는 「시루 계약」 하나다**

`first_play.js:541 openSiruContractFromManifest()` 가 manifest 를 읽는 **유일한 자리**로 보인다.
그 함수가 실제로 읽는 것:

| 필드 | 무엇에 쓰나 | 지금 값 |
|---|---|---|
| `kind` · `crop` | 시루를 찾는 열쇠 | `siru` · `beansprout` |
| `lid_state` | 열림/닫힘 짝 찾기 · `transmitsSlotDli` | `open` / `closed` |
| `source_2d` | ★ **가방 칸 그림 경로를 조립**한다 | `container_siru_open.png` / `_closed.png` |
| `size_m.w` · `size_m.d` | **자리 판정 지름** = `max(w,d)` | 0.2400 m / 0.2424 m |

⇒ ✅ **넷 다 채워져 있고, 조립되는 썸네일 경로 둘 다 파일이 있다.** 계약이 성립한다.
   (없으면 `throw` 라 **첫 플레이가 못 열린다.** 지금은 안 그런다)

**`first_play.js` 의 시루 계약 밖에서 manifest 를 읽는 곳을 못 찾았다.**

(`room_view.js:7031` 이 그렇게 말한다). **manifest 에 없는 것이 맞다.**

## 4. ★★ 재배판 칸이 **두 벌이다** — 지금은 같다. 자를 세워 뒀다

## 5. 크기 — 전부 있고 말이 된다

⚠ **열쇠 이름을 내가 틀렸었다.** manifest 는 `w/h/d` 가 아니라 **`real_max_m` · `size_m`** 을 쓴다.
처음에 `w/h/d` 로 찾아 「크기가 하나도 없다」는 결론이 나왔다 — **자가 틀린 것**이었다.

```

콩나물 0.049 / 0.086 / 0.128     무순 0.025 / 0.048 / 0.074
씨앗 0.008 · 0.010               새순 0.034 · 0.034
말린 새순 0.140 · 유리병 0.130 · 모종포트 0.130      (전부 m)
```

⚠ 그리고 **`seed_dicot` 0.008 m 를 「이상하다」로 걸 뻔했다.** 8 mm 는 **콩알**이라 정상이다.
  내가 세운 하한(0.01)이 너무 빡빡했다. **자를 두 번 고쳤다.**
