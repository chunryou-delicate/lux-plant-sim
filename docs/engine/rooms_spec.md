```
반지하·원룸·투룸  →  "선반을 어느 높이에 두나"   (한 줄뿐이라 높이가 전부)
학원교실          →  "창턱을 쓰나 못 쓰나"        (건축이라 못 팔지만 못 늘리지도 못한다)
아파트            →  "발코니에서 몇 m 안쪽인가"   (평평해서 거리만 남는다)
온실              →  "차광을 얼마나 치나"         (밝기는 이미 넘치고 관리가 문제)
```

## 6. 캐릭터별 시작 방 조건

판정 기준: 몬스테라 `min 3.0` / `갈라짐 6.0`, 무늬종 `min 4.2` / `갈라짐 8.4`.
**전부 `space.avg7_summer`(7일 이동평균) 기준** — 하루 peak 가 아니다.

| 방 | avg7 | 몬스테라 min(3.0) | 갈라짐(6.0) | 무늬종 min(4.2) | 무늬종 갈라짐(8.4) |
|---|---|---|---|---|---|
| 반지하 | 2.40 | ✗ **정체** | ✗ | ✗ | ✗ |
| 투룸 | 4.30 | ✓ | ✗ | ✓ 겨우 | ✗ |
| 원룸 | 4.34 | ✓ | ✗ | ✓ 겨우 | ✗ |
| 학원교실 | 4.87 | ✓ | ✗ | ✓ | ✗ |

**★ 자연광만으로 갈라진 잎을 보는 건 온실뿐이다.** 아파트가 5.79로 6.0에 **0.21** 못 미친다.

### 캐릭터별

| 캐릭터 | 경로 | 등 없이 | 등을 켜면 (면적=상한, 바 r=0.5m) | 무광 자리(<0.3) |
|---|---|---|---|---|
| **자취생** | 반지하 → 원룸 → 아파트 | 반지하 **정체**(2.40) → 원룸 **성장**(4.34) → 아파트 **성장**(5.79). 끝까지 안 갈라짐 | 20 → 30 → **99** 그루 | 30.3 → 33.4 → **95.1㎥** |
| **가장** | 학원교실 → 온실 | 학원 **성장**(4.87). 창턱 112칸이 공짜 | **66** 그루 — 자리는 있는데 ★전기가 식비와 경쟁 | 48.4㎥ |
| **주부** | 아파트 | **성장**(5.79). 무늬종 min 4.2는 넘지만 갈라짐 8.4는 한참 멀다 | **99** 그루 · 전기 여유 | **95.1㎥** — T자 평면이라 어두운 구석이 제일 많다 |
| **연구자** | 온실 | **유일하게 갈라짐**(10.39). 무늬종도 갈라짐 | **120** 그루(온실만 70) · ★전기 무료라 다 켤 수 있다 | 62.3㎥ (연구실 쪽) |

**★ 축이 둘이다** — 자연광은 창이, 조명등은 **면적**이 정한다.
반지하가 등 1개로 6.83이 나온 게 그 증거다. 등을 켜기 시작하면 창은 상관없어진다.

```
자연광 좋음 + 면적 작음  →  창가 명당은 있는데 확장이 안 됨   (원룸)
자연광 나쁨 + 면적 큼    →  돈만 있으면 큰 농장               (반지하가 극단)
```

**가장 66 vs 연구자 70** — 자리는 거의 같은데 **전기 면제 여부**가 갈린다.
"자리는 있는데 다 못 켠다"가 가장의 빠듯함이고, 그게 숫자로 나온다.
