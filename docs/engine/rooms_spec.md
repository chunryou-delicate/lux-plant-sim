> `space.peak` 는 여섯 방 전부 그대로고, 칸막이가 있는 방의 **면적·부피만** 줄었다

> 그 영향이 컸다. 이제 **고체 벽 속만 빼고 창·문 개구부(reveal)는 살린다** —

```
자연광 좋음 + 면적 작음  →  창가 명당은 있는데 확장이 안 됨   (원룸)

```

**가장 60 vs 연구자 70(온실 명목)** — 자리는 거의 같은데 **전기 면제 여부**가 갈린다.
"자리는 있는데 다 못 켠다"가 가장의 빠듯함이고, 그게 숫자로 나온다.

## 8. ★ 반지하 첫 플레이 두 자리 (2026-08-02)

첫 플레이는 *"몬스테라를 창가 높은 자리에 두면 새순이 난다"* 로 성립해야 한다.
그러려면 **밝은 자리와 어두운 자리가 같은 방 안에 실제 슬롯으로** 있어야 한다.

| | slotId | 좌표 | peak_summer | avg7_summer | 용도 |
|---|---|---|---|---|---|
| **밝은 자리** | `banjiha-sill:0` | (0, 1.585, −1.95) | **3.77** | 2.42 | 몬스테라 (min 3.0 대비 **+26%**) |
| **어두운 자리** | `banjiha-dresser:1` | (1.7, 0.8, 1.66) | **0.04** | 0.02 | 열린 콩나물 시루(0.24m) |

**격차 94배.** 같은 방 안에서 "어디 두느냐"가 전부라는 게 두 슬롯으로 드러난다.

### 창턱은 왜 개구부 안에 있나

창이 `y 1.495~2.045` 라 **벽이 그 구간에서 뚫려 있다**(`rectMinus`).
그 안쪽 깊이 0.2m가 실제 창턱 자리다. 벽 안쪽면(z=−1.90)에 붙이면 2.4밖에 안 나오는데,
개구부 안(z=−1.95)이면 **3.77** 이다. 창에 얼마나 가까운가가 전부다.

```
z=−1.95 (개구부 안)   3.77   ← 창턱
z=−1.90 (벽 안쪽면)   3.29
z=−1.79 (깊이 0.22 선반 중심) 2.40
```

### 1칸만 준 이유

```
0개  → 존재를 몰라 벽이 된다
1개  → "높은 선반은 밝다"는 힌트가 된다
여러 개 → 발견과 확장 동기가 사라진다
```

`shelf_sill_pot1` 은 **반지하 전용 프리셋**이다(`slots: 1`).
공용 `shelf_wall_1tier`(3칸)는 그대로 두었다 — 다른 방에 영향이 없다.

**화면 증거**: `docs/engine/shots/banjiha_first_play_wide.png` · `banjiha_sill_near.png`

## 9. 면적 라벨 — net / gross / 명목

| 라벨 | 뜻 |
|---|---|
| `area.floor_m2_net` | **0.25m 격자로 센 실제 바닥.** 외곽 벽 띠·칸막이·도려낸 자리 제외. **등 상한은 이 값 기준** |
| `area.floor_m2_gross` | 외곽 치수 곱 (`size.w × size.d`) |
| `area.split_nominal_gross` | 온실 전용. **외곽 치수 기반 명목 분할** |

**온실 관계**

```
gross 120.0㎡  =  명목 온실 70 (10×7)  +  명목 연구실 50 (10×5)
net   112.4㎡  =  gross − 외곽 벽 띠 4.36 − 칸막이 1.4 − 격자 양자화 ≈ 1.8
```

**명목 70/50 은 합이 gross 와 맞고, net 과는 안 맞습니다.** 벽 두께를 뺐기 때문입니다.
등 상한·부피는 전부 **net** 기준입니다.

## 10. `sampled_peak_ratio_pct` — 100% 를 넘을 수 있다

`slots.peak ÷ space.peak`. 예전 이름 `utilization_pct` 를 바꿨습니다 —
"활용률"로 읽으면 100% 초과가 오류로 보이는데, 실제로는 **표본이 달라서** 그렇습니다.

```
space   0.25m 격자 위의 점        y = 0.10, 0.35, ..., 1.60, ...
slots   가구가 정한 임의 높이      반지하 창턱 상판은 1.585m
```

격자는 y=1.60(3.74)을 재는데 실제 상판은 **1.585m** 라 조금 더 밝습니다(3.77) → **101%**.
**100 으로 자르지 않습니다.** 자르면 "격자 사이에 더 좋은 자리가 있다"는 정보가 사라집니다.
