# 집짓기 — 엔딩 이후 콘텐츠 (설계 기록, 2026-07-26)

> ⏸ **지금은 기록만 한다.** 핵심 루프(빛→생장)도 확인 전이고 경제도 없다.
> 구현은 한참 뒤다. 여기서 검토하는 건 **가격 구조가 말이 되는가** 하나뿐이다.
>
> 정본은 `GAME_PLAN.md`. 이 문서는 그 위에 얹는 **후반 콘텐츠 설계**다.

---

# 0. 에셋은 이미 다 있다

창틀 39종 · 가구 115종 · 벽/바닥 텍스처 27 · 방 조립 시스템(`house.js`).
**새로 만들 게 거의 없다.** 구현 부담이 낮은 편이고, 그래서 오히려 **밸런스 검토가 먼저**다.

---

# 1. ⚠ 이 기능은 밸런스를 통째로 바꾼다

지금까지 방을 **"주어진 것"** 으로 놓고 밸런스를 짰다(반지하 < 원룸 < 투룸 < 아파트 < 온실).
집을 지으면 **플레이어가 자기 방을 설계한다.**

```
창을 최대로  → 온실급 조도
남향만       → 향 계수 1.0
면적 최대     → 등 무제한
= "돈만 있으면 온실보다 좋은 집"
```

→ **온실(연구자)의 정체성이 사라진다.** 이게 이 기능의 유일한 진짜 위험이다.

---

# 2. ★ 제한이 아니라 가격으로

**"안 됩니다"가 아니라 "얼마면 됩니다".**

| | |
|---|---|
| 제한 | 플레이어를 가두는 느낌. 선택권이 없다 |
| **가격** | 선택권을 준다. **그리고 후반 돈 문제를 흡수한다** |

후반엔 돈이 계속 쌓이는데 **창값이 기하급수면 아무리 벌어도 끝이 안 난다.**
돈이 갈 데가 생긴다.

## 창값 = **방 전체 창 면적 합계**의 제곱

```
창값 = 10만원 × A²        (A = 그 방의 창 면적 합계, ㎡)
```

| A | 값 |
|---|---|
| 1㎡ | 10만원 |
| 2㎡ | 40만원 |
| 4㎡ | 160만원 |
| 8㎡ | 640만원 |
| 16㎡ | 2,560만원 |
| **31.6㎡** | **1억원** |
| 50㎡ | 2.5억원 |

**★ 반드시 "합계"의 제곱이어야 한다.** 면적당 단가로 하면 **창을 여러 개로 쪼개서 우회**한다.

## 검토 — 제곱이 맞는 곡선인가

**맞다. 효용은 선형인데 비용이 제곱이라서다.**

DLI는 창 면적에 대략 **선형**이다(입체각 ∝ 면적). 그런데 비용이 A²이므로:

```
DLI 2배 → 돈 4배
DLI 4배 → 돈 16배
비용 대비 효용 = 1/A 로 체감
```

→ **"조금 더 밝게"는 싸고, "훨씬 더 밝게"는 감당이 안 된다.**
이게 정확히 원하는 성질이다. 선형이면 돈이 쌓이는 대로 온실이 되고,
지수함수면 어느 지점에서 갑자기 벽에 부딪혀 부자연스럽다.

---

# 3. ★★ 우연이 아닌 것 둘 — 가격 구조가 기존 설계와 맞물린다

## ① 가장의 목표금액 1억 = **온실급 창 31.6㎡의 가격**

```
10만 × A² = 1억  →  A = 31.6㎡
온실 유리벽 4.9×2.7 = 13.2㎡ × 2면 = 26.5㎡ + 천창 ≈ 31㎡
```

`characters.json`의 가장 `goalValue: 100000000`은 임의로 잡은 숫자였는데,
이 가격 구조에서는 **"온실을 지을 수 있는 돈"** 이 된다.
가장의 엔딩이 *"목표금액 → 자기 온실"* 인 것과 **정확히 맞아떨어진다.**

## ② 향 계수가 **땅값을 유도한다** — 임의로 정할 필요가 없다

향은 땅이 결정한다(§4). 북향 땅에서 남향과 **같은 DLI**를 내려면 창을 키워야 하는데,
창값이 제곱이므로 비용이 이렇게 된다:

| 향 | k | 필요 창 면적 | **비용** |
|---|---|---|---|
| 남 | 1.00 | 1.00배 | 1.0배 |
| 남동/남서 | 0.85 | 1.18배 | **1.4배** |
| 동/서 | 0.62 | 1.61배 | **2.6배** |
| 북동/북서 | 0.45 | 2.22배 | **4.9배** |
| **북** | **0.38** | 2.63배 | **6.9배** |

→ **남향 땅은 북향 땅보다 최대 6.9배 비싸도 정당하다.**
땅값 배율을 손으로 잡을 필요가 없다 — **이미 있는 향 계수에서 나온다.**

## ③ 그래서 온실의 정체성이 규칙 없이 지켜진다

연구자가 **공짜로 빌려 쓰는 온실 = 1억원짜리 설비**다.

- *"연구자는 억 단위 설비를 공짜로 쓰고 있다"* 가 **숫자로 성립**한다
- 졸업하면 그걸 잃는 U자 곡선의 **낙차가 1억원으로 계량**된다
- **온실을 특별하게 두려고 규칙을 만들 필요가 없다.** 가격에서 자연히 나온다

# 4. 나머지 비용 구조

## 향은 땅이 결정한다 — **집을 지어도 못 바꾼다**

★ 이게 제일 좋은 제약이다.

- **"좋은 땅을 사느냐"가 집을 짓기 전의 선택**이 된다
- 집을 다 지어도 **땅을 잘못 사면 소용없다** = *"빛이 진짜다"* 와 맞는다
- **이사 시스템이 끝까지 의미를 갖는다** — 마지막 이사가 "땅 고르기"다

## 천창 = 면적 **×3 환산**

실제로도 구조·방수·단열 때문에 훨씬 비싸다.

```
환산 면적 = 수직창 면적 + 3 × 천창 면적
```

**못 짓게 막을 필요가 없다.** 천창 5㎡면 15㎡로 환산되어 제곱에서 폭발한다
(5㎡ 단독 250만 → 환산 시 2,250만). **가격으로 자연히 늦춰진다.**

> 온실만 천창을 갖는 게 아니라 **온실만 천창을 감당할 수 있는** 것이 된다.
> 금지가 아니라 순서다.

## 땅값 = 면적 (선형)

**창은 제곱, 땅은 선형**으로 간다. 둘 다 제곱이면 후반에 아무것도 못 짓는다.
실제 땅값도 면적에 선형에 가깝다.

면적이 **등의 상한**이므로(슬롯당 등 1개) 여기가 규모의 진짜 비용이다.

## 온도가 들어오면 이중으로 걸린다

`env_difficulty_axis.md`의 온도 축이 켜지면 **큰 창 = 겨울 열손실 = 난방비**다.
→ 창값(제곱) + 난방비(운영비)가 **초기비용과 유지비 양쪽에서** 큰 창을 누른다.
**설계를 더 할 필요가 없다.** 이미 있는 축이 알아서 한다.

# 5. ★ 재공사 — 환급 50%, 그리고 **진짜 후회는 공사 기간**

## 환급률 검토 (2㎡ → 4 → 8 → 16 확장 경로)

| | 총 지출 | 한 번에 짓기 대비 |
|---|---|---|
| 한 번에 16㎡ | 2,560만 | — |
| 단계적 · **완전 손실** | 3,400만 | **+33%** |
| 단계적 · **50% 환급** | 2,980만 | **+16%** |

**완전 손실(+33%)은 너무 가혹하다.**
초반엔 돈이 없어서 **작게 시작할 수밖에 없는데**, 그 강제된 선택이 33% 벌금이 된다.
가혹하면 **재공사를 아예 안 하게 되고**, 그러면 확장의 재미 자체가 사라진다.

**→ 자재값 50% 환급을 채택한다.** +16%는 *"한 번에 크게가 유리하지만
단계적으로 가도 파멸적이지 않은"* 크기다.

## ★ 그런데 진짜 후회 장치는 돈이 아니라 **시간**이다

```
재공사 중에는 그 방을 못 쓴다.
→ 식물을 다른 데 옮겨야 한다
→ 옮길 자리가 없으면 그동안 빛이 부족해 상한다
```

**"돈보다 시간이 아깝다"** 가 되고, 이게 볕의 정체(느린 게임)와 맞는다.
그리고 **계획의 재미**가 여기서 나온다 — *"지금 확장하면 두 달치 성장을 잃는다"*.

> 환급률로 후회를 만들면 그냥 **세금**이다.
> 공사 기간으로 만들면 **결정**이 된다. 언제 할지, 식물을 어디로 뺄지.

**공사 기간 제안**: 창 면적에 비례. 예 — `A ㎡ × 3일`(4㎡면 12일).
확장 폭이 클수록 오래 비운다 = 한 번에 크게 짓는 것의 대가도 생긴다.

# 6. 순서 — 엔딩 **이후** 콘텐츠

```
자취생   반지하 → 원룸 → 아파트 → [엔딩] → 자기 집 짓기
가장     교실 → 온실 → [엔딩] → 자기 온실
연구자   온실(빌림) → 졸업 → [엔딩] → 자기 연구실
주부     아파트 → 드림가든 → [엔딩] → 꿈의 집
```

**넷 다 "빌린 공간 → 내 공간"으로 끝난다.**

특히 **연구자**가 완성된다 — 졸업하면 온실을 잃는 U자 곡선이 있었는데
(`researcher_track.md` §3), 그 끝이 *"자기 연구실"* 이면 곡선이 닫힌다.
그리고 §3-③에서 **그 낙차가 1억원**이라는 게 숫자로 나온다.
