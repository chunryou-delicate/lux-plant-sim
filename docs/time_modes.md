# 1. 시간 모드 4단

| 모드 | 시간 | 하루 안을 | 보상 | 도감 |
|---|---|---|---|---|
| **점핑** (튜토) | 이벤트까지 스킵 | **안 본다** | 없음 | 깨면 **열림** |
| **빠른배속** (초보) | 1일 10~30초 | 압축해서 봄 | 기록 | 열림 |

| **1:1** (고인물) | 1일 24시간 | 진짜 시간 | + **증명** | **전용 칸** |

## ★ 4단인 이유는 질적 차이다

```
점핑  하루 안을 안 본다      → 관찰 없음
배속  하루가 압축돼 흐른다    → 관찰 있음   (빠름/느림은 양적 차이)
1:1   관찰이 곧 플레이
```

**빠름/느림만 양적 차이**고, 나머지 경계는 **다른 종류의 경험**이다.

## ★★ 점핑의 값어치는 "속도"가 아니라 "편집"이다

계산해보면 속도로는 설명이 안 된다.

| | 자취생 1막(150일) | 3년(1095일) |
|---|---|---|
| **점핑** | **19~47분** | — |
| 빠른배속 10초 | 25분 | 3.0시간 |
| 빠른배속 30초 | 1.3시간 | 9.1시간 |
| 느린배속 30분 | 3일 | 23일 |
| 1:1 | 150일 | 1095일 |

**빠른배속 10초면 150일이 25분이다. 점핑(19~47분)과 별 차이가 없다.**

그런데도 점핑이 필요한 이유는 **그 25분의 대부분이 아무 일도 안 일어나기 때문**이다.
잎은 10~40일에 하나 나고, 나머지 날은 화면이 그대로다.

> **점핑 = 압축이 아니라 편집이다. "볼 것만 본다."**
> 튜토는 **가르칠 게 정해져 있어서** 편집이 맞고,
> 본편은 **뭘 볼지 플레이어가 정하는 게임**이라 편집이 오히려 방해가 된다.
> → 점핑이 튜토 전용인 진짜 이유가 여기 있다. *뺏는 것*이 아니라 **본편엔 안 맞는 것**이다.

# 2. ★ 튜토리얼 캠페인 = 자취생 1막

**"쉬운 난이도"가 아니라 "맛보기 한 바퀴"다.**
전체 엔딩(이사비 150만)이 아니라 **반지하 → 원룸까지만.**

> ⚠ **[정정 2026-08-01·08-02] 아래 다이어그램은 옛 흐름이다.** 기록으로만 남긴다.

원룸  4.77    등 없이도 자람         → 환경 변화 체감

## 왜 튜토가 필요한가

**볕은 느린 게임이다** — 잎 하나 40일, 완성 3년.
처음 하는 사람이 *"이게 뭐 하는 게임인지"* 알기까지 너무 오래 걸린다.

점프로 한 바퀴 돌려주면 *"빛이 부족하면 안 자라는구나 / 등을 켜니 갈라지네 /
이사하니 자리가 늘었네"* 하고 **그다음에 진짜 시작하게 된다.**

이 한 바퀴로 **네 가지를 다 배운다**:
빛이 식물을 자라게 한다 / **자리가 중요하다** / 등을 켜면 뒤집힌다 / 환경이 좋아지면 식물도 좋아진다

## 왜 자취생인가 — 주부를 검토했다가 뺐다

| | 자취생 | 주부 |
|---|---|---|
| **이사** | 있다 — 반지하 0.35 → 원룸 3.07 = **9배** | **없다** |
| 핵심 보상 학습 | *"환경이 좋아지면 식물도 좋아진다"* ✔ | **못 가르친다** |
| 빛의 인과 | 반지하는 등이 없으면 아무것도 안 됨 = **제일 선명** | 애매 |

**★ 주부를 뺀 결정적 이유**: 아파트 3.87 < 무늬종 `min` 4.2라
**알보를 사도 새 잎이 안 난다.**
본편에서는 *"돈으로 못 뚫는다"* 는 좋은 설계지만 **튜토에서 나오면 최악**이다 —
초보가 *"샀는데 왜 안 자라지?"* 하고 **이유를 모른다.**

## 도감은 본편으로 미룬다

맛보기에서 다 열어주면 본편에 할 게 없어진다.
**깨면 도감이 열리고, 도감은 점핑이 안 되는 모드에서 차차 채운다.**

축은 이미 넷이다: **시간 / 깊이 / 정보 / 캐릭터**.
"점프 가능"은 새 축이 아니라 **시간 축의 한 단계**다.

| 프리셋 | 시간 | 깊이 | 정보 | 캐릭터 |
|---|---|---|---|---|
| **튜토** | 점핑 | 기본(빛) | 숫자 다 보임 | **자취생 고정** |

초보자에게 축 4개를 고르라면 막막하다. **"튜토" 하나 누르면 다 세팅된다.**

| 열리는 것 | 어떻게 |
|---|---|
| **도감** | 튜토에서 본 3칸이 **회색으로 채워져 있고 빈칸이 수십 개** — *"저걸 채우고 싶다"* |

# 6. 결정 3개

## 6-1. 튜토에서 한 게 이어지나 → **"봤다"만 이어진다**

| | 이어짐 |
|---|---|
| **도감 — 회색 실루엣** | ○ 튜토에서 **본** 종·무늬가 *"본 적 있음"* 으로 등재 |
| 도감 — 컬러(완성) | ✕ 본편에서 **직접 키워야** 채워짐 |
| **"첫 걸음" 칭호 1칸** | ○ 튜토 완주 기록 |
| 개체 · 돈 · 설비 | ✕ |

**"봤다"와 "키웠다"를 나눈다.** 완전히 이어지면 본편이 헐거워지고, 아예 안 이어지면 허무하다.
회색 칸이 남아 있으면 *"내가 저걸 봤었지"* 가 되고 **채우는 게 목표**가 된다.

> 이건 §3의 **기록 vs 순간**과 같은 논리다. 새 규칙이 아니다.

## 6-2. 튜토에서 실패할 수 있나 → **죽는다. 단 되돌린다**

```
쇠약 3일차   ⚠ "잎이 처져요. 이대로면 위험해요"        ← 경고
고사         💀 "7일 전으로 되돌릴까요?"  [되돌리기]    ← 이벤트 정지 지점
엔딩 화면     "되돌림 3회"                             ← 기록만 남김
```

- **죽음을 봐야 배운다.** 안 죽으면 빛이 왜 중요한지 체감이 안 된다
- **되돌릴 수 있어야 안 짜증난다.** 튜토에서 진짜로 잃으면 그만둔다
- **횟수가 남으면 다음이 생긴다** — *"다음엔 안 죽여야지"*
- 되돌리기는 **무제한**. 튜토는 도전이 아니라 학습이다

## 6-3. 튜토 전용 완화 → ★ **이사 조건을 돈이 아니라 체크리스트로**

돈으로 잡으면 안 된다. **어떻게 완화해도 빠듯하다:**

```
자취생 순지출 16,125원/일 → 시작 100만이면 62일
포토스 첫 판매 day 40 · 슬롯 포화 day 80
→ 돈을 목표로 두면 튜토가 "파산 시계 보기"가 된다
```

**튜토가 가르치려는 4가지에 돈이 없다.** 돈 관리는 본편에서 배우면 된다.

| 항목 | **튜토** | 본편 |
|---|---|---|
| **이사 조건** | **체크리스트** | 이사비 150만 |
| 파산 | **없음** (월세 유예 — *"집주인이 봐줌"*) | 있음 |
| 시작 자산 | **50만원** | 100만원 |
| **식물등** | **없다** — 첫 플레이 통과 조건이 아니다 | 성장 가속·안정화 선택지 |
| **첫 보상** | **새순 전개 / 새잎** (확정) | 갈라짐 · 무늬 |

### ★ [정정 2026-08-01] 체크리스트가 바뀌었다 — 정본은 `first_play.md`

> **이전**: `☐ 등을 켜고 갈라진 잎 1장 → ★빛이 뒤집는다는 걸 안다`

"몇 시간"보다 짧지만 **튜토로는 그게 맞다** — 한 자리에서 끝나야 다음으로 넘어간다.

# 7. 단계별 재미 축

| 단계 | 시간 모드 | 재미 | 실시간 | **다음으로 끌고 가는 것** |
|---|---|---|---|---|
| **튜토** | 점핑 | **와다다** — 빠르게 한 바퀴 | **30~50분** | ★ 아래 |
| **초반** | 빠른배속 | 관리 — 내 손으로 다시 | 3~8시간 | *"무늬가 나왔다"* · 두 번째 캐릭터 |
| **중반** | 빠른~느린 | 관리 + **수집** | 20~50시간 | 도감 빈칸 · 재현·논문 |
| **후반** | 느린배속 · 1:1 | **디테일한 수집** | 무제한 | 순간 보상 · 전용 칸 · *"내가 키웠다"* |

> 초반 3~8시간 = 자취생 150일이 빠른배속으로 25분~1.3시간인데,
> **관리하느라 멈추는 시간이 그 몇 배**다. 진행보다 **결정에** 시간이 든다.

## ★ 본편으로 넘어가는 순간 — 제일 중요한 지점

튜토가 끝날 때 플레이어의 머릿속은 **"아 이런 게임이구나"** 다.
거기서 **"그래서 더 하고 싶다"** 로 넘어가야 한다. 필요한 건 셋이다.

1. **못 본 게 있다** — 도감 회색 3칸 vs 빈칸 수십 개.
   **무늬종을 한 컷만 보여준 것**이 여기서 듣는다
2. **다른 방식이 있다** — 캐릭터 3종. 자취생만 해봤는데 *"연구자는 뭐가 다르지"*
3. **더 잘할 수 있다** — 되돌림 3회 기록. *"이번엔 안 죽이고"*

**셋 다 "튜토에서 살짝 보여주고 안 준 것"** 이다.
맛보기에서 다 열어주면 안 되는 이유가 그것이다.

## 단계 전환의 공통 형태

```
튜토 → 초반   "봤는데 못 가진 것"        (도감 · 캐릭터 · 무늬)
초반 → 중반   "하나는 됐는데 둘은?"      (다른 캐릭터 · 다른 종)
중반 → 후반   "가졌는데 증명은 못 한 것"  (순간 · 1:1 전용 칸)
```

세 전환이 전부 **"보이는데 아직 아닌 것"** 으로 끌린다. **같은 장치를 세 번 쓴다.**

# 9. ⏸ [추가·보류] 스토리 모드의 계절 진행과 식물등 (2026-08-02)

> ## ⚠ **즉시 구현 지시가 아니다. 밸런스 확정도 아니다.**
> **첫 통합 시뮬레이션 이후 상세 검토할 항목**을 잊지 않으려고 기록한다.
> **core·house·growth에 작업으로 배포하지 않는다.** plan이 나중에 다시 요청한다.

## 확정된 방향 (숫자 없음)

```
첫 플레이   novice · 맑음 · 여름 고정
   ↓  콩나물 첫 수확 + 몬스테라 말린 새순 등장을 확인한 뒤
계절 진행   여름 → 가을. 자연광이 점차 줄어든다
   ↓  겨울 전
식물등      구매·설치할 수 있게 된다   ← ★필수 구매품이 아니다
   ↓
원룸 이사   반지하 튜토리얼 종료
```

**스토리 모드는 고정된 한 지역을 전제로 한다**(`plan-to-house.md`의 [잠재 설정] 참조).

## ★ 식물등의 잠재 역할 — "정답"이 아니라 "선택"

| 용도 | |
|---|---|
| 겨울까지 반지하에 남을 경우 | 몬스테라의 생장을 **유지** |
| 밤에도 광량 보충 | 성장 기간 **단축** |
| 자연광이 부족한 자리 | 추가 광원 |
| 이후 숙련 플레이 | 공간과 시간을 **돈으로 보완** |

**그래서 선택이 생긴다:**

> **식물등을 사서 지금 방을 보완할 것인가, 그 돈을 원룸 이사 자금으로 모을 것인가?**

```
빠르게 이사한 플레이어  →  반지하에서 식물등을 안 사도 된다
진행이 늦어 겨울을 맞는 플레이어  →  식물등이 안전장치가 된다
```

**둘 다 유효한 길이어야 한다.** 한쪽이 명백히 우월하면 선택이 아니다.

## [정정] §6-3의 튜토 체크리스트가 확장된다

> **이전**(2026-08-01): 체크리스트 **3개**, *"이사 조건은 돈이 아니라 체크리스트"*
> **정정**(2026-08-02): **경제 조건과 학습 체크리스트를 함께** 쓴다. 아래 §참조

**돈만 모으면 자동으로 끝나는 구조를 피하려던 의도는 그대로**다.
다만 **돈을 아예 빼는 것도 아니다** — 둘을 **함께** 쓴다.

| 축 | 내용 |
|---|---|
| **경제 조건** | 원룸 보증금 + 첫 달 월세 + 최소 이사비 |
| **학습 체크리스트** | ① 콩나물 첫 수확·식비 절감 확인 ② 콩나물을 어두운 자리에 ③ 몬스테라를 높은 창가에 ④ 몬스테라 말린 새순 등장 |

**[취소]** 이전 체크리스트의 *"☐ (본편) 삽수 1개 판매"* — **반지하 튜토리얼 조건에서 뺀다.**
번식은 원룸 이후로 미룬다.

**최종적으로 원룸에 실제로 이사하면 반지하 튜토리얼이 종료된다.**
