## 1. 창 향(方位) — 새로 들어감

이 모델의 천공은 **방향과 무관한 균일 휘도**다. 향을 안 넣으면
**북향창과 남향창이 똑같이 밝다.** 실제로는 수 배 차이가 난다.

창마다 `evScale`(남향 대비 비율)을 곱해 근사한다.

| 향 | k | | 향 | k |
|---|---|---|---|---|
| 남 | 1.00 | | 동·서 | 0.62 |
| 남동·남서 | 0.85 | | 북동·북서 | 0.45 |
| | | | **북** | **0.38** |

방 데이터에 `facing`(= `back` 벽 바깥이 향하는 방위)을 적으면
`back → facing`, `right → +90°`, `front → +180°`, `left → +270°`로 자동 계산된다.
창 스펙에 `orient`를 직접 쓰면 그게 우선한다.

```jsonc
"facing": "south"        // back=남, right=서, front=북, left=동
```

## 2. ★ 베란다 2겹 유리 — 한국 아파트 실제 구조

```
바깥 ─[베란다 새시 τ0.92]─ 베란다 ─[거실창 τ0.92]─ 거실
```

### ★ 정정 — 명당인 진짜 이유는 유리가 아니라 거리다

처음엔 "베란다 1겹 / 거실 2겹이라 베란다가 밝다"고 적었는데 **비중을 잘못 말한 것이다.**
유리는 한 겹당 τ0.92, 즉 **−8%뿐**이다. 투명한 유리를 하나 더 지난다고 어두워지지 않는다.

안쪽 유리를 아예 없앤 것으로 치고 다시 재봤다:

| 구역 | 2겹(τ0.92) | 유리 없다 치면 | 유리 몫 |
|---|---|---|---|
| 발코니 | 8.32 | 8.32 | 0% |
| 거실 | 0.31 | 0.34 | **−8%** |
| 안방 | 1.76 | 1.91 | −8% |

**발코니 ÷ 거실 = 26.8배. 유리를 없애도 24.7배다.**

차이는 거의 전부 **기하**에서 온다 — 거리와, 그 지점이 창을 보는 입체각.
같은 창·같은 유리로 거리만 바꿔 보면:

| 창에서 거리 | 조도 | 발코니 대비 |
|---|---|---|
| 0.28m (발코니 선반) | 9,057 | 100% |
| 1.2m | 4,210 | 46% |
| 2.0m | 2,153 | 24% |
| **3.7m (거실 좌탁)** | **660** | **7%** |

거실 화분이 어두운 건 유리를 두 번 지나서가 아니라
**창에서 3.7m 떨어져 있고, 거실창(2.8m 폭) 만큼만 하늘을 보기 때문**이다.
발코니 화분은 6.8m 통창을 코앞에서 본다.

그래도 2겹을 모델에 넣어둔 이유: **차광막을 어디에 거느냐**가 선택이 되려면
바깥 새시와 안쪽 창이 각각 독립된 감쇠 지점으로 존재해야 하기 때문이다(§ 차광).

> ⚠️ **모델 한계**: 이 엔진엔 **상호반사(벽·천장 반사광)가 없다.**
> 실제 거실은 흰 벽 반사로 여기 계산보다 밝다. 실내 깊은 곳 값은 **과소평가**다.
> 순위·배치 판단엔 쓸 수 있지만 절댓값은 보수적으로 봐야 한다.

### 구현 — 슬롯당이 아니라 **광선당**

처음엔 "유리 칸막이 안쪽 슬롯에 τ를 곱한다"로 짰는데 **틀렸다.**
감쇠는 슬롯의 속성이 아니라 **(창, 지점) 광선 쌍**의 속성이다 —
같은 거실 화분이라도 베란다 창에서 오는 빛은 2겹, 자기 방 창에서 오는 빛은 1겹이다.
슬롯당으로 하면 자기 창이 따로 있는 작은방까지 감쇠를 먹었다.

지금은 `opt.glazed`에 **반투과 유리판** 목록을 넘기고,
창 샘플 → 측정점 선분이 그 판을 가로지르면 **그 기여분에만** τ를 곱한다.

```jsonc
"partitions": [{
  "id": "balcony", "axis": "z", "at": -2.4, "from": -5, "to": 1.0,
  "glazing": { "tau": 0.92 },
  "openings": [{ "at": -2.0, "w": 3.4, "y0": 0.05, "y1": 2.30 }]
}]
```

개구부 **밖**(칸막이 솔리드 부분)은 이미 차폐체라 여기서 다루지 않는다.
차폐(100% 차단)와 감쇠(τ만큼 통과)가 깔끔히 분리된다.

> **확장형/비확장형**: 지금 아파트는 **비확장형**(베란다가 별도 공간 = 명당).
> 확장형은 `partitions`에서 balcony 항목을 빼고 창을 거실 벽으로 옮기면 된다.
> 데이터만 바꾸면 되므로 나중에 아파트 변형으로 넣을 수 있다.

## 3. 아파트 평면 (10×7m, 남향)

| 구역 | 위치 | 창 | 유리 | 밝기 |
|---|---|---|---|---|
| **베란다** | z < −2.4, x < 1.0 | 남향 전창 5.6×2.0 | **1겹** | ★ 최고 |
| 거실 | −2.4 < z < 1.2, x < 1.0 | (베란다 통해) | 2겹 | 중 |
| 안방 | x > 1.0, z < 1.2 | 남향 2.4×1.8 직접 | 1겹 | 상 |
| 작은방 | z > 1.2, x < 0.2 | **북**향 + **동**향 | 1겹 | ★ 최저 |
| 현관·복도 | x > 0.2, z > 1.2 | 없음 | — | 0 |

방마다 향이 달라 **"밝은 자리는 좁고 어두운 방은 넓다"**가 성립한다.
슬롯 70개 중 좋은 자리는 한쪽에 몰려 있다.

## 4. 실측표 (차광·천창 없음, 최고 슬롯 기준)

### 맑음 · 여름

| 방 | 한낮 lx | 최고 DLI | 최저 DLI | 격차 | DLI≥3 자리 | DLI≥6 자리 |
|---|---|---|---|---|---|---|
| 반지하 | 891 | **0.55** | 0.04 | 14배 | 0/13 | 0/13 |
| 원룸 | 8,019 | **4.93** | 0.00 | ∞ | 3/11 | 0/11 |
| 투룸 | 9,669 | **5.94** | 0.00 | ∞ | 3/20 | 0/20 |
| 학원교실 | 9,220 | **5.67** | 0.02 | 270배 | 10/32 | 0/32 |
| **아파트** | 13,084 | **8.04** | 0.04 | 201배 | **42/70** | **6/70** |
| 온실 | 15,843 | **9.74** | 3.25 | 3배 | **45/45** | **34/45** |

**목표 순서 달성**: 반지하 0.55 ≪ 원룸 4.93 < 투룸 5.94 < **아파트 8.04** < 온실 9.74

### 좋은 자리 개수로도 아파트가 위

최고값만이 아니라 **DLI≥3 자리 수**가 진짜 progression 지표다.

```
원룸 3 · 투룸 3 · 학원교실 10 · 아파트 42 · 온실 45
```

투룸(3자리)에서 아파트(42자리)로 가면 **"이제 여러 개를 키울 수 있다"**가 체감된다.
최고값 차이(5.94→8.04)보다 이쪽이 크다.

### 계절·날씨

| 방 | 맑음여름 | 흐림여름 | 맑음겨울 | 흐림겨울 |
|---|---|---|---|---|
| 반지하 | 0.55 | 0.14 | 0.20 | 0.05 |
| 원룸 | 4.93 | 1.23 | 1.83 | 0.46 |
| 투룸 | 5.94 | 1.49 | 2.21 | 0.56 |
| 아파트 | **8.04** | 2.01 | **2.99** | 0.75 |
| 온실 | **9.74** | 2.44 | **3.62** | 0.91 |

**맑은 겨울에도 아파트가 2.99** — 몬스테라 `min` 3.0 바로 아래다.
겨울엔 아무리 좋은 집이어도 식물등이 필요하다는 게 숫자로 성립한다.

## 5. 캘리브레이션 감도 — 주의

베란다 선반 위치를 0.2m 옮기는 것만으로 DLI가 **2배 이상** 변한다.

| 베란다 선반 z | 최고 DLI |
|---|---|
| −3.31 (창에서 0.33m) | 12.25 |
| **−3.24 (0.4m)** | **8.04** ← 채택 |
| −3.10 (0.54m) | 5.35 |

큰 광원을 가까이서 볼 때의 `1/d²`라 물리적으로는 맞지만,
**밸런싱이 배치에 매우 민감하다**는 뜻이다.
가구를 옮기면 반드시 `_dli_probe.html`로 다시 재야 한다.
