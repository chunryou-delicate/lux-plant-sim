# 1. ⚠ **먼저 정할 것 — 「가이드」가 «누구»인가**

박사님은 *"가이드 설명만 해서"* 라고만 하셨다. **내 층 표에 이 자리가 «없다»:**
```
퀘스트   「무엇을·어디」  ⇒ ⛔ 아니다. 퀘스트는 «하나를 시킨다». 셋을 보여 주는 자리가 아니다
손짓     「첫 걸음」      ⇒ ⛔ 아니다. 가리킬 «한 곳»이 없다
몬이     「언제」         ⇒ ★ 가깝다. 다만 이건 「언제」가 아니라 «무엇을 고를 수 있나»다
```
> ## ⇒ ★★ **「고를 것이 셋이다」를 말하는 자리는 «새 자리»다.**
⇒ ★ **다만 «몬이»가 맞아 보인다. 까닭 둘:**
```
① 파는 것이 «몬이 자신»이다 — 남이 대신 말할 수 없다
② 셋 중 «권하면 안 된다». 지시하는 자리(퀘스트·손짓)는 «권하는 꼴»이 된다
   ⇒ ★ 몬이는 어제 「사도 되고 안 사도 돼」로 «권하지 않는 말버릇»이 이미 있다
```
⇒ ⛔ **단정 안 한다. 총괄이 박사님께 확인할 것.**

# 2. ★★★ **문안** (뜨는 때 — 3번째 하프문 무늬잎이 «성숙»한 날)

```
  몬이: "이제 나갈 수 있어."
  나  : "그 돈이 어디서 나."
  몬이: "★ …나한테서."
  나  : "…"
  몬이: "어떻게 할지는 «네가 정해». 세 가지야."

  [세 갈래를 «보여 준다» — ⛔ 권하지 않는다]
  ⓐ "★ 나를 통째로 팔면 «제일 빨라». 대신 저 방에선 «씨앗부터»야."
  ⓑ "잘라 둔 걸 팔면 «조금 늦어». 대신 «잘라 둔 건 데려가»."
  ⓒ "★ 안 팔아도 돼. 그럼 «나는 통째로 따라가»."          ⏸ 뒷말 보류 — §4
```

## ⓐ ⛔ **숫자를 «안» 말한다** — 규율 ㉰
```
「이백만 원」은 ★ 이미 대사에 있다 — dialogue.js:905 "이백만 원. 보증금이랑 첫 달 월세랑 이삿짐값."
⇒ ★★ 여기서 또 말하면 «두 벌»이 되고, 오늘 「이만오천 원」에서 본 그 병이 난다
⇒ ⇒ ★ "이제 나갈 수 있어"로 족하다. 금액은 «화면»과 «그 대사»가 말한다
```

## ⓑ ★★★ **「…나한테서.」가 이 문안의 심장이다**
```
몬이가 «자기 값»을 말한다
⇒ ⚠ 그런데 «벌이 아니다» — 박사님이 「몬이는 계속 따라다녀」로 «두려움을 없애 주셨다»
⇒ ⇒ ★★ 그러니 이 줄이 «무겁되 슬프지 않다». 그 균형이 이 장면의 전부다
```
⇒ ★ 그리고 **나(자취)가 «말을 못 하는 한 박자»**를 둔다 — *"…"*.
  **그 침묵이 「이건 큰 결정이다」를 말한다. 몬이가 대신 말해 주지 않는다.**
