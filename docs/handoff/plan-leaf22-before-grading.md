## ⓑ ⇒ ★★★★★★ **그리고 [leaf] 실측이 «품종» 쪽에 «더 좋은 까닭»을 준다**
```

```
> ## ★★★ **그러면 둘이 «다른 일»을 한다:**
```

상점·카드에서 «가까이» 볼 때  ⇒ ★★ «무늬»가 말한다 — 「이건 «하프문»이다」
```
> # ★★★★ **무늬는 «등급»(값)이고, 색은 «품종»(정체)이다.**
> # ⇒ ★ **그리고 그것이 「몬이는 «뜻», 화면은 «수»」와 «같은 꼴»이다.**
> # ⇒ ⇒ **값은 «화면이 숫자로» 말하고, 정체는 «눈이» 안다.**
⇒ ★★ **그러니 색 7 은 «버리는» 것이 아니라 ★ «제일 먼저 쓰는» 것이다 —
  방에 놓였을 때 «한눈에» 다른 애인 줄 아는 것이 그 일곱뿐이다.**
⇒ ⛔ **다만 「품종을 어떻게 얻나」는 «새 계통»이라 ★ 박사님 몫이다. 나는 «갈래»만 낸다.**
