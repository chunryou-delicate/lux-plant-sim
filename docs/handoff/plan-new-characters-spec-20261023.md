## 1. 공통 — 새 판이 서는 꼴

### 1-1. 문 — «집 엔딩 본 적» 열쇠
- 세이브 밖 열쇠 `byeot/meta/1 = { homeEndingSeen: true, firstOn }` — 집 엔딩 [계약한다] 때 적는다(어느 판이든 한 번).
- **다시 시작이 이 열쇠를 안 지우게** — `localStorage.clear()` 를 «세이브 열쇠들 + 판 화면 기억»만 지우는 것으로 좁힌다(core · 08-xx «초기화를 눌러도 Day 44 그대로» 까닭은 세이브 열쇠를 지우면 그대로 풀린다).
- 새 화면을 안 만든다: [처음부터 다시](게임오버 · 덮개 · 초기화)의 확인이 열쇠가 있으면 **«누구로 시작할까»** 카드 넷(진로 카드 화면 결 재사용)이 된다. 열쇠가 없으면 지금처럼 자취생으로 바로.

### 1-2. 세이브 — 캐릭터마다 한 칸 (⚖ §9 ②)
- 새 판이 자취생 판을 지우면 13달 키운 집이 사라진다 → **세이브 칸을 캐릭터마다 하나**(`byeot/save/1/{character}` · 자취생은 옛 열쇠 그대로 읽음).
- «누구로 시작할까» 카드마다 «이어하기 · 처음부터» — 이어할 판이 있으면 둘, 없으면 «처음부터» 하나.

### 1-3. 시작 — 튜토 없이 자기 집에서
- 튜토(반지하 → 원룸 → 내 집)는 **자취생 고정**(story_arc §0). 새 캐릭터는 **자기 집 첫날**에서 시작한다 — 문이 «집 엔딩 본 적»이라 빛·자리·등·가위는 이미 안다.
- 모드 `real`(날씨·철 굴림 켬) · 초보 유예 없음(삽수 8일) · 몬스테라 낙엽 켬(진로와 같은 «보호 끝»).
- 시간은 [다음 날] 하나(박사님 결정 그대로). 점핑 없음(튜토 전용).
- 첫날 철: ⚖ 봄 첫날 — ⚠ 화면 달력(튜토 «여름 45일차» 오프셋)과 빛 달력(`weather.seasonOf(S.day)` · 0 = 봄)이 어긋나지 않게 core 가 새 판은 둘을 같게 맞춘다(story_arc §5 «달력이 둘»).
- 하루 지출 = 월세/30 + 공과/30 + 식비 × **식구** + 등 전기(characters.json `economy_rule` 그대로) · 월 수입은 **월급날 한 번**(⚖ 매달 1일).
- 퀘스트: 캐릭터마다 짧은 사슬(셋~넷) + 목표 줄(§2). 몬이는 그대로 곁에 있다(§9 ④).

## 2. 캐릭터 셋 — «게임의 종류»가 다르다

| | **연구자** | **가장** | **주부** |
|---|---|---|---|

| 집 | 온실(제공 · 월세 0) · 자리 64 · 가장 밝음 | 학원 교실(제공 · 월세 0) · 자리 128 · 중간 밝기 · 식물등 가구 없음 | 아파트(월세 90만 · 공과 14만) · 자리 83 |

| 시작 그루 | 연구실이 준 것: 무늬 마디가 있는 몬스테라 모주 1 · 상점 구근 ⚖2 · PP 어린 그루 1 | 삽수 ⚖6(몬스테라 · 뿌리 낸 것) | **알보 개체** 1(무늬 몬스테라 그루 · 하프문 잎) |

| 목표 | **논문 3편** = C 기록장의 «품종 등록»이 연구자 판에선 «논문»(같은 칸 다섯 · 같은 재현 셋) | **목표 금액** ⚖(1억은 임시 · 하네스로 고름) | **드림가든** ⚖(§9 ⑤ — plan 추천: «정원 도감» — 종·등급 열 칸을 한꺼번에 방에 놓기) |
| 엔딩 | «졸업» — 논문 3편 · 온실을 떠난다(기록은 남는다 · researcher_track U자) | «온실» — 목표 금액으로 온실을 산다 | «드림가든» — 열 칸이 다 놓인 날 아파트 카메라 |
| 파산 | 없음(월급이 식비를 넘음) | **있음** — 굶음 · 게임오버 길 그대로 | 없음 |
| 이미 있는 것으로 서나 | ○ C 기록장 · 온실 방 | △ 곳간·작물 끼니·식비 있음 · 식구 배수·월급은 새 칸 | △ 무늬 그루를 «사는» 상점 줄이 있는지 core 확인 · 드림가든 판정 새로 |

- **연구자 ≠ 육종 진로**: 같은 기록장을 쓰지만 판이 다르다 — 연구자는 온실(밝은 자리 많음 · 전기 면제 · 64 자리)에서 **처음부터** 확률을 모으고, 돈은 조교 월급뿐이라 «팔아서 버티기»가 아니라 «기록으로 다음 단계». 육종 진로는 자취생이 13달 키운 투룸에서 판매가 받친다.
- **전기 면제**는 지금 전기 요금이 «표시만»이라 차이를 안 낸다 — 연구자 판을 지을 때 core 가 전기 차감이 실제로 도는지부터 가른다(§10).

## 5. 하네스 (core 판 · 총괄이 값을 박음)
캐릭터마다 한 사람 · 같은 판 씨앗 여럿:
- **연구자 사람**: 논문 1 · 3 까지 날 수 · 월급만으로 굶지 않나 · 온실 밝은 자리 몫.
- **가장 사람**: 굶음·파산 몫(⚖ «처음 90일 안에 굶는 판 ≤ 1할» · 작물을 안 키우면 굶는 것이 «부양 압박») · 목표 금액까지 날 수 → 1억을 이 판으로 고름.
- **주부 사람**: 드림가든까지 날 수 · 자취생보다 **빠르게 꾸미나**(«돈으로 시간을 산다»가 숫자로 서나) · 돈이 남아돌아 할 일이 없는 판이 아닌지.
- 공통: 엔딩까지 날 수가 서로 크게 안 벌어지게(⚖ 자취생 집 엔딩 중앙 ≈ 565일과 견줌).

- 새 그림 · 새 3D — 크레딧 표만.

## 8. plan 이 고른 것 (후보 · 고른 것 · 까닭)
1. 문 — 후보: 처음 화면 새로 / 다시 시작 확인을 카드로 · **고른 것: 다시 시작 확인을 카드로** · 까닭: 새 화면 0 · 진로 카드 화면 결 재사용.
2. 시작 — 후보: 튜토부터 / 자기 집 첫날 · **고른 것: 자기 집 첫날 · real 모드** · 까닭: 문이 «엔딩 본 적»이라 배움은 이미 끝났다.
3. 연구자 목표 — **C 기록장의 등록 = 논문**(같은 칸·같은 재현) · 까닭: 두 벌 안 지음(총괄 청).
4. 몸 — **옛 3D 를 잇되 안 맞으면 몸을 안 띄움**(자취생 몸으로 안 대신함) · 까닭: 정체가 섞이면 «다른 사람의 이야기»가 안 선다.
5. 초상 — **3D 얼굴 한 장**(크레딧 0) · 까닭: 이름표만보다 낫고 새 그림은 크레딧.

## 9. 판단필요 (총괄 · 정체·재미는 박사님께 여쭐 것 표시)
1. **짓는 차례** — plan 추천: **연구자 → 가장 → 주부**(한 번에 하나 · 재미 확인 후 다음). 까닭: 연구자는 C 기록장·온실이 다 있다 · 가장은 곳간·식비가 있고 식구·월급 칸만 더함 · 주부는 목표(드림가든)부터 정해야 함.
2. **세이브 칸** — ① 캐릭터마다 한 칸(plan 추천 · 자취생 집이 안 사라짐) / ② 한 칸(새 판이 자취생 판을 지움 · 경고 한 줄).
3. **초상** — ① 3D 얼굴 한 장(크레딧 0 · plan 추천) / ② 크레딧 열어 낯 여섯 × 성별(§4 — 박사님께 여쭐 것).
4. **몬이가 새 판에도 있나** — ① 있다(plan 추천 · 같은 동반자 · 새 그림 0) / ② 캐릭터마다 다른 동반자(크레딧) — **캐릭터 정체 → 박사님께 여쭐 것**.
5. **주부 «드림가든»이 무엇인가** — ① 정원 도감(종·등급 열 칸 — 몬스테라 산반·하프문·풀문 · PP 마블·분홍 많음 · AL 마블·반달 · 스킨답서스 · 칼라테아 · 무늬 없는 몬스테라 큰 그루 — 를 한꺼번에 방에 놓기 · plan 추천 · 있는 그루로 섬) / ② 방 꾸미기 점수(새 계통 · 예약된 «꾸미기» 진로와 겹침) — **재미·방향 → 박사님께 여쭐 것**.
6. **가장 목표 금액** — 1억(임시)을 하네스로 고름 · 엔딩 «온실을 산다» 그대로인가.

### ✔ 총괄 결정(10-23 · 캠페인 §3 D77)
- ① 연구자 → 가장 → 주부 · 한 번에 하나 · ② 세이브는 캐릭터마다 한 칸 · ③ 초상 = 3D 얼굴 한 장 · ⑥ 가장 목표 금액은 하네스로 — plan 추천대로.
- ④ 몬이가 새 판에도 있나 · ⑤ 드림가든이 무엇인가 — 캐릭터 정체·재미라 **총괄이 박사님께 여쭌다.** E 를 짓기 전까지 답이 없으면 추천대로(④ 있다 · ⑤ 정원 도감 열 칸).

## 10. 교차검사 메모 (명세를 쓰며 본 것 · 고치지 않음)
- id 가 둘이다: 코드·JSON `breadwinner` · `housewife` ↔ 3D 파일·plan-branch-job-gender `gajang` · `jubu` — 짝 표가 없다(char · core).
- characters.json 자취생 줄(시작 100만 · 목표 150만 · `balance_provisional false`) ↔ 코드(시작 150만 · 이사 200만 · 엔딩 500만) — 줄이 낡음. homes.json «moveCost = 100만+50만» ↔ 값 200만.
- 자리 수 글이 낡음: 교실 «32슬롯» ↔ 128 · 아파트 «82» ↔ 83 · 반지하 «13» ↔ 15.
- 측정판 셋(교실·아파트·온실)이 등 0 판만 · roomRev 없음 · 온실 «10.49 vs 14.55» 낡음.
- 캐릭터 칸 다섯(식구·월급·전기 면제·목표·systems)을 읽는 코드 0 · 전기 요금은 «표시만 · 차감 없음»이라 전기 면제가 차이를 안 냄.
- GAME_PLAN §5 프리셋(빠른배속 등) ↔ 박사님 «빨리감기는 없애»(loop.js) — GAME_PLAN 은 plan 이 안 고침(AGENTS.md).
- GAME_PLAN «아파트 3.87 < 무늬종 4.2» ↔ house_rooms «꼭대기 9.75» — 하나는 평균·하나는 peak 로 보인다(같은 자 아님 · 결론 내지 않음 — growth 가 avg 로 다시 잴 때 가림).
