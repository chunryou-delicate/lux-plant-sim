# ★★★★ 「언제 파는가」 — ⛔ 그 앞에 **「무엇을 파는가」**가 안 정해져 있다

# 1. ⛔ **먼저 — 「무엇을 파는가」가 «둘로» 갈려 있다**

```
설계 (dialogue.js:476 · 주석)
  "③ 그 자리에서 돈이 되지 않는다. 잘라 뿌리내려야(12일) 판다 —
   ★ 튜토의 끝이 «삽수 판매»가 되는 것이 «설계»다"
  몬이: "잘라서 물에 꽂아. 뿌리가 나오면 그때 팔 수 있어."

오늘 셈 (총괄)
  ★ «그루»를 판다 — 잎 셋 + 무늬 둘 = 1,960,000원
```
> ## ★★★★★★ **삽수를 파느냐 «그루»를 파느냐는 «값의 차이»가 아니라 «이야기의 차이»다.**
```
삽수를 판다   ⇒ 몬스테라가 «남는다». 잘라 낸 조각을 판다.  ★ 몬이가 «따라온다»
★ 그루를 판다  ⇒ 몬스테라가 «없어진다».                    ★★ 몬이를 «두고 간다»
```
⇒ ⚠⚠ **그리고 «몬이가 곧 몬스테라»다**(`chatMoniName` — *"몬스테라니까"*).
⇒ ⇒ ★★★ **그러면 「그루를 판다」는 «몬이를 파는 것»이다.**

## ⇒ ⛔ **박사님 말씀에 「무엇을」이 «없다»**
> 박사님: *"일반잎 하나 무늬 2개(하나는 하프문) 자라는 순간 «팔고» 튜토 엔딩일 텐데"*
⇒ ★ **「팔고」의 목적어가 «안 적혀» 있다.** 그리고 **기존 설계는 «삽수»**다.
⇒ ⇒ ⛔ **내가 정할 것이 아니다. 박사님께 여쭐 것이다.**

# 2. ★★★ ⇒ **그리고 「언제」의 답이 «거기에 달려 있다»**
```
삽수라면   몬스테라가 «남는다» ⇒ 되돌릴 수 있다 ⇒ ★ 「언제」는 «값»의 물음
그루라면   ★ 되돌릴 수 없다   ⇒ ★★ 「언제」는 «이야기»의 물음 — «언제 이 방을 떠날까»
```
> ## ★★★★ **「무엇을」을 정하기 «전»에는 「언제」를 못 정한다.**
⇒ ★ 오늘 세운 갈래 그대로다 — **되돌릴 수 있으면 «배움»이고, 못 되돌리면 «벌»**이다.
  ⇒ ⇒ **그루라면 «벌이 아니라 «끝»»이다.** ⚠ 후회할 «뒤»가 없으므로 «벌도 아니다».
    ★ **그건 셋째 갈래다** — 오늘 세운 둘(배움/벌)에 «끝»이 하나 더 붙는다.

# 3. ★★ **②(수를 보여 줄까) — 이미 «규칙이 있고 지켜지고» 있다**
```js
dialogue.js:475
  "② ★ «몬이가 값을 안 읊는다». 얼마짜리인지는 «상점 화면»이 숫자로 말한다.
   여기서 금액을 말하면 튜토의 마지막 장면이 «정산표»가 된다."
```
> ## ★★★ **내 층 표와 «똑같다». 그리고 «이미» 그렇게 되어 있다.**
⇒ ★ **그러니 답은 「보여 준다 — 다만 «화면»이」다:**
```
화면(파는 창)   지금 팔면 얼마 · 잎 한 장 더면 얼마 · 이사비까지 얼마 모자란가
```

⇒ ⇒ ★★ **그리고 오늘 찾은 병이 그 규칙의 «까닭»이다** —
  **몬이가 숫자를 읊으면(「이만오천 원」) 값이 바뀌는 날 «거짓말»이 된다.**
  ⇒ ★ **`varieGranted` 는 그 함정을 «피해 두었다». `lampUnlocked` 는 «안 피했다».**

# 4. ⇒ ★★★ **③ 「튜토 엔딩」의 자리 — 이미 «있다». 다만 «무엇을 파느냐»로 갈린다**
```
varieGranted (확정 무늬가 난 날)   ★ "반지하 튜토의 «마지막 장면»"이라 주석이 적어 뒀다
                                    끝 줄이 «다음 동작»을 가리킨다 — "잘라서 물에 꽂아"
```
⇒ ★ **삽수라면 그 장면이 «그대로 맞다».** 끝이 「삽수 판매」다.
⇒ ⚠ **그루라면 «한 장면이 더» 필요하다** — **몬이와 헤어지는 자리**가 없다.
  ⇒ ⇒ ★★★ **그리고 그 장면은 «몬이가 자기를 팔라고 말하는» 장면이다.**
    **오늘 내가 세운 규율(「언제」는 몬이가 짚는다)이 «여기서 극한»에 간다.**
```
곳간 팔기   몬이가 «남의 일»을 짚는다
시루 심기   〃
★ 그루 팔기  ★★ 몬이가 «자기 일»을 짚는다
```
⇒ ⛔ **그 장면을 «지금 쓰지 않는다».** 「무엇을 파는가」가 정해진 뒤다.

# 5. ⇒ **박사님께 여쭐 것 — «하나»**
> ## **튜토 끝에 파는 것이 «삽수»입니까, «그루(몬스테라 자체)»입니까?**
```
삽수     기존 설계(dialogue.js:476)이고 ★ 몬이가 «따라온다». 장면이 «이미» 있다
그루     오늘 셈이 그쪽이고 ★★ 몬이를 «두고 간다». ⇒ 헤어지는 장면이 «필요하다»
```
⇒ ⚠ **묶어서 여쭈면 안 된다** — 「언제 팔까」를 같이 물으면 **「무엇을」이 «자동으로 그루»가 된다.**
  ★ **오늘 두 번 겪은 그것이다.** ⇒ **「무엇을」만 먼저.**

## ⚠ 그리고 **셈에 붙일 단서 하나**
```
그루를 팔면 1,960,000 ⇒ 이사비에 «40,000원» 모자라 지갑에서 메운다
⇒ ★ 그러면 「콩나물이 그 사만 원을 만든다」가 된다 — 35% 갈래에서 «열쇠»다
⇒ ⚠ 그런데 «삽수»를 판다면 그 셈이 «통째로» 다르다 (삽수 한 장 값은 그루값과 다르다)
```
⇒ ⛔ **그러니 「콩나물이 열쇠다」도 «무엇을 파느냐»가 정해진 뒤에 선다.**
