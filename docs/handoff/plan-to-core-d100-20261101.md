### §1-1 내놓으면 원천이 0 이 되는 때 (won ≥ shortH ∧ `sellingLastVarieSource()`)

지금 «지금 내놓으면 이사 자금이 찹니다 — 연락이 온 뒤 거래해야 돈이 들어옵니다» 한 줄만 섰다(비판 Day 88 · 이 말을 따라 팔았다). 원천 0 이 되는 판은 자르기 문으로 갈린다.

| 때 | 글 |
|---|---|
| 자르기 문 열림 (`varieCutOpenNow() > 0`) | `지금 내놓으면 이사 자금이 찹니다 — 다만 통째로 팔면 무늬 원천 0, 원룸에서 늘릴 게 없습니다. 무늬 마디를 잘라 삽수로 팔면 그루가 남습니다` |
| 자르기 문 닫힘 | `지금 내놓으면 이사 자금이 찹니다 — 다만 통째로 팔면 무늬 원천 0, 원룸에서 늘릴 게 없습니다. 다 자란 무늬 잎이 둘이 되면 마디를 잘라 삽수로 팔 수 있습니다 (지금 {m}/2)` |

- `{m}` = motherVarieMatured(할 일 wait_varie «다 자란 무늬 잎 {m}/2»와 같은 수).
- 참: «찹니다» = won ≥ short(지금 그대로) · «무늬 원천 0» = 이사 창 `MOVE_ASK_KO.source` 와 같은 낱말 · «원룸에서 늘릴 게 없습니다» = `MOVE_ASK_KO.none` 과 같은 말 · «그루가 남습니다» = 자르기 문이 다 자란 무늬 잎 하나를 그루에 남긴다(wait_varie why) · «둘이 되면» = CUT_DOOR_VARIE_MATURED 2(무늬 잎이 하나뿐인 그루에도 참인 꼴로 «둘이 다 자라면»을 안 씀).
- «연락이 온 뒤 거래해야 돈이 들어옵니다»는 이 갈래에선 §2 확인 창으로 옮긴다(한 줄이 너무 길어짐).
- 원천이 남는 판(무늬 삽수가 있음)은 지금 그대로.
- 후보 ㉠ 원천 0 이면 «찹니다»를 빼고 경고만 · ㉡ 사실(찹니다)과 대가를 한 줄에(택함) · ㉢ 단추를 잠금 ⇒ 까닭: 총괄 «막지 않고 미리 알린다». 찬다는 사실을 숨기면 사람은 다른 데서 그 값을 보고 다시 판다.

### §1-2 «{n}장이 무늬면» (QUESTION #20)

지금 셈(`varieLeavesNeededFor(short, { leaves })`)은 잎 수를 그대로 두고 «그중 n장이 무늬면»을 묻는다. 잎 3장 · n = 3 이면 첫 잎(무늬가 안 남)까지 무늬여야 하는 못 될 일이다 — 이미 난 민무늬 잎은 무늬가 안 된다.

- 글: `{무늬 잎 a/b장} — 무늬 잎이 {k}장 더 나서 다 자라면 모자란 이사 자금 {short}원이 찹니다`
- 셈: k = 가장 작은 k ≥ 1 로 `priceOf({ leaves: b + k, leafGrades: 지금 잎 등급 + 새 잎 k장 sanban(legacyGradeId), form })` ≥ short. k 가 없거나 3 을 넘으면 지금 줄 «… 모자랍니다. 더 키우거나 무늬 삽수가 둘이면 하나를 내놓으세요».
- 참: 새 잎은 가장 싼 등급(산반)으로 셈 — 더 좋은 등급이 나면 더 일찍 찬다(«찹니다»가 거짓이 안 됨) · «다 자라면» = 잎값은 자람(leafM)만큼(priceOf) · 새 잎이 무늬일지는 조건문(«나서»)이 말한다.
- ⚠ 단추 값 ≠ 올린 값(#2 · 891,250 ↔ 1,960,000)은 core 몫이다. 이 줄의 «지금 잎 등급»도 단추와 같은 함수(quotePot · potLeafArgs)에서 읽어야 같은 판에서 안 갈린다.

## §2 확인 창 글 — [내놓기] · [거래하기] (#1 · #3)

이사 창(`MOVE_ASK_KO`)과 같은 낱말을 쓴다. 원천 줄은 «판 뒤» 값이다.

```js
const SELL_ASK_KO = Object.freeze({
  list:     '중고 거래에 내놓습니다 — {ko} · {won}원',
  listHow:  '연락이 온 뒤 [상점]에서 [거래하기]를 눌러야 팔립니다. 그 전엔 [내리기]로 거둘 수 있습니다.',
  deal:     '{ko} — {won}원에 팝니다. 되돌릴 수 없습니다.',
  source:   '팔고 나면 무늬 원천 {n} — 무늬 그루 {a} · 무늬 삽수 {b}',
  none:     '무늬 삽수나 무늬 그루 없이 이사하면, 원룸에서 늘릴 게 없습니다.',   // 반지하(이사 전)
  noneHere: '무늬 삽수나 무늬 그루가 없으면, 이 방에서 늘릴 게 없습니다.',     // 원룸(이사 뒤)
  cutOpen:  '무늬 마디를 잘라 삽수로 팔면 그루가 남습니다.',
  cutWait:  '다 자란 무늬 잎이 둘이 되면 마디를 잘라 삽수로 팔 수 있습니다 (지금 {m}/2).',
  goList: '내놓는다', goListAnyway: '그래도 내놓는다',
  goDeal: '판다',     goDealAnyway: '그래도 판다',
  cancel: '아직'
});
```

- [내놓기]: `list` + `listHow` 늘. 판 뒤 원천 0 이면 `source` + `none`(원룸은 `noneHere`) + 자르기 문에 따라 `cutOpen` / `cutWait` · 단추 [그래도 내놓는다]. 몬이 sell_last_varie(§0 갈래)는 이 창을 열 때 «창 안»에서.
- [거래하기]: `deal` 늘(되돌릴 수 없는 일 · 지금은 확인 없이 바로 팔림). 판 뒤 원천 0 이면 위 세 줄 + [그래도 판다]. 팔고 나면 sold_last_varie(§0).
- 참: «연락이 온 뒤 … [거래하기]» = 지금 흐름(listPot → 연락 → doDeal) · «[내리기]로 거둘 수 있습니다» = 상점 «아래에서 내릴 수 있습니다»와 같은 손 · 원천 셈은 `varieSourcesNow` 를 판 뒤 상태로(첫 화분을 판다면 a 에서 뺀다).
- 팔고 나서 할 일 칩이 «무늬 잎이 다 자라기를 · 0/2»(없는 그루를 기다림 · #3)로 남는 것은 core 몫이다(첫 화분이 없으면 wait_varie · first_cut 칸이 null 이거나 닫힘).
