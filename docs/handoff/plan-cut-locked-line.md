# ① ★★ **수를 말해도 되나 — ✅ 됩니다. «화면»이니까**
```
오늘 세운 갈래   ★ 몬이는 «뜻» · 화면은 «수»와 «규칙»
```
⇒ ★ **회색 문장은 «화면»입니다. 수를 말해도 됩니다.**
⇒ ⚠ **다만 여기서 「몇 장」이 «맞는 말이 아닙니다»** —
  **조건이 「3번째 «하프문» 무늬잎이 «성숙»」이라 «장 수»가 아니라 «상태»입니다.**
⇒ ⇒ ★★ **그러니 수를 말할 게 아니라 «무엇을 기다리는지»를 말해야 합니다.**

# ② ★★★ **벌인가 기다림인가 — «말이 정합니다»**
```
⛔ "아직 «자를 수 없습니다»"   ← «막는» 말이다. ★ 벌처럼 읽힌다
★ "«아직 이릅니다»"            ← «기다리는» 말이다
```
⇒ ★★ **뜻은 같은데 «누가 주인인가»가 다릅니다.**
  **「할 수 없다」는 «게임이 막는» 것이고, 「이르다」는 «때가 안 된» 것입니다.**
⇒ ⇒ ★ 그리고 이건 «누르기 전»에 회색으로 «미리» 보이므로 **「가르침」 쪽 문장이라야 합니다.**
  **오늘 세운 것 그대로 — 막힌 «뒤»에 말하면 벌이고, «미리» 말하면 가르침입니다.**

# ④ ⇒ ★ **문장**
```
[core] 임시안   "아직 «자를 수 없습니다» — 무늬 잎이 다 자라면 삽수를 낼 수 있습니다"

★ 고침         "★ «아직 이릅니다» — «세 번째 무늬 잎»이 다 자라면 자를 수 있습니다"
```
```
바꾼 것 셋
① "자를 수 없습니다" → ★ "아직 이릅니다"        ⇒ «막음»에서 «때»로
② "무늬 잎이 다"     → ★ "«세 번째» 무늬 잎이"   ⇒ 무엇을 기다리는지 «또렷»해진다
③ "삽수를 낼 수"     → "자를 수"                ⇒ 회색인 것이 «자르기 단추»이므로 말이 맞는다
```

## ⚠ **[core] 에 물을 것 하나 — 등급이 조건에 «드나»**
```
박사님 지시   「3번째 «하프문» 무늬잎이 성숙잎 됐을 때」
⇒ ⓐ 조건이 「무늬 잎 «세 번째»」면        ⇒ ★ 위 문장 그대로
⇒ ⓑ 조건이 「«하프문»인 것이 세 번째」면   ⇒ ⚠ 문장이 «달라야» 한다
```
⇒ ⛔ **ⓑ 라면 등급을 문장에 «넣지 않습니다»** —
  **어느 등급이 날지는 «빛이 정하는데», 미리 말하면 «답을 주는 것»입니다.**
  ★ **그때는 "아직 이릅니다 — 무늬가 «더 짙어져야» 자를 수 있습니다" 쪽입니다.**
⇒ ★ **[core] 가 조건을 확정하면 그 갈래로 고르면 됩니다.**
