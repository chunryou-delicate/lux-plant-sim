## 왜 이 문서가 있나
```
「몬이는 «무엇이다»」는 여기저기 있는데 ⇒ ⛔ 「«못» 한다」가 «어디에도» 없다
⇒ ★ 그래서 창마다 몬이를 «짐작»한다 — [char] 는 낯을 만들 때 · [core] 는 대사를 넣을 때 · [plan] 은 문안을 낼 때

```
> # ★ **금은 「할 수 있는 것」보다 「«못» 하는 것」이 긋는다.**

## ⛔ 이 문서를 쓰는 법 — ★ 「찾은 것」과 「지은 것」을 섞지 않는다
```
★ 줄마다 «어디서 왔는지»를 단다. 「겪어서 나온 것」만 «위»에 적는다
⇒ ⛔ 빈자리를 «찾은» 사람이 그 빈자리를 «채우면» ⇒ 찾은 것과 지어낸 것이 «한 문서»에 섞인다
⇒ ⇒ 그러면 나중에 아무도 어느 줄이 «잰 것»이고 어느 줄이 «지은 것»인지 «못 가린다»(총괄)
```
