# ⛔⛔ **정정 — 「목록에 자리 이름이 없다」는 «틀렸다». 두 겹 틀렸다** ([core] 실측)

```
① grep 을 «자리|label|slotLabel» 로 걸었다      ⇒ 실제 변수명은 «where» 였다
② sed 를 9386–9412 로 «내가» 끊었다             ⇒ pick 은 9414 에 있었다. 두 줄 아래다
```
> ## ★★★ **「없다」가 아니라 «내가 자른 범위 안에 없다»였다.**
> ## **그리고 grep 은 «내가 고른 낱말»만 찾는다.**

⇒ ★★★★ **찾으려면 「그것을 뭐라 부르는지」를 알아야 한다.**
  **모르는 것은 «이름도» 모른다. ⇒ 그래서 「없다」로 결론난다.**
⇒ ⇒ ★ **그러니 처방은 「더 열심히 찾아라」가 아니다** — 그건 안 통한다.
  **「없다」고 말할 때 «어떻게 찾았는지»를 같이 적는 것**이다.
  ⇒ 그러면 아는 사람이 **"그건 `where` 로 부릅니다"** 하고 한 줄에 끝낸다.
  ⇒ ★★ **[core] 가 실제로 그렇게 했다.** 내가 찾는 법을 안 적었어도 잡혔지만, **적었으면 더 빨랐다.**

## ⇒ ★★ 그래서 **㊲ 에 셋째 얼굴을 붙인다**
```

★ 셋째        ③ «있는데 못 찾은» 것
```
> ## ★★★ **「없다」고 말하기 전에 «어떻게 찾았나»를 적어라.**
⇒ ⚠ **새 계율로 안 세운다.** ㊲ 의 셋째 얼굴이다 — **뿌리가 같다**(안 보고 단정하는 것).
  ⇒ 총괄이 *"오늘 셋을 박아 더 박기 조심스럽다"* 하셨는데 **그 조심이 맞다.**
  ★ **계율은 늘리는 것이 아니라 «얼굴을 늘리는» 것이 낫다.**

## ⇒ ⚠ **그러면 「다섯 번 만에 찾았다」의 처방이 바뀐다**
```
㉠ 자유 좌표면 이름 대신 "방 안"만 뜬다   ← ★ 진짜 구멍. 여기가 남는다
㉡ 이름을 읽고도 방에서 «못 짚는다»        ← 그러면 「📍 자리」가 이미 답이다. ★ 안 눌러 본 것

```
⇒ ★★★ **㉢ 이면 고칠 것은 «목록»이 아니라 「목록이 있다」를 알게 하는 일이다.**
  ⇒ ⚠ 그리고 **㉡ 도 같은 결이다** — **단추가 있는데 «안 눌렀다».**
⇒ ⇒ ★★★★ **㉡·㉢ 이면 이 건은 「기능이 없다」가 아니라 «있는 것을 모른다»다.**
  **그건 «가이드» 몫이고, 내 규율 ㉱(답을 줄 것과 「선택이 있다」만 줄 것)에 걸린다.**
⇒ **[Asset] 답이 오면 그때 정한다. ⛔ 지금은 안 정한다.**

# 1. ★★★ 먼저 — 박사님 **"둘 다"**는 «그냥 둘»이 아니라 **«역할이 갈린 둘»**이다

[Asset] 이 본 것은 *"0일 · 3일 · 6일이 **다 같다**"* 다.
⇒ ★ **안 보이는 것은 「끝」이 아니라 「과정」이다.** 「다 자랐다」는 끝이고, 과정은 그 앞이다.
⇒ ⇒ ★★ **그리고 이 게임의 심장이 「과정」이다** — 빛을 재고 자리를 고르고 **기다리는** 게임이다.
  **기다리는 동안 아무 일도 안 보이면 기다림이 뜻을 잃는다.**

## ⇒ ★★★★ 그래서 둘의 몫이 깨끗하게 갈린다
```
과정 「자라는 중」   → ⓐ ★ 에셋이 말한다.  «조용히». 보고 싶을 때 본다
끝   「다 자랐다」   → ⓑ ★ 신호가 말한다.  «한 번». 놓치면 안 되니까
```
⇒ ⚠ **거꾸로 하면 둘 다 망한다** —
  과정을 «신호»로 알리면 매일 *"자라는 중입니다"* 가 뜬다. **그건 잔소리다.**
  끝을 «그림»으로만 알리면 **안 보고 있으면 모른다.** 시루는 방 구석에 있다.

# 2. ㉣ **먼저 — 열여섯이면?** ★ **표시는 «하나»다**

총괄이 *"하나일 때 예쁜 것이 열여섯이면 화면을 덮는다"* 하셨는데, ★ **덮을 일이 없다:**

```
글자(신호)   «몇 개»가 다 자랐나 · 거두라        ← ★ 하나. 늘 하나
그림(에셋)   «어느 것»이 다 자랐나                ← 시루마다. 글자가 아니라 «모양»
```
> ## ★★★ **글자는 «세고», 그림은 «가리킨다».**

⇒ ★ **열여섯이 다 자라도 글자는 한 줄이다** — *"세 시루가 다 자랐습니다 — 거두세요"*.
⇒ ⇒ **어느 것인지는 방을 보면 안다.** 그것이 ⓐ 가 하는 일이다.
⇒ ⚠ **시루마다 말풍선을 다는 길은 안 간다.** 열여섯 개면 방이 안 보이고,
  ★ 무엇보다 **글자가 그림의 일을 대신하는 것**이라 ⓐ 를 만든 뜻이 없어진다.

# 3. ㉡ **어디에** — ★★★ **새 자리를 «안» 만든다. 칩이 말한다**

총괄이 *"「층·수명」 표에 새 칸이 하나 더 붙는 셈"* 이라 보셨는데 — ★ **안 붙는다.**

⇒ 「다음 손」을 말하는 자리는 «이미 있다» — 칩(questChip)
```
| 층 | 자리 | 「다 자랐다」가 여기인가 |

| 조작법 | coach | ✖ |

| **다음 손** | **칩** | ★ **여기다** |

| 결과(6초) | banner | ✖ — **상태이지 사건이 아니다** |

⇒ ★★ **그리고 ㉣ 이 저절로 풀린다 — 칩은 «하나»다.**
⇒ ★ **표가 안 늘어난다.** 규율 ㉰(*같은 것을 두 곳에 짓지 않는다*)에도 맞다.

# 5. ㉠ **무엇을 알리나** — ★ **끝만. 과정은 «글자로» 안 알린다**
```
✅ 알린다   "다 자랐습니다 — 거두세요"      (끝 · 칩)
⛔ 안 알린다 "자라는 중입니다"                 ← 매일 뜨면 잔소리다

⇒ ⚠ **덜라는 말이 아니다 — 「어디서 볼 수 있나」를 정하자는 것이다.**
  ★ **시루를 «누르면» 그때 말해 주는 것이 맞다.** 늘 떠 있을 말이 아니다.

# 6. ⚠ ③ 화질 — **내 설계는 그 결과에 «안 걸린다»**
```
크게 찍어도 같다    ⇒ ⓐ 를 만든다 + ⓑ 를 만든다      — 위 설계 그대로
크게 찍으니 다르다   ⇒ ★ ⓐ 는 «이미 되어 있다» + ⓑ 만 만든다 — 위 설계 그대로
```
⇒ ★ **글자 쪽(ⓑ)은 해상도와 무관하다.** 갈리는 것은 **ⓐ 를 새로 만드나 아니냐**뿐이다.
⇒ ⚠ **다만 「크게 찍으니 다르다」면 새 물음이 하나 선다:**
> ★★ **「폰 화면에서 안 읽히는 변화」는 «있는 것인가».**
> 에셋이 자라 있어도 **390px 에서 안 보이면 플레이어에게는 «안 자란 것»이다.**
⇒ ⇒ **그건 「에셋을 키우자」가 아니라 「무엇을 크게 바꿔야 폰에서 보이나」다.** [Asset] 몫이다.

# 7. ★ 가구값 주석 — **이렇게 적어 주십시오** ([core] 몫)

## ⚠ 먼저 가려야 할 것 — **죽은 것은 «비교»이지 «뜻»이 아니다**
```
✅ 살아 있는 것   박사님 "좀 비싸게" — ★ 가구는 쉽게 살 물건이 아니다
⛔ 죽은 것        「식물등(25,000)의 1.68배」 — 등이 120,000 이 되어 «거짓»이 됐다
⚠ 아직 없는 것    그럼 «무엇에 대어» 30,000 인가
```

## ⇒ ★★ 그리고 **뒤집힘이 «새 뜻을 만들 수도» 있다**
```
지금   가구 실구매 42,000  <  식물등 120,000
⇒ ★ 「가구보다 등이 먼저」가 «값으로» 말해진다
```
⇒ ⚠ **그것이 의도인지는 박사님 몫이다.** 다만 **지금 값이 그렇게 말하고 있다**는 것은 사실이므로 적는다.

## ⇒ 적을 문안
```
/* 밑값 30,000원 — 실구매 42,000원.
   ⚠⚠ 2026-08-24 — **이 값의 옛 까닭이 죽었다.**
     예전 주석: "식물등(25,000원)의 1.68배 ⇒ 「제일 싼 가구도 식물등보다 비싸다」".
     ⇒ 등값이 25,000 → **120,000**(electricity.json §_note_price · 2026-08-17)이 되면서
       42,000 < 120,000 이라 **그 말이 거짓이 됐다.** ★ 값은 안 낡았는데 «까닭»이 낡았다.
   ★ 살아 있는 것 — 박사님 *"좀 비싸게"*. 가구는 쉽게 살 물건이 아니다. 그 뜻은 안 죽었다.
   ⚠ 새 까닭은 **정해진 바 없다.** 무엇에 대어 30,000 인지는 다시 정해야 한다.
   ★ 그리고 지금 값이 말하는 것 하나 — 가구(42,000)가 등(120,000)보다 **싸다**.
     ⇒ 「가구보다 등이 먼저」가 값으로 말해진다. **의도인지는 확인된 바 없다.**
   ⛔ 값(30,000)은 안 건드린다 — 박사님 *"주석만"*. */
```
⇒ ★★ **「모른다」를 적는 것이 핵심이다.** 옛 까닭을 지우고 새 까닭을 안 적으면
  **「까닭 없는 값」**이 되고, 그건 **낡은 까닭보다 나쁘다** — 다음 사람이 «아무 까닭이나» 지어 붙인다.
⇒ ★ 그리고 **shop.js:266 의 한 줄 주석도 같이** 고쳐야 한다(같은 말이 두 곳이다 · 규율 ㉰).
