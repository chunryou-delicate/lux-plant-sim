# [core] ★ 「여러 개」의 천장은 개수가 아니라 **심는 날**이다 — 실측

박사님 물음 *"콩나물을 여러 개 돌리면 가능할 텐데?"* 를 재다가 나온 것.
**답이 한 겹 더 있다.** 개수를 늘려도 안 도는 자리가 있고, 그 까닭이 개수가 아니다.

---

## ① 손(체력)이 하루 밑천이다 — 값

```
ACT_COST   = { water:1, harvest:1, sow:1, cut:1, repot:1 }      ← 한 짓에 손 하나
STAMINA_RULES.startMax = 5
  levelTable { 5:10, 6:15, 7:20, 8:25, 9:30 } · beyondFrom 10 · beyondMult 10
  xpPerStamina 1                                                ← 손 하나 쓰면 XP 하나
```
⇒ ★ **시루 하나를 한 바퀴 돌리는 데 손 둘**이 든다 — 거두기 1 + 다시 심기 1.

## ② 그런데 실측은 **「손이 다 떨어졌다」가 스물네 번**

씨앗 1(안 판 판) 로그 · `did.sowThrew = 24`:
```
Day 61  [콩나물] 오늘 손이 다 떨어졌습니다 (0/10)
Day 68  (0/11)     Day 81  [무순] (0/13)     Day 88  (0/13)     Day 95  (0/14)
   at resowCrop (src/game/state.js:1288) → canActStamina → src/game/stamina.js:225
```

## ③ ★★ 까닭은 「많아서」가 아니라 **「한날에 몰려서」**

같은 판의 수확 줄:
```
d94 수확 +8      d101 수확 +8      d109 수확 +8
⇒ 그날 드는 손 = 8(거두기) + 8(심기) = 16      ·      그날 밑천 = 14
```
⇒ ★★★ **다 거두고도 다시 못 심는다.** 그 회전이 통째로 밀린다.
⇒ 시루가 열일곱인데 **회전이 6.1~6.6일**로 늘어졌던 까닭이 이것이다(정본 `harvestDays = 5`).
  ⚠ 아침에 이 어긋난 수를 「효율 76~82%」로 적고 넘어갈 뻔했다. **수가 어긋나면 까닭이 있다.**

---

## ⇒ 그래서 답이 이렇게 된다

```
"콩나물을 여러 개 돌리면 가능할 텐데?"
 ㉠ 거둔 것을 «돈으로 바꾸면» 도움이 된다            ← 실측 d90 +215,367원 · 구제금 없이
 ㉡ 그런데 «여러 개»에는 천장이 있다 — 손이다
 ㉢ ★ 그 천장은 «개수»가 아니라 «심는 날»이 만든다
    한날에 몰아 심으면 여덟에서 막히고, 흩어 심으면 손이 남는다
    ⇒ 셈으로 본전인 스물다섯도 «고르게 흩으면» 하루 열 손이라 «닿는 수»다
```

## ⚠ 여기서부터는 [Plan] 몫이다

게임은 지금 **「몇 개를 놓아라」**(siru5 → siru8 → siru16)만 가르치고
**「언제 심어라」는 한 번도 안 가르친다.** 그런데 판을 가르는 것은 뒤쪽이다.
⇒ ★ [Plan] 이 따로 같은 데 닿았다고 한다 — *"「팔까 쟁일까」는 고민이 안 되고,
  「언제 팔까」가 고민인데 아무도 안 알려 준다."* **둘 다 「언제」가 비었다에 닿았다.**

⚠ 내 몫은 **「손이 모자라 스물네 번 던졌다」**까지다. 무엇을 가르칠지는 안 정한다.
