2026-08-24 · [Plan] · [core] 실측(여덟이 한날에 익음 · sowThrew 24)을 받아. ⛔ 문안 안 고침.

# 1. ③ 먼저 세었다 — **「언제」가 빈 자리를 «전부»**

```
게임이 가르치는 것
  얼마나   시루 5 · 8 · 16 · 무순 5 · 잎 2·3            ★ 다 가르친다
  어디     "밝은 자리로" · "어두운 자리에" · 자리 이름     ★ 다 가르친다
  무엇     콩나물/무순 · 등 셋 · 삽수 방법                ★ 다 가르친다
  언제     ⇒ 아래
```

## ⓐ ★★★★★ **「언제」가 «두 갈래»다. 하나만 가르친다**
```
① 게임이 «정해 주는 때»   가을에 등이 열린다 · 30일마다 월세 · 5일 회전 · 7일 무순
   ⇒ ★ 다 알려 준다. 값도 적혀 있다
② ★ 사람이 «고르는 때»    언제 심을까 · 언제 팔까 · 언제 옮길까 · 언제 자를까 · 언제 등을 살까
   ⇒ ⛔ «하나도» 안 가르친다
```
> ## ★★★★ **게임은 «달력»은 가르치고 «타이밍»은 안 가르친다.**
⇒ ★ 그리고 그것이 **자연스럽다** — 달력은 «사실»이고 타이밍은 «판단»이다.
⇒ ⇒ ⚠ **그런데 이 게임은 «판단하는 게임»이다.**

## ⓑ ⚠ **그러니 「안 가르치는 것이 곧 게임」일 수도 있다** — 함부로 못 고친다
```
⛔ 다 알려 주면   게임이 «없어진다». 시키는 대로 누르는 판이 된다
⛔ 하나도 안 하면 ★ 배운 적 없는 것을 «요구»하는 판이 된다
```
⇒ ★★ **갈림은 「가르치나 마나」가 아니라 «한 번은 보여 주었나»다.**

# 3. ② **「개수만 가르치는 것이 옳은가」 — ★ 옳다. 다만 «한 군데가 빈다»**

⇒ ★★★ **가르쳐야 할 것이 «하나 빠졌다」는 맞다.** 다만 **「퀘스트에 넣어라」가 아니다.**

# 4. ① **「언제 심어라」를 어디서 말하나 — ★ 「거둔 직후」다**

## ⓐ 팔기에서 쓴 셈을 그대로 대면
```
심기 «창»은 «심는 순간»에 뜬다   ⇒ 「언제」는 그 «전»에 정해진다
⇒ ★ 그 전 = «거두는 순간»이다. 거두면 «빈 시루»가 생기고,
     그때 「오늘 다 심을까 · 나눠 심을까」가 정해진다
```

## ⓑ ★★ 그리고 **그 자리에 «이미 신호가 있다» — 다만 «늦다»**
```
지금   "오늘 손이 다 떨어졌습니다 (0/10)"   ← ★ «막힌 뒤»에 뜬다
```
⇒ ⛔ **막힌 뒤에 말하면 그건 «벌»이지 «가르침»이 아니다.**
⇒ ★★★ **자리는 「거둔 직후 · 손이 떨어지기 «전»」이다.**

## ⓒ ⇒ 문안 (⏸ **220일 판 뒤에 붙인다**)
```
여덟을 한날에 거둔 그 순간
  몬이: "오늘 여덟이 다 비었네. …오늘 다 심을 거야?"
```
⇒ ★ **답을 «안» 준다.** 계율 ⑤ 그대로다. **「나눠 심어라」라고 안 한다.**
⇒ ★★ **그리고 몬이가 말해야 한다** — 자취가 말하면 «자책»이고, 몬이가 말하면 «곁에서 짚는 것»이다.
  ⇒ **「곳간에 뭐 남았어?」와 «같은 꼴»이다.** 우연이 아니다 — **둘 다 「언제」를 짚는 자리다.**

# 5. ★★★★ ⇒ **그러면 「언제」의 자리가 «셋»이고, 셋 다 «몬이»다**
