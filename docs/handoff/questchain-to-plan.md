## 0. 먼저 — 무엇이 잘못돼 있었나

박사님 원문: *"**잎 3개 날 때까지 너무 이벤트가 없더라.** 퀘스트가 **단계별로 풀려야**
되는데 지금 몇 개 없잖아.. 그리고 **한 번에 보여주고**... **단계적 목표로 가이드랑 연계해서.**"*

재서 확인한 것은 하나다. **퀘스트 여덟 줄 중 여섯이 `firstPlayDone` 뒤에 걸려 있었고,
첫 플레이는 실측 Day 33 에 끝난다.** 나머지 둘(`first_cut`·`varie_bright`)도 모주 잎·무늬가
나야 열리니 더 뒤다. ⇒ **처음 30일 넘게 퀘스트가 한 줄도 안 열렸다.**

★ 그런데 `quest.js` 머리말은 그 상태를 **의도**라고 적어 두었다 —
*"③ **첫 33일에는 안 넣는다.** 거기는 이미 꽉 차 있다(첫 플레이 대사·안내·말풍선)."*

**그 판단이 틀렸다.** 꽉 찬 것은 「말」이고 비어 있던 것은 「할 일」이다. 같은 파일 맨 위가
바로 그 구분을 적어 두었는데(*"「조용해서」가 아니라 「할 말은 있는데 시킬 일이 없어서」"*)
첫 33일에만 그 진단을 적용하지 않았다. 머리말의 ③ 을 **물리고 그 자리에 까닭을 적었다.**

⚠ **그리고 검사가 그 상태를 정상으로 못 박고 있었다** — `tools/test_questui.mjs B-3`
*"첫날에는 **한 줄도 안 열린다**"*. START-HERE §2 가 *"제일 위험하다"* 고 적은 그 모양이다.
(그 파일은 마스터 창 소유라 **안 고쳤다.** 아래 §6 에 고쳐야 할 두 줄을 적어 둔다.)

### ★ 몇 가지 판단 — 되묻지 않게 까닭을 적어 둔다

- **「씨앗 심기」를 따로 안 넣었다.** 첫 시루는 `createFirstPlayState` 가 `sown: true` 로
  만들어 준다(`makeCropPot` 기본값). 심기 손짓은 **둘째 시루부터** 생기고, 그것은 ④ 가 가르친다.
- **「무순 알기」를 따로 안 넣었다.** ⑨`crop_mix` 가 이미 그 줄이고, 무순은 첫 플레이가
  끝나야 상점에 뜬다(`game.html §musunOpen`). 두 줄로 만들면 `teaches` 가 겹쳐
  `test_quest ⑴`(가르치는 것이 안 겹친다)이 깨진다.
- **「몬스테라 도착」과 「자리 잡기」를 한 줄로 묶었다.** 도착은 플레이어가 하는 일이 아니다.
  할 일은 자리를 잡아 주는 것 하나다.
- **⑥ 은 앞 줄 완료 + 몬스테라 도착을 같이 본다.** 앞 줄만 보고 열면 「없는 화분을
  옮기세요」가 된다. 사슬은 **더 좁아질 뿐** 안 넓어진다.
- **⑧ 이 잎 3장에서 끝난다** — 박사님이 *"잎 3개 날 때까지"* 라고 하신 그 끝이다.

## 2. 사슬을 **표에 적었다** — `after`

열 줄이 `opens` 안에서 서로를 부르고 있었는데, 그 사슬은 **함수 안을 하나씩 열어 봐야만**
보였다. 사슬이 끊겨도 눈에 안 띈다는 뜻이다. 그래서 **`after: '<앞 줄 id>'`** 를 표에 적었다.

⚠ **판정은 여전히 `opens` 가 한다.** `after` 는 읽히는 칸이 아니라 적힌 칸이라
**두 벌이 될 위험**이 있다(START-HERE §2.8). 그 위험을 검사가 막는다 —
`test_quest ⑶` 이 **`after` 를 지운 판에서 `opens` 가 정말 거짓이 되는지**를 물어
둘이 같은 말을 하는지 매번 대조한다. 갈리면 검사가 깨진다.

`after` 가 붙은 줄 열: ①→②→③→④→⑤→⑥→⑦→⑧ · ⑨→⑩→⑪→⑫

## 3. ★★★ `game.html` 이 쓸 계약 — **이것만 읽으면 배선이 된다**

### 3-1. `questView(S, snap)` 가 **더 내는 것** (예전 칸은 하나도 안 없앴다)

```js
{
  schema, done, open, next, all,      // ← 예전 그대로. game.html 이 쓰던 것 전부 산다
  current,      // 지금 할 **하나**. `next` 와 같은 객체다(이름이 뜻을 말하라고 둔 것)
  upcoming,     // ★ 다음에 올 줄들 — `current` **뒤**의 안 끝난 줄 전부, 정의 순서
  counts,       // { total, done, open, locked }
  stage,        // 'first_play' | 'main' | 'clear'
  chain         // { index, total } — 초반 사슬의 몇째/여덟. 사슬이 끝났으면 null
}
```

`all[]` 한 줄이 갖는 것 — 예전 것(`id · ko · todo · why · teaches · reward · state`)에
**셋이 늘었다**:

| 칸 | 값 | 쓰임 |
|---|---|---|
| `stage` | `'first_play'` \| `'main'` | 「단계」로 묶어 그릴 때 |
| `index` | 정의 순서 0부터 | 정렬·「몇째」 |
| `speaks` | 이 줄이 대사를 갖나 | 지금 초반 여덟은 `false` |

### 3-2. ★ 마스터 창이 그리기로 한 세 무리 — **그대로 나온다**

> *끝낸 줄은 한 줄로 접고 · 열린 줄은 펼치고 · 잠긴 줄은 **다음 둘만** 흐리게,
> 그 뒤는 「그 뒤로 N가지가 더 있습니다」*

```js
const v = questView(S, questSnapshotNow(lastTurn));

const doneRows = v.all.filter(a => a.state === 'done');     // 접어서 도장만
const nowRow   = v.current;                                 // 펼친다 (todo + why + reward)
const peek     = v.upcoming.slice(0, 2);                    // 흐리게 둘
const moreN    = Math.max(0, v.upcoming.length - 2);        // 「그 뒤로 N가지」
// 진행도: `${v.counts.done}/${v.counts.total}`
// 단계 머리말: v.stage === 'first_play' ? `첫걸음 ${v.chain.index}/${v.chain.total}` : …
```

⚠ **`upcoming` 을 코어가 안 자른다.** 몇 줄이 들어가는지는 **폭**이 정하는 것이라 화면의 일이다.
권장값은 `QUEST_PREVIEW`(= 3) 로 내보냈으니 쓰든 말든 화면이 정하면 된다.
⚠ `v.next` 는 **그대로 살아 있다.** 아래 한 줄(`#quest`)의 `v.next.todo` 배선은 안 고쳐도 된다.

### 3-3. ⚠⚠ `questSnapshotNow` 에 **칸 넷을 채워 달라**

지금 스냅샷이 안 내주는 사실 넷이다. **`game.html` 안에서 이미 도는 코드 옆 두세 줄**이다.

```js
// ① cropPots 를 만드는 그 map 안에 세 칸을 더한다 (game.html:6425 언저리)
cropPots = cropSites(fp).flatMap(site =>
  ((site && site.pots) || []).map(p => ({
    kind: (site.kind || 'beansprout'),
    harvestCount: (p && p.harvestCount) || 0,
    placed : cropPotPlaced(p),                 // ← 새 칸. first_play 에서 import
    watered: !!(p && p.startedOnDay != null),  // ← 새 칸. 「회전이 시작됐나」
    sown   : cropPotSown(p)                    // ← 지금 사슬은 안 보지만 같이 넣기 좋다
  })));

// ② return 하는 객체에 둘을 더한다
monsteraArrived: !!(fp.monstera && fp.monstera.arrived),
monsteraHomed  : !!(fp.monstera && fp.monstera.guide && fp.monstera.guide.moved),
```

`import` 두 개가 는다 — `cropPotPlaced` · `cropPotSown` (`./src/game/first_play.js`).

### 3-4. ★★ **안 붙여도 사슬은 돈다** (재서 확인함 · `probe_questchain D-1`)

위 넷을 **하나도 안 채운 판**에서도 여덟 줄이 전부 열리고 전부 끝난다. ①②⑥ 의 `done` 에
**함의**를 걸어 두었기 때문이다:

- *거둔 적이 있다 ⇒ 놓여 있었고 물을 받았다* (`placedCropPots` 만 자라고 `startedOnDay`
  없이는 안 자란다 — 그 길 말고 수확이 없다)
- *잎이 둘이 됐다 ⇒ 자라는 자리에 있다* (도착 자리 `banjiha-desk:0` DLI 0.61 로는 안 난다)

⚠ 이것은 「모르면 지어내기」가 **아니다.** 지어내는 것은 없는 사실을 참으로 치는 것이고,
여기 것은 **강한 사실이 약한 사실을 논리적으로 함의**하는 것이다.
⇒ 배선을 붙이면 왼쪽 항이 **먼저** 참이 되므로 폴백은 안 쓰인다. 즉 붙이면 **더 일찍** 끝난다.

| ⑶ *"여는 순서가 정의 순서와 같다"* | **`after` 로 잰다**로 바꿨다 (사슬로 걸린 줄만) | 열여섯이 되면서 **참이 아니게** 됐다. 버그가 아니라 구조다 — 줄기가 둘이고 나란히 돈다. `first_cut` 은 모주 잎 둘이면 열리는데 그건 첫 플레이가 끝나기 **전**이라, 정의가 뒤인 `first_cut` 이 앞인 `crop_mix` 보다 먼저 열린다. ⚠ 그것을 「어긋남」으로 재면 **`first_cut` 을 건드리게 된다 — 그게 회귀다** |
| *"아무것도 안 열린 판은 next 가 null"* | **뒤집었다** — *"켠 첫 순간에 **딱 한 줄**이 열린다"* | **고장난 상태를 검사가 정상으로 못 박고 있었다**(START-HERE §2 의 제일 위험한 모양) |
| 새로 넣은 것 | 사슬 여섯 검사(첫 플레이 안에 다 끝나나 · 한 걸음에 하나만 · 표 차례대로 · 마디가 맞나 · `after` 가 판정과 같은 말을 하나) + 화면 계약 셋(`current`/`upcoming` 이 갈리나 · 셈이 스스로 안 어긋나나 · 다 끝낸 판이 `clear` 인가) | |

⚠ 줄 수를 검사 **이름**에 안 박았다 — 표에서 센다. 2026-08-16 에 여덟이 열여섯이 되면서
*"여덟 줄"* 이라 적힌 이름 넷이 한꺼번에 낡을 뻔했다(§2.8 의 그 모양).

## 7. ⚠ 판단필요 — 박사님께 여쭐 것

### ⓐ **초반 여덟 줄에 체력을 줄까** (⇒ 지금은 **0**)

`data/balance/stamina.json` 도 `src/game/stamina.js` 도 이 창의 쓰기 영역 밖이라
`STAMINA_RULES.quests` 에 못 넣었다. `grantStaminaQuest` 가 없는 id 를 **0 으로 읽고
안 던진다**(확인함). 대신 **세상이 주는 것**을 `reward` 에 적었다(§1 표 맨 오른쪽 칸).

★ **안 주는 쪽에도 근거가 있다** — 이 여덟은 「배우는 줄」이고, 실제로 주는 상은
*몬스테라가 온다 · 회전이 돈다 · 자를 수 있게 된다* 처럼 **판이 앞으로 가는 것**이다.
거기에 체력을 얹으면 진짜 보상이 가려진다(`quest.js §보상` 이 `buy_lamp`·`varie_bright`·
`sell_varie` 에 대해 이미 한 판단이다).

⚠ **주기로 하면 값이 커진다.** 지금 체력을 주는 줄이 다섯(5 → 10)인데 여덟을 더 주면
**5 → 18** 이 된다. 첫 플레이 구간에서 손이 세 배가 되는 것이라 **밸런스 결정**이다.
⇒ 붙이는 자리는 `data/balance/stamina.json §quests` 한 곳이고, 코드는 한 글자도 안 고쳐도 된다.

### ⓑ **여덟 줄이 아직 말을 안 한다** (`speaks: false`)

`dialogue.js` 가 이 창의 쓰기 영역 밖이라 `QUEST_OPEN_SCRIPT`·`QUEST_DONE_SCRIPT` 에
**열여섯 줄**(줄마다 열림·완료)을 못 넣었다. 지금은 조용히 지나간다 —
`dialogue.js §scriptOf` 가 *"여기 없는 questId 는 조용히 지나간다"* 를 이미 계약으로 적어 뒀다.

⇒ 지금 이 줄들이 내는 것은 셋이다: **할 일 창의 줄 · 아래 한 줄 · [할 일] 단추의 점.**
