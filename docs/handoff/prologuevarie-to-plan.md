## 0. 먼저 — 「80%」는 옛 문장이다

박사님 지시문의 근거였던 *"모주가 무늬면 그 삽수는 훨씬 높은 확률(80%)을 물려받는다"* 는
`plant_grow.html:203` 의 주석이고 **끝이 「~구조로 갈 것」인 예고문**이다.
그 예고는 **2026-08-04 에 박사님이 직접 갈아엎으셨다** — 지금 도는 것은 키메라 세 갈래다
(`propagation.js` §③ · 박사님 원문 *"실제도 알보가 유지될 확률도 있지만 다시 원복될 확률도 있던데"*).

    w = 자른 마디가 달고 있는 무늬 잎의 비율
    원복 (1−w)²  ·  유지 2w(1−w)  ·  고스트 w²

**유지의 최댓값은 w=0.5 에서 50%다. 80%는 이 식에서 나올 수 없다.**
그리고 무늬 잎이 **한 장뿐인 그루**에서는 그 잎만 떼면 w=1 이라 **고스트 100%** 다.
⇒ 「모주가 무늬니까 삽수도 무늬」가 성립하려면 **무늬 잎이 최소 두 장**이라야 한다.
이게 아래 §3 이 막히는 진짜 이유다.

## 1. 바뀐 것 (네 파일 + 검사 하나)

### ① `plant_grow.html` — §프롤로그 보장
`varieProb`(0.20)은 **한 글자도 안 건드렸다.** 대신 굴림에 **진 뒤에** 그 한 잎만 참으로 덮는다.

```js
const PROLOGUE_VARIE={ leafNo:0, used:false, leafBirth:null };   // ★ 기본은 꺼짐
function varieRoll(leafBirth, roll){
  let v=VARIE_STATE.get(leafBirth);
  if(v===undefined){
    v = roll < calcVarieProb(lightCtx());
    if(!v && prologueVarieHit(leafBirth)) v = true;   // ★ 이겼으면 안 쓴다
    VARIE_STATE.set(leafBirth, v);
  }
  return v;
}
```
안 주는 경우 셋: **이미 줬다** · **이미 무늬 잎이 있다** · **N번째 잎이 아니다**.
`rng()` 은 예전과 똑같은 자리에서 똑같이 뽑힌다 — 난수 스트림도 형태도 안 움직인다.

창구 셋을 냈다: `setPrologueVarieLeaf(n)` · `prologueVarieState()` · `varieStateAll()` 에 `prologue` 칸.

### ② `src/game/growth_adapter.js` — 켜는 자리
`PROLOGUE_VARIE_LEAF_NO = 2`. **`setGrowth`(개체 도착) 안에서 한 번 켠다.**
도착은 판마다 한 번뿐이고(state.givePlant · save.js §growth) 그 한 번이 곧 프롤로그다.
그 뒤 하루 진행은 전부 `advanceTo` 라 여기를 다시 안 지난다 ⇒ **「첫 플레이에서만」이 배선 하나로 성립한다.**

### ③ `src/game/loop.js` — 말하게 한다 (⚠ 쓰기 영역 밖이다)

## 4. 캐논 검사 — 「20%」의 뜻을 안 깼나

`tools/test_prologue_varie.mjs` 를 새로 두고 **같은 씨앗·같은 빛으로 두 판을 겹쳐 봤다.**
겹쳐 보는 것이 제일 센 자다 — 난수 스트림이 한 칸이라도 밀렸으면 **뒤쪽 잎의 판정이 같이 흔들린다.**

```
보장 없이: [[36,f],[136,f],[256,f],[376,f],[496,t],[616,f]]
보장 켜고: [[36,f],[136,t★],[256,f],[376,f],[496,t],[616,f]]
  ✓ 부팅 기본은 꺼짐 (leafNo 0) — 안 켜면 안 돈다
  ✓ 켜도 확률 정본이 그대로 — varieProb 0.2 → 0.2
  ✓ 잎 수가 같다 — 6장 (난수 스트림이 안 밀렸다)
  ✓ 보장 말고는 한 잎도 안 바뀐다 — 달라진 잎 1장 [136]
  ✓ 붙은 것은 두 번째 잎이다
  ✓ 세 번째 잎부터는 안 붙는다 — 뒤 4장 전부 굴림
  ✓ 보장 밖에서도 굴림으로 무늬가 난다 — 1장 (20% 가 살아 있다)
  ✓ 이미 무늬가 난 그루에는 덤을 안 준다 — 잎 4장 중 보장 0장
```
다섯 번째 잎(496)은 **여전히 굴림으로 무늬가 난다.** 캐논이 살아 있다.
