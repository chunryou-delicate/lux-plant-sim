# ㉠ 「가을 해금」은 **돌고 있다.** ★ 다만 **«무엇의» 해금인지가 문서에 안 적혀 있었다**

```js
tutorial.js:721   season === R.lampUnlockSeason && seasonDay === LAMP_NUDGE_DAY
shop.js:393       "가구는 아직 살 수 없습니다 — 식물등이 열리는 때(가을)에 같이 열립니다"
```
⇒ ★★ **가을에 열리는 것은 «살 수 있는 것»이다. «기구가 방에 생기는 것»이 아니다.**
```
가을에 열림   ★ 사는 것          ← 이건 «돈다»
안 잠김       ★ 기구가 방에 있는 것  ← 이건 «처음부터 있다»
```
⇒ ⛔ **내 목록이 「가을 해금」이라고만 적고 «무엇의» 해금인지를 안 적었다.**
  ⇒ **낡은 게 아니라 «모자랐다».** 읽는 사람이 「기구도 가을에 생긴다」로 읽는다.
  ⇒ ★ 오늘 여러 번 본 그 병이다 — **답이 맞으니(가을에 열리긴 하니) 무엇이 열리는지를 안 봤다.**

# ㉡ 미리 놓아 둔 것이 **의도인가** — ★ **「어디 붙나」는 의도이고 「언제 보이나」는 아니다**

## ⓐ 박사님이 직접 정하신 것은 **자리**다
```
house_rooms.json 주석
  bar    "★★ 2026-08-16 (G-16 · 박사님 «식물등 최초 위치 이상, 몬스테라 위쪽으로»)"
  stand  "★★ 2026-08-17 (박사님 «식물등도 집게형 말고 그냥 거치형 하나 추가해»)"
```
⇒ ★ **정하신 것은 「어디에 붙나」·「어떤 종류가 있나」다.** **「처음부터 보이나」는 정하신 적이 없다.**

## ⓑ 그리고 구조가 그렇게 되어 있다
```js
light_adapter   rigsOn = growRigs.slice(0, n)     n = «산 개수»
```
⇒ ★★ **기구는 방에 다 있고, 산 개수만큼 «앞에서부터» 켠다.**
⇒ ⇒ **상점이 파는 것은 「기구」가 아니라 «켤 권리»다.**
⇒ ★ 그래서 **잠그는 줄이 0건인 것이 자연스럽다** — 애초에 잠글 대상으로 안 만들었다.

## ⓒ ⇒ **판정: 「그냥 안 잠근 것」이다.** 전기 기획도, 「저기 달 수 있구나」도 아니다
⇒ ⚠ [Asset] 이 친 울타리(*"일부러 그런 것일 수 있습니다"*)는 옳았다. **그런데 아니다.**

---

# ★★★ ㉢ 어떻게 할 것인가 — 먼저 **왜 문제인지**부터

[Asset] 이 든 근거(첫 긴장 · 「등이 곧 길」)에 **동의한다.** ★ 여기에 하나 더 붙인다:

> ## **첫 퀘스트가 「밝은 자리를 찾아라」인데,**
> ## **밝게 만드는 물건이 이미 방에 «셋» 서 있다.**
> ## ⇒ **자리를 찾으라면서 답을 옆에 세워 둔 것이다.**

⇒ ★ 내 규율 **㉱**(*답을 줄 것과 「선택이 있다」만 줄 것을 미리 정한다*)에 정면으로 걸린다.
⇒ ★★ 그리고 계율 **⑦**(*힘은 드묾에서 온다*) — **셋이 서 있으면 드물지 않다.**
⇒ ⚠ [Asset] 말대로 **흐리게 하는 걸로는 안 풀린다** — *"꺼져 있어도 「있다」는 사실이 화면에 남는다."*

## ⚠⚠ 그런데 **지금 정하면 안 된다** — 박사님 ② 와 충돌한다
```
박사님 ②   "집게등은 없애고 벽부등이 «바닥 및 벽 모든 곳»에 붙을 수 있게"
⇒ 기구 셋(bar·clip·stand)의 «구성 자체»가 바뀐다
⇒ ★ 그리고 벽부등을 «플레이어가 붙인다»면, 「미리 놓여 있다」가 «저절로» 없어진다
```
⇒ ★★★ **㉢ 은 벽부등 개편이 선 «뒤»에 정하는 것이 맞다.**
  지금 정하면 **두 번 고치고, 그 사이에 한쪽이 낡는다.**

---

# ⇒ ★ 박사님께는 **물음이 하나**면 된다

⚠ 셋을 다 여쭈면 안 된다 — ㉠㉡ 은 **내가 답할 수 있는 것**이고, ㉢ 은 **아직 이르다.**

```
여쭐 것 하나
  ★ 「안 산 식물등이 첫 화면에 서 있는 것」 — 이걸 없애는 방향이 맞습니까?

  ⓐ 없앤다   사기 전에는 «안 보인다». 사면 그 자리에 나타난다
  ⓑ 둔다     「저기 달 수 있구나」를 미리 보여 주는 것이 낫다

  ⚠ 어느 쪽이든 «벽부등을 어디에나 붙게» 고친 뒤에 손댑니다 — 지금 고치면 두 번 고칩니다
```
⇒ ★ **「어떻게」(그림만 끄나 / 배치에서 빼나)는 안 여쭌다.** 그건 **방향이 서면 [core]·[House] 가 정할 일**이다.
⇒ ⚠ 그리고 **「흐리게 할까요」는 선택지에 안 넣는다** — [Asset] 이 그게 안 풀린다고 쟀다.

## ★ 내 기울기는 **ⓐ** 다
```
① 첫 퀘스트가 「밝은 자리를 찾아라」인데 답이 화면에 서 있다
② 「등이 곧 길」인데 길이 처음부터 열려 있다
③ ★ 그리고 «사는 맛»이 없다 — 사도 화면이 안 바뀐다. «켜질 뿐»이다
   ⇒ 25,000원을 썼는데 «새로 생긴 것»이 없다. 원래 있던 것이 켜진다
```
⇒ ★★ ③ 이 셋 중 제일 크다. **살 이유를 «돈으로만» 만들고 있다.**
  ⇒ **없던 것이 생기면, 산 것이 눈에 보인다.**
