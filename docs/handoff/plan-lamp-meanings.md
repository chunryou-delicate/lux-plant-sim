# 4. ⚠⚠⚠ **그리고 이것이 급하다 — 「모름 = 0」이 «수입»에 닿는다**

[growth] 가 찾은 것:
```
헤드리스에서 «바닥»을 물으면 0 이 온다. 그 0 은 「어둡다」가 아니라 「모른다」다
⇒ 콩나물 품질표는 «하한이 없다» ⇒ 「모름 = 0」이 «최상»으로 읽힌다
⇒ 그램 표가 그 끼니에 얹혀 있다:  500g / 350g / 200g
⇒ ⇒ ★ 「모름」이 «최대 수확 500g» = «최대 돈» 이 된다. 최하와 «2.5배»
```
> ## ★★★★ **검사가 초록인 채로 수입이 2.5배가 된다.**

## ⇒ ⚠ **그러면 내가 이번 주에 판단한 «밸런스 숫자»에 닿을 수 있다**
