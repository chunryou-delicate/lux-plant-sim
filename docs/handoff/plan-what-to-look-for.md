# 씨앗 표가 오면 «무엇을 볼 것인가» — ⛔ 판정 아님. 자를 세운다

2026-08-24 · [Plan] · 「완벽한 사람」 한 판(씨앗 1 · 140일 파산)을 보고. **결론은 안 낸다.**

> ⚠ **한 씨앗으로 「못 닿는다」를 말하면 오늘 여덟 번 한 그것이고,
> 이번엔 틀리면 «밸런스를 통째로 고치자»가 된다.** 총괄 판단이 옳다.

---

# ㉠ 「이사에 무엇이 드나」 — ★ **돈이 «모자란» 게 아니라 «안 는다»**

```
이사 조건   돈 2,000,000원  +  무늬 잎(새 조건 · 확정)
시작 자금   1,500,000원
한 판의 봉우리   d40 737,699  ·  d60 593,099  ·  d100 413,300
```
> ## ★★★★★ **지갑이 «한 번도 시작 자금을 안 넘는다».**

⇒ ★ 그러면 물음이 「닿나 못 닿나」가 아니다:
```
못 닿는다        = 가다가 모자란다
★ 이 판          = «가고 있지도 않다». 첫날이 제일 부자다
```
⇒ ⚠ ⛔ **한 씨앗이므로 단정 안 한다.** ★ **다만 씨앗 표에서 볼 것은 정해진다:**
> **「어느 씨앗이든 지갑이 «1,500,000 을 넘은 적이 있나»」**
⇒ 넘은 적이 있으면 **「모자란다」**이고, 한 번도 없으면 **「방향이 반대다」**다. **처방이 완전히 다르다.**

# ㉡ ★★★★ **톱니 — 「회복했다 떨어진다」가 아니라 «내려가는 톱니»로 보인다**

```
봉우리   d40 737,699  →  d60 593,099  →  d100 413,300      ★ 낮아진다
골       d80 224,699  →  d120 268,200 →  d140 0
```
⇒ ★★ **월세가 30일마다이니 톱니 자체는 «당연»하다.**
  ⇒ ⇒ ★★★ **문제는 톱니가 아니라 «봉우리가 낮아지는 것»이다.**
  **회복이 «전보다 낮은 곳»까지만 온다.**

## ⇒ ★ 그러면 「마지막 골에서 못 버텼다」가 «아니다»
```
못 버텼다   ← 마지막 한 번이 나빴다. ⇒ 운이다. 씨앗 바꾸면 달라진다
★ 이 판     ← «처음부터 내려가고 있었다». ⇒ 구조다. 씨앗 바꿔도 같다
```
⇒ ⛔ **어느 쪽인지는 씨앗 표가 정한다.** ★ **그래서 볼 것:**
> ## **파산일(140)이 아니라 «봉우리 추세»를 본다.**
```
씨앗마다 파산일은 흔들린다 — 운이 섞인다
★ 봉우리가 «씨앗마다 다 낮아지면» 그것은 구조다
```
⇒ ★★ **파산일 다섯 개를 평균 내는 것보다 이쪽이 훨씬 많이 말한다.**

# ㉢ ★ 「d60~d90 이 고비」 — **맞았다. 다만 «범위가 좁았다»**

```
내가 앞서 세운 것   ★ 「d60~d90 이 고비다」
이번 판             d80 이 바닥 (224,699)          ✅ 맞다
⚠ 그런데            d140 에 «더 깊은» 바닥(0)이 있다
```
> ## ★★ **고비가 «하나가 아니다». d60~d90 은 «첫» 고비였다.**
⇒ ★ **그리고 첫 고비는 «넘는다»**(d100 에 413,300 으로 반등).
⇒ ⇒ **못 넘는 것은 «둘째·셋째»다.**

## ⇒ ⚠ **그래서 내 「채소 팔기」 처방의 자리가 바뀔 수 있다**
```
내가 붙인 곳   ★ 첫 고비(문턱 = 월세 한 달치)
그런데         첫 고비는 «넘는다». 못 넘는 것은 뒤쪽이다
⇒ ⚠ 첫 고비에서 채소를 다 팔면 «뒤쪽에 팔 것이 없다»
```
⇒ ★★★ **「급전을 언제 쓰게 하나」가 새 물음이 된다.**
  **첫 고비에서 쓰면 편한데, 그러면 진짜 고비에서 «맨몸»이다.**
⇒ ⛔ **지금 안 정한다.** 씨앗 표가 **「고비가 몇 번인가」**를 말해 준 뒤다.
⇒ ★ **다만 이것은 «구호금이 한 번뿐»인 것과 «같은 모양»이다** — 오늘 §「0원 위에는 아무것도 없다」.

# ⇒ ★★ **씨앗 표에서 볼 것 — 넷**
```
① 지갑이 «1,500,000 을 넘은 적이 있나»        ⇒ 「모자라다」 vs 「방향이 반대다」
② 봉우리가 «씨앗마다 다 낮아지나»              ⇒ 「운」 vs 「구조」
③ 고비가 «몇 번»인가                          ⇒ 급전을 어디에 붙이나
④ ★ 파산일이 «얼마나 흩어지나»                 ⇒ 운이 밸런스에 얼마나 섞였나
```
⇒ ★★★ **④ 가 총괄이 짚으신 그것이다** — *"닿을 수 있는데 운이 나쁘면 못 닿는다"* 는
  **「못 닿는다」와 다른 병이고 처방도 다르다.**
⇒ ⚠ **그리고 ④ 는 «다섯 판으로는 잘 안 보인다».** 흩어짐을 보려면 판이 더 있어야 한다.
  ★ **다섯이 «다 비슷하면»** 그것만으로도 「운이 적다」는 말은 된다. **다르면 더 돌려야 한다.**

# ⚠ 마지막으로 — **내 앞선 판단들의 «지금 상태»를 적어 둔다**
```

⏸ 보류   「d60~d90 이 고비」 범위           — 첫 고비였다. 뒤가 더 있다
⏸ 보류   문턱 안(월세 한 달치)              — ㉢ 에 걸린다
✅ 유효   「급전은 손해가 아니라 값」         — 자리만 다시 잡으면 된다
✅ 유효   「아는데 안 알려 준다」             — 대사가 손을 안 가리킨다는 것은 그대로다
```
