## 0. 뭔지부터 — 소리를 어디서 가져왔나

**아무 데서도 안 가져왔다. 그 자리에서 만든다.**

박사님이 말씀하신 여섯(딸칵·사각사각·물·저벅저벅·띠로롱·턱)은 전부 **WebAudio 로 지었다.**
오실레이터 몇 개와 잡음 한 덩이를 필터에 물려 포락선을 씌운 것이 전부다.

왜 파일을 안 썼나 — 근거 넷:

| | |
|---|---|
| ① | **받을 바이트가 0 이다.** 이 저장소는 방금 428MB 를 줄인 참이다. wav 여섯이면 짧아도 200~600KB 이고 그건 첫 화면이 뜨는 시간이다 |
| ② | **로딩 구간이 없다.** 파일이면 「아직 안 받아져서 안 나는」 구간이 반드시 생긴다. 합성은 부르는 순간 만들어진다 |
| ③ | **저작권을 확인할 데가 없다.** 이 환경은 오프라인일 수 있다 |
| ④ | ★ **매번 조금씩 다르게 낼 수 있다.** 발소리·사각사각은 되풀이되는데 파일이면 100% 똑같아 기계로 들린다. 잡음 버퍼에서 읽는 자리를 미는 것만으로 결이 바뀐다 — 파일로는 못 하는 일이다 |

⚠ **「합성이라 싸구려」를 막으려고 한 것** — 여섯 다 **한 겹이 아니다.**
딸칵은 잡음 + 피치 틱, 물은 잡음 + 물방울 셋, 저벅은 저음 + 눌린 잡음, 턱은 저음 + 잡음 + 나무 울림.
한 겹짜리(사인 하나·잡음 하나)가 곧 「전자음」으로 들리는 소리다.

★ **직접 들어 보실 수 있다** — `docs/sfx.html`
```
python tools/serve.py 8963
http://localhost:8963/docs/sfx.html
```
여섯을 하나씩 눌러 보고, 저벅저벅·사각사각은 켜고 끌 수 있다.

## 1. 여섯 소리 — 표

⚠ **길이가 둘이다.** 헷갈리면 이 표가 곧 거짓말이 된다.
· **예약** = 그래프에 걸어 둔 길이(오실레이터를 언제 멈추나)
· **들림** = 실제로 귀에 닿는 길이. 지수 감쇠라 예약보다 짧다.
  `tools/test_sfx.mjs` 가 **최댓값의 0.3%(≈−50dB) 를 넘는 구간**으로 잰 값이다.

**무엇을 켜고 무엇을 껐나** — `OfflineAudioContext(1채널 · 44,100Hz · 1.5초)` 에
목소리 **하나만** 걸어 렌더했다. 배경 음악·마스터 볼륨·컴프레서는 **껐다**(목소리 원음이다).

| 이름 | 파형 | 예약 | 들림 | 최대 | RMS | 왜 그렇게 |
|---|---|---|---|---|---|---|
| **딸칵** `tap` | 밴드패스 잡음(2.2kHz Q1.2) + 삼각파 틱 1900→950Hz | 95ms | **32ms** | 0.254 | 0.0066 | 진짜 딸칵은 **넓은 띠의 순간음**이다. 사인만이면 「삐」, 잡음만이면 「치익」. 둘을 겹쳐야 플라스틱 단추가 된다. ⚠ 들림이 30ms 대라야 한다 — 길면 대사를 빨리 넘길 때 「딸-깍」이 겹쳐 들린다 |
| **사각사각** `scrape` | 밴드패스 잡음(1.7 / 1.45kHz) **두 덩이**, 130ms 간격 | 245ms | **203ms** | 0.119 | 0.0044 | 스치는 소리는 1~3kHz 잡음이다. 덩이가 **둘**인 것이 핵심 — 하나면 「슥」이고 둘이라야 「사각-사각」이다. 되풀이되는 소리라 **일부러 여섯 중 제일 여리게** 뒀다 |
| **물** `water` | 중심이 800→2600Hz 로 오르는 잡음 + 사인 물방울 셋 | 520ms | **402ms** | 0.176 | 0.0122 | 뿌리는 소리는 **밝아지는 쉭**이다(입자가 퍼지며 고음이 는다). 그것만이면 바람이라, 물방울 셋을 얹어야 「물」로 읽힌다 |
| **저벅** `step` | 사인 132/118→50Hz + 로우패스(520Hz) 잡음 | 140ms | **65ms** | 0.307 | 0.0154 | 발소리는 **몸이 닿는 둔탁함**(저음) + **바닥을 쓰는 소리**(눌린 잡음)다. 사인만이면 북이 된다. 좌우 발을 14Hz 다르게 낸다 — 같으면 기계다 |
| **띠로롱** `chime` | 5음 아르페지오 A4·C5·E5·A5, 75ms 간격 (삼각 + 옥타브 사인) | 585ms | **461ms** | 0.204 | 0.0235 | **배경 음악과 안 부딪히게** `music.js` 가 쓰는 5음 음계(A C D E G)에서 뽑았다. 올라가는 차례라 「좋은 일」로 읽힌다. 3화음을 한 번에 쌓으면 씩씩해져 선물의 결이 아니다 |
| **턱** `thud` | 사인 190→58Hz + 로우패스 잡음 + 380Hz Q4 울림 | 165ms | **78ms** | 0.449 | 0.0225 | 「놓았다」는 **질량이 멈추는 소리**다. 저벅보다 높게 시작해 더 낮게 떨어지고 더 세다(0.449 vs 0.307) — 그 차이가 「걷는다」와 「놓았다」를 가른다. 380Hz 좁은 울림 하나가 「바닥」이 아니라 「가구 위」로 만든다 |

★ **세기를 왜 갈랐나 — 한 번 나는 소리는 세게, 되풀이되는 소리는 여리게.**
딸칵·턱·띠로롱은 사건이라 들려야 하고, 저벅·사각사각은 몇 초씩 이어지므로 같은 세기면 그것만 들린다.
⚠ **첫 판은 반대였다** — 딸칵이 0.157 로 턱(0.487)의 3분의 1이라 **제일 자주 나는 소리가 제일 안 들렸다.**
재서 올렸다(0.157 → 0.254). 짐작으로 고른 게 아니라 렌더해서 본 것이다.

★ 감쇠는 전부 **지수**다. 선형으로 떨구면 끝에서 딱 끊겨 '틱' 이 덧난다(`music.js §envGain` 과 같은 손).

## 3. ★ 끄는 스위치를 어떻게 했나 — 그리고 왜

**결론: `#btnMusic` **하나**를 쓴다. 새 단추를 안 만들었다. 새 저장 열쇠도 안 만들었다.**

근거 넷:

| | |
|---|---|
| ① | **띠에 자리가 없다.** `game.html` CSS 주석이 직접 적어 두었다 — 아래 띠는 44px 고정이고 [다음 날]이 나머지를 통째로 쓴다. 탭 줄은 방 위에 얹혀 있어 칸이 늘 때마다 방을 그만큼 가린다. 「띠에서 옮겨 온 이유가 방을 안 줄이려고인데 거기서 방을 갉으면 뜻이 뒤집힌다」 |
| ② | **스위치가 둘이면 「왜 소리가 안 나지」가 두 배가 된다.** 사람은 하나를 끄고 나머지를 잊는다 |
| ③ | **열쇠를 새로 안 만든다.** `sfx.js` 는 `localStorage` 를 **안 읽는다.** 읽으면 정본이 둘이 되고, 그러면 「어느 쪽이 참인가」를 아무도 못 가린다 — 이 저장소가 여러 번 밟은 모양이다. `byeot.music` 하나가 정본이고 화면이 `sfx.setEnabled()` 로 알려 준다 |
| ④ | **기본이 켬이다.** `musicWanted()` 가 `!== 'off'` 라 처음 켠 사람은 소리가 난다. 박사님 지시 그대로다 |

⚠ **갈라야 할 때가 오면** — `sfx.js` 는 이미 갈라져 있다. `setEnabled/isEnabled` 가 음악과
아무 관계가 없고 자기 볼륨(`setVolume`)도 따로 갖는다. **단추 하나와 열쇠 하나만 늘리면 된다.**
그때는 「음악 ♪ / 소리 🔔」 두 단추가 되고 `sfx.js` 는 한 글자도 안 바뀐다.

⚠ **다만 지금은 「음악을 끈 사람은 딸칵도 못 듣는다」이다.** 이것이 옳은지는 박사님 몫이다 → §5

★ **「함수가 안 던진다」는 안 잰다.** WebAudio 는 조용히 실패하는 길이 많다 —
포락선을 0 에서 시작하면 지수 램프가 영영 안 올라오고, 지나간 시각에 걸면 그 음은 그냥 안 나고,
필터를 잘못 물리면 전부 깎인다. 전부 「코드는 도는데 소리는 없다」로 끝난다.
⇒ `OfflineAudioContext` 에 그래프를 걸어 **렌더한 파형을 잰다. RMS 가 0 이면 안 난 것이다.**

**결과 — 36건 전부 통과** (2026-08-16 11:54)

| 잰 것 | 결과 |
|---|---|
| ★ 여섯이 다 난다 (RMS > 0) | 6/6 — 0.0044 ~ 0.0235 |
| 안 찢어진다 (최댓값 < 1.0) | 6/6 — 0.119 ~ 0.449 |
| ★ 여섯이 **서로 다른 소리**다 (배선이 한 데로 안 갔다) | 6/6 가지 |
| 표에 적은 예약 길이를 실제 길이가 크게 안 넘는다 | 6/6 |
| ★ **연타를 삼킨다** — 딸칵 5번 연달아 → 실린 것 **1회**, 파형이 한 번 낸 것과 **완전히 같다**(0.000739 vs 0.000739) | 통과 |
| ★ **끄면 조용해진다** — `setEnabled(false)` 뒤 6번 강제로 불러도 RMS **0.00e+0** | 통과 |
| ★ **저벅저벅이 멈춘다** — `walk(false)` 뒤 `isWalking()` 거짓 · `stopAll()` 뒤 `isGauging()` 거짓 | 통과 |
| 소리가 던져도 게임이 안 멈춘다 | 통과 |
| ★ **`game.html` 부팅 예외 0** | **0건** |

⚠ **부팅 예외 0 은 sfx 가 아직 `game.html` 에 안 붙은 상태에서 잰 것이다.**
그래도 쟀다 — 붙이고 나서 무언가 나면 「내가 깼나」를 가릴 **기준선**이 필요하기 때문이다.
붙이신 뒤에 같은 검사를 다시 돌리시면 그 자리에서 답이 나온다.

★ 잡음은 **씨앗 난수**(20260816)로 만든다. `Math.random()` 을 쓰면 같은 소리를 두 번 렌더해도
파형이 달라져 **검사가 스스로 재현이 안 된다.** `music.js` 가 이미 그것으로 한 번 데었다
(`probe_music §hat` 주석). 재현되지 않는 검사는 검사가 아니다.

**못 잰 것 — 적어 둔다.** 되풀이(저벅저벅·사각사각)는 `setInterval` 로 도는데
`OfflineAudioContext` 는 시계가 안 흘러 **파형으로는 못 쟀다.** 「켜지고 꺼진다」(`isWalking()`)까지만
쟀고, **몇 초 걷는 동안 발소리가 몇 번 나는지는 안 쟀다.** 귀로는 `docs/sfx.html` 에서 확인된다.

## 5. ★ 판단필요 — 박사님/마스터

| 무엇 | 왜 물어보나 |
|---|---|
| ★ **음악을 끈 사람은 딸칵도 못 듣는다** | 스위치를 하나로 했기 때문이다(§3). 「음악은 싫은데 조작감은 있으면 좋겠다」가 흔한 취향이라, 단추를 갈라야 할 수도 있다. `sfx.js` 는 갈라도 안 바뀐다 — **단추 하나와 열쇠 하나**만 늘리면 된다 |
| ★ **실패에도 소리를 낼까** | 지금은 **성공에만** 난다. 「놓지 못했습니다」·「가지는 못했습니다」는 조용하다. 「안 됐다」를 소리로도 말하려면 일곱째 소리(짧은 낮은 「덜컹」)가 필요하고, 그건 박사님이 말씀하신 여섯에 없어서 **안 지었다** |
| **저벅저벅 걸음 간격 420ms** | 분당 143걸음 — 씩씩하게 걷는 속도다. 방뷰의 실제 걸음 애니메이션과 **안 맞춰 봤다**(`room_view.js` 는 안 건드리기로 한 파일이라 클립 길이를 못 쟀다). 발이 땅에 닿는 순간과 소리가 어긋나 보이면 `SPEC.step.loopMs` 하나만 고치면 된다 |
| **사각사각 간격 300ms** | 소리가 250ms 라 50ms 쉬고 다시 난다. 게이지가 길면 조금 단조로울 수 있다 |
