# 창별 상태 — 요약만. 상세는 {창}-to-{상대}.md

> **자기 섹션만 고친다.** 섹션이 나뉘어 있어 git 이 자동 병합해 준다.
>
> ⚠ **파일을 통째로 다시 쓰지 말 것.** 2026-08-01에 실제로 사고가 났다 —
> 한 창이 전체를 재작성하고 다른 창이 그걸 커밋하면서 **두 창의 섹션이 날아갔다.**
> (git 이력에서 복구함) **자기 `## {창}` 블록만 편집한다.**

```markdown
## {내창}
갱신: 2026-08-01 (커밋 abc1234)
완료: (이번에 한 것 2~4줄)
발견: (★다른 창이 알아야 할 것 — 없으면 생략)
대기: (누구의 무엇을 기다리나)
판단필요: (★사용자·plan이 정해야 할 것)
```

★ **"발견"과 "판단필요"가 핵심.** 완료는 커밋 로그에도 있지만 저 둘은 여기 없으면 어디에도 없다.
커밋·**푸시**까지 해야 읽힌다.
