## #7 Day 0 — 시루를 놓은 직후 네 지시를 «한 말»로
지금(한 화면에 넷):
| 자리 | 지금 글 | 코드 |
|---|---|---|
| 배너 | 「빈 시루를 하나 놓았습니다」 / 「[🌱 심기]를 눌러 콩 씨앗을 뿌리세요」 | game.html commitPlace ~13726 |
| 알약 | 「💧 아직 안 심었습니다 — [🌱 심기] 먼저」(226px 에서 잘림) | drawWater ~9574 |
| 칩 | 「놓은 시루에 씨앗을 심으세요」 | quest.js water_siru todo |
| 손가락 | 「사람을 눌러 보세요」 | updateHint ~5700 |
실제 길은 **내 캐릭터 → 시루 옆 바닥(걸어가기) → 시루 위 🌱** 이다(force5). 「[🌱 심기]」 단추는 닫힌 시트 안이라 화면에 없다 — 배너·알약이 «안 보이는 단추»를 가리켰다.

고친 글(넷이 같은 길을 같은 낱말로):
| 자리 | 새 글 |
|---|---|
| 배너 | 「빈 시루를 하나 놓았습니다」 / **「내 캐릭터를 눌러 시루까지 걸어가세요 — 🌱 이 뜨면 눌러 콩 씨앗을 뿌립니다」** |
| 알약 | **「💧 심기 먼저」** (잘리지 않게 짧게 — 무엇을 심는지는 배너·칩이 말한다) |
| 칩 | **「시루까지 걸어가 씨앗을 심으세요」** ← quest.js(이 커밋) |
| 손가락 | 안 고름: **「내 캐릭터를 눌러 보세요」** · 고름: 「여기를 눌러 걸어가 보세요」(그대로) |
- 「사람」 → 후보 ㉠ 사람(지금) · ㉡ 나 · ㉢ 내 캐릭터 ⇒ 고른 것 **㉢**. 까닭: ㉠은 방 안의 «누군가»로 읽힌다. ㉡ 「나를 눌러 보세요」는 손가락(또는 몬이)이 «저를 누르세요»라 하는 말로도 읽힌다. ㉢은 처음 하는 사람이 바로 알아듣고 대사창의 «나»와도 안 부딪힌다.
- 같은 꼴의 다른 글도 같이(같은 «안 보이는 단추» 병):
  - game.html ~10277 「놓은 시루에 [🌱 심기]를 눌러 콩 씨앗을 뿌려 주세요 — 심어야 N칸이 생깁니다.」 → 「시루까지 걸어가 🌱 을 눌러 콩 씨앗을 뿌려 주세요 — 심어야 N칸이 생깁니다.」
  - 무순 ~13754 「[🌱 심기]를 눌러 무 씨앗을 뿌리세요」 → 「재배판까지 걸어가 🌱 을 눌러 무 씨앗을 뿌리세요」
  - 몬스테라 화분 ~13667 · ~14329 「[🌱 심기]를 눌러 몬스테라 씨앗을 심으세요」 → 「화분까지 걸어가 🌱 을 눌러 몬스테라 씨앗을 심으세요」
  - ⚠ 시트가 열려 [🌱 심기] 단추가 «보이는» 판이면 그 단추도 같은 일을 한다 — 말은 걷는 길 하나로 맞춘다(손가락이 그 길을 짚으니까).

## #8 「할 일이 가려졌습니다」 — 말과 자리
지금: 시트가 열려 목표를 덮으면 손가락이 켜진 레일 탭을 짚고 「할 일이 가려졌습니다 — 한 번 더 누르면 닫힙니다」(game.html ~4219 · ~6141 · ~6155). 그 말풍선이 오른쪽 위 「📜 할 일」 칩을 83~95% 덮어, 막 바뀐 칩 글이 안 보인다. 「할 일」이 칩인지 방 안의 일인지도 모른다.

고친 글: **「한 번 더 누르면 닫힙니다」**
- 후보 ㉠ 「시트를 닫으세요 — [식물]을 한 번 더」(마찰 문서) · ㉡ 「[{탭}]을 한 번 더 눌러 닫으세요」 · ㉢ 「한 번 더 누르면 닫힙니다」 ⇒ 고른 것 **㉢**. 까닭: 손가락이 이미 그 탭 «위»에 있다 — 탭 이름을 또 말할 까닭이 없고, «시트»는 개발 낱말이며, 탭 이름을 끼우면 조사(을/를)가 탭마다 갈린다. 「할 일」 낱말은 칩 이름이라 여기서 안 쓴다.
- 자리: 말풍선 사각형이 `#questChip` 사각형과 **겹치면** 말풍선을 탭 «아래»로 내린다(placeHintAt 의 옆 → 아래). 아래도 겹치면 왼쪽. ⛔ 칩을 옮기거나 가리지 않는다 — 칩은 퀘스트가 바뀌는 그 순간에 읽혀야 하는 글이다(#8 의 알맹이).
- 세 자리(~4219 hintAtPoint · ~6141 · ~6155)가 같은 글을 쓴다 — 한 상수로 묶을 것.

## #14 「방」 탭 — Day 0 에 «설정판»이 열림
지금: 「방」 탭에 화면 밝기 아래 「집과 자리」(방 [반지하 (최악)▾] · 식물등 [0개 (자연광만)▾] · 점등시간 [12] · 포인터 이동)와 「개발자 설정」이 그대로 보인다(game.html ~2590 정적 마크업). 집을 바꾸고 등을 공짜로 켤 수 있어 «반지하 먼저»·«등은 퀘스트로»가 새 나간다.

고침: **「방」 탭엔 화면 밝기만.** 「집과 자리」·「개발자 설정」은 통째로 검수 탭(D11 로 숨는 곳)으로 옮긴다.
- 후보 ㉠ 통째로 검수로 · ㉡ 점등시간만 등 단 뒤 「방」에 남김 ⇒ 고른 것 **㉠**. 까닭: 마찰 문서의 고침 그대로이고, 점등시간이 지금 판에서 «사람이 고르는 손잡이»인지(전기값·빛 셈에 걸리나) plan 이 아직 모른다. ⇒ ㉡은 [core] 가 «점등시간이 판에 걸린다»를 확인하면 다음 판에 다시 본다(그때 낱말은 「등 켜는 시간」).
- 검수 탭으로 간 뒤에도 글 두 개는 고친다(검수자도 사람이다): 「반지하 (최악)」 → 「반지하」 · 「0개 (자연광만)」 → 「0개」.

## ★ 덧붙임 (core 40bd1392 뒤) — 「사람」을 끝까지 「내 캐릭터」로
core 가 #7 을 넣으며 쪽지 walkTip 제목만 맞추고 물었다: 본문·조작 안내판까지 바꿀지.
⇒ **바꾼다.** 한 화면에서 손가락은 「내 캐릭터」, 쪽지는 「사람」이라 하면 둘이 다른 것으로 읽힌다. 처음 한 번은 «내 캐릭터», 같은 글 안 둘째부터는 «캐릭터».
| 자리 | 지금 | 새 글 |
|---|---|---|
| 조작 안내판(game.html ~4393 · stage) | 「사람을 누르면 → 바닥을 눌러 걸어갑니다」 | 「내 캐릭터를 누르면 → 바닥을 눌러 걸어갑니다」 |
| 쪽지 walk 제목(~5211) | 「사람을 골랐습니다」 | 「내 캐릭터를 골랐습니다」 |
| 쪽지 walk 본문 | 「… 사람을 <b>잡고 끌어도</b> 됩니다 …」 | 「… 캐릭터를 <b>잡고 끌어도</b> 됩니다 …」 |
| 쪽지 walkTip 본문(~5222) | 「사람을 누르면 <b>이동 모드</b>가 켜지고 …」 | 「내 캐릭터를 누르면 <b>이동 모드</b>가 켜지고 …」 |
