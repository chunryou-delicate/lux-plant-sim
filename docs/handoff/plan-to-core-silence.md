## 1-2 ★ 무엇을 먼저 하라고 말하나 — **돈이다**

*"둘 다 모자라"* 로 끝나면 **침묵과 같다.** 그러니 **순서를 말해야 한다.**

**돈을 먼저 말하는 까닭 둘:**
1. **무늬는 기다리면 온다** — 가을에 확정 무늬가 있다(`varieGrantOpensDay`). **돈은 안 기다리면 안 온다.**
2. ★ **무늬를 얻으려 해도 돈이 든다** — 무늬는 **빛**이 정하고 빛은 **등**이고 등은 **돈**이다.
   ⇒ **돈이 무늬의 앞에 있다.** 순서가 뒤집히지 않는다.

**그리고 돈의 답은 「시루」다** — 내 실측:
```
시루 1개  → 모자란 돈 중앙값이 **이사비 전액**(지갑이 사실상 0)
시루 16개 → 200일에 2,218,400원으로 이사비를 넘긴다
```

## 1-3 문안 — **두 갈래**. 둘 다 채워지므로 이번엔 침묵이 안 생긴다

### ㉠ 시루가 적을 때 (기본)
```
몬이   ─ 둘 다 멀어. 돈도, 무늬도.
자취생 ─ …뭐부터 해야 돼.
몬이   ─ 돈. 무늬는 기다리면 와. 돈은 안 그래.
몬이   ─ 시루를 늘려. 하나로는 안 모여.
```

### ㉡ 시루가 이미 넉넉할 때
```
몬이   ─ 둘 다 멀어. 근데 채소는 잘 돌고 있어.
자취생 ─ 그럼 뭐가 문제야.
몬이   ─ 빛. 무늬는 밝은 데서 나. 등을 놓을 자리를 봐.
```

⚠ **갈림은 [core] 가 정한다** — 나는 「시루가 적다/넉넉하다」로만 적는다.
  **숫자를 대사에도 이 문서에도 안 박는다**(§2.8 · 이사비가 3벌인 자리를 오늘 봤다).
  ⇒ 문턱은 **퀘스트가 이미 아는 값**을 쓰면 된다 — `siru5_cycle5` 가 다섯을 말한다.

★ **이번 갈래는 삼항이어도 안전하다** — **둘 다 채워지기 때문**이다.
  ①의 병은 삼항이 아니라 **「그 밖의 경우」를 비워 둔 것**이었다.

# ② §D4 첫 월세 — ★ **①과 「한 뿌리」는 아니다. 다만 같은 병이다**

총괄 물음: *"둘이 같은 자리에서 나오면 고치는 곳도 하나일 수 있다."*
⇒ **재 봤다. 고치는 곳은 다르다.**

| | ① 둘 다 모자랄 때 | ② 첫 월세 |
|---|---|---|
| 어디 | `loop.js §③` 삼항 | `tutorial.js:622` 조건식 |
| 무엇이 | `null` 로 떨어져 **갈래가 없다** | `ts.day === nextDueDay − 7` 이 **−6일**을 가리킨다 |
| 고치는 법 | **셋째 갈래를 만든다** | **첫 회를 따로 본다** |

⇒ **파일도 다르고 식도 다르다. 한 커밋으로 못 묶는다.**

## ★ 그런데 **병은 같다 — 「경계를 안 봤다」**

```
① 둘 다 빈손    ← 경계
② 첫 회         ← 경계
```
둘 다 **가운데 경우는 잘 도는데 끝이 빠졌다.** 그리고 **둘 다 조용히 빠진다** —
던지지도 않고 빨갛지도 않고, **그냥 말이 안 나온다.**

⇒ ★ **그래서 같이 봐야 하는 건 「고치는 곳」이 아니라 「찾는 법」이다:**
> **말을 내는 자리마다 「이 조건이 한 번도 참이 안 되는 판이 있나」를 물어라.**
> ②는 `−6일` 이라 **원리적으로 한 번도 안 참**이었고, ①은 `null` 이라 **갈래 자체가 없었다.**

⚠ 그리고 ②는 **박사님이 08-09 에 일부러 그렇게 두신 것**이다(`tutorial.js:615` —
  첫 달 유예를 폐지하며 *"예고의 뜻이 「또 돌아온다」로 바뀌었다"*).
  ⇒ **예고를 첫 회로 당기지 마라.** 내 낮 판단(`plan-fail-triage`)은 그대로다 —
    **고칠 곳은 `tutorial.js` 가 아니라 서막 대사**이고, 그건 **내 몫**이다.
