# 원룸 — **어디까지 됐나** (2026-08-23 밤 · plan)

> 박사님 지시: *"원룸부분 초반 스토리라던지 퀘스트라인이라던지 **기획 및 제작까지** 해두도록"* ·
> *"**원룸초반 가이드는 삽수 위주로** 가면 좋을거같어"*
>
> ⇒ 여러 파일에 흩어진 것을 **한 곳에서 보게** 모은다. **상세는 각 파일에 그대로 둔다.**
> ⚠ **방 데이터·조도·값은 하나도 안 건드렸다**(「반지하 먼저」). **이야기·퀘스트·대사까지**다.

---

## 0. ★ 한 줄 — **원룸은 「늘리는 법을 배우는」 판이다**

| | 반지하 | **원룸** |
|---|---|---|
| 무엇을 배우나 | **한 그루를 지켜 내는 것** | ★ **여러 그루로 늘리는 것** |
| 적 | **어둠** | ★ **시간**(뿌리 20일 · 혹 20일) |
| 빛이 무엇인가 | **살리는 것**(어두우면 안 자람) | ★ **값을 정하는 것**(등급이 갈림) |
| 자리 | 하나뿐 — **어디 두느냐**가 전부 | 는다 — **몇 개를 굴리느냐** |

★ **그래서 삽수가 다리다.** 박사님 *"원룸 가이드는 삽수 위주"* 가 그 말이다.

## 1. ✅ **되어 있는 것** — 붙일 수 있는 형태로 다 썼다

| 무엇 | 어디 |
|---|---|
| **퀘스트 다섯 줄** — id · `opens` · `done` · `teaches` 까지 | `plan-oneroom-questline.md §1` |
| **이사 직후 세 박자** ㉠넓어졌다 ㉡늘릴 수 있다 ㉢시간이 든다 | 〃 `§2` |
| **③ 대사** — *"이제 하나 잃어도, 하나 남아"* | 〃 `§2-5` |
| **⑤ 대사** — *"저 방에서 빛은 살리는 거였어. 여기선 값을 정해"* | 〃 `§2-6` |
| **②의 중간 한 줄** — *"뿌리 나왔네. 이제 혹만 나면 그루야"* | 〃 `§1-②` |
| **잡담 — 계절 셋 · 날씨 둘** | 〃 `§5-1` |

★ **순서가 뜻을 만든다** — ④「급하면 판다」가 ③「두 그루가 된다」 **뒤**다.
  파는 것을 먼저 배우면 삽수가 **「돈 버는 것」**으로 굳고,
  늘리는 것을 먼저 배우면 파는 것이 **「늘릴 것을 포기하는 것」**이 된다. **그게 급전의 뜻이다.**

## 2. ⏸ **칸을 기다리는 것** — 셋. **[core] 에 넘겼다**

```
movedOut          원룸 줄이 「이사 뒤에」 열리려면 필요        → 퀘스트 다섯 전부
cuttingSaleCount  ④가 「민무늬 포함」 판 적을 본다             → 퀘스트 ④
                  (varieSaleCount 는 무늬만 센다)
cuttingStage      삽수 잡담의 조건                            → 잡담 넷 · ★ §B3
```

★ **셋 다 새 어휘가 아니다** — `S.tutorial.movedOut` 과 `cuttings[].status`(`bag · rooting ·
  rooted · node · established · dead`)가 **이미 있다.** **꺼내 주기만 하면 된다.**

### ★★ `cuttingStage` 가 제일 값지다 — **내 설계의 구멍을 메운다**
퀘스트 ②「뿌리를 본다」는 **손짓이 아예 없는 20일**이라 내 어색함 문턱 §B3(한 줄이 열흘 넘게
안 바뀜)에 **정면으로 걸린다.**
⇒ **잡담이 그 20일을 채운다. 퀘스트는 안 움직여도 말은 움직인다.** 문안은 미리 써 뒀다(§5-0).

⚠ **없으면 못 쓴다** — 조건을 걸 칸이 없으면 **늘 참이거나 늘 거짓**이 된다.
  **오늘 `move_short_*` 가 그랬던 자리다.**

## 3. ⏸ **박사님 결정을 기다리는 것** — 셋. **한 묶음이다**

```
① 삽수를 튜토에서 「민무늬 팔기만」 막나, 「전부」 막나
   ⚠ 전부면 이사 게이트 둘째 축(무늬 삽수 판 적)이 안 열려 **튜토가 안 끝난다**
② 팔 수 없게 된 삽수는 죽지도 않게 하나
   ★ 팔기를 막았으면 죽는 것도 막아야 한다. 안 그러면 길을 막아 놓고 벌을 준다
③ first_cut(물에 꽂아 본다)을 원룸으로 옮기나  ← 나는 옮기는 쪽
```
⇒ ★ **셋이 한 결정이다.** 따로 물으면 **하나만 통과해서 어중간해진다.**
  근거: `plan-night-cutting-block.md`

## 4. ⛔ **안 한 것 · 안 할 것**

| | 까닭 |
|---|---|
| **방 배치 · 조도 · 자리 수** | 박사님 *"반지하 먼저"*. **원룸 방 데이터를 아직 못 쓴다** |
| **월세·지출 잡담** | 원룸 월세가 **정본에만 있고 게임은 20만을 뗀다**(`oneroomRentWon: null`). **숫자가 갈린 자리라 말을 만들면 거짓이 된다** |
| **값** | 하나도 안 움직였다 |
