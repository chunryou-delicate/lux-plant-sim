## 0. 먼저 — 둘은 **한 뿌리**였다

박사님이 잡으신 둘이 따로가 아니었다.

| 화면에 보인 것 | 실제로 난 일 |

## 1. ㉠ 캐릭터가 사라진다 — 재현 조건을 **찾았다**

### 재현 조건

> **「방」 탭에서 가구를 한 칸이라도 옮기면** 자취생이 사라진다. **100%다.**

등을 옮기거나 방을 바꿔도 같다. 셋 다 `assemble()`(방 재조립)을 타기 때문이다.
게임에서 이 길을 부르는 데는 `game.html:9536` 의 `roomView.commitFurnitureAt` 하나다.

실측 (`probe_char_moni.mjs` C절 · 옛 코드):

```
C. 가구를 한 칸 옮긴다 (banjiha-bed → x -1.425)
   전 jachwi·moni  →  후 moni     ★ 사라진 것: jachwi
```

사진: `img/char/A_boot_before.png`(자취생 있다) → `img/char/C_after_furnmove_before.png`(몬이만 남았다).
색 가짓수 9,626 / 11,902 — 둘 다 살아 있는 사진이다(§2.9 ③).

### 원인 — 순번(charSeq)이 **하나**였다

`setCharacter()` 는 「나보다 나중에 부른 게 있으면 내 것은 버린다」를 `charSeq` 하나로 셌다.
그런데 **자취생과 몬이는 서로 다른 자리**라 나중 것이 앞 것을 무를 이유가 없다.

`assemble()` 은 방을 비우면서 있던 사람을 기억했다가 **`await` 없이 둘 다** 다시 부른다
(`room_view.js:1095`). 그래서

```
setCharacter('jachwi') → my=1
setCharacter('moni')   → my=2,  charSeq=2
… 자취생 GLB 가 다 실린 뒤 →  my(1) !== charSeq(2)  →  자취생을 버린다
```

가 **반드시** 성립한다. 늦게 실려서 진 게 아니라 **구조적으로 늘 진다.**

⚠ 이게 조용했던 이유: **실패가 아니라 성공한 뒤에 버리는 것**이라
`.catch` 에도 안 걸리고 콘솔에도 한 줄이 안 났다. 부팅 JS 예외는 **내내 0건**이었다.

★ `game.html:7781` 에 *"★순차로 세운다. 동시에 부르면 둘이 자리를 겹쳐 잡아 하나만
남는다(실측으로 확인)"* 라고 이미 적혀 있었다. **증상은 전에 봤는데 원인을 못 봤고,
화면 쪽만 줄을 세워 두었다.** 방 재조립 쪽은 그대로 남아 있었다.

### ★ 짚어 주신 `nudgeIfOccluding` 은 범인이 아니었다 — 재서 지웠다

- 화분이 없으면 **아예 안 돈다**(`if (!built || !plants.size) return 0`). 사라진 장면 다수가 화분 0개인 구간이다
- 밀어내는 자리는 `nav.nearestFree` → `nav.path` 를 거친다. 둘 다 **방 안쪽 격자**에서만 답을 낸다 — 화면 밖·벽 속으로는 못 보낸다
- `settleCam._nudge`(시점을 돌린 뒤) 도 같은 함수라 같이 무관하다

⇒ **못 밀어낸다.** 다만 아래 §5 에 한 줄 남길 것이 있다.

### 고친 것

1. **순번을 자리마다 센다** — `charSeq` 를 `Map`(key → 번호)으로 바꿨다.
   `setCharacter(null)`(전부 치우기)은 오는 중인 것까지 무르도록 두 자리를 다 올린다.
2. `assemble()` 의 다시 세우기를 **줄 세웠다**. 순번을 고쳐서 이제 겹쳐 불러도 안 죽지만,
   **몬이는 사람 뒤에 서므로 사람이 먼저**여야 첫 자리가 제자리다.
   `wasHere` 도 사람이 앞에 오게 정렬한다.

실측(고친 뒤): `전 jachwi·moni → 후 jachwi·moni`. 가구 옮기기·겹쳐 부르기 **둘 다 안 사라진다.**
사진 `img/char/C_after_furnmove_after.png`(자취생이 돌아왔다).

```js
root.rotation.y += (Math.PI - root.rotation.y) * Math.min(1, dt * 2);   // ← 늘 π 로만 간다
```

즉 **게임 안에서 몬이가 무언가를 바라본 적은 한 번도 없다.**
박사님이 보신 「바라보면서 이동」은 `assets/characters/mascot_follow_preview.html`
(원안 미리보기)다. 거기서는 `monPivot.rotation.y = atan2(vel.x, vel.z)` 로 **가는 쪽**을 봤다.
그 뜻을 방 뷰로 옮긴 것이 이번 코드다. **새로 만든 것**이다.

### ★ 앞이 어느 쪽인지는 **재서** 정했다

`tools/_moni_face.html` 로 몬이를 yaw 0·+90·180·−90 으로 나란히 세우고 **+Z 에서** 찍었다.
