| 모드 | 하루 3~4번이면 |

→ **수분 게이지 하나.** 마름 속도가 빠른 작물(콩나물)은 게이지가 빨리 준다.
*"하루 3~4번"*은 **게이지 감소 속도로 표현**하고 행동 횟수로 만들지 않습니다.

```
콩나물   게이지 100% → 0%  까지 약 0.3일   (자주 봐야 함)
관엽     〃                 약 5~7일       (가끔)
```

**이벤트 정지는 "마름 임박"에서만** 겁니다(`time_modes.md` §1 목록).

## ★ 5. 그쪽 발견이 제 계산을 뒤집습니다 — 더 알려주세요

> *"콩나물 시루는 방 슬롯 1칸을 쓰면서 재배 슬롯 15칸을 준다. 방 슬롯 ≠ 재배 슬롯"*

**중요한 지적입니다.** 다만 제 계산은 이미 **시루 단위**였습니다 —
"시루 1개 = 품질100%면 3끼"라서 자취생은 시루 3개 = **방 슬롯 3칸**입니다.
거기까진 어긋나지 않습니다.

**제가 진짜 알고 싶은 건 관엽 쪽입니다:**

```
지금 가정:  포토스 1그루 = 방 슬롯 1칸  →  반지하 10칸 = 10그루
            이 10그루로는 생활비의 48%밖에 못 번다 (자취생 미성립의 원인)
```

→ **번식 중인 삽수(물꽂이)도 슬롯 1칸을 통째로 먹나요?**

물꽂이는 병 하나에 여러 개 꽂는 게 실제 방식이고,
그렇다면 **"번식 중 = 슬롯을 적게 먹는다"**가 되어 자취생 경제가 바뀝니다.

| 만약 | 자취생에 미치는 영향 |
|---|---|
| 물꽂이 병 1칸 = 삽수 6~10개 | ★ **증식 단계가 슬롯을 거의 안 먹는다** → 미성립 문제의 답이 될 수 있음 |
| 물꽂이도 1칸 = 1개 | 지금 계산 그대로. 다른 방향(지출↓·목표↓)으로 가야 함 |

**만들어 두신 용기 중 물꽂이/번식용이 있으면 슬롯 수를 알려주세요.**
없으면 "몇 칸짜리로 만들지"를 제가 정해 드리겠습니다 — 그게 밸런스에 직접 닿습니다.
