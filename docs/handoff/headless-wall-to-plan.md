# 자의 벽 둘 — 「두 번째로 못 짓는다」와 「경계를 통과로 센다」 (2026-08-30 · core)

다음 사람이 또 막힐 자리라 남긴다. 게임 이야기가 아니라 **재는 법** 이야기다.

## 1. 헤드리스는 방을 「두 번째로」 못 짓는다

```
증상  이사한 뒤 원룸이 안 선다. 2분을 기다려도 window.__rv 가 null 이다.
      덮개에는 「방을 그리지 못했습니다 — Cannot read properties of null (reading 'precision')」
```

이사를 **안 하고** 같은 방을 그대로 다시 지어도 똑같다(`tools/probe_remountable.mjs`).
그러니 이사가 깨진 것이 아니다. 헤드리스 크롬(swiftshader)이 WebGL 판을 두 번째로
못 여는 것이다. `remountRoomView` 를 지나는 길은 전부 이 벽에 걸린다.

이 벽에 걸린 채로 잰 수는 값이 아니다. 실제로 그랬다 —
「가구 하나 놓는 데 31,088 ms」는 놓기 값이 아니라 **기다림 고리가 끝까지 돈 값**
(60회 × 500 ms)이었다. 그 판에서는 방이 아예 안 서 있었다.

### 넘는 법 — 다시 짓지 말고 저장하고 새로 켠다

```
이사 → (3D 는 안 선다. 상태만 넘어간다) → localStorage 에 저장 → page.goto 로 새로 켠다
⇒ 새로 켜면 방을 「처음」 짓는 것이라 그 벽을 안 지난다
```

`tools/probe_oneroom_boot.mjs` 가 그 길이다. 그래서 잰 것:

| 물음 | 답 |
|---|---|
| 이사한 원룸이 서나 | 선다 — 7,779 ~ 8,190 ms |
| 가방 아홉이 그대로 있나 | 있다 (저장·복원이 돈다) |
| 거기서 가구 하나 놓으면 | 140 ~ 238 ms · 3D 에도 선다 |

⚠ 남는 것: **`remountRoomView` 를 지나는 길 자체**는 여전히 못 잰다.
실제 브라우저에서 봐야 한다 — 박사님이 원룸을 해 보실 때 그것부터 봐 주시면 된다.

### 재는 자를 쓸 때 지킬 것

- 재기 **전에** `window.__rv` 가 참인지 본다. 널이면 그 판은 무효다.
- 기다림 고리가 **끝까지 돌아서** 빠져나온 것인지, 조건이 맞아서 빠져나온 것인지
  구분해서 찍는다. 안 그러면 고리의 천장을 값으로 읽는다.
- 헤드리스 엔진(vm + three · 조도만)은 이 벽이 없다. 여러 번 지어도 선다([House] 확인).
  브라우저(CDP)만 한 번이다.

## 2. 경계값을 「통과」로 세는 자

```
증상  가방에서 꺼낸 가구가 벽을 뚫고 반쯤 나가 섰다
까닭  자리를 { x: 방너비/2, z: 방깊이/2 } 로 줬다. 방은 한가운데가 원점이라
      쓸 수 있는 값이 |x| ≤ w/2 다(place.js §inRoom) — 그러니 그 값은
      한가운데가 아니라 「벽에 붙은 금」이다
⇒ 그리고 검사가 그것을 통과시킨다. 경계는 ε(1e-6) 로 봐주기 때문이다
   (창턱처럼 경계에 정확히 놓이는 자리를 안 떨구려고 그렇게 돼 있다. 그 자체는 옳다)
```

주석은 「방 한가운데」라고 **말하고** 값은 구석을 **가리키고** 있었다.
말과 값이 갈렸는데 검사가 통과시켜서 아무도 안 봤다.

### 조인 자 — 가운데 점이 아니라 덩치를 본다

`tools/probe_oneroom_boot.mjs §④` 가 놓인 가구마다 폭·깊이를 회전각만큼 돌려
네 귀가 방 안인지 본다.

```
hw = w/2·|cos| + d/2·|sin| · hd = w/2·|sin| + d/2·|cos|
넘은 길이 = max(|x| + hw − 방너비/2, |z| + hd − 방깊이/2)
```

⚠ 코어(`inRoom`)는 안 고쳤다. 가운데 점만 보는 것이 틀린 규칙은 아니다 —
가구는 벽에 붙여 놓는 것이고, 사람이 끌어다 놓는 자리는 3D 가 따로 본다
(`room_view.furnitureFit`). 다만 **화면이 자동으로 세워 주는 자리**가 벽을 넘으면
그것은 화면 몫의 탈이고, 이 자가 그것을 잡는다.

### 자를 조였으면 자가 잡는지도 재야 한다

같은 자에 한 줄 더 붙였다 — 옛 자리를 그 가구에 대 보고 몇 m 넘는지 셈한다.

```
[잰 것] 싱글 침대 · 옛 자리 (3, 2.5) · 원룸 6×5
        ⇒ 벽을 넘었을 길이 1.00 m ⇒ 「★ 자가 잡는다」
```

조여 놓고 안 재면 조인 줄 모른다.
