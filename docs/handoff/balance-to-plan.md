### ② 무순 회전분 — 표를 갈랐다

`cropKindSavedWon = [3,000 · 2,000 · 1,000]` **한 표**가 두 일을 겸하고 있었다.
그래서 `[1]` 을 2,800 으로 바꾸면 **콩나물 겹침 벌**까지 같이 움직인다. 그래서 축을 갈랐다:

```
작물 기본값   CROP_KINDS[i].savedWonPerCycle   콩나물 3,000 · 무순 2,800
질림 배율     CROP_TIRED_MULTIPLIER            첫째 1 · 둘째 2/3 · 셋째 1/3 · 넷째부터 0
실제 절감  =  작물 기본값 × 질림 배율 × (품질 끼니 / 3)
```

★ **질림은 여전히 한 표다.** 2026-08-04 확정(*"둘을 다른 표로 만들면 안 된다"*)이 안 깨졌다.
가른 것은 「질림」이 아니라 「작물마다 다른 값」이고, 그건 애초에 질림이 아니었는데 같은 표에
얹혀 있던 것이다. `harvestDays`·`seedWonPerPot` 이 이미 `CROP_KINDS` 로 옮겨져 있었으니
회전분이 그 옆에 앉은 것이다.

⚠ **배율은 0.667·0.333 이 아니라 2/3·1/3 이다.** 인계에 적힌 소수를 그대로 곱하면
콩나물 둘째가 2,000 이 아니라 **2,001원**이 되어 2026-08-04 확정값이 1원 어긋난다.
뜻하신 것은 정확한 삼분의 이·삼분의 일로 읽었다.

**결과 — 콩나물은 한 푼도 안 움직였고 무순만 내려갔다:**

| | 첫째 | 둘째 | 셋째 | 넷째 |

| 콩나물 같은 날 겹침 | 3,000 | 2,000 | 1,000 | 0 |
| 무순(2종째라 한 칸 밀려 시작) | 1,867 | 933 | 0 | — |

## 2. ★ 다른 창이 알아야 할 것

### ★★ 시작돈 1,500,000원 = 이사비 1,500,000원 — **셋이 동시에 터졌다**

`moveOutCostWon` 이 1,500,000원이라 **시작돈과 정확히 같아졌다.** 그래서
`canMoveOut` 의 **돈 조건이 첫날부터 참**이고, 남은 관문은 배움 넷뿐이다.
재는 도중에 이것이 세 곳에서 한꺼번에 드러났다:

| 어디서 | 무슨 일이 | 실측 |
|---|---|---|
| 대사 검사 경로 B | **여름에 이사가 끝난다** | 게임 48일 · 여름 62일째 |
| 확정 무늬 | `varieGrantCheck` 가 **첫날부터 닫혀 있다** | 사유: *"다 팔면 1,500,000원 — 이사 자금에 닿습니다"* |
| ★ 튜토 목표 줄 | **「돈을 모으는 단계」가 아예 없다** | 배움 넷을 채우는 순간 `learn` → **`ready`**. `money` 단계를 한 번도 안 지난다 |
| 재현 하네스 | **모주가 도착한 날 12,000원에 팔린다** | 현금 1,492,700 + 어린 포기 12,000 ≥ 1,500,000 |

- 앞 셋은 **게임 규칙 그대로**다. 하네스 탓이 아니다.
  ⇒ 튜토가 「이사 자금 N원 남았습니다」를 **한 번도 안 말한다.**
- 넷째만 재는 자의 문제였고 고쳤다(§3).

⇒ **plan 판단 필요.** `plan-2026-08-09-decisions §4` 가 막으려던 것이 정확히 이것이다 —
「빨리감기를 없애고 가을·식물등·겨울을 실제로 만나게 한다」. 지금은 **여름에 끝난다.**
후보 셋:

| 후보 | 뜻 | 값 |
|---|---|---|
| ㉠ 이사비를 올린다 | 시작돈이 이사비의 일부만 되게 | `moveOutCostWon` > 1,500,000 |
| ㉡ 시작돈을 조금 내린다 | 「석 달」을 지키면서 문턱은 남긴다 | 1,300,000~1,400,000 |
| ㉢ `canMoveOut` 에 계절 관문을 단다 | 확정 무늬처럼 「가을부터」 | 돈은 그대로 |

⚠ 지금 `characters.json` `jachwi.goalValue` 도 1,500,000원이라 **같이 움직인다.**

### ★ 원룸으로 이사하면 하루 살림이 1,667원이 된다

`dailyCashOutWon` 은 원룸에서도 반지하의 `dailySpendWon` 을 쓰고 월세 몫만 갈아 낀다.
반지하 월세를 내린 결과:

```
하루 지출 16,667  −  원룸 월세 450,000 / 30 (= 15,000)  =  1,667원
```

남는 1,667원이 공과·전기·식비 **전부**다(식비만 7,500원인데). 위험선이
「원룸 월세 월 60만」에서 **「월 50만」**으로 내려왔고, 실제 원룸 값이 45만이라
여유가 1,667원밖에 없다. **원룸이 자기 `dailySpendWon` 을 갖는 일이 이제 미룰 수 없다**
(`docs/oneroom.md §2` 의 ⏸ 가 실제 위험이 됐다).

### 손익분기가 **두 작물 반대로** 움직였다

| | 전 | 후 | 왜 |
|---|---|---|---|
| 콩나물 | 23.3% | **16.7%** | 씨앗이 싸졌다 (700 → 500원) |
| 무순 | 30.0% | **32.1%** | 회전분이 내려갔다 (2,000 → 1,867원) |

한쪽만 보고 「다 내려갔다」로 읽으면 안 된다.

### 곳간 하루 상한이 5,000 → **4,867원**

2종 합계가 `3,000 + 2,000 = 5,000`(끼니 상한과 정확히 같았다)에서
`3,000 + 1,867 = 4,867` 로 내려갔다. ⇒ **끼니 상한이 더는 안 이긴다**(`cropCapBinding: false`).
`game.html` 2886줄 주석 *"3,000+2,000 이 정확히 자취생 2끼 = 5,000원이다"* 가 이제 틀린 말이다.

| 대사 | 전 | 후 | 근거(실측) |

| `rentFirst` | 두 달 / 세 달 | **석 달 / 넉 달** | 작물 없이 **90일** · 곳간 상한까지 **121일** |

## 5. ★ 판단이 필요한 것

### ① ★★ 씨앗·시루 — 「실구매」인가 「정가」인가

넣은 것은 **실구매** 쪽이다(지시대로). 두 해석의 차이:

| | 실구매 해석 (넣은 것) | 정가 해석 |
|---|---|---|
| 콩 씨앗 정가 | 350원 | 500원(지금과 같다) |
| 콩 씨앗 실구매 | **500원** | 700원(지금과 같다) |
| 시루 정가 | 3,550원 | 5,000원(지금과 같다) |
| 시루 실구매 | **5,000원** | 7,000원(지금과 같다) |
| 콩나물 손익분기 | 16.7% | 23.3% |
| 시루 한 개 회수(85%) | 3회전 15일 | 4회전 20일 |

⇒ **정가 해석이면 아무것도 안 바뀐다.** 지금 `listWon` 이 마침 500·5,000 이라
「500 으로 하자」가 이미 그 값이다. 박사님이 「싸게 해 달라」는 뜻이셨다면 실구매 쪽이 맞다.

### ② ⚠ 시루 정가 3,500 은 **틀린 답이다** — 산수를 정정한다

인계문에 *"실구매 5,000 → 정가 3,500"* 이라 적혀 있는데 **재 보니 아니다.**

```
3,500 × 1.4 = 4,900  →  4,900 은 이미 100원 단위라 올림이 아무 일도 안 한다  →  실구매 4,900원
```

실구매 5,000원을 내는 정가는 **3,500 < L ≤ 3,571** 구간이고, 그 안의 고른 값 **3,550원**을 넣었다.
(콩 씨앗 350 은 맞다: 350 × 1.4 = 490 → 올림 500.)
⇒ **3,550 이 마음에 안 드시면 시루 실구매를 4,900원으로 두는 쪽도 된다**(그때 정가는 3,500).

### ③ ★★ 시작돈 = 이사비 (§2) — 여름에 튜토가 끝난다

### ④ 원룸 하루 살림 1,667원 (§2)

### ⑤ 「두 달, 밥값 아끼면 세 달」 — 실측이 90/121일이라 **석 달/넉 달**이다

대사는 실측 쪽으로 옮겼다. 「두 달」이라는 말을 지키시려면 값을 그쪽으로 맞춰야 한다.
