# B. ⏸ **사용자 답을 기다리는 것**

## B-1 선반 — **1층** (ⓐ/ⓑ 결정 대기 · §9 묶음 3)
```
몬이   ─ 등은 샀는데 자리가 그대로야.
자취생 ─ 밝아졌잖아.
몬이   ─ 밝아진 데가 허공이야. 올려놓을 게 없으면 소용없어.
몬이   ─ 선반을 창턱 밑에 붙여. 그 위에 등을 올리고.
```
· **때**: 등을 산 뒤 며칠 지나도 칸이 안 늘 때(`MONSTERA_LAMP_HINT_DAYS` 결)
· **ⓑ(사서 놓기)면 앞에 한 줄**: *"선반이 있어야 해. 상점에 있어."*
· ★ **붙는 검사**: 놓은 뒤 배너 — *"키울 수 있는 자리가 늘었습니다."* **없으면 또 「안 변했다」다**

## B-2 선반 — **2층 · 등을 어디 두나** (1층 뒤)
```
몬이   ─ 등, 옮길 수 있는 거 알아?
자취생 ─ 옮기면 더 밝아져?
몬이   ─ 어떤 자리는. 근데 딴 데가 어두워져.
몬이   ─ 뭘 어디 놨는지에 따라 달라. 재 보는 수밖에 없어.
```
· **때**: **책상 위에 무언가를 처음 놓은 순간**(그 전엔 창턱이 그냥 낫다)
· ⚠⚠ **답을 주지 않는다.** 1층은 답을 주고 2층은 **선택이 있다**만 준다
· ★ **붙는 검사**: **옮기기 전에 「이 자리면 자랄 칸이 몇 개」 미리보기.** 없으면 던진 것이다

## B-3 급전 — **원룸으로 옮긴다** (삽수 묶음 셋 결정 대기 · §9 묶음 2)
```
몬이 ─ 팔 수는 있어. 근데 그건 다음 잎을 미리 쓰는 거야.
몬이 ─ 급하면 써. 급하지 않으면 붙여 둬.
```
⚠ **「손해」라고 안 쓴다.** 급전은 손해가 아니라 **값**이다. 손해라 하면 그냥 나쁜 선택이 되고,
  **그러면 안 만든 것과 같다.**
· 안내판(`[?]`) 열째 줄: *"삽수 — 늘리는 데 씁니다. 급하면 팔 수도 있는데, 모주 값이 그만큼 줍니다."*

# C. 🏠 **원룸이라 나중** — 방 데이터는 아직 못 쓴다. **말만** 준비됐다

## C-1 이사 직후 세 박자
```
㉠ 넓어졌다 (이사 이튿날)
   자취생 ─ 자리는 늘었는데.
   자취생 ─ …놓을 게 하나뿐이네.

㉡ 늘릴 수 있다 (퀘스트 ①이 열릴 때)
   몬이 ─ 하나를 둘로 만드는 법이 있어.
   몬이 ─ 잎 한 장이 붙은 마디를 잘라서, 물에 꽂아.
   몬이 ─ 아프지 않아. 원래 그렇게 늘어나는 애야.

㉢ 시간이 든다 (퀘스트 ②가 열릴 때)
   몬이 ─ 뿌리가 나와도 아직이야.
   몬이 ─ 혹이 나야 새 잎이 서. 그때까진 그냥 두는 게 일이야.
```
★ ㉡의 *"아프지 않아"* — **기른 것을 자르라는 말이라 거리낌이 생기는 자리**다.
★ ㉢의 *"그냥 두는 게 일이야"* — **이 게임에서 기다림을 일로 부르는 첫 줄**이다.

## C-2 퀘스트 ② 중간 — **뿌리가 났을 때 한 줄**
```
몬이 ─ 뿌리 나왔네. 이제 혹만 나면 그루야.
```
⚠ **퀘스트를 쪼개지 않는다.** ②는 여전히 `node` 에서 닫히고 **말만** 붙는다.
★ 기다림의 길이는 그대로인데 **「아무 일도 안 일어나는 길이」가 반으로 준다.**

## C-3 퀘스트 ③ — **④의 뜻을 여기서 만든다**
```
자취생 ─ 얘가… 이제 따로 사는 거지?
몬이   ─ 응. 뿌리도 잎도 제 거야.
몬이   ─ 하나였을 때랑 뭐가 다른지 알아?
몬이   ─ 이제 하나 잃어도, 하나 남아.
```
★★ **늘린다는 건 「많아지는 것」이 아니라 「안전해지는 것」**이다.
  그러면 ④(B-3)에서 파는 것이 **「그 안전을 되파는 것」**이 된다. **③ 없이는 그냥 거래다.**
⚠ ③에서 **값을 말하지 않는다.** ③은 셈이 아니라 **처지**를 말한다.

## C-4 퀘스트 ⑤ — **두 방을 한 줄로 가른다**
```
몬이   ─ 뿌리를 어디서 내리느냐가 무늬를 정해.
자취생 ─ 어차피 뿌리는 나잖아.
몬이   ─ 나긴 나. 근데 어두운 데서 난 건 어두운 값이야.
몬이   ─ 저 방에서 빛은 살리는 거였어. 여기선 값을 정해.
```
★★ 반지하에서 빛은 **살리는 것**이었고, 원룸에서 빛은 **값을 정하는 것**이다.
  ⇒ **배운 것을 안 버리게** 한다 — *"빛이 중요하다"* 는 그대로 맞고 **무엇을 정하느냐가 바뀐 것**이다.
⚠ **문턱을 대사에 안 적는다.** *"어두운 데"·"밝은 데"* 로만.
