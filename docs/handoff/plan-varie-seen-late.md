# 무늬 — 「말하는 날」과 「보이는 날」이 다르다
2026-09-07 · [plan] · [leaf] 걸어서 잰 것 위에 · ⛔ 설계는 «안 고친다» · 코드 0 · 값 0

---
## ⓐ [leaf] 가 잰 것 — ★ 「무늬는 «나오는데» «어느 무늬인지»가 안 나온다」
```
같은 세이브 · 같은 잎 · 창턱 · 중간잎 · 유효 90 · Day 64 ⇒ 바꾼 것은 «등급 한 낱말»뿐(sanban ↔ fullmoon)
⇒ ★ 다른 화소 «0.0000%» — 등급 19장이 «한 장»으로 그려진다. 값은 화면 «직전»까지 온다
✔ 다만 무늬 «자체»는 뜬다 — ★ «중간잎»에서 짙은 잎에 흰 점박이가 또렷하다. ⛔ «어린잎»에서는 안 보인다
⛔ 아직 안 본 것 — «성숙잎»(스킨 104장) · 작은 화면 · 나머지 등급 둘
```
> ## ⇒ ⛔ **설계(「전백 → 산반은 배신 · 흔한 그림 → 풀문은 선물」)를 «안 고친다».**
> ## ⇒ 성숙잎에서 갈리면 그 설계는 «그대로 산다» — 다만 «늦게» 사는 것이다. [leaf] 말이 옳다.

## ⓑ ★ 그런데 «내 마당»에 걸리는 것이 하나 있다 — [잰 것]
```
loop.js:447  「✨ 새 잎 «한 장»이 무늬로 나왔습니다」 ⇒ ★ 무늬 잎이 «날 때» 뜬다 ⇒ ⇒ 그 잎은 «어린잎»이다
[leaf]      ⛔ 어린잎에서는 무늬가 «안 보인다»
dialogue.js:535  자취녀 surprise 「…새로 난 잎에 무늬가 «섞였어».」  ⇐ ★★ 사람이 «본» 것처럼 말한다
```
> # ⇒ ⛔ **「무늬야」라고 말하는 «그날», 그림에는 «아직 없다».**
> ## ⇒ 오늘 여러 번 난 「화면이 «자기와» 어긋난다」인데 ⇒ ★ 이번엔 «사람이 못 본 것을 «봤다»고 말하는» 꼴이라 더 세다.

## ⓒ ✔ 고칠 것은 «설계»가 아니라 «누가 먼저 아나»다 — ★ 몬이가 먼저 안다
```
지금
  자취녀 surprise 「…새로 난 잎에 무늬가 섞였어.」        ⇐ 사람이 «먼저 봄» — ⛔ 못 본다
  몬이 curious   「무늬야. 무늬 진 데는 빛을 못 만들어서, 밝은 자리에서만 나와.」

★ 되어야
  몬이   「이 잎, 무늬가 섞였어.」                        ⇐ ★ «몬이»가 먼저 — 몬이는 «식물»이다
  자취녀 surprise 「…어디? 아직 잘 모르겠는데.」           ⇐ ★★ 사람이 «못 보는» 것이 «참»이 된다
  몬이   「자라면 보여. 무늬 진 데는 빛을 못 만들어서, 밝은 자리에서만 나와.」  ⇐ ★ 「«언제» 보이나」
```
> ## ⇒ ★★★ 오늘 세운 것의 짝이다 — 「막힌 «그 순간»에 «까닭»을 말한다」 ⇒ ⇒ **「«안 보이는» 그 순간에 «언제 보이는지»를 말한다」**
⇒ ✔ 그리고 이 고침은 ★ «성숙잎 결과와 무관»하다 — 어린잎에 안 보이는 것은 어느 쪽이든 그대로다. ⇒ 지금 해도 안 물린다.
⇒ ⛔ 나머지 줄(「내가 뭐 한 것도 없는데」 · 「창턱에 올려놨잖아. 그게 한 거야」)은 «그대로» 둔다 — 그건 «자리»에 대한 말이지 «보이나»에 대한 말이 아니다.

## ⓓ ★★ 그리고 이것이 「몬이는 무엇인가」에 한 줄 더한다
> # **「몬이는 «식물»이라 ⇒ 사람보다 «먼저» 안다.」**
⇒ 오늘 세운 「몬이도 «모를» 때가 있다」의 «뒷면»이다 — ⇒ ★ 몬이가 «먼저 아는» 것과 «끝내 모르는» 것이 갈린다
```
먼저 안다  무늬가 났나 · 자라기 시작했나 · 빛이 모자란가   ⇐ ★ «식물의 몸»에서 나는 일
끝내 모른다 「이상하지? 물도 줬고 날짜도 갔는데」          ⇐ ★ «자리»의 일 — 그건 «사람»이 움직여야 안다
```
⇒ ⏸ `plan-moni-is.md` 는 「«못» 하는 것」 문서라 여기 안 올린다. ⇒ ★ 다만 「겪어서 나온 것」이므로 그 문서 «머리»에서 이 파일을 가리키게 둔다.

## ⓔ ⚠ 안 정한 것 — 적어만 둔다
```
varieSecond 「두 장째네. 이제 됐다.」 ⇒ ⚠ 그때 «첫 잎»은 중간잎이 되어 «보일» 수도 있다 ⇒ 같은 병인지 «모른다»
성숙잎에서 등급이 갈리나 ⇒ [leaf]·[growth] 몫. ⇒ ★ 갈리면 「배신·선물」이 «거기서» 일어난다 — 설계가 «늦게» 사는 것
작은 화면(방)에서 중간잎 무늬가 보이나 ⇒ [leaf] 가 아직 안 봤다
```
