## 이 기록의 한계 — 먼저 밝힌다

1. **다른 작업창 넷이 같은 기계에서 헤드리스 크롬을 동시에 돌리고 있었다.**
   재는 동안 크롬 프로세스가 30~44개까지 올라갔고, 부팅이 240초 제한을 넘겨 한 번 죽었다.
   ⇒ **프레임·시간 숫자는 못 믿는다.** 그래서 이 문서에 성능 수치를 안 적었다.
   "렉이 있나 · 프레임이 언제 떨어지나"는 **기계가 조용할 때 다시 재야 한다.**
2. 뒤쪽(**삽수 자르기 · 분갈이 · 팔기 · 식물등 · 가을 · 잭팟 · 원룸 이사**)은
   손으로 20일 넘게 눌러야 닿는데, 위 사정으로 **거기까지 못 갔다.** 안 본 것은 안 봤다고 적는다.

# ■ 눌러 봤는데 **멀쩡했던** 것 — 이것도 정보다

### 물 주기 — 캐릭터는 **걸어갔다.** 박사님 증상을 재현 못 했다

박사님이 "물부으로캐릭이 이동안하는거같어"라 하신 건데, 배포본에서 **한 번도 안 났다.**
1일차에 [💧 콩나물에 물 주기]를 손가락으로 누른 결과:

```
actAt = { key:"free:crop_01", kind:"water", walk:1, phase:"act", done:true, fail:null, ms:3681 }
게이지 = { acting:true, bar:"가는 중" }
캐릭터 = (-1.14, 1.26) → (-0.38, 0.45)   이동 1.61m
```

걷고(게이지 "가는 중") · 서고 · 모션하고 · 끝났다. **계약 순서대로 돌았다.**

★그래도 **아니라고 단정하지 않는다.** 내가 못 본 조건이 셋 남아 있다:
1. **느린 폰**(CPU 4배)에서는 못 재 봤다 — 기계가 다른 창들 때문에 이미 느렸다.
2. **시루가 여럿**일 때, **다시 심은 뒤**의 물주기는 못 봤다(씨앗 사는 길을 내가 놓쳐서
   1회전에서 멈췄다).
3. **화분을 구석에 몰아넣었을 때** `onFail('가지 못했습니다')` 로 빠지는 경우를 못 만들었다.
   이때 `doAct` 는 **논리도 안 돌린다**(`game.html:2043`) — 즉 물이 안 들어간다.
   박사님이 보신 게 이것이면 "캐릭이 안 움직인다"가 아니라 "물이 안 들어간다"로 보였을 수 있다.
   ⇒ **이 셋을 조용한 기계에서 다시 재야 한다.**

### 그 밖에 확인된 것

- 시루를 **끌어서** 방 아무 데나 놓는 자유 배치가 된다(`free:crop_01` 열쇠로 붙었다).
  끄는 동안 격자·링·미리보기가 켜진다.
- 첫 플레이 중에도 상점 상자가 열려 있다(`drawShop` 이 `S.tutorial.enabled` 만 본다) —
  2e59f63 에서 고친 그대로다.

```

      body.dataset.hardLock = '1'. **화면에는 배너도 문구도 안 뜬다.**
      더 이상 하루를 넘길 수 없다(새로고침해야 풀린다. 풀어도 또 누르면 또 잠긴다)
증거: 검수 탭 기록 첫 줄 — "47일⛔ [빨리감기] 배속에는 maxDays 가 필요합니다 — 무한 진행은 없습니다"
      콘솔 — Uncaught TypeError: Cannot read properties of null (reading 'insertAdjacentHTML')
              at HTMLButtonElement.<anonymous> (game.html:2522)
      docs/engine/shots/qa_phone_hardlock_silent.png
```

짐작(둘이 겹쳐 있다):

1. `game.html`의 `$('ff').onclick` 은 `startFastForward(S, io, { msPerDay: 140, ... })` 만 넘기고
   **`maxDays` 를 안 넘긴다.** `timeModeOf(S)` 는 `firstPlay.completed` 가 켜지는 순간
   `'jump'` → `'fast'` 로 바뀌고, `fast` 에서는 `loop.js:1044` 가 `maxDays` 없으면 던진다.
   즉 **첫 플레이가 끝나는 그 순간부터 빨리감기 버튼은 반드시 터진다.**
   버튼은 여전히 눌리고 툴팁도 "다음 일이 생길 때까지"로 남아 있어 누르라고 부른다.
2. `guard()` 의 오류 표시가 자기가 먼저 터진다 — `const side = $('side')` 인데
   **`game.html` 에 `id="side"` 인 요소가 없다.** `side` 는 null 이고
   `side.insertAdjacentHTML(...)`(2522행) 에서 예외가 난다. 그 다음 줄 `console.error(e)` 도
   실행되지 않아 **콘솔에도 원인이 안 남는다.**
   ★ 이 자리는 2522 말고 3750·3763 에도 있다 — 치명 오류 전부와 첫 플레이 시뮬 실패까지
   같은 방식으로 조용해진다. 잠그는 코드(`GATED.forEach(...disabled = true)`)는 그 앞줄이라
   **잠금은 걸리고 설명만 사라진다.**

고리가 거의 옆면으로 눌려 그려진다. `slotRings()` 는 `visible:true` 라고 하는데 화면에선 못 찾는다.
`focusSlot('banjiha-sill:0')` 으로 붙여 보면 고리는 분명히 있다.
증거: docs/engine/shots/qa_phone_move_rings_no_sill.png

## 확인해 봤고 **멀쩡했던** 것 (없는 버그를 만들지 않으려고 적는다)

- **터치·드래그·확대·시야이동 전부 살아 있다.** 폰 세로에서 한 손가락 드래그로 회전(az),
  두 손가락으로 확대/축소(dist), 세로 드래그로 부감(el) 다 먹는다. PC 는 마우스 드래그·휠 다 먹는다.
  az 는 한 바퀴(0~π 이상) 자유롭게 돈다
- **"20초 안에 부팅이 끝나지 않았습니다" 배너 안 뜬다.** `__rv` 까지 2.3~9.9초, `bootMsg` "방이 떴습니다"
- **검은 화면 없다.** PC 와이드에서 `#app` 1040×860 · 시트 360×860 으로 제대로 갈린다
- **식물이 안 날아다닌다.** 몬스테라도 시루도 자리에 제대로 붙어 있다
- **콩나물 시루가 비지 않는다.** 5일 회전이 돌고 `crisp_white`·3끼·3,000원이 정확히 들어온다
- 대화 중 하단 바가 안 눌리는 것은 **의도**다(`#bottom` 이 `pointer-events:none` + `opacity:.35`).
  다만 [거두기] 버튼은 흐려져도 꽤 밝아 보인다
- 저장·복원 정상 — 새로고침해도 Day·자리·수확 횟수·아낀 식비가 그대로다(**각도만 안 남는다**, 위 참고)
- 거둘 때가 됐는데 며칠 지나쳐도 **안 썩는다**(ageDays 가 harvestDays 에서 멈춘다)
- 몬이는 사라진 게 아니라 **기본 카메라에서 왼쪽 벽에 가려 있는 것**이다. 카메라를 반대로 돌리면 멀쩡히 서 있다
- 캐릭터 탭 → 고르기 → 바닥 탭 → 걷기 다 된다(히트 박스가 좁아 몇 번 빗나갔을 뿐이다)
- 물 주기·수확은 캐릭터가 걸어가서 하느라 **누르고 3~10초 뒤에** 반영된다. 그 동안 버튼 문구가
  안 바뀌어서 "안 먹었나" 싶지만, 두 번 눌러도 두 번 처리되지는 않았다
- 자세히(plant_grow.html iframe)는 잘 뜨고 잘 닫힌다. 콘솔 0건
