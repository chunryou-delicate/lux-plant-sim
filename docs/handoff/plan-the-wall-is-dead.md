# 「자리가 모자라다」의 최후 · 그리고 ★ 자의 «성공»도 의심해야 한다

2026-08-24 · [Plan] · [core] 새 판(시루 16 채움)을 받아. ⛔ 값 안 건드림.

---

# 1. ⛔ **벽은 «세 번» 죽었다. 세 번 다 «다른 사람»이 «다른 자»로**
```
① 「21」이 «가정»이었다      ← [Plan] 이 스스로 물림 (무순 판 4개는 probe 가 고른 배치였다)
② 「바닥이 있다」            ← ★ 박사님이 짚으심 ("시루는 땅바닥에 놓으면 되는데")
③ ★ 「실제로 16을 채웠다」   ← [core] 판 (시루 16 · 산 15 = 놓은 15 · 낭비 0)
```
> ## ★★★ **셈 → 상식 → 실물. 셋이 «다른 층»에서 같은 것을 죽였다.**

## ⇒ 최종 취소 목록
```
⛔ 「21칸 필요한데 14칸뿐」
⛔ 「siru16 만으로 16칸, 반지하는 15칸」          — 바닥이 빠진 셈이었다
⛔ 「앞문을 빼자」의 근거 중 «자리» 쪽
   ⚠ 다만 «벌이 죄보다 크다» 쪽은 «별개»다 — 자리와 무관하고, 박사님이 가이드로 푸셨다
```

## ⇒ ★ 그리고 **남는 것**은 하나뿐이다
```
✅ 「시루 16 은 이 방에서 «채워진다» — 바닥을 쓰면」
```

# 2. ★★★★ [core] 의 결산 한 줄이 **밸런스 쪽으로 이어진다**

> [core]: ***"이번 판에서 자를 «네 번» 고쳤습니다 — 어두운 자리 · 바닥 · 재고 · 무 씨앗.
>   ⚠ 네 번 다 「사람이면 안 그럴 짓」이었습니다."***

## ⓐ ★★ 넷의 «공통점»을 세워 보면
```
어두운 자리에 안 놓음      ← 사람은 안내를 읽으면 어두운 데 놓는다
바닥을 안 씀               ← 사람은 자리가 모자라면 «바닥에 놓는다»
재고를 53개 쌓음           ← 사람은 «필요한 만큼» 산다
씨앗 0 인데 95번 심으려 함  ← ★ 사람은 «두 번» 실패하면 사러 간다
```
> ## ★★★★★ **사람은 막히면 «길을 바꾸고», 자는 막히면 «같은 문을 계속 민다».**

⇒ ★★ **그래서 자가 낸 파산은 「판이 막혔다」의 증거가 «아닐 수» 있다.**
  **「자가 안 돌아갔다」의 증거일 수 있다.** ⇒ **오늘 네 번 다 그랬다.**
⇒ ⇒ ★ **자가 파산하면 물을 것: 「사람이면 여기서 무엇을 했겠나」.**

## ⓑ ⚠⚠ **그런데 «뒤집으면» 아무도 안 본 것이 나온다**
```
자의 «실패»   사람이면 «안 그럴 짓»을 해서 실패했을 수 있다   ⇒ ★ 오늘 네 번 잡혔다
자의 «성공»   ★ 사람은 «못 할 짓»을 해서 성공했을 수 있다     ⇒ ⛔ 아직 아무도 안 봤다
```
⇒ ⚠ 지금 판이 하는 것:
```
· 매일 «빠짐없이» 물을 준다        ← 사람이 그러는가
· 시루 열여섯을 «어긋나게» 돌린다   ← 달력을 손에 들고 있어야 한다
· 한 번도 «안 잊는다»              ← 사람은 잊는다
· 거둔 날 «그날» 다시 심는다        ← 사람은 미룬다
```
> ## ★★★ **「이사에 닿는다」가 나와도, 그것이 «사람의 길»인지는 별개다.**

⇒ ★ 그리고 이것이 **밸런스에서 제일 위험한 자리**다 —
  **실패는 눈에 띄어 고치는데, «성공은 안 고친다».**
  ⇒ ⇒ ⚠ **자가 이사에 닿으면 우리는 「됐다」 하고 덮는다.** 그때 **사람은 못 닿을 수 있다.**

## ⓒ ⇒ ★★ **그래서 잴 것이 하나 더 있다 — 「덜 부지런한 판」**
```
지금 판   «완벽한 사람» 하나뿐이다
★ 필요    물을 «가끔 빼먹고» · 다시 심기를 «하루 미루고» · 어긋내기를 «안 하는» 판
⇒ 그 판이 이사에 닿나
```
⇒ ⛔ **내가 만들 것이 아니다**(도구는 [core]·[growth] 몫).
  ★ **다만 「완벽한 판 하나로 밸런스를 판정하면 안 된다」는 것은 내 몫이라 적어 둔다.**
⇒ ⚠ **그리고 지금 그렇게 하고 있다.** 134일 파산도, 앞의 400일도, 전부 **완벽한 판**이다.

# 4. ★★★ 「물을 거르면 무슨 벌인가」 — **코드에 그대로 적혀 있다**

```js
first_play.js:1904
  "물을 안 주면 «벌을 받는 것이 아니라» 아직 «시작을 안 한 것»이다. 시루는 그대로 놓여 있다."
first_play.js:422   ★ 자라는 날 = «물을 준 날» 5일. 달력 5일이 아니다
```
⇒ ★ **직접 벌은 «없다».** 안 죽고 안 상한다. **간접 벌만 있다:**
```
물을 안 준 날 = 회전이 «시작 안 됨»
⇒ 그날치 수확이 뒤로 밀리고, 지출(16,667원/일)은 «안 밀린다»
⇒ ★ 벌 = «기회비용»뿐이다
```
⇒ ⚠ **총괄 ①의 걱정(「아무 일 없으면 게으름이 공짜」)은 «절반» 맞다** —
  **공짜는 아닌데, «싸다».**

# 5. ★★★★★ 그리고 여기서 **아무도 안 센 것**이 나온다

## ⇒ **게으름의 벌이 «시루 수에 반비례»한다**
```
시루 1개   하루 거르면 → 그날 수입의 «전부»가 밀린다
시루 16개  하루 거르면 → 그 시루 하나만 밀린다. 나머지 열다섯은 «돈다» ⇒ «1/16»
```
> ## **초반에는 게으름이 «비싸고», 후반에는 «싸다».**

## ⓐ ★★ 그리고 그것이 **설계로 «옳다»**
```
초반   시루가 적다 → 게으름이 비싸다 → ★ 배우게 한다
후반   시루가 많다 → 게으름이 싸다   → ★ 봐준다
```
⇒ ★ **가르칠 때 엄하고, 배운 뒤에 느슨하다. 좋은 곡선이다.**
⇒ ⇒ ★★ **그리고 초반이 정확히 «돈이 제일 적은 구간»이다.** 벌이 아픈 자리에 붙어 있다.

## ⓑ ⚠ **뒤집으면 다른 물음이 하나 선다**
> **후반에 게을러도 되면, 후반이 «심심»하지 않은가.**
⇒ ⛔ **지금 답하지 않는다.** 다만 **「덜 부지런한 판」이 그것도 같이 잰다** — 적어 둔다.

## ⓒ ⇒ ★ **그러니 「덜 부지런한 판」은 «초반에» 갈린다**
```
같은 게으름 0.2 라도  d0~d40 과 d100~ 이 «다른 값»이다
⇒ ★ 결과를 「닿았나/못 닿았나」로만 읽으면 그 갈림이 안 보인다
⇒ ⇒ ⚠ 「어디서 뒤처졌나」를 같이 봐야 한다
```

# 6. ★ 총괄 물음 — **「어긋내기」는 [core] 읽기가 맞다. 다만 까닭이 다르다**

## ⓐ ⛔ **「모른다」 갈래는 «없다» — 게임이 가르친다**
```js
quest.js:394   todo: '시루를 N개로 늘려 «엇갈리게» 하세요'
quest.js:392   why:  '시루가 둘이면 물 주는 날을 어긋나게 할 수 있습니다. 그래야 수확이 안 끊깁니다.'
dialogue.js:640  몬이: '그래서 늘리는 거야. 물 주는 날을 어긋나게 하면 안 끊겨.'
```
⇒ ★ **총괄이 물으신 둘 중 「모른다」는 «안 섭니다».** 퀘스트와 대사가 «둘 다» 말한다.
⇒ ⇒ **내 뜻은 셋째였다** — *「할 줄 알고 게으르지도 않은데 «신경을 못 쓴다»」*(달력을 머릿속에 들고 있어야 한다).
  ⇒ ⚠ **그것도 지금은 안 잰다.** 아래 까닭 때문이다.

## ⓑ ⚠ **[core] 의 「물을 거르면 저절로 어긋난다」는 «방향»이 다르다**
```
어긋냄     ★ 의도적 «고르게» 벌리기   ⇒ 최저점을 «올린다»
흐트러짐   무작위                    ⇒ ★ 최저점을 «내릴 수도» 있다
```
⇒ ★★★ **어긋내기는 «총수입»을 안 바꾼다. «수입의 고름»을 바꾼다.**
  ⇒ ⇒ **그리고 고름은 «파산 시점»에 걸린다** — 몰아서 들어오면 그 사이에 0원이 된다.
⇒ ★ **그러니 어긋내기의 값어치는 «평균»이 아니라 «최저점»에서 나온다.**

## ⓒ ⇒ **그래도 [core] 안을 받는다**
```
지금 재려는 것   「덜 부지런해도 닿나」   ⇒ ★ 거르는 판이 그것을 잰다
어긋내기         「수입이 고른가」        ⇒ «다른 물음»이다. 미룬다
```
⇒ ★ **따로 만들지 않는 것에 동의한다.** 규율 ㉰ 와도 맞다.
⇒ ⚠ **다만 「거르면 어긋난다」를 «장점»으로 적지는 말 것** — 그건 **반대로 갈 수도** 있다.
  ★ **「어긋내기는 이 판이 안 잰다」로 적는 편이 정직하다.**
