# ★ 「한글로 적힌 숫자」와 「값에서 나온 말」 — ⛔ 목록만. 안 고쳤다

2026-08-24 · [Plan] · 총괄 요청. **어느 것이 낡았는지는 [core] 가 값을 대 봐야 안다.**

> ⚠ **까닭: 「이만오천」은 `grep 25000` 에 «안 걸린다».** 대사가 낡은 채 살아남은 까닭이 그것이다.

---

# 1. ⛔ **확정 낡음 — 값을 대 봤다**
```
dialogue.js:340   몬이: "★ «이만오천 원». 전기는 하루 이십삼 원이고."      ⛔ 지금 120,000
dialogue.js:343   나  : "★ «이만오천 원»이면… «하루 반»은 사는 돈인데."     ⛔ 값 + ★ 파생
```

# 2. ✅ **맞음 — 값을 대 봤다**
```
dialogue.js:261   "이레 남았어. «이십만 원»."     ✅ 월세 200,000
dialogue.js:265   "«이십만 원». 들어오자마자 한 번에 빠져나갔다."   ✅
```

# 3. ★★★★★★ **여기가 제일 크다 — 「본전은 열여섯」을 «네 줄에 걸쳐» 말한다**

```
questDoneSiru5   몬이: "다섯 개가 다섯 바퀴. 이제 이 방이 «밥값은 내네»."
questDoneSiru8   몬이: "«아직 본전은 아니야». 조금 더 가야 해."
questSiru16      몬이: "«조금만 더» 늘리면 ★ «하루가 안 깎여»."
                 몬이: "거기까지 가면 ★ «처음으로 버는 쪽»이 돼."
```
⇒ ⚠⚠ **총괄 전달: *"셈으로는 25~30개인데 퀘스트는 16 이라 가르칩니다."***
⇒ ⇒ ★★★ **그러면 위 «네 줄이 통째로» 흔들린다.**
```
"다섯이면 밥값은 낸다"        ⇒ 정말 내나?
"아직 본전은 아니다"          ⇒ 「조금」이 맞나?
"조금만 더 늘리면 안 깎인다"   ⇒ ★ 16 에서 안 깎이나?
"처음으로 버는 쪽이 된다"      ⇒ ★★ 16 이 그 자리인가?
```

## ⇒ ★★★★ **그리고 이것이 「이만오천 원」보다 «더» 나쁘다**
```
「이만오천 원」    숫자 «하나»다   ⇒ grep 으로 찾히고, 값만 갈아 끼우면 된다
★ 「하루가 안 깎여」  숫자가 «아니다» ⇒ 자에 안 걸리고, 고치려면 «이야기를 다시 써야» 한다
```
> ## ★★★ **값이 바뀌면 숫자는 «틀린 티»가 나는데, 말은 «그럴듯한 채로» 틀린다.**
⇒ ⛔ **단정 안 한다.** 220일 판이 「몇 개면 흑자인가」를 낸다. **그때 이 네 줄을 «한꺼번에» 본다.**

# 4. ⚠ **말끼리 어긋나 보이는 것 — 자에 «안 걸리는» 종류**
```
dialogue.js:562   몬이: "놓기만 하면 날짜만 가. ★ «물을 준 날»부터 세는 거야."       ← ✅ 맞다
dialogue.js:92    (cropPlaced · «놓은 직후») 몬이: "좋아. ★ «나흘»이면 먹을 수 있어."
```
⇒ ⚠ **놓은 직후에 「나흘」이라 말한다. 그런데 회전은 «물을 준 날»부터 «닷새»다.**
⇒ ★ **두 대사가 서로 어긋나 보인다.**
```
ⓐ 「나흘」이 틀렸다 (닷새여야 한다)
ⓑ 「나흘 자면 닷새째」로 읽는 말이다        ⇒ 그러면 맞다
ⓒ 물을 곧 줄 것을 전제한 말이다            ⇒ 그러면 «놓은 직후»에 할 말이 아니다
```
⇒ ⛔ **셋 중 어느 것인지 안 정한다.** [core] 확인 대상.


> ## **«규칙»을 말한 대사는 안 낡고, «값»을 말한 대사는 낡는다.**
> ## ⇒ 그리고 **«값에서 나온 말»**(「하루 반」·「조금만 더」)은 **낡아도 티가 안 난다.**
