## ⚠ 커밋 손 (2026-09-07 · [core] 가 찾고 총괄이 세움)

**「내 파일만 `add`」로는 안 막힌다.** 저장소가 하나면 **색인도 하나**라,
남이 `add`·`git mv` 로 세워 둔 것을 다음 사람의 `git commit` 이 전부 데려간다.
`-a` 를 안 써도, 폴더째 `add` 를 안 해도 그렇다.

```
① 커밋 «전»에 색인을 본다
   git diff --cached --name-only     ⇒ 내 것 아닌 이름이 있으면 멈추고 알린다
★② 커밋에 «경로를 박는다»
   git commit -m "..." -- <내 파일들>
   ⇒ 색인에 남의 것이 서 있어도 내 커밋은 깨끗하다. 이게 핵심이다
③ add 하고 «뜸 들이지 않는다» — 세워 둔 시간이 길수록 남이 데려간다
```
⚠ 되감지 않는다. **기록이 틀렸으면 지우지 말고 「틀렸다」고 적는다.**

★ 이 창은 2026-09-06 밤 커밋 일곱(`45c3091`~`6661479`)을 확인했다 —
경로를 박아 커밋해 와서 **남의 파일이 하나도 안 딸려갔고 색인도 비어 있다.**
