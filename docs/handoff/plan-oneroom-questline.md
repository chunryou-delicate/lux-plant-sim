# 2026-08-23 밤 · plan — **원룸 퀘스트라인 제작 명세**

> 밑그림은 `plan-night-cutting-block.md §4`. 여기는 **붙일 수 있는 형태**로 적는다.
> ⚠ **방 데이터·조도·값은 하나도 안 정했다**(박사님 「반지하 먼저」). 이야기·퀘스트·대사뿐이다.
> ⚠ 조건은 전부 **`quest.js §스냅샷` 의 말**로 썼다. 지어낸 칸에는 ★ 표를 붙였다.

## 0. ★ 먼저 — **새로 필요한 칸은 둘뿐이다** (재서 확인했다)

처음엔 넷이 필요할 줄 알았는데 **스냅샷이 이미 갖고 있었다.**
`cuttings[].status` 가 `bag · rooting · rooted · node · established · dead` 를 그대로 낸다
(`propagation.js §CUTTING_STATUS_KO`). ⇒ **②③ 은 새 칸 없이 써진다.**

| 칸 | 왜 필요한가 | 무엇에서 나오나 |
|---|---|---|
| ★ `movedOut` | 원룸 줄이 **이사 뒤에** 열려야 한다 | `S.tutorial.movedOut` |
| ★ `cuttingSaleCount` | ④가 **민무늬 포함** 판 적을 본다. `varieSaleCount` 는 **무늬만** 센다 | 판 횟수 |

⚠ 그리고 스냅샷 규율을 지킨다 — **`null`=모른다 · `false`=아니다.**
  둘을 안 가르면 **배선이 안 붙은 판과 실제로 아닌 판을 못 가른다**(그 파일 §초반 사슬).
⇒ 그래서 **안전 폴백**을 아래마다 적었다. **칸이 없어도 사슬이 굴러야 한다.**

## 1. 퀘스트 다섯 — 붙일 수 있는 형태

### ① `oneroom_cut_water` — **물에 꽂아 본다**
```
teaches  잎 1장까지 쪼개야 물꽂이
why      잎이 한 장이라야 물에 꽂힙니다. 여러 장은 화분에만 심습니다.
todo     잎 1장짜리 마디를 잘라 물에 꽂으세요
opens    s.movedOut === true
done     cuttings.some(c => c.method === 'water' && isRooted(c))
speaks   true
```
⚠ **튜토의 `first_cut` 을 여기로 옮기는 것**이다(`opens` 를 「잎 2장」 → 「이사 뒤」로).
  같은 줄을 두 벌 만들지 않는다.
**폴백**: `movedOut` 이 `null` 이면 옛 조건(`motherLeaves >= 2`)으로 연다 — 안 붙은 판에서도 막히지 않는다.

### ② `oneroom_cut_node` — **뿌리를 본다**
```
teaches  뿌리 → 혹 → 잎. **기다리는 것이 일이다**
why      뿌리가 나도 아직 그루가 아닙니다. 혹이 나야 새 잎이 섭니다.
todo     삽수에 혹이 날 때까지 둡니다
opens    ①이 끝남
done     cuttings.some(c => c.status === 'node' || c.status === 'established')
```
★ **여기가 원룸의 성격을 정한다.** 반지하의 적은 **어둠**이었고 원룸의 적은 **시간**이다
  (물꽂이 뿌리 → 혹 `nodeDays 20`). **이 줄은 손짓이 없다** — 기다리는 것이 일이다.
⚠ 그래서 **§C(할 일 없는 날)에 걸릴 위험이 제일 큰 줄**이다. 밤샘 검사에서 **이 구간을 따로 봐야 한다.**

#### ★ 추가 2026-08-23 밤 — **중간에 한 줄 말해 준다** (총괄 승인)

⚠ 이 줄은 **손짓이 없는 20일**이라 내 어색함 문턱 §B3(한 줄이 10일 넘게 안 바뀜)에 **정면으로 걸린다.**
⇒ **퀵스트를 쪼개지 않는다.** ②는 여전히 `node`(혹)에서 닫힌다.
⇒ 대신 **뿌리가 난 순간(`status === 'rooted'`)에 대사 한 줄**을 붙인다:

```
몬이 ─ 뿌리 나왔네. 이제 혹만 나면 그루야.
```

★ **기다림의 길이는 그대로인데 「아무 일도 안 일어나는 길이」가 반으로 준다.**
  20일이 **10+10** 으로 쪼개진다. **값은 한 톨도 안 움직이고 말만 늘어난다.**
⚠ 뿌리가 나는 날은 `METHODS.water.rootDays` 가 정한다 — **숫자를 여기 안 적는다.**

### ③ `oneroom_two_plants` — **두 그루가 된다**
```
teaches  한 그루가 둘이 된다
why      혹이 자리를 잡으면 그것은 삽수가 아니라 그루입니다.
todo     삽수를 그루로 키워 냅니다
opens    ②가 끝남
done     cuttings.some(c => c.status === 'established')
```
★ **이 판의 한 줄이 여기서 손에 잡힌다** — 「늘리는 법을 배운다」.

### ④ ★ `oneroom_quickcash` — **급하면 판다**
```
teaches  삽수는 급전이다 — 파는 만큼 다음 잎이 준다
why      팔 수는 있습니다. 다만 그것은 다음 잎을 미리 쓰는 것입니다.
todo     급하면 삽수를 내놓아 팔아 보세요
opens    ③이 끝남
done     ★ cuttingSaleCount >= 1
```
★★ **④가 ③ 뒤인 것이 이 줄의 전부다.**
> 파는 것을 **먼저** 배우면 삽수가 **「돈 버는 것」**으로 굳는다.
> 늘리는 것을 먼저 배우면 파는 것은 **「늘릴 것을 포기하는 것」**이 된다. **그게 급전의 뜻이다.**

⚠ **이 줄을 「지금 할 일」에 띄우는 것이 맞나** — 낮에 나는 *"급전은 가르치되 권하지 않는다.
  퀘스트는 권하는 장치다"* 라고 정했다. **그 판단이 여기서 바뀐다:**
  - 튜토에서는 **막는 것**이 답이라 퀘스트가 필요 없었다
  - 원룸은 **가르치는 것이 목적**이다. 그리고 ③ 뒤라서 **이미 늘릴 줄 안다** —
    그때 파는 것은 **손해가 아니라 선택**이다. **선택은 시켜도 된다.**
  ⇒ ★ 그러니 **퀘스트로 만든다.** 다만 **한 번 팔면 끝**이고, 두 번째부터는 아무도 안 시킨다.

**폴백**: `cuttingSaleCount` 가 없으면 이 줄을 **안 연다**(0으로 치지 않는다).
  ⚠ 0으로 메꾸면 **「안 팔았다」가 되어 영영 열린 채로 남는다.**

### ⑤ `oneroom_varie_bright` — **밝은 데서 뿌리내리기**
```
teaches  빛이 무늬 등급을 정한다
opens    motherVarieLeaves >= 1  (튜토의 varie_bright 와 같다)
done     cuttings.some(c => c.varieFromCut && c.varieLightBand === 'bright')
```
값이 붙는 것은 **마지막**이다. 앞의 넷을 다 배운 뒤라야 **왜 밝은 데가 중요한지**가 산다.

## 2. 초반 스토리 — 세 박자 · 대사 문안

`movedInOneroom` 10줄(*"…창이 눈높이에 있네"*) **뒤에** 붙는다.

### ㉠ 넓어졌다 — 이사 이튿날
```
자취생 ─ 자리는 늘었는데.
자취생 ─ …놓을 게 하나뿐이네.
```
★ **빈 자리를 먼저 보여 준다.** 문제 제기가 대사가 아니라 **화면**에서 나온다.

### ㉡ 늘릴 수 있다 — ①이 열릴 때
```
몬이 ─ 하나를 둘로 만드는 법이 있어.
몬이 ─ 잎 한 장이 붙은 마디를 잘라서, 물에 꽂아.
몬이 ─ 아프지 않아. 원래 그렇게 늘어나는 애야.
```
⚠ *"아프지 않아"* 를 넣은 까닭 — **자르는 것을 처음 시키는 자리**다.
  기른 것을 자르라는 말이라 **거리낌이 생긴다.** 그 한 줄이 그것을 푼다.

### ㉢ 그런데 시간이 든다 — ②가 열릴 때
```
몬이 ─ 뿌리가 나와도 아직이야.
몬이 ─ 혹이 나야 새 잎이 서. 그때까진 그냥 두는 게 일이야.
```
★ **「그냥 두는 게 일이야」** — 이 게임에서 **기다림을 일로 부르는 첫 줄**이다.

### ④의 대사 — **낮에 만든 것을 그대로 옮긴다**
```
몬이 ─ 팔 수는 있어. 근데 그건 다음 잎을 미리 쓰는 거야.
몬이 ─ 급하면 써. 급하지 않으면 붙여 둬.
```
⚠ **「손해」라고 안 쓴다.** 급전은 손해가 아니라 **값**이다.
⚠ 팝업 한 줄(**모주 값 −N원**)은 [core] 가 이미 **「자를 때」**에 붙였다.
  ★ 원룸에서는 **그 줄이 처음 보이는 자리**가 된다 — 튜토에서 안 보이니까.

## 2-5 ★ ③의 대사 — **④의 뜻을 여기서 만든다**

★ **③에서 「늘린다」가 무엇인지 새겨야 ④에서 파는 것이 「포기」로 읽힌다.**
  그냥 *"이제 둘이야"* 로는 부족하다 — **둘이 되면 무엇이 달라지는지**를 말해야 한다.

```
자취생 ─ 얘가… 이제 따로 사는 거지?
몬이   ─ 응. 뿌리도 잎도 제 거야.
몬이   ─ 하나였을 때랑 뭐가 다른지 알아?
몬이   ─ 이제 하나 잃어도, 하나 남아.
```

★★ **「하나 잃어도 하나 남아」가 이 대사의 전부다.**
> **늘린다는 것은 「많아지는 것」이 아니라 「안전해지는 것」이다.**
> ⇒ 그러면 ④에서 파는 것은 **「그 안전을 되파는 것」**이 된다.
> ⇒ *"다음 잎을 미리 쓰는 거야"* 가 **그 위에서 읽힌다.** ③ 없이는 그냥 거래다.

⚠ **여기서 값을 말하지 않는다.** 값은 ④의 몫이다. ③은 **셈이 아니라 처지**를 말한다.

## 2-6 ★ ⑤의 대사 — **반지하와 원룸을 한 줄로 가른다**

⑤가 가르치는 것은 *"빛이 무늬 등급을 정한다"* 인데, **반지하에서 배운 빛과 다르다:**

| | 빛이 무엇이었나 |
|---|---|
| **반지하** | **살리는 것** — 어두우면 **안 자란다** |
| **원룸** | **값을 정하는 것** — 자라긴 자라는데 **등급이 다르다** |

```
몬이   ─ 뿌리를 어디서 내리느냐가 무늬를 정해.
자취생 ─ 어차피 뿌리는 나잖아.
몬이   ─ 나긴 나. 근데 어두운 데서 난 건 어두운 값이야.
몬이   ─ 저 방에서 빛은 살리는 거였어. 여기선 값을 정해.
```

★★ **「저 방에서 빛은 살리는 거였어. 여기선 값을 정해」** 가 이 대사의 전부다.
> **한 줄로 두 방을 가른다.** 그리고 **반지하에서 배운 것을 안 버리게** 한다 —
> *"빛이 중요하다"* 는 그대로 맞고, **무엇을 정하느냐가 바뀐 것**이다.

★ 그리고 이 줄이 **「자리를 만드는 것이 놀이」를 원룸으로 잇는다** —
  반지하에서는 **선반을 쌓아 밝은 자리를 만들었다**(`plan-night-shelf-teaching.md`).
  원룸에서는 **그 밝은 자리에 무엇을 뿌리내리느냐**가 값이 된다.
  ⇒ **같은 손짓이 두 방에서 다른 뜻을 갖는다.** 그게 두 판을 잇는 결이다.

⚠ **문턱(무늬 최소 DLI)을 대사에 안 적는다.** *"어두운 데"* · *"밝은 데"* 로만 말한다.
  숫자는 화면이 안다(§2.8 · 오늘 이사비가 3벌인 자리를 봤다).

# 5. 원룸 살림 잡담 — **빈칸을 메운다** (2026-08-23 밤)

> ⚠ 먼저 세었다. **원룸 잡담이 이미 15줄 있다.** 없는 것만 쓴다.
> `Morning · Dark · Siru · Bright · Window · Empty · Lamp · NoLamp · Varie · Winter ·

## 5-0 ⚠⚠ **제일 큰 빈칸 — 삽수 잡담이 하나도 없다. 그리고 못 쓴다**

**원룸의 주제가 삽수인데**(박사님: *"원룸 가이드는 삽수 위주"*) **잡담이 그것에 침묵한다.**
`chatOneroomVarie`(무늬)는 있는데 **증식·기다림**이 없다.

⇒ ★ **그런데 쓸 수가 없다.** `chatterContext` 가 내는 칸 열여섯에 **삽수가 하나도 없다:**
```
movedInOnDay · daysInOneroom · day · weather · season · seasonDay · cashWon ·
living · firstPlayDone · cropAgeDays · cropHarvested · grew · blocked ·
fenestrating · lampOwned · movedOut
```
⇒ 조건을 걸 칸이 없으니 **늘 참이거나 늘 거짓**이 된다. **오늘 `move_short_*` 가 그랬던 자리다.**

### ⇒ ★ 필요한 칸 — **하나면 된다**
```
cuttingStage   지금 가진 삽수 중 제일 앞선 단계
               (bag · rooting · rooted · node · established 중 하나 · 없으면 null)
```
★ **새 어휘가 아니다** — `cuttings[].status` 가 이미 그 다섯을 낸다(`propagation.js §CUTTING_STATUS_KO`).
★ 이건 `plan-oneroom-questline §0` 의 **새 칸 둘**(`movedOut` · `cuttingSaleCount`)과 **같은 계통**이다.
  ⇒ **셋을 한 번에 붙이면 된다.**

### ★★ 그리고 이 칸이 **§B3(한 줄이 오래 안 바뀜)을 메운다**
퀘스트 ②「뿌리를 본다」는 **손짓 없는 20일**이라 §B3 에 정면으로 걸린다(§2-4).
⇒ **잡담이 그 20일을 메운다.** 퀘스트는 안 움직이는데 **말은 움직인다.**

### 문안 (칸이 오면 바로 붙는다)
```
[rooting]  자취생 ─ 물이 흐려졌나.
           몬이   ─ 아직이야. 흐려지는 게 정상이야.

[rooted]   자취생 ─ 하얀 게 나왔어.
           몬이   ─ 뿌리야. 이제 기다리는 게 일이야.

[node]     몬이   ─ 혹 났다. 이제 잎이 설 거야.
           자취생 ─ 오래 걸렸네.
           몬이   ─ 늘리는 건 원래 그래.

[established] 자취생 ─ 화분이 둘이네.
              몬이   ─ 이제 하나 죽어도 안 끝나.
```
★ 마지막 줄이 **퀘스트 ③의 대사(§2-5)와 짝**이다 — *"이제 하나 잃어도, 하나 남아."*
  **퀘스트는 한 번 말하고 잡담은 두고두고 말한다.** 같은 뜻을 다른 무게로.

## 5-1 ✅ **지금 쓸 수 있는 것** — 칸이 이미 있다

### 계절 — **`Winter` 하나뿐이다.** 셋이 빈다
반지하와 **다른 까닭**이 있다: **원룸은 창이 눈높이**다(`movedInOneroom` — *"…창이 눈높이에 있네"*).

```
[spring]  자취생 ─ 볕이 방 안까지 들어온다.
          몬이   ─ 저 방에선 저기까지가 끝이었지.

[summer]  자취생 ─ 볕이 너무 센가.
          몬이   ─ 셀 수도 있어. 여긴 가릴 줄도 알아야 해.

[autumn]  자취생 ─ 해가 낮아졌네.
          몬이   ─ 낮아지면 더 깊이 들어와. 가을이 나쁘지만은 않아.
```
★ **여름 줄이 이 방의 성격을 말한다** — 반지하에서 여름은 **제일 좋은 때**였는데,
  원룸에서는 **가릴 줄 알아야 하는 때**다. **빛이 모자란 방에서 빛을 다루는 방으로 옮긴 것**이다.

### 날씨 — **비·흐림이 없다**
```
[rain]    자취생 ─ 비 온다.
          몬이   ─ 저 방에선 소리만 들렸는데.

[cloudy]  자취생 ─ 오늘은 하루가 통째로 쉬는 것 같네.
```
