### ① [다음 날]이 막히던 것

`game.html` 의 문지기가 `S.firstPlay.beansprout.slotId` **하나**를 봤다.
시루가 각개가 되면서(2026-08-09) 자리의 정본은 **시루마다**(`pots[i].slotId` / `pots[i].at`)로
내려왔고, `beansprout.slotId` 는 대표 시루의 **읽기용 사본**일 뿐이다.
사본이 비면 방에 시루가 서 있어도 하루가 안 갔다.

고친 것:

- 문지기가 **시루를 센다** — `cropPotList(fp, day)` 의 `placed`(= `placedCropPots` 와 같은 판정).
- **콩나물만 안 본다** — `cropPotList` 가 `cropSites` 전부를 훑는다. 무순만 놓은 판도 하루가 간다.
  문구도 「콩나물 시루」에서 「시루」로 바꿨다(무순 재배판을 놓은 사람에게 거짓말이었다).
- 세면서 **자리 사본을 고쳐 놓는다**(`syncCropLead`). 아래 §다른 창이 알아야 할 것 ①이 그 이유다.
- 하나도 안 놓았으면 **계속 막는다**. 그건 옳은 안내다.

### ② 오류 상자가 쌓여 화면을 덮던 것

`insertAdjacentHTML('afterbegin', …)` 로 앞에 붙이기만 하고 지우는 곳이 없었다.
`#side` 는 폰 세로 레이아웃으로 바뀌며 없어졌으므로 오류가 **전부 하단 액션바(`#bottom`)에**
붙었고, 바가 자라 버튼을 밀어냈다.

2026-08-08 에 배너(`#event`)에서 세운 규칙을 그대로 옮겼다 — 상자는 이제 **하나만 산다**:

| 규칙 | 어떻게 |
|---|---|
| 같은 말은 한 번만 | 같은 내용은 한 줄로 접고 `×N` 만 붙인다 |
| 많아야 셋 | 나머지는 「…외 N개」 |
| 누르면 사라진다 | 상자 어디를 눌러도 닫힌다 · 성공한 동작이 있으면 저절로 치운다 |
| 높이 상한 | `max-height:38dvh`, 넘으면 상자 안에서 스크롤 |
| **꺼진 상자는 포인터를 안 먹는다** | `#errBox` 는 `display:none`, `.on` 일 때만 `pointer-events:auto` |
| 버튼을 안 덮는다 | 아래 여백을 **하단 액션바의 실제 높이**에서 그때그때 잰다(px 로 박지 않는다) |

  「전부 자라는 중」은 **작물** 물주기 버튼, 「아직 촉촉합니다 (1일 뒤)」는 **몬스테라** 물주기 버튼이다.
  뒤 둘만 주어가 빠져 있어서 한 판을 두고 셋이 싸우는 것처럼 읽혔다. 주어를 적었다:
  `💧 작물은 전부 자라는 중` · `💧 몬스테라는 아직 촉촉합니다 (N일 뒤)`.
