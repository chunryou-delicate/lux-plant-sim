# 1. ★★ 겹침이 «늘지» 않는다 — **평평하다**

```
012 day001    겹침 6
014 waterCrop_d1  ★ 18   ← 여기서 뛴다
015 ~ 035         17~19  ← ★★ 스물한 걸음 동안 «평평하다»
```
⇒ ★ **걸음마다 새로 나는 것이 아니다.** **같은 것 열여덟이 «계속» 겹쳐 있다.**
⇒ ⇒ **낱개 사고가 아니라 «상시 겹침»이다.** 고칠 것도 열여덟이 아니라 **몇 개다.**

## ⇒ 무엇이 상시인가 (019 day004 에서 뽑음)
```
① month*   「첫 달 가계부」 팝업        ← ⚠ day 1 에 뜨고 «day 12 까지» 있다
② b        「빈 시루를 하나 놓았습니다」  ← ⚠ day 0 의 배너가 «day 12 까지» 있다
③ dlg*     대사                        ← 그날 것. 맞다
④ 네 자리  「시루를 방 안에 놓아 보세요」 ← §3
```

## ⚠⚠ ① 의 증거 — **팝업이 열린 채 «낡는다»**
```
019 day004 [실측]   monthSub «살림 «0~1일차» · 월세는 30일마다 나갑니다»
                    ← ★ day 4 인데 「0~1일차」라고 적혀 있다
```
⇒ ★★ **떠 있는 동안 안 갱신된다.** ⇒ **열린 채 틀린 말을 한다.**
⚠ **자의 한계일 수 있다** — 자동 판이 「알겠습니다」를 안 눌렀을 수 있다. ⛔ **단정 안 한다.**
⇒ ★ 그래도 **하나는 확실하다**: **팝업이 떠 있는데도 날이 넘어간다.** 모달이 모달이 아니다.

# 2. ★★★★ ② 가 핵심이다 — **배너는 「방금」인데 「항상」이 됐다**

```
day 0    "빈 시루를 하나 놓았습니다"   ← 맞다. 방금 났다
day 4    〃                          ← ⚠ 나흘 전 일이다
day 12   〃                          ← ⛔ 열이틀 전 일이다
```

## ⇒ ★★ 그래서 층 표가 **틀린 게 아니라 «모자랐다»**
[core] 가 「coach·banner 가 표에 없다」 한 것 맞다. ⇒ ⚠ **넣어도 안 풀린다.**
**칸이 하나 더 있어야 한다 — 「수명」.**

| 자리 | 층 (무엇을 말하나) | ★ **수명** (얼마나 있나) |
|---|---|---|
| `coach` | **조작법** — 화면 다루는 법 | ★ **한 번 배우면 끝**. 판이 아니라 사람에게 붙는다 |
| `questSub`(패널) | **줄 이름** — 무엇을 배우는 줄 | 그 줄이 열린 동안 |
| `chip`·`quest`·`sheetQuest`·`qtodo` | **다음 손** | 그 손을 할 때까지 |
| 손짓 👆 `hint`/`hand` | **첫 걸음** — 이 물건을 어디에 | ★ **그 물건을 놓을 때까지** |
| `banner` | **결과** — 방금 무슨 일이 났나 | ★★ **몇 초** ⛔ **지금 안 사라진다** |

⇒ ★★★ **「층」은 «무엇을 말하나»이고 「수명」은 «언제 사라지나»다.**
  **층만 맞추면 여섯이 다 옳은 말을 «동시에» 한다.** 그것이 지금 화면이다.

# 3. ★★ 「같은 글자」는 **넷**이다 (둘이 아니다)
```
[실측]  "시루를 방 안에 놓아 보세요"
        ← questChipText · quest · sheetQuest · qtodo      ★ 네 자리
```
⇒ ★ **넷 다 «한 곳에서 짓고 옮긴 것»이다** — ㉰ 는 **지켜지고 있다.**
⇒ ⇒ ⚠ **문제는 문구가 아니라 «네 자리가 동시에 켜져 있는 것»이다.**
⇒ ★★ 그리고 **셋은 안 겹쳐야 정상이다**:
```
sheetQuest   시트가 «열렸을 때»만          ┐
qtodo        할 일 «탭»에서만              ├ ★ 서로 배타적이어야 한다
chip + quest 시트가 «닫혔을 때»            ┘   ⚠ 그런데 이 둘은 «같이» 켜진다
```
⇒ **끌 것은 하나다 — 칩이나 아래 줄 중 하나.** (§5 ①)

---

# 4. ★★★ coach 와 손짓이 어떻게 다른가 — **총괄이 물으신 것**

```
coachTitle  「사람을 눌러 보세요」
coachBody   「사람을 누르면 …켜지고, 방바닥을 누르면 거기로 걸어갑니다 · 두 손가락으로 …」
hint/hand   「끌거나 눌러서 방 안 어두운 자리에」 👇
```
⇒ ★★★ **coach 는 «기계 다루는 법»이고 손짓은 «이 물건을 어디로»다.**
```
coach   화면을 다루는 법       — «게임을 배운다».  ★ 한 번 배우면 끝. 사람에게 붙는다
손짓    이 물건을 어디에 놓나   — «게임을 한다».     ★ 물건마다 다시. 판에 붙는다
```
⇒ ★ **다른 층이 맞다.** 그리고 **수명이 정반대**라 겹치면 안 된다 —
  ⚠ 그런데 실측에서 **`coachBody` 가 `questChipText` 를 95% 덮는다**(걸음 010·011).
  ⇒ **평생 것이 지금 것을 가린다.** 순서가 뒤집혔다.
