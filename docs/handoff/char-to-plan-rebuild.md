  지금 A포즈 때문에 못 하고 있는 일은 **없습니다.**

### ② 재질 — **아틀라스 한 장에 온몸이 구워져 있다** ★ 이것이 진짜입니다


⇒ ⛔ **그래서 부위별로 색을 못 바꿉니다.** 셔츠만 파랗게, 머리만 갈색으로가 안 됩니다.
⇒ ★ 왜 못 하나 — 색으로 갈라내려 해 봤는데 **갈리지 않았습니다** [실측]:

```
남주부 «셔츠» ↔ 그의 «얼굴»      색도 거리 0.0247
남연구원 «손» ↔ 그의 «얼굴»      색도 거리 0.0374
⇒ ★★ 셔츠가 «손보다 얼굴에 가깝습니다». 어떤 색공간으로도 못 가릅니다
```

⇒ 그래서 색 커스터마이징을 **접었습니다**(README §4·§5).

### ③ 얼굴 — 3D 표정 · ⛔ **이건 닫혔습니다. 값이 없습니다**

⇒ ⇒ **「얼굴 때문에 다시 만드는 것」은 값이 없습니다.**

> ★ **그러므로 「무엇 때문에 다시 만드나」는 사실상 ②(재질) 하나입니다.**
> ①은 다시 만들면 따라오는 것이고, ③은 닫혔습니다.

## ㉯ 다시 만들면 **무엇이 되나**

### 되는 것

| | 무엇이 | 왜 지금은 안 되나 |
|---|---|---|
| ★ 부위별 색 | 머리·눈·피부·옷 색을 따로 바꾼다 | **한 장 아틀라스**라 부위를 못 가른다(위 ②) |
| ★ 눈 색·눈매 | 눈알을 별도 메시로 얹는다 | 지금 눈은 **형태가 없다** — 텍스처에 «그려진 그림»뿐이다 [실측] |
| 옷 색·무늬 | `retexture` 로 통째로 다시 굽는다 (10cr/벌) | ⚠ **지금도 됩니다.** 다시 만들 이유가 아닙니다 |

★ **눈 이야기를 덧붙입니다** — 「안구 없는 베이스」를 말씀하셨는데, 재 보니
**구멍을 팔 필요가 없습니다.** 지금 얼굴은 눈두덩도 안구도 **형태로 존재하지 않고**,
그 자리는 거의 평면입니다(곡률 반경 무한대~1019mm, 사람 안구는 12mm).
⇒ **「눈이 안 그려진 얼굴」로 뽑고 눈알을 뼈에 매달면 됩니다. 0크레딧.**

### ⛔ 안 되는 것 — **옷을 갈아입히는 것**

```

㉯ 뼈에 딱 매단다        O  0cr      ⇒ 머리카락·모자·안경·가방·눈알
㉰ 새 옷을 같은 뼈에      X  —       ⇒ 셔츠·바지·«치마»
```

⇒ ⛔ **Meshy 에 「이미 있는 뼈대에 새 메시를 스키닝한다」는 기능이 없습니다.**
  ([Asset] 이 도구 목록을 전수 확인)
⇒ ★ **그러므로 「퍼지는 옷(치마·코트)」은 다시 만들어도 안 됩니다.** Blender 를 놓아야 합니다.

> ⚠ **이 대목에서 제가 한 번 틀렸습니다.** 저는 총괄에 *"㉰(덧씌우기) 이것뿐입니다"* 라고
