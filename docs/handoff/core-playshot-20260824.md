## ① ★★ Day 0 에 안내가 **셋**이 한꺼번에 뜬다 (내 몫)

```
coach       "사람을 눌러 보세요 / 사람을 누르면 …"      ← 조작 안내
banner      "빈 시루를 하나 놓았습니다"                  ← 방금 한 일
questChip   "시루를 방 안에 놓아 보세요"                 ← 다음 손
겹침 95~100% · 010·011 두 걸음에서 같은 모양
```
⇒ 총괄이 「Day 0 은 지시가 둘」이라 했는데 **셋이다.** 그리고 셋이 **서로 다른 층**이다 —
조작 / 결과 / 다음 손. **[Plan] 이 오늘 세운 층 표와 같은 얘기**로 보인다.
⚠ 어느 것을 미룰지는 [Plan] 몫이다. 여기서는 **셋이 같은 자리에 겹친다**만 적는다.

## ② ★ `coachClose ✕` 가 `guideOpen ?` 위에 92% 얹힌다 (내 몫)

```
92% — coachClose «✕»  ⇄  guideOpen «?»
59% — coachClose «✕»  ⇄  coachTitle «사람을 눌러 보세요»
```
⇒ 안내를 닫으려고 [✕] 를 누르면 **[?] 를 누를 수도** 있다. 둘 다 44px 급이라 손가락 하나에 든다.
⚠ 눌러서 어느 쪽이 먹는지는 **안 쟀다.** 겹쳤다는 사실만이다.

## ③ ★ 대사 중 `[다음 날 ▸]` 와 `▼ 탭` 이 **100%** 겹친다 (내 몫 · 판단 필요)

```
100% — next «다음 날 ▸»  ⇄  dlgNext «▼ 탭»
 67% — next «다음 날 ▸»  ⇄  dlgText
```
⇒ ⚠ **고장은 아니다.** 대사 중에는 `#next` 가 `pointer-events:none` 이라 그 자리를 누르면
**대사가 넘어간다** — 그게 맞는 동작이다(내 하네스가 `offWhileTalking` 으로 갈라 찍었다).
⇒ ★ 그런데 **보이기로는** 흐린 「다음 날 ▸」 위에 「▼ 탭」이 정확히 포개진다.
  **누를 수 없는 단추 위에 누르라는 표시가 있다.** 그것이 어색한지는 [Plan] 판단이다.
⚠ 320 에서도 같다([Char] 실측). 해상도 문제가 **아니다** — 두 요소가 원래 같은 자리다.
