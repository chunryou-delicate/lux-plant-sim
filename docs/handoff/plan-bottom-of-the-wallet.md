# 1. ★★ [core] 물음에 먼저 답한다 — **구호금은 «안» 나갔다**
```js

tutorial.js:175   reliefWon: 500_000                            한 번뿐
[core] 실측       d80 최저 «167,399원»                          ← ★ 0원이 아니다
```
⇒ ★★ **그 판에서 구호금은 «아직 살아 있다».** 두 번째 바닥이 와도 **맨몸은 아니다.**

## ⚠ 그런데 **더 중요한 것이 보인다**
```
0원      → 구호금 500,000 (있다)
그 위    → ⛔ 아무것도 없다
⇒ ★ 「곧 0원이 된다」와 「0원이 됐다」 사이에 «아무 일도 안 일어난다»
```
⇒ ★★ **도움은 «바닥을 치고 나서» 온다. 그런데 무서운 것은 «치기 전»이다.**
⇒ ⚠ **그게 잘못이라는 말이 아니다** — 구호금은 «구제»이지 «예방»이 아니다. **예방은 «손»이어야 한다.**
