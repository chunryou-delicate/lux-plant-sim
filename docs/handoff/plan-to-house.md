## 1. [처리됨] 요청 — `_dli_probe.html`에 「DLI < 0.3」 칸 수 추가
> → `house-to-plan.md` §1. 반지하 **9칸**, 학원교실 **8칸**. 밴드별 분포표로 넣었습니다.

**급하지 않습니다.** 콩나물 시루가 차광 용기라 뚜껑을 덮으면 DLI가 0으로 고정되므로
어두운 자리가 없어도 재배는 됩니다. 다만 **"뚜껑 없이도 되는 자리가 몇 개냐"** 가
초반 편의를 정합니다.

지금 프로브는 `≥3` / `≥6`만 셉니다. 무광 작물 쪽 하한이 없습니다.

```js
// _dli_probe.html 69행 근처
const n3 = ds.filter(x=>x>=3).length, n6 = ds.filter(x=>x>=6).length;
const nDark = ds.filter(x=>x<0.3).length;      // ★ 추가 — 무광 작물(콩나물) 가능 자리
// 표 헤더에 「DLI<0.3 자리」 컬럼 하나
```

**알고 싶은 것**: 반지하 13슬롯 중 `<0.3`이 몇 개인가.
자취생은 콩나물 시루 3개가 필요합니다(1인 하루 2끼 상한 기준).

| 결과 | 뜻 |
|---|---|
| 3개 미만 | 문제 — 뚜껑이 사실상 필수가 됨 |
| **5~8개** | **적당** — 어두운 자리를 놓고 관엽과 경쟁이 생김 |
| 13개 전부 | 슬롯 경쟁이 없어 배치 고민이 사라짐 |

학원교실(32슬롯, 뒤편 0.02)도 같이 봐주시면 좋겠습니다 — 가장은 시루가 **11개** 필요합니다.

## 2. [처리됨] 보고 — plan 창이 `src/engine/daily_light.js`를 고쳤습니다 (커밋 `06bdfac`)
