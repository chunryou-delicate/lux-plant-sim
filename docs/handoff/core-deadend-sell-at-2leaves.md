# [core] ⛔ 잎 두 장에서 그루를 팔면 **판이 끝난다** — 실측

`tools/night_play.mjs --ending pot --seed 1` 이 밟았다. **읽어서도 셈해서도 안 나온 것**이다.

## 밟은 자리
```
d37  잎 2장(무지1 + 산반1)에서 「몬스테라 내놓기 ★(518,000원)」이 «열렸다»
d38  팔았다 ⇒ 지갑 795,766 → 1,300,666 · ★★ 화분수 «0»
d90  잎 2 · 화분 0 · 지갑 882,066 — 줄기만 한다
⇒ ⛔ 그루가 사라졌다. 이사비 2,000,000 은 «영영» 못 채운다. 되돌릴 수 없다
```

## 왜 함정인가
```
· d37 은 이르다 — 무늬 잎이 «하나»뿐이다(잎3 하프문은 d87 에 온다)
· 아무 경고가 없다
· ★ 글자가 «좋아 보인다» — 「+518,000원」. 그날 지갑이 795,766 이라 «커 보인다». 누를 만하다
```
⇒ [Plan] 갈래로 **「벌」**이다 — 되돌릴 수 없는 막다른 길. 「배움」이 아니다.

## ★ 그리고 문 둘이 어긋나 있다
```
자르는 문   ✔ 2026-08-24 좁혔다 — 「무늬 잎 «둘»이 다 자랐을 때」 (2690e3b · 박사님 B1)
파는 문     ⛔ 그대로 — 「잎 «2장»」 (shop.js MARKET_MIN_LEAVES = 2)
```
⇒ ★★ **자르는 문만 좁히면 사람은 「더 나쁜 쪽」으로만 갈 수 있다.**
  삽수는 **잎 하나**를 잃고, 그루째는 **판**을 잃는다.

## ⛔ 값은 안 건드렸다 — 밸런스다. 물음만 남긴다
```
「잎 두 장에서 그루를 팔 수 있게 둘 것인가」
  ㉮ 삽수와 «같은 문»으로 — 무늬 잎 둘이 다 자랐을 때
  ㉯ 그대로 — 팔아서 망하는 것도 배움이다
  ㉰ 다른 문 (경고 한 번 · 되묻기 · 값이 이사비에 못 미치면 회색 …)
```

## ⚠ 그리고 지금 도는 판에 대한 기록
```
--tag potend2 (2026-08-24) 는 «파는 문이 잎 2장인 채»로 돈다
⇒ ★ 내 손이 「팔면 나갈 수 있을 때만」 팔아서 «안 밟을» 뿐이지, 문은 «그대로 열려 있다»
⇒ ⚠ 그러니 그 판의 결과는 「이 함정이 없는 판」이 아니라 「이 함정을 피해 간 판」이다
```
