## git
- 저장소는 하위 `lux-plant-sim/`. remote 이름은 **`origin`**.
- **`git add .` 금지.** 내가 만진 파일만 지정해서 커밋한다.
- 커밋 뒤 `git show HEAD:파일 | grep -c 표식` 으로 실렸는지 확인한다.
- 배포는 GitHub Pages다. `game.html` 의 「이 판」 표식(`content="2026-08-.."`)을 올리고,
  푸시 뒤 배포 URL 을 curl 로 긁어 **그 표식이 실렸는지 글자로 확인**한 다음에 박사님께 링크를 드린다.

## 부록 — 박사님께 (붙여 넣지 않아도 되는 부분)

### 왜 「먼저 읽어라」를 맨 앞에 뒀나

새 창은 저장소를 모른다. 그런데 이 저장소는 **계율이 코드보다 앞선다** — 특히
「재는 자를 먼저 의심하라」를 모르면, 새 창은 어제 제가 여섯 번 빠진 함정에 똑같이 빠진다.
그래서 지시서의 첫 줄이 「코드를 고치기 전에 저 둘을 읽어라」다.

### 왜 지뢰를 지시서 본문에 넣었나

`gen_room_profile.mjs --write` 는 **한 줄이면 실행되고, 실행하면 검사가 붉어진다.**
그리고 붉어진 검사를 보면 새 창은 「내가 뭘 깼나」를 찾느라 한참을 쓴다.
문서 안쪽에만 적어 두면 그때는 이미 늦다. 그래서 **읽는 순서상 세 번째 문단**에 뒀다.

### 남은 것의 차례를 왜 이렇게 뒀나

1·2번은 **박사님이 직접 보신 것**이라 체감이 크다. 3번은 제가 남긴 빚이고,
4번은 **검사 두 개를 한꺼번에 풀 수 있는 뿌리**라 맨 뒤에 뒀다(급하지 않지만 값이 크다).

⚠ 1번에 「먼저 여쭤라」를 붙인 까닭 — 격자와 상판은 **어느 쪽을 맞춰도 잃는 게 있다.**
제가 골라 버리면 박사님은 잃은 쪽만 보시게 된다. 이런 건 물어야 하는 자리다.

### 원화 항목을 목록에서 빼고 규칙으로 바꾼 까닭

원화는 끝났지만 **다시 뽑을 일은 또 온다.** 그래서 「이번에 그릴 것」이 아니라
**「그릴 때 지킬 것」**으로 옮겨 적었다 — 어제 제가 실사를 뽑은 그 실수가
다음 창에서 되풀이되지 않게.
