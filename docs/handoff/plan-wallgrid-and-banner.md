# 1. ⛔⛔⛔ 먼저 — **배너는 «6초»다. 내 판정이 세 번째로 틀렸다**

```js
game.html:14305   bannerTimer = setTimeout(() => el.classList.remove('on'), 6000);
game.html:14303   el.onclick = () => { clearTimeout(bannerTimer); el.classList.remove('on'); }
game.html:14286   "③ 누르면 사라진다 — 읽었으면 치울 수 있어야 한다. «6초를 기다릴 이유가 없다»"
```
⇒ ⛔ **「사건이 안 나면 영원」도 취소한다.** **시계가 이미 있고, 누르면 더 빨리 없어진다.**
⇒ ★ **§5 의 「고칠 넷」에서 ② 를 뺀다. 넷 → 셋.**

## ★★★ 그런데 **낱개로 틀린 게 아니다 — 같은 자에서 세 번 틀렸다**
```
§6  "열이틀에 한 번도 못 거둔다"   ← 자가 「심기」를 «안 눌러서»
§2  "배너가 day 12 까지 있다"      ← 판이 «안 굴러서»
§3  "배너 수명은 사건까지다"        ← 자의 6초와 사람의 6초가 «달라서»
```
⇒ ★★★★ **한 자에서 나온 세 판정이 세 번 다 틀렸다.**
  ⇒ **문제는 낱개 판정이 아니라 «그 자를 읽는 법»이다.**

> ## **`playshot` 은 「무엇이 화면에 있나」를 잰다.**
> ## **「사람이 그것을 얼마나 «오래» 보나」는 «못» 잰다.**
> ## ⇒ **시간이 그 자의 눈에는 안 보인다.**

⇒ ★★ **내 검사 갈래로는 ㉤(애초에 못 재는 자)다** — 다만 **시간에 관해서만** 그렇다.
  **자리·겹침·같은 글자는 잘 잰다.** ⇒ **자를 버릴 것이 아니라 «무엇을 물을지»를 가려야 한다.**
```
★ 이 자에 물어도 되는 것    무엇이 있나 · 어디 있나 · 겹치나 · 같은 글자인가
⛔ 이 자에 물으면 안 되는 것  얼마나 오래 · 언제 사라지나 · 사람이 무엇을 먼저 보나
```
⇒ ★ **「수명」이라는 축 자체는 선다.** 다만 **그 축의 값은 이 자로 못 잰다.**
  ⇒ ⚠ **축을 세운 것과 값을 채운 것을 내가 안 갈랐다.** 그것이 세 번의 공통점이다.

# 2. ★ 벽 격자 — **ⓐ(0.25m · 바닥과 같은 자) 다.** [House] 와 같은 답, **다른 까닭**

[House] 까닭은 **「자를 늘리지 마라」**(코드 위생)다. ★ 더 센 까닭이 **사람 쪽**에 있다:

> ## **바닥에서 배운 자가 벽에서도 통하면, 벽은 「배울 것이 없는 곳」이 된다.**
> ## **벽마다 칸이 다르면, 사람은 벽에서 «다시» 배워야 한다.**

⇒ ★ 계율 ④(*줄지어 있는 것은 따로, 짝인 것은 같이 가르친다*)에 걸린다.
  **바닥과 벽은 짝이다** — 둘 다 「물건을 놓는 곳」이다. **따로 가르칠 것이 아니다.**

## ㉡ ★★★ 그리고 ⓑ 는 **눈에 보이는 어긋남을 만든다**
```
ⓑ 가로 칸이 벽마다 0.714m / 0.800m
⇒ ★ 같은 등이 «벽 A 에서 두 칸, 벽 B 에서 세 칸»을 먹는다
```
⇒ ⚠ 총괄이 *"안 보이니 상관없나"* 하셨는데 — **보인다.**
  **등을 이 벽에서 저 벽으로 «옮길 때» 보인다.** 그리고 벽부등은 **옮기는 물건**이다(박사님 ②).
⇒ ★★ **옮길 수 있게 만든 물건인데, 옮기면 앉는 법이 달라진다.** 그건 사람이 못 배운다.

## ㉢ ★★ ⓑ 는 **「값이 뜻을 정하는」 구조**다 — 오늘 본 그 병을 «구조로» 박는다
```
ⓑ  칸 크기 = 등 크기      ⇒ 등 크기를 고치면 «격자가 통째로» 바뀐다
```
⇒ ⚠ **오늘 우리는 「값은 맞는데 까닭이 낡은」 것을 봤다**(가구 30,000 / 등 1.68배).
  ⇒ ★ ⓑ 는 그 병을 **고칠 수 없게 만든다** — 값이 곧 격자라서.
⇒ ★ 화분에서 이미 겪어 **시루 0.24 로 못을 박았다**. **같은 못을 또 박느니 안 박는 쪽이 낫다.**

## ㉠㉣ ★★★ **둘은 «같은 물음»이고, 답이 하나다**
```
㉠  608칸을 다 그리면 벽이 뒤덮인다
㉣  사람이 벽 칸을 «언제» 보나
```
⇒ ★★★ **칸을 「그릴」 필요가 없다.**
```
사람은 칸을 «세지» 않는다. 등을 «끌» 뿐이다
⇒ 끌고 있는 동안 «붙을 그 칸 하나»만 밝히면 된다
⇒ ★ 그러면 608 이든 202 든 «화면에 보이는 것은 늘 하나»다
```
⇒ ⇒ ★★ **㉠ 은 「자의 문제」가 아니라 「그리는 문제」다.** 자를 바꿔서 풀 일이 아니다.
⇒ ⚠ **바닥이 지금 어떻게 하고 있는지 [House] 가 봐 주면 좋겠다** —
  **바닥과 같게 하는 것이 이 답의 전부**이므로, 바닥이 격자를 늘 그리면 벽도 그래야 한다.

## ⇒ ★ 한 줄로
> **자는 하나(0.25m)로 두고, 「보이는 것」으로 푼다.**
> **칸을 다 그리지 말고, 붙을 칸만 밝힌다.**

# 4. ★★★ ① 칩/줄 — **끌 것은 「자리」가 아니라 「겹침」이다**

## ⓐ 먼저 잰 것 — **「시트가 말한다」는 가정이 «반쪽»이다**
```
sheetQuest   game.html:2215  ← ★ pagePlants(식물 탭) «안»에만 있다
qtodo        game.html:7899  ← ★ 할 일 «탭»의 줄 목록 «안»에만 있다
game.html:4933 주석  "시트가 열려 있으면 손가락은 쉰다. 그 안에서 할 일은 «시트 자신이 말한다»"
```
⇒ ⚠⚠ **그 가정은 「시트 = 식물 탭」일 때만 참이다. 탭은 다섯이다.**
```
시트 열림 + 식물 탭    sheetQuest 가 말한다        ✅
시트 열림 + 할일 탭    qtodo 가 말한다             ✅
시트 열림 + 가방 탭    ⛔ 아무도 말 안 한다
시트 열림 + 상점 탭    ⛔ 아무도 말 안 한다
시트 열림 + 방 탭      ⛔ 아무도 말 안 한다
```
⇒ ★★★ **그런데 그 셋이 «할 일을 하는 곳»이다** — 시루를 끌고(가방) · 씨앗을 사고(상점) · 자리를 고른다(방).
⇒ ⇒ ★★★★ **할 일을 «하는» 탭에 할 일이 «안 보인다».** 지금도 그렇다.

## ⓑ ⇒ **그래서 [core] 물음의 답이 「어느 것을 끄나」가 아니다**
```
지금     chip.on = 말이 있고 && !시트열림
★ 바꿈   chip.on = 말이 있고 && !(sheetQuest 나 qtodo 가 «지금 보이나»)
```
| | 지금 | ★ 바꾼 뒤 |
|---|---|---|
| 시트 닫힘 | 칩 + 줄 **둘 다** | 칩만 |
| 식물 탭 | sheetQuest | sheetQuest (칩 끔) |
| 할일 탭 | qtodo | qtodo (칩 끔) |
| **가방·상점·방 탭** | ⛔ **아무도** | ★ **칩** |

⇒ ★ **그리고 줄(`#quest`)은 «끈다».** 칩이 모든 경우를 덮으므로 자리가 겹치지 않는다.

## ⓒ ★★ 줄을 끄는 까닭 — [core] 둘에 하나 더
```
[core] ① 칩은 «누를 수 있고» 누르면 할 일 판이 열린다. 줄은 읽기만 한다
[core] ② 줄은 하단 띠라 sellPantry 91% · ledgerBackHint 86% 로 «계속» 부딪힌다
★ 하나 더  줄은 «못 누르는 지시»다. 지시인데 손이 없다
```
⇒ ★★ **내 층 표와 맞는다 — 「다음 손」을 말하는 자리는 «손이 붙어 있어야» 한다.**
  **칩은 지시이면서 손이다. 줄은 지시이기만 하다.**

## ⓓ ⇒ ★★★ 그리고 이것이 **규율 ㉰ 의 정확한 구현**이다
> **㉰ 같은 글자를 두 곳에 짓지 않는다 — 한 곳에서 짓고 가져다 쓴다**
> ★ **여기에 짝이 붙는다: 「가져다 쓴 자리는 «원본이 안 보일 때만» 켠다」**

⇒ ★★ **일반 규칙으로:**
> ## **「어디에 두나」가 아니라 「누가 이미 말하고 있나」로 켠다.**

⇒ ★ 이러면 탭이 늘어도 규칙을 안 고친다. **새 탭은 「말하는 자리가 없다」에 저절로 들어간다.**

## ⓔ ⚠ **[core] 가 확인할 것 하나**
칩을 가방·상점·방 탭에서 켜면 **z 23 이라 시트 위에 뜬다.**
⇒ ⚠ **거기서 새 겹침이 날 수 있다** — 지금 실측에는 안 나온다(칩이 꺼져 있어서다).
⇒ ★ **켜 보고 다시 찍어야 안다.** 겹치면 **칩 자리를 옮기는 것**이지 규칙을 되돌릴 일은 아니다.
