# 원룸 첫 장면 — 「반지하 있던 가구만 가져와서」 놓는다
2026-09-06 밤 · [plan] · 박사님 「반지하 있던 가구만 가져와서」 · agree-oneroom-move ㉢ 「이사 때 반지하 가구를 가방으로 · 등도 가구」
⛔ 값 없음. 순서·뜻·문안만. 원룸 밝기·등 값은 [house]·[growth] 것이고 「기준 배치」(박사님 묶음 ④)가 서면 수가 붙는다.

---
## ⓐ 첫 장면이 가르치는 것 — 반지하와 «다르다»
```
반지하  ⇒ 자리를 «고른다»          — 칸은 방이 주고, 사람은 밝은 칸을 «찾는다» (옮기는 것이 두 번째 학습)
★ 원룸  ⇒ 자리를 «만든다»          — 방은 창턱 4칸뿐(빈손 [잰 것]: 무순 자리 4/4 · 콩나물 자리 0/4)
                                     ⇒ 어두운 자리는 «가구를 놓아야» 생긴다 ⇒ ★ 「가구가 자리를 만든다」
```
> **⇒ 첫 장면의 배움은 「어디에 놓나」가 아니라 「무엇을 놓으면 자리가 «생기나»」다.** 반지하에서 「밝기의 층」을 보기만 했다면, 원룸에서는 «만든다».

## ⓑ 도착 순간 — 방은 비어 있고 «가방이 차» 있다
```
방      창턱 · 벽 · 바닥 — 가구 없음 (천장등만 두고 온다 · rooms_spec §13)
가방    반지하 가구(선반·책상·에타제르 …) · 식물등(가구다) · 그리고 «세 갈래»에 따라 다른 것
          ⓐ 그루째 팔았다 ⇒ 씨앗·시루만       ⓑ 잘라 두고 왔다 ⇒ 삽수 n개      ⓒ 안 팔았다 ⇒ 그루 (plan-oneroom-order ⓒ)
```
⇒ ★ 도착 배너는 「놓였습니다」라 하지 않는다 — 반지하 ㉣의 병. 「가방에 다 들어 있습니다」가 참인 말이다.

## ⓒ 손가락 — ⛔ 강제(어둡게) 없음. 안내(가리킴)만. 두 번째 방이라 배운 것을 «쓴다»
```
①  가방        「가방을 열어 보세요 — 반지하에서 가져온 것이 다 있습니다」
②  가구 하나   「선반을 꺼내 놓아 보세요」        ⇐ 반지하의 「놓기」를 그대로 쓴다. 무엇이든 하나
★③ 그늘 칸     (가구가 놓인 «순간») 「선반 아래가 어두워졌습니다 — 콩나물 자리입니다」   ⇐ ★ 여기가 새 배움. 놓은 «그 순간»에 말한다
④  식물·시루   「이제 식물과 시루를 놓으세요」   ⇐ 세 갈래마다 문안이 다르다(아래 ⓓ)
⑤  등          손가락 «없음». ⛔ 등은 퀘스트(buy_lamp 계열 · 원룸용)가 연다 — 원룸에서 등은 「길」이 아니라 「속도」다([growth] 빈손 400일)
```
⇒ ①~④가 끝나면 손가락은 없다. 그 뒤는 원룸 퀘스트(plan-oneroom-questline)가 받는다.

## ⓓ ④의 문안 — 세 갈래
```
ⓐ 씨앗   「시루를 놓고 씨앗을 심으세요 — 처음처럼」          ⇐ «맨 처음»이다. 몬스테라는 없다
ⓑ 삽수   「삽수를 «밝은 자리»에 놓으세요」                    ⇐ 반지하 d11 문안 그대로 — 「어디」는 안 말한다
ⓒ 그루   「몬스테라를 «밝은 자리»에 놓으세요」                ⇐ 같음
```

## ⓔ ⚠ 여기서 걸리는 것 둘 — 정하지 않고 적어 둔다
```
① 「가방에 다 들어 있다」인데 가방이 «격자 인벤»이다(bagui) ⇒ 가구가 가방 칸을 «몇 개» 먹나 — [core]·[house]. 값 아님이지만 화면
② 「기준 배치」(박사님 묶음 ④)가 ㉯(들고 온 가구를 다 놓은 상태)로 서면 ⇒ ★ 이 첫 장면의 «끝 상태»가 곧 기준 배치다 — 둘이 «한 벌»
```

## ⓕ ★ [core] 가 원룸을 «세운 판»으로 걸어 보니 — 첫 플레이 사슬이 원룸에서 «도로 켜졌다» (09-06)
```
도착 대사 → 손가락이 «첫 플레이 시루 놓기»(cropThumb)를 짚음 → 놓임 → ★ fp 단계가 grow_beansprout 로 «다시» 돎
그 뒤 손가락 «없음» — 가방의 가구 아홉을 받아들이고·놓고·옮기는 손가락이 없다
```
### 답 — ② «다른 사슬»이다. ① 「다시 돈다」는 병이고 ③ 「자유」는 박사님 말씀(「플레이어가 배치」 — 가이드가 있다는 뜻)과 어긋난다
```
① 첫 플레이 사슬을 다시 돈다   ⛔ 「시루 하나 놓기 → 닷새 → 몬스테라 도착 …」은 «반지하의 이야기»다. 원룸엔 몬스테라가 «오지» 않고 «들고 온다»
② ★ 다른 사슬                 ⓒ 손가락 넷(가방 → 가구 하나 → 그늘 칸 → 식물·시루) — 강제 없이 안내만. 위 ⓐ~ⓓ가 그것이다
③ 자유                        가방에 아홉이 든 채 아무 말이 없으면 「가방은 잊히는 곳」이 «가구 아홉»으로 일어난다
```
### ★ 그러니 «먼저» 서야 할 것 — 「첫 플레이는 «반지하 한 번»이다」
```
뜻   첫 플레이 사슬은 ⓐ 끝난 것은 다시 안 켜진다  ⓑ 방이 바뀌면 안 켜진다 — «둘 다»
칸   ⓐ 는 이미 있다 — fp.completed. 참인데 phase 가 다시 돈다면 «칸»이 아니라 «검사»가 빠진 것이다(㊺ 세이브 판 — 새 칸 만들지 말 것)
     ⓑ 는 방 칸(home.room 계열)이 있다. 「반지하가 아니면 첫 플레이가 아니다」
⇒ ★ 어느 것이 정본인지는 [core]와 직접 세운다. 내 뜻: ⓐ가 «주», ⓑ는 «띠» — 이사는 첫 플레이가 끝난 뒤에만 오므로 ⓐ만으로도 막히지만, 옛 세이브·손 스냅샷이 fp.completed 를 안 실을 수 있어 ⓑ가 받친다
```
### 원룸 첫 장면 사슬의 «끝» — 「무엇이 끝나면 손가락이 없어지나」
```
끝 = 가방에 든 «식물(그루/삽수/시루)»이 다 놓였다 — 가구는 «다» 놓지 않아도 된다(자유 · 박사님 「플레이어가 배치」)
⇒ 가구가 남아 있어도 끝난다 — 남은 가구는 「가방은 잊히는 곳」이 아니다. 가구는 «안 잊혀도 되는 것»이라(자라지 않는다)
⇒ ⚠ 박사님 「시작 원룸을 내가 해보고 너무 비어 있으면 기본 가구 배치 추가」 ⇒ 지금은 «안 넣는다». 박사님이 해 보신 뒤
```
⇒ ✔ [core] 밤 수확 — 새싹 재배판 가방 칸이 죽어 있었다(id 겹침 · 누르면 놓기 없음) → 고침. 80일 표의 「무순 0」이 그것. radish5 는 6판에서 «처음» 난다 — 빈 날 표(plan-empty-days)에 그때 얹는다.
