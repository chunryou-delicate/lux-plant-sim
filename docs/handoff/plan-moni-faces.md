## ⓔ ★★★ [char] 가 낸 것이 더 낫다 — 「몬이는 «가르치는» 캐릭터인데 얼굴이 「궁금」이다」
```
[char] 실측 ⇒ curious 87줄 «대부분»이 궁금이 아니라 «설명»이다 —
  「무늬 진 데는 빛을 못 만들어서, 밝은 자리에서만 나와」 · 「거둬야 다음 바퀴가 돌아」 · 「그 자리가 밝아진 거야」
  진짜 궁금은 「이상하지? 물도 줬고 날짜도 갔는데…」 몇 줄뿐
```
### ⇒ ★ `teach`(가르침 · 50~60줄)가 필요한 까닭 둘
```
① 오늘 세운 것 그대로 — 「한 낱말이 «다른 것»을 가리키면 그 낱말로 규칙을 세우지 마라」. curious 가 둘을 가리킨다
★★② 가르침과 궁금이 «같은 얼굴»이면 ⇒ 몬이가 «아는 것»과 «모르는 것»을 사람이 «못 가른다»
   「이상하지? 물도 줬고 날짜도 갔는데…」 ⇒ 몬이도 «모른다» ⇒ ★ 사람이 «자리를 옮겨야» 한다
   「무늬는 정해져 있어」                  ⇒ 몬이가 «안다»   ⇒ 사람은 «기다리면» 된다
⇒ ⇒ ★★★ 「몬이도 «모르는» 때」가 곧 「«네가» 움직일 때」다. 이 게임이 「막혀 봐야 안다」로 가르치는데 그 신호가 «얼굴에 없다»
```
### ⇒ 나머지 판정
```
proud ↔ cheer   ✔ 가른다. 향하는 데가 다르다 — proud 는 «사람»을 향하고(「그게 한 거야」 = 「옮기는 것이 두 번째 학습」의 보상 · 이 게임의 가르침 그 자체)
                cheer 는 «제가» 신난 것(「— 뿅!」)이라 «맛»이다 ⇒ ★ proud 를 «먼저»
⛔ tired/sleepy  안 넣는다. 원화가 있어도 «대사가 안 부르는 것»이 까닭 있는 것이다 —
                ★ 「몬이는 지치지 않는다」. 체력은 «사람»의 것이고, 몬이가 지치면 「몬이도 손이 모자란가」로 읽혀 체력 계통이 흐려진다
```
### ★★★ 그리고 [char] 의 자취녀 줄이 «대칭»을 보여 줬다
```
몬이   «가르치는» 캐릭터인데 얼굴이 「궁금」(curious 87)
자취녀 «묻는» 캐릭터인데 curious 4줄이 「think」 «별칭»
⇒ ★★ 둘의 얼굴이 «뒤바뀌어» 있다 — 몬이가 궁금해하고 자취녀는 «생각한다»
⇒ ⇒ 자취녀 `curious` 도 넣는다. 「몬이는 «가르치고» 자취녀는 «묻는다»」가 서면 ⇒ ★ 둘이 «다른 일»을 한다는 것이 «얼굴만으로» 보인다
```
> ## ⇒ ★ 차례 — **teach → worry → 자취녀 curious → proud → calm → cheer.** 앞의 셋이 「«누가» 아는가」를 만든다.


## ⓘ ★★★ 총괄 물음 — 「당연해서 안 적은 것」 한 자리
> # **「몬이가 무엇을 «못» 하나」가 어디에도 없다.**
```
오늘 «셋»이 흩어져 나왔다 — 다 「오늘 처음」 적힌 것이다
  · 몬이는 «지치지 않는다»            (낯 판정에서 · 체력은 사람의 것이라)
  · 몬이는 «이름을 안 부른다»          (독촉 문안에서 · 「그거」라고 한다)
  · 몬이는 «모를 때가 있다»            (teach 판정에서 · 그때가 「네가 움직일 때」다)
⇒ ⛔ 셋이 «한 자리»에 없다. 그래서 창마다 몬이를 «짐작»한다 —
   [char] 는 낯을 만들 때 · [core] 는 대사를 넣을 때 · 나는 문안을 낼 때
```
⇒ ★ 총괄 말 그대로다: **「안 적은 것은 지어내진다」.** 그림에만 나는 병이 아니다. 오늘 아침 「바닥」이 그랬다.
⇒ ⇒ ★★ 그리고 「몬이는 «무엇이다»」는 여기저기 있는데 「«못» 한다」가 없는 것 — ⇒ **금은 «할 수 있는 것»보다 «못 하는 것»이 긋는다.**
