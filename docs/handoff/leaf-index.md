## ⚠ 먼저 — 이 창의 표를 읽는 법

「보인다」는 **네 가지가 다 정해져야** 뜻이 있다. 안 밝히면 반드시 오독된다.

```

② 밝기      휘도비 — 텍스처 대비 화면에 찍힌 값
             어두운 자리 0.380 / ★ 창턱 0.516 (실측 · 2,443화소) / 밝은 바탕 1.00

             ★ 배경이 바뀌면 「멀리서/당겨서」 비의 «방향»이 뒤집힌다
```
