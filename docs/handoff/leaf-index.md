## ⚠ 먼저 — 이 창의 표를 읽는 법

**같은 잎을 재도 조건이 다르면 다른 표다.** 이 창의 수는 거의 다 「보이나」인데,
「보인다」는 **네 가지가 다 정해져야** 뜻이 있다. 안 밝히면 반드시 오독된다.

```
① 크기      «화면 px» 인가 «실물 m» 인가 — ★ 섞으면 3배 틀린다
             ⚠ 내 phone_pixel_table.md 는 «환산»(1m≈106px)이라 «전부 위쪽 값»이다
             ★ 실측은 [core] 것이다 — 성숙잎 14×15 · 중간잎 4×7 / 9×8 · 45일 그루 잎 3×3
             ⚠ 그리고 그것도 bbox 라 기울면 실제보다 크다 ⇒ ★ «또» 위쪽 값이다
② 밝기      휘도비 — 텍스처 대비 화면에 찍힌 값
             어두운 자리 0.380 / ★ 창턱 0.516 (실측 · 2,443화소) / 밝은 바탕 1.00
             ⛔ 「어두운 자리」로 잰 표는 «쓰지 마라» — 거기선 잎이 «안 난다»([growth])
③ 배경      잎 «뒤»가 무엇인가 — 어두운 바닥 58 / ★ 창턱 122 (실측)
             ★ 배경이 바뀌면 「멀리서/당겨서」 비의 «방향»이 뒤집힌다
④ 눈인가 셈인가  ★★ 이 창의 「몇 갈래 갈리나」는 «전부 내 눈»이다
             ⛔ 셈으로는 못 잰다 — 자 둘(색까지 · 색 뺀 무늬만)이 어느 크기에서나 34~36 을 낸다
             ⇒ 12px 에서도 「36갈래가 다 갈린다」고 말한다. 사람이 그럴 리 없다
```
> ★ **그리고 이 창의 수는 «다 위쪽 값»이다.** 어느 쪽으로 틀려도 **실제가 더 나쁜** 쪽이다.
> ⇒ 그러니 「45% 보다 나쁘다」면 **45% 로 정해도 안전하다.**
