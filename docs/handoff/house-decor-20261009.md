## 잰 것

### ① 상점 — 바뀐 것 없음

- 새 GLB 는 **그림만** 바꿨다. 프리셋(`furniture_presets.json`)은 한 줄도 안 바꿨으므로 가구점 줄 수(83)·값(=크기 규칙)·되파는 값은 그대로다 — `test_furnishop` 68/68.

### ② 충돌·길 — v2 옷이 새로 만든 «뚫고 지나감»은 없다
