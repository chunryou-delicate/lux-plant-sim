# ② 속의 수 — 「이렇게 돈다」

## 조도 셈의 밑 — **다섯을 곱한다**
```
그날 천공 상한 = 25,000 lx × 날씨 × 계절 × 지역
   25,000       맑은 하늘 상한. ⚠ «캘리브레이션값»이다 (문헌 실내 창가 DLI 3~8에 맞춤)
   날씨   맑음 1.00 · 흐림 0.25 · 비 0.12
   계절   여름 1.00(14.5h) · 봄 0.85(12.7h) · 가을 0.80(11.8h) · 겨울 0.55(9.8h)
   지역   전부 1.00  ⚠ 자리만 잡아 뒀다. 서울 기준 ±5%라 뒤로 미룸
⇒ 겨울 총량 = 0.55 × 9.8/14.5 = 여름의 «37%»
```
```
그 자리가 받는 lx = 천공 × «조도비»
   조도비 = 창을 3D 사각 개구부로 보고, 그 점에서 «창이 보이는 입체각»을 적분
   ⇒ 시간과 무관한 «기하학» 값이다. 창을 안 옮기면 안 변한다
   가리는 것: 가구(occluders) · 벽 · 다른 층(자기 자신은 뺀다 = occIdx)
```
```
창 향(方位) 계수 — 남 1.00 · 남동/남서 0.85 · 동/서 0.62 · 북동/북서 0.45 · 북 0.38
                   천창(zenith) 1.20
   ⚠ 이 모형의 하늘은 «방향 없는 균일 휘도»다. 향을 안 넣으면 북창과 남창이 똑같이 밝다
```
```
lx → PPFD   × 0.0185  (태양광 기준 · Apogee)
PPFD → DLI  peak × (2/π) × 낮시간 × 3600 / 1e6
            ⇒ (2/π)는 해가 반원을 그리는 것의 적분
```
⚠ **층은 안 본다.** 반지하가 어두운 것은 「반지하라서」가 아니라 **창이 작고 높이 있어서**다.

## 식물등 — 거리로 준다
```
PPFD = ppfd_ref × (기준거리² / 거리²)         ← 역제곱
       × 광축에서 벗어난 각도 감쇠
       × 0.18                                 ← 뒤쪽(반사광). 0 이 아니다
   기준거리 0.3m · 최소거리 0.06m (발산 방지)
   퍼짐 반경 = coverage_r × (거리/기준거리)    ← 멀수록 넓게
```
