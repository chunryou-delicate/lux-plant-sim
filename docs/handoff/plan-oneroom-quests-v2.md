## 3. 세 갈래 시작 상태 — 버튼이 아니라 «들고 온 것»으로 갈린다
이사는 「갈래 고르기」 화면이 없다. 사람이 이사 «전»에 그루를 팔았나·잘랐나에 따라 들고 오는 것이 달라질 뿐이다. 그래서 갈래는 **이사하는 순간의 사실**로 읽는다.
```
갈래            이사 순간의 사실(읽기만)                         들고 오는 것 → 원룸에서(지금 코드 · oneroom.js)
ⓒ 안 판다       모주 화분(pot0) 이 있다                          그루 → 가방(placedOnce=false) · 삽수·시루 → 새 방 자리로 다시 앉힘
ⓑ 잘라 두고     모주가 없고 · 무늬 삽수(varieFromCut)가 있다       삽수 → 새 방 자리로(rehomeCuttings) · 시루 → reseatCrops
ⓐ 그루째 판다   모주도 무늬 삽수도 없다                          시루·씨앗뿐 (현금이 많다 — 프롤로그 그루 = 1,960,000원 · test_variegrade B-1)
```
- **[core] 에 부탁 — 이사 순간에 «한 번만» 적는다:** `story.branchAtMove = 'keep' | 'cuttings' | 'sold'` · `story.varieSaleAtMove = ts.varieSale.count`. 두 칸 다 세이브에 실리고, 지우거나 바꾸지 않는다(그날의 사실이다). 화면·자·대사가 이 둘을 읽는다.
- 다섯 줄이 갈래마다 어떻게 굴러가나:
  - **ⓒ** — ① 그루를 놓고 → ② 잎2·잎3(무늬)의 마디를 잘라 밝은 데서 → ③ → ④ → ⑤. 막힘 없음.
  - **ⓑ** — ① 은 들고 온 것이 자리로 다시 앉아 «바로» 끝날 수 있다(가방이 비어서 — 참말이다). ② 는 두 길: 들고 온 무늬 삽수가 아직 «뿌리내리는 중»이면 원룸 밝은 데서 뿌리내려 그대로 끝난다. 이미 반지하에서 뿌리낸 것이면 흙에서 그루로 키워 잎이 난 뒤 잘라야 해서 길다(삽수 잎 하나 32일 · growth).
  - **ⓐ** — ⛔ **② 에서 막힌다.** 원룸에 무늬 원천이 없다. 몬스테라 씨앗(상점 1립)부터면 540일에 새 잎 5~6장 · 새 무늬 중앙값 0장(growth). 지금 수로는 «막다른 길»이다.
