## ⓐ 먼저 — 「빈 날」은 «넷»으로 갈린다. 셋은 병이 아니고 하나가 병이다
```
Ⓐ 손가락이 있는 날        강제 가이드가 이끈다                        ⇒ 세팅 안(d0~d13)
Ⓑ 독촉이 채우는 날        열린 퀘스트를 안 한 날. 사건 > 독촉 > 잡담   ⇒ 세팅 뒤 대부분
Ⓒ 진짜 빈 날              열린 퀘스트 «없음» · 손가락 «없음» · 기다림  ⇒ ★ 잡담 몫. 「기다리는 게임」의 날
⛔Ⓓ 병                    퀘스트는 열렸는데 손가락도 독촉도 «없는» 날   ⇒ 오늘 아침까지 d18~24 가 이것이었다 — 이제 0
```
> **Ⓒ는 고칠 것이 아니다.** 25일·75일을 기다리는 게임에 빈 날이 없으면 그게 병이다. 고칠 것은 Ⓓ뿐이고, 사건>독촉>잡담 차례가 그것을 없앴다.
