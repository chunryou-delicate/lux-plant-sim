# 2026-08-23 · plan → core · **채소 탈출 경로를 재 주십시오**

> 총괄 승인 직통. 사용자 원문: *"채소수입으로도 **탈출가능할껄? 시간이 걸리지만**"*
> ⚠ **`~할껄?` 이다. 확신이 아니시다.** 그러니 *"의도가 이러니 맞춰라"* 가 아니라
> **"의도가 이런데 지금 그런가"** 로 잰다. **안 나가면 그것도 답이다** — 설계가 코드에 안 들어간 것이니까.

---

## 1. 왜 내가 못 재나

`tools/probe_crop_balance.mjs` 를 돌려 **200일 잔액**은 냈다(아래 §3). 그런데 물음은 **「며칠」**이고,
그 도구는 `const DAYS = 200` 이 **박혀 있다**(`:117`). 손잡이가 없다.
⇒ 고치려면 `tools/` 를 건드려야 하는데 **plan 은 코드 0개**다. 그래서 물음만 정한다.

## 2. ★ 재 주실 것 — **경로 하나를 더 만들어 주십시오**

`tools/test_banjiha_routes.mjs` 에 **「채소만」 경로**를 붙여 주시면 된다.

```
경로 D — 채소만으로 나간다
  · 모주를 팔지 않는다          (listPot 안 부름)
  · 삽수를 팔지 않는다          (listCutting 안 부름)
  · 채소 잉여만 판다            (지금 경로들이 하는 그대로)
  · 시루는 퀘스트 사슬대로 늘린다  (siru5_cycle5 → siru8 → siru16)
  · 등은 사도 되고 안 사도 된다   ★ 두 벌로 재 주시면 더 좋다
```

### ★ 내 놓을 것 — **셋. 「며칠」이 핵심이다**

| # | 무엇 | 왜 |
|---|---|---|
| ① | **나가나 못 나가나** (몇/몇 판) | 「가능」의 답 |
| ② | ★ **나갔다면 며칠**(튜토일 중앙값) | **이게 진짜 답이다.** 「가능합니다」로는 박사님이 판단하실 수 없다 |
| ③ | 못 나간 판은 **어디서 막혔나** | 돈인가 · 무늬 판 적인가 · 체력인가 |

⚠ ③ 이 중요하다 — 이사 게이트는 **돈 + 무늬 판 적** 둘이다(`canMoveOut`).
  **채소만 파는 판은 무늬를 안 판다.** 그러면 돈이 넘쳐도 **둘째 축에서 막힌다.**
  ⇒ ★ 그러면 답은 *"채소로는 못 나간다"* 가 아니라 ***"채소로 돈은 되는데 게이트가 하나 더 있다"*** 다.
    **그 둘은 완전히 다른 답이다.** 꼭 갈라서 적어 주십시오.

## 3. 내가 이미 잰 것 — 출발점으로 쓰십시오 [실측]

`probe_crop_balance.mjs` · 200일 · 시작 1,500,000원 · 잉여까지 다 팔기 · 등 없음

| 배치 | 200일 잔액 |
|---|---|
| 시루 1 / 3 | **126일 / 151일에 파산** |
| 시루 9 | 459,500 |
| 시루 12 · 판 4 | 1,954,800 ← 이사비의 **97.7%** |
| **시루 16** | **2,218,400** ★ 넘는다 |
| 시루 25 | 4,515,500 |

⚠⚠ **이 표를 그대로 「며칠」로 읽으면 안 된다** — 두 가지가 빠져 있다:
1. **시루 16개가 처음부터 있다고 친다.** 실제로는 퀘스트 사슬로 **늘려 가는 시간**이 든다
2. **용기값을 안 뺐다**(시루 16 = 80,000원. 작지만 초반엔 크다)

⇒ 그래서 아래는 **[추론]이고 「가장 유리한 가정」**이다. 실제는 **이보다 느리다:**
```
시루 16 고정 · 200일에 +718,400  →  평균 3,592원/일
이사비까지 모자란 500,000  ÷ 3,592  ≈  139일   ← 바닥값
```

## 4. ★ 판정 기준 — **내가 정한다** (밸런스 판정은 plan 몫)

견줄 자는 **모주 경로**다: 재현 중앙값 **A 89일 · C 175일**.
사용자 말씀은 **「시간이 걸리지만」**이다. 그 말이 참이 되는 구간을 이렇게 긋는다:

| 채소 경로 ÷ 모주 빠른 쪽(89일) | 판정 |
|---|---|
| **≤ 2배 (≤178일)** | ✅ **설계대로.** 「시간이 걸리지만」이 맞다 |
| **2~3배 (178~267일)** | ⚠ **느리다.** 걸어지긴 하는데 박사님 확인이 필요하다 |
| **> 3배 (>267일)** | ❌ **길이 적혀만 있는 것**이다 |
| **아예 못 나감** | ❌ 설계가 코드에 안 들어간 것 — ⚠ 단 §2-③ 으로 **까닭을 갈라야** 한다 |

★ **왜 2배인가** — 이 판의 두 축이 *"많이 키우는 건 **노가다**, 몬스테라는 **대박**"* 이다
(박사님 · `first_play.js:667`). **노가다가 대박보다 느린 것은 당연**하지만,
**세 배를 넘으면 「느린 길」이 아니라 「없는 길」**이다. 아무도 그 길을 안 고른다.
⚠ 이 선은 **내가 그은 것**이고 실측이 아니다. 숫자가 나오면 **다시 볼 수 있다.**
