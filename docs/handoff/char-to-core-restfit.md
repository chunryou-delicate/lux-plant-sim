# [Char] → [core] — 앉기가 **좌석 높이만큼 안 올라간다** (−0.465 m)

2026-08-30 밤 · `tools/char/probe_rest_fit.mjs` · 크레딧 0

⛔ **제가 안 고쳤습니다.** `room_view.js` 는 그쪽 것입니다. **잰 수만** 드립니다.

---

## ★ 재는 법 — 게임이 **이미 미터로** 갖고 있다. 셈하지 않았다

```
rv.characters()   → { id, pos:{x,y,z}, yaw, ground:{ y, clips:{이름:값} } }
rv.furniture()    → { uid, preset, size:{w,h,d}, x, y, z, rot }
rv.surfaceTopAt(x, z)                    ★ 「앉는/눕는 면」 높이
rv.actAt(가구uid, 'sit'|'sleep')
```

## ⛔⛔ ① 앉기 — **사람이 의자 위로 «안 올라간다»**

```
의자 앉는 면 y  = 0.465 m      [surfaceTopAt]
사람  pos.y     = 0.000 m      ← ★ «바닥»이다
★ 높이 차       = −0.465 m
자리 차         = x +0.000 · z +0.000 m   ✔ 가구 중심과 «정확히» 같다
yaw             = 180.0°  ·  의자 rot 180  ✔ 방향도 «정확히» 맞다
ground.clips['clip:sit:act'] = −0.0083    ← ★ 거의 0. 보정이 «없다»
```

> ★★ **자리와 방향은 «완벽»합니다. 높이 하나만 안 올라갑니다.**
> ⇒ 그래서 그림에서 「의자 뒤에 있다」처럼 보였습니다 — 실은 **의자 «앞 바닥»에 앉아 있는** 것입니다.

## ✔ ② 눕기 — **높이는 거의 맞다(4cm)**

```
침대 눕는 면 y  = 0.530 m
사람  pos.y     = 0.490 m
★ 높이 차       = −0.040 m      ⇒ 4cm 박힘. 앉기와 «자릿수가 다르다»
자리 차         = x +0.000 · z +0.000 m   ✔
yaw             = 0.0°  ·  침대 rot 0     ✔
ground.clips['clip:sleep:act'] = −0.5131  ← ★ 보정이 «크게» 걸려 있다
```

⇒ ★ **`sleep` 은 바닥 보정이 −0.513 으로 걸려 있고 `sit` 은 −0.008 뿐입니다.**
  ⇒ ⇒ **`sit` 에만 「좌석 높이만큼 올린다」가 빠진 것으로 보입니다.**
    ⛔ **다만 이건 제 «짐작»입니다.** 어디서 올리는지는 그쪽이 압니다.
