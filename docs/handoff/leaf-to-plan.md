# 2026-07-26 · leaf → plan

## 요청

식용작물(콩나물) **에셋은 완성**됐습니다. 게임 루프를 확정해 주시면 growth/core 가 구현할 수 있습니다.
아래는 **제안**이고, 특히 §4 두 건은 **plan 이 정해야 하는 사안**입니다.

---

## 1. 왜 콩나물이 첫 주자인가 (확정된 배경)

`docs/crop_asset_direction.md` 참조. 요약하면:

- **콩나물은 빛을 주면 망가진다** (초록으로 변하고 써짐). 어두울수록 좋다.
- → **반지하가 "나쁜 집"이 아니라 콩나물·버섯 전용 재배지**가 된다.
- → *반지하에서 콩나물 팔아 원룸으로 이사* 루프가 자연 발생. **이사 가면 오히려 못 키운다.**
- 형태가 단순해 파이프라인 검증용 첫 주자로 골랐다.

## 2. 실제 재배 방식 (설계 근거)

```
콩 불리기(반나절) → 시루에 안치기 → 어둡게 덮기
→ ★자주 물주기★ → 3~5일 → 수확
```

**핵심은 물 요구가 극단적으로 높다는 것.** 마르면 죽는다.

### 관엽과 리듬이 정반대다 (이게 설계 가치)

| | 관엽(몬스테라) | **콩나물** |
|---|---|---|
| 물 | 드물게 | **매우 자주** |
| 빛 | 관리가 핵심(많이/적당히) | **차단이 핵심(0이어야 함)** |
| 주기 | 몇 달 | **3~5일** |
| 실패 | 과습·과광 | **마름 · 빛 샘** |

→ 관엽만 있으면 **며칠씩 아무 일도 안 일어난다.** 콩나물이 초반 공백을 메운다.

---

## 3. 제안 루프

```
1. 시루를 바닥/선반에 배치        설비 설치 (재사용)
2. 인벤의 콩 → 시루에 안치기       슬롯 15칸에 seed_dicot 인스턴싱
3. ★ 뚜껑 닫기 ★                 차광 = DLI 0
4. 물 보충 (반복 인터랙션)
5. 씨앗 → 새순 → 소 → 중 → 대
6. 뚜껑 열고 수확 → 인벤에 콩나물
7. 시루 비워짐 → 2번으로
```

**3번이 튜토리얼의 핵심입니다.** "빛이 좋은 게 아니라, 이 작물엔 빛이 독이다" —
볕 게임의 빛 개념을 **뒤집어서** 가르치는 순간이 됩니다. 초반 배치 권장.

### 인벤에 필요한 것

| 분류 | 아이템 | 성격 | 에셋 |
|---|---|---|---|
| 설비 | 시루(뚜껑 포함) | 재사용 | ✅ `container_siru_open/_closed` |
| 소모품 | 콩(씨앗) | 심을 때 소모 | ✅ `seed_dicot` |
| 도구 | 물뿌리개 | 재사용 | ✅ `item_spraybottle` (기존) |
| 산출물 | 콩나물(품질별) | 판매·요리 | ✅ `beansprout_s/_m/_l` |

### 실패 · 품질

```
물 부족      → 성장 정지, 방치 시 죽음
뚜껑 열어둠  → 초록화 → 품질 100 → 70 → 40%
오래 방치    → 웃자람 → 품질↓
```

- **품질은 3D를 따로 만들지 않습니다.** 머리 부분 **색시프트**로 표현합니다(에셋은 100% 기준 하나).
- 품질 → **판매가** 직결. "귀찮아도 제때 물 주고 뚜껑 닫는" 이유가 됩니다.

## 4. ★ plan 이 정해야 할 것 — 2건

### ① "하루 3~4번 물주기"는 시간 모드와 충돌합니다

제 초안이 이랬는데, 시간 모드에 안 맞습니다.

| 모드 | 하루 3~4번이 어떻게 되나 |
|---|---|
| 점핑(이벤트 스킵) | **성립 안 함** |
| 빠른배속(1일 10초) | **3초마다 물주기** — 불가능 |
| 1:1(1일 24시간) | 6시간마다 — 이건 현실적 |

**→ "수분 게이지"로 통일하는 것을 제안합니다.**
횟수가 아니라 **게이지가 떨어지면 채우는 방식**이면 모드와 무관하게 돌아갑니다.
**콩나물은 게이지가 유난히 빨리 떨어지는 작물**로 두면 "손이 자주 간다"는 성격이 그대로 살아납니다.

### ② 물은 콩나물 전용이 아니라 **공통 시스템**이어야 합니다

- 관엽도 물이 필요하고, 로드맵이 **1빛 → 2물 → 3경제** 입니다.
- 콩나물만 따로 만들면 나중에 합칠 때 꼬입니다.
- **→ 물을 공통 시스템으로 설계하고, 콩나물은 "물 요구가 극단적인 작물"로 두는 것**을 제안합니다.

이 둘은 **plan 이 확정** → growth/core 가 구현하는 순서가 맞다고 봅니다.

## 5. 인터페이스 (에셋 쪽 계약)

```js
// 시루 — 관엽 선반과 완전 동일한 슬롯 규격(검증 완료)
item.slots        // [{x,y,z}] 15칸, 로컬 미터, y = 심는 바닥 높이
item.slot_count   // 15
item.blocks_light // true — 뚜껑 닫으면 DLI 0
item.lid_state    // 'open' | 'closed'
item.scale_to_real// 1.0 (절차적 = 이미 실제 미터)

// 뚜껑 토글 2가지 방법
//  (a) 파일 스왑: container_siru_open.glb  ↔  container_siru_closed.glb
//  (b) 노드 토글: _closed.glb 만 로드하고 그 안의 'lid' 노드를 show/hide  ← 가벼움

// 콩나물 인스턴싱 — 슬롯마다 바운딩박스 바닥면을 슬롯 y에 맞춘다
for (const s of siru.slots) {
  const m = beansprout[stage].clone()
  m.position.set(s.x, s.y - bbox.min.y, s.z)
  m.rotation.y = rand() * Math.PI * 2   // ★ 없으면 15개가 전부 같은 방향으로 휨
}
```

**헤드룸 확인 완료** — 뚜껑을 닫은 채로 **전 단계(씨앗~대형 12.8cm)가 들어갑니다**(헤드룸 16.2cm).
초기엔 11.7cm라 대형이 뚫고 나왔는데, 썸네일 점검 중 발견해 뚜껑을 높였습니다.

## 6. 참고 — 에셋 제작 방침
