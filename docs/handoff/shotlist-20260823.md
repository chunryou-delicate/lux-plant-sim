## ★★★ A. 진행이 막히는 것 — 제일 급하다

### A-1 방에 놓으면 **심은 것이 풀린다** `[실측]`
```
놓기 전   slotId=null          sown=true      ← 처음 주는 시루는 «이미 심어져» 있다
놓은 뒤   slotId=banjiha-sill:0  sown=false    ← ★ 놓으니 sown 이 꺼졌다
```
⇒ 그래서 물주기 단추가 **「💧 아직 안 심었습니다 — [🌱 심기] 먼저」** 라고 답한다.
⇒ ⚠ **의도인지 버그인지 모른다.** 「가방에 있는 동안은 심은 게 아니다」가 규칙일 수도 있다.
  다만 **처음 주는 시루가 `sown:true` 로 오는 것**과 짝이 안 맞는다. **[core] 판단 필요.**

### A-2 Day 2 인데 첫 칸이 아직 **「시루를 방에 놓는다」** `[그림 015_day002.png]`
```
할 일 0/18
지금 할 것 — 시루를 방에 놓는다
  ▶ 시루를 방에 놓는다      「시루를 방 안에 놓아 보세요」
  🔒 물을 준다              「아직 열리지 않았습니다」
  … 그 뒤로 16가지가 더 있습니다
```
⇒ **시루는 Day 0 에 놓았다.** 그런데 첫 칸이 안 닫혔고 **둘째가 잠긴 채**다.
⇒ ⚠ A-1 이 원인일 «수» 있으나 **단정 안 한다.** 내 자(`window.__quest()`)가 null 을 돌려줘
  **퀘스트 쪽은 못 읽었다.** 화면만 봤다.

## ★ C. 같은 말이 두 곳에

```

Day 45   무순을 길러 콩나물과 한 상에 올리세요   (두 곳)
Day 120  〃                                   (두 곳)
```
⇒ ⚠ **의도일 수 있다**(하나는 상시 · 하나는 알림). 다만 **Day 0 은 다르다** ↓
