# 2026-08-09 · bagcell → plan (가방 카드는 빈 시루로 · 게이지는 칸으로)

## 요청 / 보고

박사님이 폰으로 하시고 두 가지를 지적하셨다.

> ① *"가방에 열린 콩나물 시루가 있으면 안 되지. **콩나물시루 아이템만 있어서**
>    그걸 드래그 하면 하나씩 따로따로 설치되게."*
> ② *"콩나물 시루에 콩 심으면 **5칸짜리 빈 게이지**가 생기고 날이 지나면 **1칸씩** 차도록
>    **직관적으로** 하자."*

고친 파일은 **`game.html` 하나**와 새 검사 **`tools/test_bagcell.mjs`** 뿐이다.
`src/game/**` 과 `data/**` 는 한 줄도 안 건드렸다 — 새 숫자도, 새 상태 칸도 안 만들었다.
칸 수·나이·물 여부는 전부 `cropPotList()` 가 이미 내던 값이다.

---

# 1. ★ 먼저 — 앞 작업이 왜 「고쳤는데 그대로」였나

①은 이미 한 번 「고쳤다」고 보고된 건이었다. 실제로는 **반만 고쳐져 있었다.**

| | 앞 작업 | 남아 있던 것 |
|---|---|---|
| 카드의 **자리** | 가방↔식물을 오가던 것을 **늘 가방**으로 고정 | — |
| 카드의 **내용** | — | 카드를 누르면 열리는 상세 창(`detail.crop()`)이 그대로 |

그 상세 창이 내던 것:

```
제목  열린 콩나물 시루
부제  가방에 있음
본문  자란 날 1/5일 · 받은 빛(평균) — DLI · 품질
```

**가방 안에 심어져 자라고 있는 시루** 그 자체다. 박사님이 폰에서 보신 그림이 이것이었다.
자리를 옮기는 것만으로는 안 없어진다 — 눌러서 열면 똑같은 말이 나오기 때문이다.

> **교훈** — 「고쳤다」를 쓰기 전에 **화면을 띄워 눈으로 본다.** 그래서 이번에는
> 새 검사가 상태 값이 아니라 **화면에 실제로 찍힌 글자(`textContent`)** 를 읽는다.

---

# 2. ① 가방 카드 — 이제 「빈 시루」만 말한다

`game.html` `detail.crop()` 을 다시 썼다.

| | 전 | 후 |
|---|---|---|
| 제목 | 열린 콩나물 시루 | **콩나물 시루** |
| 부제 | 가방에 있음 / …에 있음 / 수확을 마침 | **가방에 N개** (없으면 「가방에 없음」) |
| 본문 | 자란 날 · 받은 빛 · 품질 | **가방에 남은 것 N개** · (방에 서 있는 것 M개) · 쓰는 법 |

- **자란 날 · 받은 빛 · 품질을 지웠다.** 빈 용기에는 그런 값이 없다
- 말하는 것은 둘뿐이다 — **가방에 몇 개인가** · **어떻게 쓰나**(끌어다 놓기 · 물 · 칸)
- 자라는 중인 시루는 **[식물] 탭 `#siruBox`** 가 시루마다 한 줄로 그린다(전부터 있던 것)
- ⚠ **끌기는 그대로 산다.** 손잡이는 여전히 `#cropThumb` 이고 카드 노드도 그대로다

무순 상세(`detail.musun()`)도 같은 규칙을 받았다 — **놓기 전에는** 자란 날·빛·품질을 안 적고
「빈 재배판 · 7칸」이라고만 말한다.

# 3. ② 게이지 — 매끈한 막대에서 **칸**으로

## 왜 칸인가 (박사님 말씀의 「직관적으로」)

매끈한 막대는 **"60%"** 를 말한다. 그런데 플레이어가 알고 싶은 것은 **"며칠 남았나"** 다.
칸이면 **안 찬 칸을 세는 것이 곧 남은 날**이라 눈으로 바로 읽힌다.

## 규칙

```
칸 수  = 그 작물의 주기(harvestDays)     콩나물 5칸 · 무순 7칸
찬 칸  = ageDays                          하루가 지나면 정확히 한 칸
흐름   = 지금 차는 칸 **안에서만** 연하게   (하루가 흐르고 있다는 표시일 뿐)
```

⚠ **5를 박지 않았다.** `cropPotList()` 가 낸 `harvestDays` 를 그대로 쓰고, CSS 는 칸 수를
모른다(`grid-auto-flow:column`). 작물이 늘어도 화면은 안 고친다.

## 물을 안 준 상태가 화면에서 갈린다

박사님 지적의 절반이 여기다 — 심어 놓고 물을 안 주면 **칸이 안 찬다.**
빈 칸만 그리면 「심었는데 왜 안 차지」가 되고 답이 화면에 없다.

| 상태 | 칸의 옷 | 옆줄 |
|---|---|---|
| 물 대기 | **물빛 테두리**(`.cells.dry`) | 「물을 주면 5칸이 하루에 하나씩 찹니다」 |
| 자라는 중 | 초록 칸 + 지금 칸 연하게 | 「1/5칸 · 4일 남음」 |
| 다 참 | **금빛 칸**(`.cells.done`) | 「거둘 때가 됐습니다 · 5칸 다 참」 |

## 덤 — 퀘스트 줄이 거짓말을 하고 있었다

시루를 놓은 첫날, 화면 셋이 **서로 다른 말**을 했다.

```
퀘스트 줄   "콩나물이 자라는 중입니다. 수확까지 5일."   ← 거짓. 물을 안 줘서 안 돈다
게이지      빈 칸 5개                                    ← 사실
손가락      "물을 주면 자라기 시작합니다"                ← 사실
```

플레이어가 믿는 것은 **글자**라, 물을 안 준 채 [다음 날]을 눌러 하루를 버린다.
(`updateHint §③` 이 같은 사고를 손가락 쪽에서 이미 한 번 잡았다 — 줄 쪽이 남아 있었다.)
⇒ 도는 시루가 하나도 없으면 **「시루에 물을 주면 칸이 돌기 시작합니다」** 라고 말한다.
