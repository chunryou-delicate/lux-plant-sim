# ① ★★★ **층계의 ⓑ — 「가는 값」을 말한다** (제일 급함)

## ⓐ 지금 층계와 **빠진 것**
```
questDoneSiru5   "다섯 개가 다섯 바퀴. 이제 이 방이 «밥값은 내네»"
questDoneSiru8   "«아직 본전은 아니야». 조금 더 가야 해"
questSiru16      "★ «조금만 더» 늘리면 하루가 안 깎여" / "거기까지 가면 «버는 쪽»이 돼"
```
```
실측   여덟 → 열일곱 늘리는 동안  하루 ★ «−14,685원»
       갖춘 뒤                    하루 ★ «+1,818원»
```
> ## ⛔ **퀘스트가 «제일 비싼 구간»을 「조금」이라 부른다.**
⇒ ★ **틀린 말이 아니라 «값을 감추는» 말이다** — 계율 ②(막지 않고 «대가를 보여 준다»)에 걸린다.

## ⓑ ⇒ **고칠 한 줄 + 보탤 세 줄**
```
⛔ 지금   몬이: "조금만 더 늘리면 하루가 안 깎여."

★ 고침   몬이: "«한참» 더 늘려야 하루가 안 깎여."
★ 보탬   나  : "지금도 빠듯한데."
         몬이: "늘리는 동안은 «더» 깎여. 시루값이 «먼저» 나가고 첫 회전은 «닷새 뒤»라서."
         나  : "…그럼 지금보다 나빠진다는 거네."
         몬이: "«한동안은». 그러고 나서 넘어가."
```
⇒ ★★ **숫자를 «한 톨도» 안 말한다** — 오늘 배운 것이다(값이 바뀌면 대사가 거짓말이 된다).
  **말하는 것은 «방향»과 «까닭»뿐이다: 「먼저 나가고 나중에 온다」.**
⇒ ★ 그리고 **마지막 줄이 «뒤»를 준다** — 대가만 말하면 의욕이 꺾인다.
  **「한동안은」이 «끝이 있다»를 말한다.**
⇒ ⚠ **「거기까지 가면 버는 쪽이 돼」는 «그대로 둔다».** 그 줄이 «뒤»를 이미 말하고 있다.

# ② **「전부」 한 줄** (값 안 걸림 · 바로 됨)
```
⛔ 지금        "…(남는 것 150g 남음)"
★ 남을 때      "…(남는 것 150g — «다음에 또 급할 수 있습니다»)"
★ 「전부」일 때  "…(«다 넘깁니다» — 다음에 급하면 «팔 것이 없습니다»)"
```
⇒ ★★ **새 자리를 안 만든다.** «이미 있는 줄»에 붙인다(규율 ㉰).
⇒ ⛔ **「전부」 단추를 «막지 않는다». 되묻지도 않는다** —
  **손해 금액이 «이미 그 줄에» 있어서 또 되물으면 «잔소리»다.**
⇒ ⚠ **「전부」일 때는 「남는 것 0g」이라 앞 문장이 «안 뜬다».** 그래서 «다른 말»이 필요하다.

# ③ **「언제 심을까」** (⚠ 「더 번다」는 여전히 보류)
```
쓸 수 있는 것   ★ "한날에 몰리면 «그날 손이 모자라» 못 심는다"   (실측 sowThrew 24)
⛔ 못 쓰는 것    "어긋나게 심으면 «더 번다»"                      ⏸ 보류
```
```
★ 자리   여덟을 «한날에» 거둔 그 순간 — «거둔 직후»다
★ 문안   몬이: "오늘 여덟이 다 비었네. …오늘 «다» 심을 거야?"
```
⇒ ★★ **답을 «안» 준다.** ⛔ **「나눠 심어라」라고 «안» 한다.**
⇒ ⚠ **지금 신호(*"오늘 손이 다 떨어졌습니다"*)는 «막힌 뒤»에 뜬다** — **그건 «벌»이지 «가르침»이 아니다.**
  ★ **이 줄은 「막히기 «전»」에 놓는다.**

# ★★★★★★ **그리고 셋을 다 쓰고 나니 «빈 곳»이 보인다**

## ⓐ **「왜 «지금» 나가야 하나」에 값의 이유가 «하나도» 없다**
```
그루값   기다리면 «오른다» (잎 하나에 무늬가 안 실려도 무지 20,000 이 붙는다)
지갑     기다리면 «는다»   (갖춘 뒤 하루 +1,818원)
⇒ ★★ 두 쪽 «다» 기다림 편이다
```
> ## ⛔ **이 게임은 「나가라」고 «값으로» 말하지 않는다.**

## ⓑ ⇒ ★★★ **그러면 «이야기»가 말해야 한다. 그리고 그 몫이 «몬이»다**
오늘 세운 규율 그대로다 — **「언제」는 몬이가 짚는다.**
⇒ ⚠ **그런데 이번 「언제」는 «게임의 끝»이다.**
```
곳간 팔기   몬이가 «남의 일»을 짚는다
시루 심기   〃
그루 팔기   ★ 몬이가 «자기 일»을 짚는다
★ 이 방 떠나기  ★★ 몬이가 «이야기를 끝내자»고 말한다
```
⇒ ★★★ **값이 안 정해 주면 «누군가는 「이제 됐다」고 말해야» 한다.**
  **안 그러면 판이 «영영 안 끝난다» — 기다릴수록 좋으니까.**

## ⓒ ⚠ **이미 있는 «재촉»들을 세어 두었다** — 다만 다 «약하다»
```
계절     "반지하는 여름에 덥고 겨울에 춥다"        ⇒ 분위기다. 값이 안 걸린다
집주인   "학생, 아직 있었네"                        ⇒ ★ 제일 세다. 그런데 «한 번»뿐이다
겨울     winter_still — "겨울 N일째 · 아직 반지하"  ⇒ ★ 알림이지 «권함»이 아니다
```
⇒ ★ **셋 다 「아직 있네」를 말하고 「이제 가라」는 «안» 한다.**
⇒ ⇒ ⛔ **그리고 그게 «옳을» 수도 있다** — 박사님이 *"안 사는 것도 답이다"* 를
  등에서는 «폐기»하셨지만, **떠나는 때까지 정해 주는 것은 다른 이야기다.**

## ⓓ ⇒ ⛔ **그래서 여기서 «멈춘다». 박사님께 물음으로 남긴다**
> ## **「이제 나갈 때다」를 게임이 «말해 줍니까», 아니면 «플레이어가 정합니까»?**
```
말해 준다   ⇒ ★ 몬이가 그 말을 한다. 그러면 「튜토 엔딩」의 «방아쇠»가 생긴다
안 말한다   ⇒ ★ 플레이어가 «스스로» 접는다. 대신 «영영 안 끝나는 판»을 허락하는 것이다
```
⇒ ⚠ **그리고 이 물음은 「그루냐 삽수냐」와 «한 벌»이다** —
  **그루를 판다면 몬이가 «자기를 팔라» 해야 하고, 그건 곧 「이제 나갈 때다」이다.**
⇒ ★ **묶어서 여쭙는 편이 맞다.** 앞의 것들과 달리 **이 둘은 «같은 장면»이다.**
