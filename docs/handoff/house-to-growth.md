## ★★ 확인 요청 — 날씨 '확률'과 '계수'가 섞여 있습니다

`growth-to-plan.md` 에 이렇게 적혀 있습니다:

> 날씨 계수(맑음 **.55** / 흐림 .25 / 비 .12)

**0.25·0.12는 계수가 맞는데 0.55는 계수가 아닙니다.** 맑음 계수는 `1.00` 입니다.

```js
// src/engine/daylight_lux.js
export const WEATHER = {
  clear:  { k: 1.00, ko: '맑음' },
  cloudy: { k: 0.25, ko: '흐림' },
  rain:   { k: 0.12, ko: '비'   }
};
```

`.55` 는 아마 **맑은 날이 나올 확률**이었을 텐데, 계수 자리에 쓰면
맑은 날 조도가 45% 깎여 밸런싱이 통째로 어긋납니다. 어느 쪽인지 확인 부탁드립니다.

### 그래서 날씨를 공용 모듈로 뺐습니다 — `src/engine/weather.js`

각자 굴리면 같은 날의 날씨가 달라져 같은 방에 다른 답이 나옵니다. 실제로 그랬습니다.

```js
import { weatherOf, seasonOf, skyOf, movingAvgStats, WEATHER_P } from './engine/weather.js';

weatherOf(41)          // 'clear' | 'cloudy' | 'rain' — 날짜가 시드라 되감아도 같다
seasonOf(41)           // 'spring' (1년 360일 · 계절당 90일)
skyOf(41)              // { season:'spring', weather:'clear' }
```

`WEATHER_P` 가 계절별 **확률**입니다(계수 아님 — 계수는 `daylight_lux.js` 의 `WEATHER`):

| 계절 | 맑음 | 흐림 | 비 |
|---|---|---|---|
| 봄 | 0.50 | 0.36 | 0.14 |
| 여름 | 0.40 | 0.36 | **0.24** (장마) |
| 가을 | 0.55 | 0.33 | 0.12 |
| 겨울 | 0.52 | 0.40 | 0.08 |

**이 숫자는 제가 서울 기준으로 잡은 초안입니다.** 그쪽이 쓰던 분포가 따로 있으면
말씀해 주세요 — 파일이 house 소유라 제가 고칩니다. 다만 **한쪽으로 통일**은 해야 합니다.

7일 이동평균 헬퍼도 같이 있습니다:

```js
const st = movingAvgStats((weather, season) => dliOf(weather, season), {season:'summer', win:7});
// { mean, min, max, dailyMean, n }  ← min/max 가 '최악주/최고주'
```
