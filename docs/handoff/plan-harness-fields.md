## 1. 찍을 칸 — **날마다 열둘 · 판마다 여섯**

### 날마다 (`perDay[]`)
```
day            달력일          ⚠ 튜토일과 둘 다 찍는다(§2.9-⑤ 가 이걸로 네 번 틀렸다)
tday           튜토일
season         계절
★ handsToday   그날 「미루면 손해」인 손짓 수      ← §C 의 뿌리. 이게 없으면 C 를 통째로 못 잰다
★ siruCount    그날 시루 수                       ← §C 판정이 시루 수마다 달라진다
questOpenIds   열린 퀘스트 id 들
questCurrentId 「지금 할 일」 한 줄
saidIds        그날 뜬 대사 id 들 (★ 뜬 순서대로)
cashWon        지갑
pantryWon      곳간
★ netWorth     지갑 + 모주값(quotePot) + 삽수값(quoteCutting 합) + 곳간
bigSpendWon    그날 나간 목돈(월세 등)
```

★ **`handsToday` 의 뜻을 못 박는다** — `plan-night-oddities §4-1`:
> **「미루면 회전이 늦어지는 일」만 센다.**
> 물 주기 · 수확 · 재파종/주문 · **몬스테라 물**은 센다. **상점 구경·가구 옮기기는 안 센다.**
> ⚠ 「해도 되는 것」을 세면 상점이 늘 열려 있어 **모든 날이 할 일 있는 날**이 된다.

★ **`netWorth` 에 모주 값을 반드시 넣는다** — 안 넣으면 *"삽수를 팔면 이득"* 이라는 거짓말이 나온다.
  오늘 실측으로 그 셈이 **−15,000원**이었다.

### 판마다 (`perRun`)
```
seed · axes{}   축 여섯의 값(삽수·모주·등·시루상한·채소·안내)
movedOutTday · movedOutDay
★ gate{ ok, money, varie, shortWon }   못 나갔으면 **어디서 막혔나**
```

  「돈에서 막힘 20 · 무늬에서 막힘 0」이 나왔고 **아침 물음 하나가 그 자리에서 없어졌다.**

## 2. 판정식 — **찍힌 칸만으로 선다**

## 3. ⚠⚠ **번역이 안 되는 줄 — 둘. 이게 소득이다**

### ⛔ B4 · E1 — **「퀘스트가 시킨 손짓」을 기계가 못 안다**

`plan-night-oddities §E1` 은 *"**퀘스트·손가락이 가리킨 손짓**의 즉시 순자산 변화"* 를 재라고 했다.
**못 잰다.** 까닭:

> 퀘스트의 `todo` 는 **사람 말**이다 — *"잎 1장짜리 마디를 잘라 물에 꽂으세요"*.
> **그 문장과 실제 손짓(`takeCutting`)을 잇는 칸이 데이터에 없다.**

⇒ ★ **이건 하네스의 한계가 아니라 「퀘스트 ↔ 손짓」 연결이 없다는 것**이다.
⇒ **세 갈래 중 하나를 골라야 한다** — 셋 다 코드·계약 변경이라 **아침 판단**이다:

| | 무엇 | 값 |
|---|---|---|
| ㉮ | 퀘스트 줄에 **`acts: ['takeCutting']`** 같은 칸을 붙인다 | 판정이 정확해진다. **계약이 는다** |
| ㉯ | **모든 손짓의 순자산 변화를 다 찍고** 사람이 본다 | 계약을 안 늘린다. **사람 손이 든다** |
| ㉰ | **E1 을 버리고 E2·E3 만 쓴다** | 싸다. **「시켰는데 즉시 손해」를 못 잡는다** |

★ **나는 ㉯ 를 권한다** — 밤에는 사람이 없지만 **찍어 두면 아침에 볼 수 있다.**
  ㉮ 는 값어치가 크지만 **계약을 늘리는 일이라 밤에 할 것이 아니다.**

### ⚠ A3 — **반쯤만 된다**

*"대사에 적힌 금액과 그날 화면 금액이 다르다"* — 대사에서 숫자를 뽑아 견줄 수는 있는데,
**대사에 나오는 모든 숫자가 화면 값은 아니다.** 거짓 양성이 는다.
⇒ **찍기만 하고 판정은 안 한다** — `saidTexts` 에서 뽑은 숫자를 그날 값과 **나란히 남기고**,
  다른 것만 **사람이 보게** 한다. ★ 이사비가 실제로 **3벌**이라(`homes.json`·`tutorial.js:59`·
  `dialogue.js:863`) **볼 값어치는 있다.**
