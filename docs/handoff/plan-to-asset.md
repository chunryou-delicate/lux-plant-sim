## 3. 🔨 해야 할 것 — **급한 순**

### ⓪ 크레딧이 안 드는 일부터 (지금 바로 됨)

- [ ] **원화 206장을 갈래별 폴더로 옮긴다.** 지금 `assets/gen/2026-08-12/` 에 번호만 붙어 한 덩이다.
      3D 로 넘길 때 짝을 맞추려면 갈래가 갈려 있어야 한다. **파일 이름의 번호는 바꾸지 마라** —
      `README` 의 표와 물려 있다
- [ ] **manifest 에 새 썸네일을 등록할지 정한다.** 지금 156장이 파일로만 있고 `manifest.json`
      항목이 없다. 「이름으로 에셋 찾기」가 manifest 를 읽으므로 등록해야 찾힌다.
      ⚠ manifest 가 생성물인지 손으로 쓰는 것인지 **먼저 확인해라.** 생성물이면 뽑는 도구를 찾아 돌린다
- [ ] **상점 목록에 그림을 붙인다.** 지금 상점 줄은 글자뿐인데 썸네일은 다 있다.
      `game.html` 의 `$('shopList').innerHTML` 한 곳이다. ⚠ `game.html` 은 다른 창과 겹치니
      「어느 줄을 무엇으로」로 넘기든지, 그 파일을 쥔 창에 부탁해라

### ① 크레딧이 차면 — **이 순서로**

- [ ] **중간 크기 화분 3~4종부터.** 게임에 제일 빨리 티가 난다.
      지금 화분 지름이 0.13 · 0.18 · 0.20 아니면 0.25 초과라 자리 선택이
      **「14칸 전부」 아니면 「4칸」** 양극단이다. 중간(0.21~0.25)이 비어 화분 고르기가 선택이 안 된다

      ★ **지금 게임이 도는 작물은 콩나물과 무순 둘뿐이다**(`first_play.js` 실측).
      반지하는 어두운 자리가 9칸인데 쓸 작물이 없어 **노는 자리**다
- [ ] 원예 소품 · 조명 — 상점을 채운다
- [ ] 토마토·고추 6종 — ⚠ `leaf-to-plan` 의 판단이 아직 유효하다:

## 4. ⚠ 이 창이 안 밟았으면 하는 지뢰

1. **그림이 없다고 하기 전에 GLB 부터 찾아라.** 오늘 세 번 다 「없는 그림」이 아니라
   **「안 찍은 그림」**이었다(모종포트 · 수경병 · 하프문 잎). 하프문은 AI 로 다섯 번 실패한 뒤에야 알았다
2. **주석이 낡으면 재는 자가 된다.** 재배판이 「0.43」이라 적힌 주석 때문에 「서랍장에 못 올라간다」는
   없는 진단이 나왔다. 실제 값은 **0.20** 이고 14칸 전부에 올라간다(`START-HERE §2.6`)
3. **원화 뽑을 때 프롬프트에 `no text` 와 `no numbers` 를 같이 넣어라.** 달력·시계·라벨·씨앗봉투는
   안 넣으면 읽을 수 없는 가짜 글자와 눈금이 찍힌다
4. **실패는 편차다.** 한 묶음(12장) 중 3~7장은 그냥 실패한다. 속도를 늦춰도 안 없어진다.
   **다시 넣으면 대개 통과**하므로 **작업 번호를 파일로 먼저 적어 두고** 기다려라
   (`_pending_jobs.txt` 방식). 창이 끊겨도 안 잃는다
5. **팔레트는 지어내지 말고 게임에서 재라.** 오늘 쓴 여덟 색은 실제 썸네일에서 뽑은 값이다:
   `#BEB4A2` `#D6CEBE` `#5C4E42` `#92AC98` `#E2C89C` `#5C625E` `#9EC484` `#84B26E`
