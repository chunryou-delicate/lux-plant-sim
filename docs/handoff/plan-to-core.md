## 0. 무엇을 만드나

박사님 원문: *"몬스테라 물주기 기능 실제 주는 주기 반영해서 하고"*

실제 실내 몬스테라는 **7~10일에 한 번** 물을 준다. 그리고 **밝고 더울수록 빨리 마른다** —
겨울 북향 방이면 2~3주에 한 번이고, 여름 창가면 5~6일에 한 번이다.
이 「자리에 따라 다르다」가 이 작업이 게임에 들여오려는 것 전부다.

---

## 1. 왜 이 모양인가 — **문이지 곱셈이 아니다**

```
빛(DLI)  →  오늘 얼마나 자라나        (이미 있다 · growth 소유)
물        →  오늘이 하루로 세어지나    (이것이 새로 생기는 것)
```

두 문은 **직렬**이고 **곱하지 않는다.** 근거 셋:

1. 곱하면 *"물을 반만 줬으니 반만 자란다"* 가 되어 **처방이 흐려진다.** 화면이
   "물을 주세요"라고 말할 수 없고 "물을 조금 더 주세요"라고 말하게 된다.
2. 이 게임의 다른 정지가 **전부 문 모양**이다 — 형태 정지(`growthBlocked`) ·
   머리공간(`headroomBlocked`). 물만 다른 모양이면 화면이 한 칸씩 말하지 못한다.
   (`loop.js` §644 가 이미 못 박아 둔 판단이다: *"셋을 한 칸에 섞으면 처방이 뒤섞인다"*)
3. 콩나물 물이 이미 문이다(`startedOnDay` — 물을 준 날이 0일차).
   같은 게임 안에서 물이 두 가지 뜻을 가지면 안 된다.

### ⚠ 죽지 않는다

이 게임의 규약이다. 무순 카드에 그대로 적혀 있다 — *"죽지는 않는다. 자리가 값을 바꿀 뿐이다."*
마른 몬스테라는 **날짜만 가고 형태가 안 는다.** 잎이 지거나 개체가 사라지는 일은 없다.

### ⚠ 콩나물 물주기와 **뜻이 다르다** — 한 함수로 합치지 마라

| | 콩나물 | 몬스테라 |
|---|---|---|
| 물의 뜻 | **회전 시작** (`startedOnDay`) | **유지** |
| 한 번 주면 | 그 회전이 끝날 때까지 안 준다 | 주기마다 다시 준다 |
| 안 주면 | 아직 **시작을 안 한 것** | 하루가 **안 세어진다** |
| 자리에 걸리나 | 안 걸린다 | **걸린다** (밝을수록 빨리 마른다) |

`waterCrop(S, {kind})` 에 `'monstera'` 를 얹는 것이 자연스러워 보이지만,
그 함수는 「회전을 시작한다」를 하는 함수다. **`waterPot(S)` 를 따로 두는 편이 낫다.**

---

## 2. 이게 왜 중요한가 — **밝은 자리가 공짜가 아니게 된다**

지금 게임에서 밝은 자리는 **순수 이득**이다. 몬스테라는 밝을수록 잘 자라고, 잃는 것이 없다.
그래서 「자리」의 교훈이 *"제일 밝은 데 두면 된다"* 한 줄로 끝난다.

물이 들어오면 이렇게 갈린다:

| 자리 | 자라기 | 마르기 | 그래서 |
|---|---|---|---|
| 밝다 | 빠르다 | **빠르다** | 잘 크지만 **자주 챙겨야 한다** |
| 어둑하다 | 느리다 | 뜸하다 | 손이 덜 간다 |

체력이 하루 10인 판(`stamina.js`)에서 이건 **진짜 고민**이 된다 —
시루를 늘릴수록 몬스테라를 챙길 손이 준다.

---

## 3. 얼마나 만에 마르나 — **숫자를 새로 짓지 않는다**

밝기를 재는 자를 새로 만들면 색·등급·물주기가 **세 벌**이 되고 세 벌은 반드시 어긋난다.
`growth` 가 이미 내는 **밴드**를 그대로 읽는다(`game.html` §RANK_BY_BAND 와 같은 자).

| 밴드 | 뜻 | 마르는 주기 |
|---|---|---|
| `over` · `best` | 아주 밝다 | **7일** |
| `good` | 밝다 | **8일** |
| `slow` | 어둑하다 | **10일** |
| `stagnant` · `poor` · `critical` | 어둡다 | **12일** |

계절 보정 — 실제로 이게 밝기만큼 크다:

| 계절 | 보정 |
|---|---|
| 여름 | **−1일** |
| 봄 · 가을 | 0 |
| 겨울 | **+3일** |

⇒ 폭은 **6일(여름·창가) ~ 15일(겨울·구석)** 이다. 실제 범위와 맞는다.

> ⚠ **밴드는 7일평균(`dli7`)으로 잰다.** 하루 값으로 재면 흐린 날마다 주기가 들썩여
> "어제는 8일이라더니 오늘은 12일"이 된다. 흙이 마르는 속도는 그렇게 안 움직인다.
> `growthSpeedOf` 가 이미 `dli7` 을 쓴다(`loop.js` §701) — **같은 값을 쓴다.**

---

## 4. 상태 — 어디에 무엇이 붙나

화분(`pot0(S)`)에 **한 칸**만 는다.

```js
wateredOnDay: null   // 마지막으로 물 준 날. null = 아직 한 번도 안 줌
```

파생값은 **저장하지 않는다**(저장하면 날짜와 어긋난 사본이 생긴다):

```js
dryDays  = S.day - p.wateredOnDay      // 물 준 지 며칠 됐나
interval = 주기(밴드, 계절)             // §3
leftDays = interval - dryDays          // 며칠 남았나 (음수면 말랐다)
```

### ★ 도착한 날에 `wateredOnDay = S.day` 로 채운다

선물로 온 화분이 **온 날부터 목말라 있으면 안 된다.** 받자마자 벌이 된다.
`harvestCrop` 의 선물 블록(`loop.js` §958)에서 화분을 만들 때 같이 채운다.

---

## 5. 판정 — 마른 날은 **하루를 안 먹인다**

```
dryDays <= interval   →  촉촉.  advanceTo 를 부른다 (지금 그대로)
dryDays >  interval   →  마름.  advanceTo 를 **안 부른다**
```

### ⚠⚠ 빛은 **그래도 넘긴다**

`loop.js` §694 가 이미 못 박아 둔 규칙이다 — *"빛은 막혔어도 넘긴다. DLI 이력은 사실이어야 한다."*
마른 날도 `io.growth.setDailyLight(dli)` 는 **부르고**, `advanceTo` 만 안 부른다.
안 그러면 `dliHist` 가 코어와 갈라져 세이브 재생이 다른 형태를 만든다(`save.js` §growth).

> 이건 머리공간 정지(`headroomBlocked`)가 이미 하는 것과 **똑같은 모양**이다.
> 그 경로를 그대로 따라가면 새로 지을 것이 거의 없다.

### 과습 — **아무 일도 안 난다**

마르기 전에 또 주면 물이 안 든다. **체력도 안 쓴다.**
실제로도 과습이 몬스테라를 죽이는 1위지만, **벌을 주지 않는다** — §1 의 "죽지 않는다"와
같은 판단이고, 하루 한 번 눌러 두는 습관이 손해가 되면 플레이어가 버튼을 무서워한다.
화면은 *"아직 촉촉합니다 — 3일 뒤에 주면 됩니다"* 라고만 말한다.

## 6. `turn` 에 실릴 칸 — 다른 정지와 **다른 칸**

```js
potDry:   '흙이 말랐습니다' | null,          // ← growthBlocked · headroomBlocked 와 섞지 마라
potWater: { dryDays, interval, leftDays, dry }
```

`loop.js` §644 의 판단 그대로다 — 셋을 한 칸에 섞으면 화면이
「등을 켜라 / 자리를 옮겨라 / 물을 줘라」를 못 가른다.

**반환구가 둘인 것을 잊지 마라.** `loop.js` 는 몬스테라가 없을 때 §636 `earlyTurn` 으로
일찍 반환한다. 그 경로에도 칸을 넣어야 한다(값은 `null`) — 이 파일의 오랜 함정이다(§809 주석).

## 8. 체력 — **다시 잴 필요 없다**

`stamina.js` §STAMINA_MAX 가 하루 손 7번을 셀 때 이미 **「몬스테라 → 물1」을 넣어 뒀다.**
그때 계산은 몬스테라도 **매일 1** 로 잡은 것인데 실제로는 **8일에 한 번**이라 예산이 남는다.
⇒ `ACT_COST.water = 1` 그대로 쓰고, 상한 10 도 그대로다.

## 9. 빨리감기 — 콩나물과 **같은 길**이어야 한다

`loop.js` §1083 이 콩나물 물에 대해 이미 정해 둔 것:

| 모드 | 물 |
|---|---|
| 점핑 (튜토) | **선다** — 안 서면 헛돈다 |
| fast (본편) | **같이 준다** — `autoWater` 기본 켜짐 |

몬스테라도 이 표에 **얹는다.** 새 갈래를 만들면 두 벌이 되고 두 벌은 어긋난다.

> 콩나물과 달리 몬스테라는 8일에 한 번이라 **서는 비용이 낮다** — 30일 배속에서 3~4번이다.
> 콩나물 물을 세우면 배속이 −97% 였던 것(§1118)과 자릿수가 다르다.
> 그래도 `autoWater` 에 얹는 쪽이 맞다 — 이유는 값이 아니라 **한 벌**이기 때문이다.

## 10. 세이브 — 옛 판을 열 때

옛 세이브엔 `wateredOnDay` 가 없다. 복원할 때 **`S.day` 로 채운다.**

⚠ **0 으로 두지 마라.** 300일째 세이브를 열자마자 *"물 준 지 300일"* 이 되어
그 판의 몬스테라가 영영 안 자란다. `ensureCropPots` 가 옛 칸을 옮길 때 쓴 사상과 같다 —
**지어낼 값이 없으면 잃는 쪽이 아니라 안전한 쪽으로 채운다.**
