# 식물 가게 — 진로 최소판 상세 명세 (plan · 2026-10-10 · core 가 바로 짓게)

> 결정: 10-10 총괄 D59(진로 최소안 `plan-jobs-min-20261010.md` 판단필요 아홉). ⚖ = 첫 판 값(총괄이 박음 · core 판으로 바로잡음).
> 원칙: **새 값표를 안 만든다** — 주문 값은 «납품한 그것의 시세(지금 판매 함수) × 웃돈». **할 수 없는 주문을 안 낸다** — 주문은 그 판이 가진 원천으로만.

## 1. 화면 흐름

1. 엔딩 [계약한다] → endingHome 열세 줄 → 마무리 카드 → [다음] → (지금 D28 «여기까지 — 첫 이야기» 덮개 자리) **진로 고르기 화면**
   - 카드 셋: **식물 가게**(열림) · 식물 돌봄(«준비 중») · 무늬 육종(«준비 중»). 카드 글 §6.
2. [가게를 연다] → 몬이 한 줄(초보 보호 끝 알림 · §6) → **투룸으로 이사**(가방 · `moveIntoOneroom` 일반화) → 첫날 «들고 온 것부터 놓자»(D43 재사용).
3. 가게 첫날 사건 `shop_open` → **주문판** 소개 + 첫 주문 하나(§2-4 «첫 주문»).
4. 날마다: 상점 패널 안 새 탭 **«주문판»**(가구 탭 D47 결) — 열린 주문 줄 · [납품]. 칩·할 일은 가게 사슬(§5).

## 2. 주문

### 2-1. 꼴
`{ id, customerId, kind, need, openedOn, dueOn, premium, tier }`
- `kind`: `monstera_cutting` · `monstera_pot` · `pp`(핑크프린세스 그루 · 잘라 낸 윗부분 포함) · `al`(알로카시아 그루) · `al_corm`(구근)
- `need`: 조건 **하나**(종은 kind 가 이미 말함 → «종 + 하나» = D59 «조건 둘까지»): `{ grade: 'sanban'|'halfmoon'|'fullmoon' }`(그 등급 이상인 무늬 잎이 하나라도) · `{ leaves: n }`(잎 n장 이상) · 없음(꼴만)
- `tier`: 쉬움 · 보통 · 어려움 → 기한·웃돈(⚖ D59): 쉬움 21일 ×1.3 · 보통 30일 ×1.45 · 어려움 45일 ×1.6

### 2-2. 언제 나나 (⚖ D59)
- 새 주문 **이레에 한 번쯤** — 마지막 주문 뒤 5~9일 중 하루(판 씨앗으로 고른다 · 세이브에 다음 날을 적는다). 열린 주문 **최대 3**.
- 겨울에 알로카시아가 자면 `al` 주문은 안 낸다(구근 주문 `al_corm` 은 낸다).

### 2-3. 무엇을 내나 — «할 수 있는 것만»
뽑기 차례: 원천이 있는 kind 만 후보 → 그 kind 에서 tier 를 뽑고 → need 를 고른다. 원천 판정은 **core 한 곳**(nudge_wait 와 같은 뜻을 두 벌로 두지 않게 — 거기 함수가 있으면 그것을 부른다):
| kind | 후보가 되는 때 | need 고르기 |
|---|---|---|
| monstera_cutting | 자를 수 있는 몬스테라(모주·키운 삽수)가 있다 | 쉬움: 없음 · 보통: `leaves ≥ 2` · 어려움: 무늬 원천이 있을 때만 `grade ≥ halfmoon`(밝은 데 뿌리 자리가 있을 때 — 등 놓임 · 아니면 `≥ sanban`) |
| monstera_pot | 그루(모주 · 흙에 자리 잡은 삽수)가 둘 이상 | 보통: `leaves ≥ 지금 가진 그루 중 가장 많은 잎 수 − 1` · 어려움: 무늬 그루가 있을 때만 `grade ≥ sanban` |
| pp | 핑크프린세스가 있다 | 쉬움: 없음 · 보통: `grade ≥ sanban`(분홍 마블) · 어려움: `grade ≥ halfmoon` — ⚠ «분홍 잎»(풀문 자리)은 주문하지 않는다(못 자라는 잎) |
| al | 깨어 있는 알로카시아가 있다 | 보통: `leaves ≥ 2` · 어려움: 무늬 알로카시아가 있을 때만 `grade ≥ sanban` |
| al_corm | 구근을 찾은 적이 있다 | 쉬움: 없음 |
- **첫 주문**(가게 첫날): 지금 가진 것으로 **바로** 맞출 수 있는 쉬움 하나(가장 흔한 kind · need 없음) — 첫 납품을 첫 주에 겪게.

### 2-4. 납품
- [납품] 은 조건에 맞는 것이 있을 때만 켜진다(가방이든 놓였든 · 맞는 것이 여럿이면 고르는 목록). 몬스테라 «모주 마지막 한 그루»는 고를 때 지금 «마지막 무늬» 말림(D22 sellLastVarie)과 같은 확인을 거친다.
- 값 = **그것의 지금 시세 × premium** — 시세는 지금 판매 함수 그대로(삽수 `priceOf`/listCutting 의 셈 · 그루 `quotePot` · 새 종 `speciesPriceOf`). 화면은 주문 줄에 «시세보다 3할~6할 더»를 글로, 고르는 목록에 그 그루의 값을 수로 보인다(몬이는 수를 안 말한다 — 화면 글만).
- 납품하면 그것은 판 것처럼 사라지고 지갑 += 값 · 손님 단골 처리(§3) · 사건 `order_done`.
- 기한이 지나면 주문만 사라진다 — 벌 없음 · 단골 안 셈 · 사건 `order_expired`(조용한 기록 줄 · 대사는 사흘에 한 번까지).

## 3. 손님과 단골

- **손님 표** `data/balance/shop_customers.json`(plan 이 씀 · §6): 손님 36(30 이정표가 서게 넉넉히) — 실존 인물·상호 없음 · «동네 사람» 결(예: 2층 카페 주인 · 신혼부부 · 화원 견습생 · 출판사 디자이너…). 손님마다 `id · ko · 한 줄(주문 붙일 때 · 맞췄을 때)`.
- 주문의 손님은 표에서 고른다(아직 단골이 아닌 손님 쪽으로 기울게 ⚖ 3:1). **첫 손님은 «반찬가게 사장님»**(D35 반지하 주문을 겪은 판이면 — 아니면 표 첫 줄) — 반지하에서 온 인연이 첫 단골.
- **단골 = 주문을 하나라도 맞춘 서로 다른 손님 수.** 같은 손님이 또 오면 수는 그대로(그 손님은 웃돈 ⚖ +0.1 — 최소판엔 «다시 온 손님» 글만).
- 이정표(D59): **3명 · 10명(간판) · 30명** — 돈을 안 준다.
  - 3명: 몬이 한 줄 + 칩 머리말.
  - **10명: 간판** — 투룸 창밖(또는 문 옆)에 가게 간판이 선다(house 소품 · 가게 외관이 바뀌는 보상). 장면 원화 한 장(char).
  - 30명: 몬이·자취생 두 줄 + «동네 식물 가게» 칭호(할 일 탭 머리).
  - 진로 «끝»은 없다 — 30명 뒤도 가게는 돈다(D28 같은 멈춤 없음).

## 4. 규칙 (D59)

- 집: **산 투룸** — 월세 0 · 관리비(utility) **한 달 8만**(⚖ D59). homes.json 에 «산 집» 줄(`tworoom_owned` 꼴 · 방은 tworoom) 하나 — 월세 줄의 투룸(60만 · 공과 9.5만)과 섞지 않는다.
- 초보 보호 끝: 낙엽·고사 켜짐(growth `health.drop_enabled` · story_arc «스토리 뒤») · 굶음 그대로.
- 세이브: `story.job = { id: 'shop', since }` · `S.shop = { orders, nextOrderDay, regulars: [customerId…], done, expired, milestones: {3,10,30: day}, signOnDay }`. 직업 상태를 `ending.js` 에 두지 않는다.

## 5. 퀘스트 (plan · quest.js — room 'tworoom' · 칸 `job === 'shop'`)

사슬: **짐 풀기**(투룸 · 원룸 짐 풀기 결) → **첫 납품**(`done ≥ 1`) → **단골 셋**(`regulars ≥ 3`) → **간판 달기**(`regulars ≥ 10`) → (느린 줄) **동네 식물 가게**(`regulars ≥ 30`).
- 칩 글(D51 결 · 날마다 바뀜): «단골 4명 — 간판까지 6명» · 열린 주문이 있으면 «주문 2건 · 가장 급한 것 9일 남음».
- 스냅샷 칸(core): `job` · `shopRegulars` · `shopDone` · `shopOpenOrders` · `shopDueSoonest`. null = 모른다 → 안 열림.
- questRoomOk 에 'tworoom'(= 산 집으로 옮김) 갈래를 더한다(core 칸 `movedHome`).
