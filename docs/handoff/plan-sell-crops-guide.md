# 채소 팔기 — ★ 새 자리를 안 만든다. **같은 자리의 말이 «바뀐다»**

2026-08-24 · [Plan] · 박사님 *"넣어, 그리고 채소 파는 가이드도 넣으면 좋겠다. **월세 보탬 된다는 식으로**"*
⛔ 값 안 건드림. ③ 문턱은 **안**이고 정하는 것은 박사님이다.

---

# 0. ★★★★ 먼저 잰 것 — **상점 화면은 «이미 다 되어 있다»**
```js
game.html:14030  btn.textContent = `보유 채소 팔기 (${max}판)`
game.html:14035  "보유 채소 350g · 3판이 있습니다 — «밥으로 먹을 몫입니다». 팔면 85%만 받습니다"
game.html:14038  "보유 채소가 없습니다 — … (밥으로 먹는 편이 «이득»입니다)"
game.html:14027  ★ 곳간이 비어도 «단추를 안 감춘다» — 「파는 길이 있다」를 배울 자리가 없어지니까
```
⇒ ★★ **손해도 말하고, 판 수도 말하고, 단추도 늘 있다.** ⇒ **거기까지는 «고칠 것이 없다».**

## ⚠⚠ 그런데 **지금 화면이 박사님 말씀과 «반대»로 말한다**
```
화면      "밥으로 먹는 편이 «이득»입니다" · "팔면 85%만 받습니다"   ⇒ ★ 팔지 «마라»
박사님    "«월세 보탬» 된다는 식으로"                              ⇒ ★ 팔면 «도움»
```
⇒ ⚠ **모순이 아니다. 「언제」가 다르다:**
```
평소          팔면 손해다 — 밥으로 먹는 게 낫다        ✅ 지금 말이 «맞다»
돈이 마를 때   ★ 밥보다 «월세»가 급하다                 ← 이때는 «파는 것이 맞다»
```

> ## ★★★★★ **같은 행동이 «평소에는 손해»이고 «급할 때는 살 길»이다.**
> ## **그리고 지금 화면은 «평소 말»만 한다.**

⇒ ★ **내 계율 ②(*급전은 손해가 아니라 «값»이다 — 숨기면 함정, 보여 주면 기능*)의 정확한 자리다.**

# 1. ⇒ ★★★ 처방 — **새 자리를 안 만든다. «말이 바뀐다»**
```
평소            "…밥으로 먹을 몫입니다. 팔면 85%만 받습니다"          ← ★ 그대로 둔다
★ 문턱 아래     "지금은 월세가 먼저입니다 — 다 팔면 N원, 월세의 X할입니다"
```
⇒ ★★ **한 자리 · 두 얼굴.** 규율 ㉰(*한 곳에서 짓고 가져다 쓴다*)를 안 깬다.
⇒ ★ **금액은 `pantrySaleStatus` 가 이미 낸다.** 새로 안 센다.
⇒ ⚠ **월세도 정본을 «참조»한다.** 여기 200,000 을 박으면 **값이 두 벌이 되고 하나가 낡는다.**

# 2. ㉠ **대사** — 확정 한 줄, 앞뒤 확인함
```
chatLowCash1 지금
  나  : 통장을 세 번 봤다. 세 번 다 같았다.
  몬이: 세 번 볼 시간에 자.
★ 보탬
  몬이: …곳간에 뭐 남았어?
```
⇒ ★ **몬이가 연달아 두 줄인 것이 «오히려 맞다»** — *"자"* 라 해 놓고 **자기가 딴생각하는 것**이라
  몬이답고, **잔소리가 아니라 «같이 걱정하는 것»**으로 읽힌다.
⇒ ⛔ **「팔아」라고는 안 한다.** 파는 것이 늘 옳지 않다(밥이 없어진다).

# 3. ㉡ **가이드** — 언제 · 어디 · 무슨 말
```

```
⇒ ★★ **금액은 손짓이 안 말한다** — 누르면 화면(§1)이 말한다. **한 번에 두 곳이 말하면 겹친다.**
⇒ ★ 손짓의 몫은 **「거기 단추가 있다」**뿐이다. **그것이 「첫 걸음」 층이다.**

# 4. ㉢ **한 번인가 늘인가** — ★ **가이드는 한 번, 손은 늘, 말은 늘**
| | 언제 | 수명 |
|---|---|---|
| 손짓 가이드 | 문턱 아래 **처음** 한 번 | 누를 때까지 |
| 단추 | **늘** (이미 그렇다) | — |
| 화면 말(§1) | 문턱 아래면 **늘** | 문턱 위로 올라가면 원래 말로 |
| 대사 | 문턱 아래면 가끔 | 잡담 구조 그대로 |

⇒ ★ **내 「층·수명」 표 그대로다.** 새 칸이 «안» 붙는다.

# 5. ★★★ ③ **문턱 안 — 「월세 한 달치」**

## ⚠ 먼저: **절대 금액은 뜻이 없다**
```
지금  300,000
실측  d80 «167,399»  ·  d100 370,500  ·  d109 245,500
⇒ ⛔ 30만이면 d109 «에도» 뜬다 — 회복 중인데 라면 이야기가 나온다
```

## ⇒ ★ 안 — **월세 한 달치(지금 200,000)를 «참조»한다**
```
문턱 = 월세 1개월분
⇒ d80 167,399  →  ✅ 뜬다        (진짜 바닥)
⇒ d109 245,500 →  ✅ 안 뜬다      (톱니의 위쪽)
⇒ d100 370,500 →  ✅ 안 뜬다
```
⇒ ★★★ **실측 셋과 정확히 맞는다.** 그리고 **까닭이 있다:**
> ## **「월세 한 번 낼 돈밖에 없을 때」부터 무섭다.**
⇒ ★★ **그리고 그 까닭이 «대사·가이드의 말»과 같다** — 박사님이 *"월세 보탬"* 이라 하셨다.
  ⇒ **문턱과 문안이 «같은 까닭»을 쓴다.** 값이 바뀌어도 뜻이 안 낡는다.

## ⚠ 갈래 둘을 같이 적는다 (박사님 고르실 것)
```
ⓐ ★ 월세 1개월분 (지금 200,000)   — 위 근거. 내 기울기
ⓑ   월세 1개월분 + 열흘치 살림      — 200,000 + 166,670 ≈ 366,670
     ⇒ ⚠ 그러면 d100(370,500)에서 «거의» 뜬다. 지금 30만과 비슷해진다
```
⇒ ⛔ **값은 안 건드렸다.** ★ **다만 「월세를 참조하라」는 것이 안의 핵심**이다 —
  **숫자를 박으면 월세가 바뀔 때 조용히 낡는다.**
