# 안내 문안 규율 — 「목표」와 「다음 손」은 층이 다르다

2026-08-24 · [Plan] · 스샷 검토 C · C-1 · D-3 판정 + **원룸에 쓸 규율**

---

# 1. C 「같은 말이 두 곳에」 — ★ **의도다. 다만 의도는 «중복»이 아니라 «대체»다**

`game.html:8886` 이 그 의도를 그대로 적어 두었다:
> *"[가방]에 있던 진행 안내가 [식물] 맨 위로 왔다. 없애면 처음 하는 사람이 시트 안에서
>   길을 잃는다 — **아래 퀘스트 줄은 시트를 열면 가린다.**
>   ⚠ 문구를 여기서 새로 짓지 않는다. **같은 한 줄을 두 곳이 나눠 볼 뿐이다.**"*

```
설계   시트 «닫힘» → 아래 줄만 보인다
       시트 «열림» → 아래 줄이 가려지고 시트 안 상자가 대신 보인다
⇒ ★ 둘은 «동시에 안 보여야» 한다. 한 줄이 자리를 옮기는 것이지 두 줄이 아니다
```
⇒ ⚠ **그림에 둘이 «같이» 보인다면 그 가림이 안 되고 있는 것이다.**
⇒ ★ **판정**: 「같은 문구를 쓰는 것」은 **의도이고 옳다**(한 곳에서만 짓는다 — 낡음을 막는 바른 방법).
  **문제는 문구가 아니라 «가림»이다.** ⇒ ★★ **고칠 것은 문안이 아니라 화면이다.**
⚠ 내 순번(Chrome 3번)에서 **시트가 열린 그림인지** 직접 보고 확정한다. **아직 단정 안 한다.**

# 2. ★★★ C-1 「지시가 둘」 — **둘인 게 «잘못»이 아니다. 둘이 «같아 보이는» 것이 잘못이다**

```
👆 노란 상자   "가방을 열어 보세요"          ← 다음 손 하나
할 일 / 하단   "시루를 방 안에 놓아 보세요"   ← 무엇을
```

★ **설계는 이미 이 층을 갖고 있다** (`game.html:8871`):
> *"`tutorialGoal` 은 **「무엇을」**만 말하고 퀘스트는 **다음 손 하나**를 말한다."*

⇒ ★★★ **층은 있는데 «말이 그 층을 안 드러낸다».**
  둘 다 「~해 보세요」로 끝나서 **같은 크기의 지시 둘로 읽힌다.**

## ⇒ 처방 — **두 글자면 된다**
```
지금    "가방을 열어 보세요"
★ 바꿈  "먼저, 가방을 열어 보세요"
```
⇒ ★ **「먼저」가 「이건 첫 걸음이고 목표는 따로 있다」를 말한다.** 화면을 안 고치고 층이 선다.
⇒ ⚠ **목표 쪽은 «안» 건드린다.** 목표가 흔들리면 방향을 잃는다.

# 3. D-3 「120일차에 초반 대사」 — ★ **문제가 아니다. 다만 위험은 실재한다**

`dialogue.js:1316` 이 까닭을 적어 두었다:
> *"★ 부모 얘기를 여기서 한 번 더 한다 — 다만 **웃으면서** 한다.
>   오프닝의 울음과 이사 장면의 한 줄 사이를 **이 톤이 이어 준다.**"*

```
chatParents  네 줄이다
  ① 나: 엄마가 화분을 잘 죽였어.        ← ⚠ 스샷이 잡은 것은 «이 한 줄»
  ② 나(웃음): 물을 너무 많이 줘서.       ← ★ 여기서 톤이 뒤집힌다
  ③ 몬이: 너는 안 죽이잖아.
  ④ 나: …아직은.                        ← ★★ 이 줄이 이 잡담의 전부다
```
⇒ ★ **잡담(`chat*`)이고 서장 대사가 아니다.** 120일차는 *"오프닝과 이사 사이"*라 **자리가 맞다.**
⇒ ★★ **판정: 순서 문제 아님.** ⇒ ⚠ **그러나 총괄이 오해한 것 자체가 결과다** —
  **첫 줄만 떼면 서장 대사로 읽힌다.** 읽는 사람이 넷째 줄까지 본다는 보장이 없다.

## ⇒ ★★★ 그래서 나온 규율
> **여러 줄로 뜻이 뒤집히는 잡담은, «첫 줄만 읽어도» 오해되지 않아야 한다.**
```
지금    ① "엄마가 화분을 잘 죽였어."          ← 첫 줄이 무겁다
★ 대안  ① "엄마도 화분을 길렀는데, 잘 죽였어."  ← 「~는데」가 뒤에 뭔가 온다고 알린다
```
⚠ **대사를 바꾸자는 것이 아니다.** *"첫 줄이 혼자 서면 어떻게 읽히나"*를 **한 번은 보자**는 것이다.
⇒ ★ 나머지 잡담 묶음도 같은 눈으로 훑겠다(§5 일감).

# 4. ★★★ 규율 — **원룸 가이드를 짜기 전에 세운다**

총괄: *"반지하 첫 화면이 이 꼴이다. 가이드 규율을 먼저 세우셔야 원룸에서 같은 일이 안 난다."*

```
㉮ 층을 말로 드러낸다
   목표   「무엇을」        — "시루를 방 안에 놓아 보세요"
   손짓   「다음 한 걸음」   — ★ "먼저, 가방을 열어 보세요"
   ⇒ 손짓 문안은 «먼저 / 이제 / 그다음» 중 하나로 연다. 목표는 안 연다

㉯ 한 손짓에 한 곳만 가리킨다
   ⇒ 사기 · 놓기 · 심기는 걸음 셋이다 (계율 ④ — 줄지어 있는 것은 따로 가르친다)

㉰ 같은 글자를 두 곳에 «짓지» 않는다
   ⇒ 한 곳에서 짓고 다른 곳은 그것을 «가져다» 쓴다 (지금 게임이 그렇게 하고 있다 — 옳다)
   ⇒ ⚠ 그러면 «둘이 동시에 보이지 않게» 하는 것이 짝이다. 한쪽만 하면 중복으로 보인다

㉱ 답을 줄 것과 「선택이 있다」만 줄 것을 «미리» 정한다
   콩나물  답을 준다 (어두운 데)      — 첫 작물이라 막히면 안 된다
   무순    ★ 안 준다                  — 자리를 배우는 줄이다
   삽수    ⇒ 원룸에서 정한다 (§5)

㉲ 첫 줄이 혼자 서도 오해되지 않게 쓴다 (§3)
```
