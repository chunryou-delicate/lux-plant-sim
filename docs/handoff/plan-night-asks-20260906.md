**선택안**
```

**결과예상** [셈]
```

## ② 바닥에 시루를 놓게 하나

**배경** [잰 것]
방의 「자리」는 칸(창턱·책상·선반 …)이고 바닥은 칸이 아니다. 좌표 조도 계약은 D로 결정됐다 — 「헤드리스는 바닥을 모른다고
던지고, 바닥 표가 필요하면 브라우저 자로만 낸다」. 그래서 지금 바닥에 시루를 놓고 하루를 넘기면 게임이 «멎는다»(조용히 틀리지 않고
던진다 — [core] 302a4fe). 곧 「바닥에 놓을 수 있는가」가 아직 안 정해진 채 울타리만 서 있다.

**배경 둘째 — 바닥은 «어둡지 않다»** [잰 것 · growth · 브라우저 자 하나(`probe_floor_dli ROOM=oneroom`)]
⚠ 조건을 반드시 같이 읽을 것: 원룸(비운 것 · d4a4221) · 등 «0개» · ★ «맑음·여름 하루값» — real 400일이 «아니다».
아래 「0.35↑」는 «하루값이 문턱을 넘은 점 수»이지 «무순 7일평균 판정»이 아니다.
```

  맑음·여름 «하루» DLI:  0.35 이상 «152/289» · 0.30 초과 «166/289» · 최고 1.79
  계절·날씨별 «폭» (등0):  봄 맑음 0.02~1.33 · 여름 맑음 0.03~1.79 · 가을 맑음 0.02~1.17 · 겨울 맑음 0.01~«0.67»
                          흐림은 각각 0.33 · 0.45 · 0.29 · «0.17»
견줄 것 — 같은 원룸 «가구 위» 무순 최상(7일평균 · 한 해 내내 ≥0.35): 등0 «4/18» (창턱뿐)

⇒ 겨울 맑음 최고가 0.67 이고 흐림은 0.17 이라, 겨울엔 그 152 의 «대부분»이 0.35 아래로 내려간다.
> **원룸 빈 바닥은 «여름엔» 가구 위(4칸)보다 훨씬 넓게 무순 문턱을 넘지만(152점), «겨울엔» 대부분 내려앉는다 — 바닥 시루는 「자리가 넓다」와 「계절을 탄다」가 «한 몸»이다.** ([growth] 뜻 한 줄 · 「그러니」 없음)
⇒ 바닥은 헤드리스로 못 재므로(D) real 400일 표는 계약이 실린 «뒤»다.

**선택안**
```

   (⚠ 「어두운 자리」가 아니다 — 위 배경 둘째. 여름엔 무순 자리, 겨울엔 아무 자리도 아니다)
```
**결과예상** [판단]
```
