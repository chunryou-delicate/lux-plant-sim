# ★ 문안 넷

## ① **로그** (`src/game/state.js:400`)
```
🪴 축복받은 몬스테라 삽수가 도착했습니다 — 화분째, 이미 ${growthDays}일 자란 개체입니다
```
⇒ ★ **「화분째」가 «심는 걸음이 없다»를 그 자리에서 말한다.** 새 가이드가 필요 없어진다.
⇒ ✔ `${growthDays}` 는 **읽어 쓰는 값이라 안 낡는다** — 그대로 둔다(계율 ㊶).

## ② **배너** (`game.html:9804`)
```
title  🪴 축복받은 몬스테라 삽수가 도착했습니다
sub    창가가 아닌 자리에 놓였습니다        ← ⛔ «안 바꾼다»
```
⇒ ⛔ **sub 는 손대지 않는다.** 이미 「창가가 «아닌»」이 사실을 말하면서 «시키지는» 않는다. ⓒ①에 맞다.
⇒ ⚠ **다만 [core] 가 재 준 것 — d12 에 자리가 `null` 이다.** 배너가 그 «전»에 뜬다면
  「놓였습니다」가 «아직 안 놓인 것»을 말하는 셈이다. ⇒ ★ **[core] 가 눌러 봐야 한다. 내가 셈으로 안 민다(㊷).**

## ③ **가방 칸 `title`**
```
축복받은 몬스테라 삽수
```
⇒ ⛔ **줄이지 않는다.** 박사님이 그렇게 부르셨고, 자리가 좁으면 [core] 가 재서 알린다.

## ④ ★★★ **가방 칸 `sub`** — 여기가 「끌 것을 잘못 잡으신 것」을 «그 자리에서» 푼다
```
화분째 받았습니다 · 옮기려면 방에 놓인 화분을 끄세요
```
⇒ ★★ **「끌지 마세요」(부정)가 아니라 「끌 것은 저기입니다」(가리킴)다.**
⇒ ★ **박사님이 끄시던 «바로 그 칸»이 답한다. 그리고 «찾아본 사람만» 본다 — ⓒ② 그대로다.**

## ⑤ ⏸ **몬이 — «며칠째 그대로일 때»** (자리는 [core] 가 정한다)
```
"…며칠째 그대로네. 자리가 «안 맞나» 봐."
```
⇒ ★ **「언제」만 짚고 «어디»는 안 정해 준다.** 계율 — **「어디」는 퀘스트가, 「언제」는 몬이가.**
⇒ ⇒ ★★ **그래서 «옮길지 말지»도, «어디로»도 사람이 고른다. 두 번째 학습이 «남는다».**
