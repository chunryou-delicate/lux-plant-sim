# ★★★★★★ ①② 「가이드가 다 뻑이 난다」 — **`phase` 가 «앞으로만» 간다**
2026-08-29 · [plan] · 박사님 *"시루를 배치하고 «가이드하기전에» 시루를 옴기면 «가이드자체가 다 뻑이나는거같어». 손가락가이드라던지 «모든 지침»이"*
⚠ **판정이 아니라 «물음»이다. 코드는 읽었고 «안 눌렀다».**

---

## ⓐ ★★★ **첫 플레이는 `phase` 사슬로 구른다 — 그리고 «되돌아오는 대입이 없다»**
```
src/game/first_play.js

```
> ## ⛔ **뒤로 가는 대입이 «하나도 없다». 오직 «앞»으로만 간다.**

## ⓑ ⇒ ★★★★★★ **그러면 박사님 말씀이 «구조»로 설명된다**
```
① 시루를 «놓는다»            ⇒ 판이 「했다」고 «기억»한다
② 가이드 뜨기 «전»에 «치운다»  ⇒ ★ 그 전제가 «사라진다»
③ ⇒ ⇒ ★★ 그런데 판은 «안 돌아온다»
④ ⇒ ⇒ ⇒ ⛔ 가이드는 「①을 이미 했다」고 믿고 «다음 것»을 말한다 — ★ «허공»에 뜬다
```
⇒ ★★★ **「하나」가 아니라 «얼개»가 무너진다. 박사님 말씀 그대로다 — 「모든 지침이」.**

## ⓒ ⇒ ⛔ **그리고 손가락은 «말없이» 사라진다**
```
game.html:3649  "⇒ «다시 고른다». 고를 것이 없으면 updateHint 안에서 ★ hintAt(null) 로 «끝난다»"
```
> ## ★★ **가이드가 «죽는» 게 아니라 «조용히 없어진다». 그게 제일 나쁘다.**
```
벌이면      「내가 잘못했구나」  ⇒ ★ 배울 것이 있다
★ 이건      「★ 뭘 잘못했는지도 모른다」 ⇒ ★★ 배울 것이 «없다»
```
> # **㊼ 사람은 되돌릴 수 있는데 «판»이 안 되돌아가면, 그건 «벌»보다 나쁘다 — «버려진» 것이다.**
⇒ ★ 계율 「되돌릴 수 있는 막다른 길은 «배움»이고 못 되돌리는 것은 «벌»이다」의 **셋째 꼴**이다.

## ⓓ ★ **갈래 셋 — ⛔ 얼개는 [core] 가 정한다. 나는 «말»만 낸다**
```
㉠ 못 되돌리게 «막는다»   ⇒ ⛔ 손이 묶인다. 3단 선반의 「배우고 · 잃고 · 되찾는다」와 어긋난다
★㉡ 되돌리면 판이 «따라간다» ⇒ ★★ phase 를 되돌린다. 손가락이 «다시» 그 자리를 짚는다
★㉢ 되돌리면 «말해» 준다    ⇒ ★ 그러면 «벌»이 «배움»이 된다
```
> ## ★★★ **㉡ + ㉢ 이다. ⛔ ㉠은 안 된다 — 되돌리는 것을 «막을» 게 아니라 «받아» 줘야 한다.**

## ⓔ ★ **㉢ 문안 — 「되돌렸다」를 «말해» 주는 자리**
```
시루를 치웠을 때   "시루를 다시 챙겼습니다 · ★ «놓을 자리»를 고르세요"
```
⇒ ★★ **어제 배운 것 그대로다(㊺) — «게임이 이미 쓰는 말»을 쓴다:**
  `game.html:9193/9207` 「아직 안 놓았습니다」 · `4139` 「가방 — 아직 안 놓았다」
⇒ ⇒ ★ **그러니 새 말을 안 짓고 «그 말투»로 돌아가면 된다. 손가락도 «그 자리»로 돌아간다.**

# ★★★★★★★★ ⓖ — **㊽ 「길이 없다」와 「길을 «안 알려줬다»」는 «똑같이» 보인다**
2026-08-29 · [core] 가 낸 한 줄에서

## ⓐ **[core] 말**
> *"★ 박사님이 나흘 «끌기»만 하고 계셨고, 「누르면 된다」를 화면이 «한 번도 안 말했습니다»."*
```
박사님 ⑤   "★ 드래그 배치 «자체가 없어진거야»? 살렸으면 좋겟어"
[core] 실측  ★ 끌기는 «살아 있다» — 짧은 가방 · 긴 가방 · 화분 둘인 판, 다 됨
⇒ ⇒ ★★★ 그런데 박사님은 «없어진 줄» 아셨다
```
> # **㊽ 「길이 «없다»」와 「길을 «안 알려줬다»」는 사람에게 «똑같이» 보인다.**
> # ⇒ ★ **그리고 고치는 법이 «정반대»다 — 앞은 «만들고», 뒤는 «말한다».**
⇒ ⛔ **㉠~㉤ 를 다 「기계」로 세었는데, ㉥ 는 «말한 적이 없는 것»이다.
  ★ 없는 흠은 세어도 안 나온다. 「안 한 것」은 «목록에 안 뜬다».**
⇒ ⇒ ★★ 계율 ㊲-e(있는데 «한 군데 빠진» 것)의 «가장 나쁜 꼴» — **아예 «한 군데도 없는» 것.**

## ⓑ ⇒ ★★★★ **그래서 「끌거나 눌러」가 «어느 쪽이든» 구한다**
```
끌기가 «되면»    ⇒ 사람이 몰랐던 것 ⇒ ★ 문안이 «알려 준다»
끌기가 «안 되면»  ⇒ ★★ «누르는 길»이 있다 ⇒ 문안이 «그것»을 알려 준다
```
⇒ ★★★ **둘 다에서 그 한 줄이 사람을 구한다. 그래서 «지금 제일 급하다». [core] 판단이 맞다.**
⇒ ⚠ **그리고 [core] 가 밝힌 자 한계(CDP 는 «진짜 손짓 처리»를 안 지난다)가 그것을 «더» 굳힌다** —
  ★ **자로 「된다」가 나와도 폰에서 안 될 수 있으니, «누르는 길»을 말해 두는 것이 «보험»이다.**

# ★ ⓒ **㉢ 문안 — 시루 것을 «고치고» 몬스테라 것을 «같은 꼴»로 낸다**
```
⛔ 내가 어제 낸 것  "시루를 «다시 챙겼습니다» · 놓을 자리를 고르세요"
★ 고침              "★ «가방으로 돌아왔습니다» · 놓을 자리를 고르세요"
★ 몬스테라           "★ «가방으로 돌아왔습니다» · 놓을 자리를 고르세요"   ⇐ 같은 줄이면 된다
```
⇒ ★★ **「챙겼습니다」는 «무엇을 했나»만 말하고, 「가방으로 돌아왔습니다」는 ★ «어디 있나»를 말한다.**
> ## ★★★ **그리고 그것이 어제 ㉣ 의 교훈 그대로다 — 「어디」를 안 말하면 사람은 «딴 데»서 찾는다.**
⇒ ★ **한 줄이 둘 다에 쓰이니 «따로 지을» 것도 없다.** ⇒ ⇒ **㊺(이미 쓰는 말) + ㉣(어디를 말하라)의 겹.**

## ⓓ ⇒ ⚠ **그러면 «묻을 것»이 하나 생긴다**
```
★ 「끌거나 눌러」를 «가방 안내»에만 넣으면 되나?
⇒ ⚠ 박사님이 «가방을 안 열고» 헤매셨으면 그 말이 «안 보인다»
⇒ ⇒ ★ 그리고 «시루»도 같은 병이면 시루 안내도 같이 고쳐야 한다
```
⇒ ⛔ **내가 안 눌렀다. [core] 가 「시루 안내가 «누르는 길»을 말하나」를 재면 갈린다.**
