## 인터페이스

```js
// 1) 모든 GLB는 정규화돼 있지 않다. manifest 의 scale_to_real 을 곱해야 실제 크기가 된다.
//    (절차적 산출물 — 선반·작물 — 은 이미 실제 미터라 1.0)
gltf.scene.scale.setScalar(item.scale_to_real)

// 2) 시루 슬롯 = 관엽 선반과 완전 동일 규격 (검증함: 키 {x,y,z} 일치)
item.slots        // [{x,y,z}, ...] 로컬 미터, y = 심는 바닥 높이
item.slot_count   // 15
item.blocks_light // true — 뚜껑 닫으면 DLI 0
item.lid_state    // 'open' | 'closed'

// 3) 콩나물 인스턴싱 — 슬롯마다 바운딩박스 바닥면을 슬롯 y에 맞춘다
for (const s of siru.slots) {
  const m = beansprout[stage].clone()
  m.position.set(s.x, s.y - bbox.min.y, s.z)
  m.rotation.y = rand() * Math.PI * 2   // ★ 이걸 꼭 주세요 (아래 참고)
}
```

**참고**: 콩나물 에셋은 1개를 인스턴싱하는 구조라 **Y축 랜덤 회전을 주지 않으면 15개가 전부 같은 방향으로 휩니다.**
