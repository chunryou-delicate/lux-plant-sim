## 1. ★★ game.html 이 넘겨야 하는 spec — **계약**

마스터 창이 제안한 것과 **한 칸도 다르지 않다.** 그대로 배선하면 된다.

```js
const cont = CONTAINERS[c.container] || {};
const spec = {
  kind:       c.container === 'jar' ? 'cutjar' : 'cutpot',   // ← 여기만 바뀐다
  potId:      c.id,
  variegated: !!c.variegated,
  leaves:     c.leaves,                    // 0~2 · 없으면 방뷰가 1 로 본다
  rooted:     c.status !== 'rooting',      // 뿌리가 났나
  potD:       cont.realMaxM || 0.12
};
roomView.setPlantAt(c.id, c.at, spec);     // 또는 setPlant(c.slotId, spec)
```

칸마다의 규약:

| 칸 | 받는 값 | 안 주면 | 그림에 어떻게 나오나 |
|---|---|---|---|
| `kind` | `'cutjar'` · `'cutpot'` | — (필수) | 모르는 이름이면 **던진다**(일부러 그렇게 뒀다) |
| `potId` | 삽수 id | null | `free:{id}` 열쇠·이동·탭이 이 값을 탄다 |
| `leaves` | 0~2 정수 | **1** | 잎 장수. 범위 밖·NaN·문자열은 조용히 잘라 쓴다 |
| `variegated` | true/false | false | 참이면 무늬 잎 GLB(`skins/monstera_leaf_young_albo.glb`)로 그린다 |
| `rooted` | true/false | false | **병에서만** 보인다 — 물속에 흰 뿌리 6가닥. 포트는 흙 속이라 안 보인다 |
| `potD` | `CONTAINERS[*].realMaxM` | 0.13 / 0.12 | 자리 지름 상한. 안 줘도 같은 값으로 떨어진다 |

★ **`growthDays` 는 이제 안 넘겨도 된다.** 삽수는 날짜로 안 자란다 —
  지금 `game.html:8771` 이 넣고 있는 `Math.min(120, 34 + c.days)` 는 몬스테라 조립기를
  달래려던 임시 값이었고, 새 갈래는 그 칸을 아예 안 읽는다. 넣어도 무해하지만 뜻이 없다.

⚠ **잎 수는 코어가 더 좁다** — `propagation.METHODS.water.maxLeaves === 1` 이라
  **병에 실제로 오는 잎은 0~1장**이다(흙은 제한 없음). 방뷰가 2장까지 받는 것은
  흙 포트와 옛 세이브 몫이다. 실측으로 확인했다(재는 자 ⓪).

⚠ **잎·무늬·뿌리가 바뀌면 방이 다시 짓는다** — `needsRebuild` 에 한 줄을 더했다.
  안 넣었으면 12일 뒤 뿌리가 나도 **병 속이 영영 그대로**였다(삽수는 `days` 가 안 움직인다).
  `sown`(무순)·`count`(시루)가 겪은 그 함정과 같은 자리에 같은 식으로 막아 뒀다.

| | 렌더 중앙값 | 드로우콜 | 화면 |
|---|---|---|---|

⇒ 고른 길에는 **새로 짤 것이 없었다.** `pot_glassjar.glb` 의 재질이 이미 `alphaMode:BLEND` 라

## 3. 그림을 어떻게 만들었나 — **있는 GLB 를 썼다**

§2.7 의 *"그림이 없다고 하기 전에 GLB 부터 찾아라"* 를 그대로 따랐다. 넷 다 manifest 에 있다.

| 쓴 것 | 무게 | 왜 |
|---|---|---|
| `pots/pot_glassjar.glb` | **360삼각형 · 텍스처 0장** | 노드가 `glass`·`water` 둘이라 **물까지 들어 있다.** 물 높이를 GLB 에 물어서 쓴다 |
| `pots/pot_nursery_black.glb` | 3,591삼각형 | 검은 모종포트 그 물건 |
| `monstera/monstera_leaf_young.glb` | 3,993삼각형 | plant_grow 의 `leaf_young` 과 **같은 파일** |
| `monstera/skins/monstera_leaf_young_albo.glb` | 3,983삼각형 · 253KB(그림 내장) | `leaf_young_albo` 와 같은 파일. 확대창의 무늬와 **같은 그림** |

**그 자리에서 만든 것은 셋뿐이다** — 잘린 줄기(원기둥) · 자른 자리(원반) · 물뿌리(원기둥).
까닭: **「잘린 줄기」 에셋이 없다.** `stem_early.glb` 는 뿌리에서 올라오는 온전한 줄기라
«자른 자리»가 없고 951KB 다. 2cm 짜리 조각에서 그 차이는 안 보인다.
물뿌리개가 쓰는 것과 같은 구조다(§ensureCanAsset) — GLB 를 못 실으면 원기둥으로 떨어진다.

### 크기를 어떻게 정했나

- **용기 지름**은 코어 값이다(0.13 / 0.12). 지어낸 숫자가 아니다.
- **잎은 실물보다 작게 그린다.** manifest 의 어린 잎은 `real_max_m 0.18` 인데, 그대로 세우면
  잎(0.18)이 병(0.13)보다 커서 **화면에서 병이 안 읽힌다.** 박사님이 보고 싶다 하신 것은
  «유리 수경병»이다. ⇒ **0.12m 로 줄여 그린다.** 무순 재배판을 0.4327 → 0.20 으로 줄여
  그린 것과 **같은 사고**다(§MUSUN_D): 에셋은 안 건드리고 그릴 때 줄인다.

### 사진 보고 세 번 고친 것 (「고쳤다」를 화면 확인 없이 안 썼다)

1. **잎이 병목을 뚫고 나왔다.** 줄기 길이를 «물 면 위 5.5cm» 로 잡았더니 줄기 끝이
   병 안에서 끝났다. ⇒ **아가리 높이를 GLB 에 물어서** 그보다 5.5cm 위까지 세운다.
2. **검은 포트에 «흰 흙»이 담겼다.** 흙을 5mm 아래 → 1.4mm 아래 → 아가리에 딱 맞춰
   세 번 옮겨도 그대로였다. 장면에서 메시를 훑어 재 보니 이 GLB 는 **실사 스캔이라
   안쪽 바닥이 크림색으로 막혀 있고 그 뚜껑이 bbox 꼭대기와 같은 높이**였다 —
   z-싸움에서 크림이 이겼다. ⇒ 흙을 **아가리 위로 조금 봉긋하게** 올렸다.
3. **그 흙이 이번엔 날아갔다.** 흙 윗면은 해를 정면으로 받는 면이라 `0x4b3a2c` 가
   화면에서 크림색이 됐다. 잎은 세워져 있어 같은 빛에서도 안 날아간다 —
   **같은 색이라도 면이 어디를 보느냐가 다르다.** ⇒ `0x33261b` 로 더 어둡게 적었다.

`monstera` · `emptypot` · `beansprout` · `musun` 의 동작은 한 줄도 안 바꿨다.

| `test_pots` | FAIL 69/70 | **FAIL 69/70** (같다) |

| `test_musun_view` | FAIL 17/21 | **FAIL 17/21** (같다) |

⚠ 세 검사의 빨간 줄은 **내가 만든 것이 아니다.** 전부 옛 상수를 박아 둔 것들이다 —
  시루 지름 0.24(지금 0.20) · 칸 20×16(지금 19×15) · 가구 좌표. START-HERE §2.5 가

## 5. 못 한 것 · 남은 것

- ⛔ **`game.html` 배선은 안 했다.** 그 파일은 다른 창이 고치는 중이라 한 글자도 안 건드렸다.
  §1 의 계약대로 `kind` 한 칸만 바꾸면 된다. **마스터 창 몫이다.**
- ⚠ **무늬가 «눈에» 강하게 안 읽힌다.** 화소로는 3.6% 가 달라지고 GLB 도 게임이 쓰는
  바로 그 무늬 잎인데, 이 크기(잎 12cm)·이 빛에서는 «조금 밝은 잎» 정도로 보인다
  (`cutjar_3_varie.png`). 확대창의 무늬와 **같은 에셋**이라 이건 그림의 성질이지 배선 문제가
  아니다. 더 티나게 하려면 에셋 쪽 일이다 — **내가 정할 일이 아니라 적어만 둔다.**
- ⚠ **삽수의 빛 규칙은 없다.** 지시대로 조도를 한 톨도 안 건드렸다. 삽수는 자리만 차지한다.
  (뿌리내리는 동안은 두 갈래 다 빛과 무관하다는 것이 `propagation.md §3` 의 계약이다.)
- ⚠ **잎 한 장이 3,993 삼각형**이다. 삽수를 여럿 세우면 그만큼 는다 —
  잎 2장짜리 포트 셋이면 +35,000 으로 방(31,546)을 넘긴다. 지금 문제는 아니지만
  **삽수를 여러 개 세우는 화면을 만들 때는 이 값을 기억해야 한다.**
- ⚠ `cutpot` 은 `rooted` 로 **그림이 안 바뀐다.** 흙 속 뿌리는 원래 안 보이기 때문이다.
  안 보이는 것을 보여 주면 화면이 거짓말을 한다 — 그 자리를 비워 둔 것이 사실이다.
