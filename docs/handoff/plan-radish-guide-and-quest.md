# ⛔⛔ **정정 2026-08-24(2) — 「무순은 팔 작물이 아니다」를 «보류»한다**

## ① ⛔ 내 비율이 틀렸다 — **밑을 잘못 잡았다**
```
[core] 가 «엔진을 직접 불러» 잰 것    콩나물 0.70 · 무순 0.80
내가 «읽어서» 낸 것                  콩나물 0.84 · 무순 0.64
```
⇒ ★ **정본 밑은 `WON_PER_GRAM = 10원/g`**(곳간 장부값)이고, 나는 **밥 효율(8.33·12.50)**을 밑으로 썼다.
⇒ ⇒ ⚠ **높낮이가 «뒤집혔다»** — 무순이 더 나쁜 줄 알았는데 **덜 깎인다.**

## ② ⚠ 그런데 **내 셈이 «틀린» 것인지 «다른 물음»인지는 가려야 한다**
```

내 셈        =  파는 값 / «밥 효율»       ⇒ 「먹는 것 «대비» 얼마나 손해인가」
```
⇒ ⛔ **내가 그것을 「화면이 말하는 %」라고 «부른» 것이 틀렸다.** 그 이름으로는 [core] 것이 맞다.
⇒ ⚠ **「먹는 것 대비」 쪽도 다시 세어야 한다** — ⛔ **지금 안 센다. [core]·[growth] 에 되묻는다.**

## ③ ⛔ **「화면이 무순에게 거짓말한다」도 취소**
```

⇒ 숫자를 박아 놓은 데가 «없다». 「85%」는 주석에만 있다
```
⇒ ★★ **낡은 것은 «주석»이지 «화면»이 아니었다.** 「85%가 낡았다」는 맞고,
  ⇒ **거기서 「그러니 화면이 거짓말한다」로 간 «한 걸음»이 틀렸다.**
⇒ ★ **다만 그 한 걸음을 ⛔ 「단정 안 한다 · [core] 몫」으로 «멈춰 둔 것»이 문서를 살렸다.**

## ④ ⏸ **그래서 「무순은 팔 작물이 아니다」를 «보류»한다**
```
⛔ 죽음   "무순은 팔 작물이 아니다(1.56배 손해)"   ← 밑이 틀렸다
⏸ 보류   "채소는 버티는 것 · 무늬는 만드는 것"     ← ★ 이건 tutorial.js:130 이 받쳐 준다. 다만 다시 재고 쓴다
```

# 2. ㉠ **손가락 가이드** — 「시루 둘로 늘리기」 직후

## 어디에 붙나
```
siru2(시루 둘로 늘리기) 끝남
   ↓  ★ 여기
㉠ 무순 손가락 가이드 — 걸음 셋
   ↓
siru5_cycle5(콩나물 다섯을 다섯 바퀴)
   ↓
㉡ ★ 새 줄 — 무순 다섯
```

## 걸음 셋 — **한 걸음에 하나만 가리킨다**
```
㉠-1  가게 → 「재배판」을 가리킨다        (사는 것)
㉠-2  가방 → 재배판을 방으로 끌게 한다    (놓는 것)
㉠-3  가게 → 「무순 씨앗」을 가리킨다      (심는 것)
```
⚠ **셋을 한 손짓으로 묶지 않는다.** 사는 것과 놓는 것과 심는 것은 **다른 동작**이고,
  묶으면 어디서 막혔는지 플레이어가 못 짚는다. (계율 ④ — 줄지어 있는 것은 따로 가르친다.)

## 문안 — **왜 사는지를 먼저 말한다**
```
㉠-1   "콩나물만으로는 끼니가 안 채워져요.
        하나 더 길러 볼까요 — 이번엔 «빛을 봐야 하는» 걸로."
          → 가게의 재배판을 가리킴

㉠-2   "무순은 시루에 안 담아요. 얕은 판에 펴서 길러요."
          → 가방의 재배판을 가리킴 · 방으로 끄는 손짓

㉠-3   "콩나물은 어두울수록 하얗고 아삭해요.
        무순은 «반대예요» — 빛을 봐야 파래지고 알싸해져요."
          → 가게의 무순 씨앗을 가리킴
```
⇒ ★ **㉠-3 이 이 가이드의 전부다.** 「반대」라는 말 하나가 **자리라는 축을 켠다.**
⇒ ⚠ **어디에 놓으라고는 «안» 말한다.** 계율 ⑤ — **답을 주는 것과 「선택이 있다」만 주는 것.**
  콩나물은 답을 줬다(어두운 데). **무순은 안 준다.** 그래야 ㉡ 이 가르칠 것이 남는다.

# 3. ㉡ **「무순 다섯」 퀘스트** — 무엇을 가르치나

## ⚠ 먼저, 겹치면 안 되는 것
```
siru5_cycle5(콩나물 다섯)  = ★ "체력이 천장이다"    — 한계가 «내 손»에 있다
```
⇒ 무순 다섯이 또 「많이 돌려라」면 **같은 줄을 두 번 가르치는 것**이다.

## ★★★ 그래서 이 줄의 뜻은 — **「한계가 내 손 밖에 있다」**
> ## **콩나물은 내가 얼마나 부지런한가로 정해지고,**
> ## **무순은 «방이 얼마나 밝은가»로 정해진다.**

```
콩나물   어두우면 «된다».  반지하는 어두운 자리가 남아돈다  → 자리가 축이 아니다
무순     0.35 를 넘어야 한다.  넘는 자리가 «다섯»뿐이다     → ★ 자리가 축이 된다
```
⇒ ★ **다섯 개를 채우는 순간 방의 밝은 자리가 «정확히» 바닥난다.**
⇒ ⇒ **그게 이 줄이 가르치는 것이다 — 「이 방에는 밝은 자리가 다섯뿐이다」.**
⇒ ⇒ ⇒ ★★ 그리고 **여섯째를 놓고 싶어지는 순간 등을 떠올린다.** ⛔ 말해 주지 않는다.

## ⚠ 그런데 **튜토 안이면 이게 안 배워진다**
```
튜토(novice)  맑음·여름 고정   → 다섯 칸이 «전부» 최상. 아무 데나 놔도 3끼가 난다
튜토 뒤(real) 계절이 돈다      → ★ 다섯이 한꺼번에 내려앉고 창턱만 남는다
```
⇒ ★★★ **「무순 다섯」은 튜토 «안»에 두면 「사서 놓으면 되는 줄」이 되고,
  튜토 «뒤»에 두면 「자리를 고르는 줄」이 된다.**
⇒ ⚠ **박사님께 물을 것 하나** — 아래 §5 ①.

## 문안
```
열릴 때   "무순도 다섯 판까지 늘려 볼까요.
           ⚠ 그런데 콩나물처럼 아무 데나 놓으면 안 돼요."

중간      "판마다 색이 다르죠. 어두운 데 둔 건 희멀겋게 웃자랐어요."
           ⇒ ★ 값을 안 말하고 «눈에 보이는 것»만 말한다

끝날 때   "이 방에서 무순이 파래지는 자리는 몇 개 없어요.
           더 늘리려면… 방을 바꾸든지, 빛을 들이든지요."
           ⇒ ★★ 이 한 줄이 «등»과 «이사» 둘 다를 처음 가리킨다. 답은 안 준다
```

---

# 4. ⇒ ★ 이 두 줄이 **다른 것 셋을 같이 고친다**

```
① 「crop_mix 를 안 사면 사슬이 잠긴다」  → 가이드가 사게 하므로 «안 잠긴다»    (박사님 처방)
② 「등이 몬스테라 전용이라 살 이유가 하나뿐」 → ★ 무순이 «둘째 이유»가 된다
③ 「계절이 와도 살림에서 안 느껴진다」    → ★★ 겨울에 무순이 «눈에 보이게» 나빠진다
```
⇒ ★★★ **③ 이 제일 크다.** 지금까지 계절은 **몬스테라에서만** 느껴졌다.
  ⇒ 무순이 들어가면 **계절이 밥상에서도 보인다.** 그리고 **콩나물은 겨울에 오히려 낫다** —
  ★ **한 방에서 두 작물이 계절에 «반대로» 움직인다.** 그것을 읽는 것이 플레이어의 일이 된다.

---

# 5. ⚠ 박사님께 물을 것 — **둘뿐이다**

```
① ★ 「무순 다섯」을 튜토 «안»에 둘 것인가 «뒤»에 둘 것인가
     안 — 사서 놓으면 끝난다(쉽다). 튜토가 길어진다
     뒤 — ★ 계절이 붙어서 「자리를 고르는 줄」이 된다. 대신 튜토에서는 안 배운다
   ⇒ 내 쪽 기울기: **뒤**. 튜토는 이미 길고, 이 줄의 값어치는 계절에서 나온다

② 무순 다섯을 채우면 「밝은 자리가 바닥난다」를 ★ «말해 줄» 것인가
     ⓐ 말 안 함 — 여섯째를 놓아 보고 웃자란 걸 보고 스스로 안다 (내 쪽 기울기)
     ⓑ 위 §3 끝 문안으로 말해 줌
```

⛔ **퀘스트 요구 수·문턱·가격은 손대지 않았다.** 위 「다섯」은 **박사님이 말씀하신 수**이고,
  내가 한 일은 **그 수가 방과 맞는지 잰 것**뿐이다.
