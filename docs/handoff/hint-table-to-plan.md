# 손가락 조건표 — 언제 뜨고, 무엇을 짚고, 언제 안 뜨나

2026-08-30 · [House 마당: game.html §updateHint] → 총괄(머메이드 지도용) · [Plan]

총괄이 청한 「손가락 조건표」다. 트리를 그릴 때 이 표를 그대로 옮기면 된다.
값은 하나도 안 바꿨다. 여기 적힌 것은 지금 코드가 하는 그대로다.

---

## 0. 먼저 — 손가락이 **안 뜨는** 자리 (여기가 트리의 «가지치기» 지점이다)

순서대로 걸린다. 위에서 걸리면 아래는 아예 안 본다.

| # | 안 뜨는 까닭 | 자 |
|---|---|---|
| ⓐ | **쪽지가 떠 있다** | `coachNow` — 같은 순간에 안내가 둘이면 둘 다 안 읽힌다 |
| ⓑ | **대사 중이다** | `#stage.talking` — 박사님 「대사 끝나고 손가락이 나타나야지」 |
| ⓒ | **자세히 보기 중** | `#stage.zoom` |
| ⓓ | **집는 중 · 끄는 중** | `picked.mode` · `drag.on` — 지금 할 일이 이미 분명하다 |
| ⓔ | **첫 판이 꺼져 있다** | `!fp.enabled` — 안내는 첫 판에서만 돈다 |
| ⓕ | **짚을 것이 화면에 없다** | `onScreen(el)` 이 거짓 (좁은 화면의 [가방], 넓은 화면의 격자 등) |
| ⓖ | **시트가 그것을 덮는다** | `sheetCovers(el)` — ★ 2026-08-30 에 「시트가 열렸나」에서 바꿨다 |

⚠ ⓖ가 오늘 고친 구멍이다. 넓은 화면(1770×1188)은 시트가 **늘 펴져 있어서**
「열렸나」로 물으면 네 갈래가 통째로 죽었다. 「이것을 덮나」로 물으면 안 죽는다.

⚠ ⓑ는 구멍이 아니라 규칙이다. 재는 판에서 대사를 안 걷고 재면 언제나 「손가락 없음」이 나온다.

## 2. 덮개(울타리)가 같이 뜨는 자리

손가락이 뜨면 덮개도 같이 뜬다(`dimAt`). 짚은 자리 **밖**에서 시작한 손짓은 삼키고,
손가락이 한 번 뛴다. ⚠ [다음 날]은 겹침이 아니라 **z-index 71** 로 늘 눌린다 —
구멍을 둘 뚫어 겹치면 evenodd 가 다시 메워 버린다(그렇게 하루가 안 넘어간 적이 있다).

## 3. 밖에서 읽는 문 (자를 짤 때 쓴다)

- `window.__hintLast` — 마지막으로 «무엇을·무슨 말로·어느 줄이» 짚었나. `{id, say, 보임, 자리}`
  ⇒ 「왜 손가락이 없나」를 갈래를 손으로 뒤지지 않고 한 번에 답한다.
- `window.__pickState()` — 집는 중 · 끄는 중 (위 ⓓ를 밖에서 가른다)
- 둘 다 읽기용이다. 게임은 안 쓴다.

## 5. 2026-08-30 덧 — 「보이는데 안 눌리는 것을 짚는다」

하루에 같은 병을 다섯 번 잡았다. 따로 난 벌레가 아니라 **한 뿌리**다:
화면이 「저것이 보인다」와 「저것이 눌린다」를 **같은 것으로 여겼다.**

| 잡힌 자리 | 무엇이 덮었나 | 고친 자 |
|---|---|---|
| [거두기]가 안 눌린다 | 잠긴 [물주기]가 같은 자리에 얹혀 있었다 (둘 다 `bottom:12px`) | 알림뿐인 줄이 물러난다 |
| 넓은 화면에서 손가락이 다 죽는다 | 시트가 늘 펴져 있다 | `sheetCovers` — 열렸나가 아니라 덮나 |
| [주문] 개수 창에서 손가락이 없다 | 시트 네모가 창과 겹친다 | `.pop`(z 84)은 시트(z 40) 위다 — 안 덮인다 |
| [다음 날]을 아홉 번 눌러도 날이 안 간다 | 밥상 창이 화면을 통째로 덮는다 | 창 «밖»은 아예 안 짚는다 · 창 안 [이대로 다음 날 ▸]을 짚는다 |
| 탭을 바꾼 뒤에도 손가락이 그 탭에 붙어 있다 | 아무것도 안 덮었다 — **다시 안 물었다** | 지킴이가 반 초마다 다시 고른다 |

★ 마지막 것이 뿌리다. 따라다니는 고리는 **자리만** 옮기고 「무엇을 짚을까」를 다시 안 물었다.
  탭 바꾸기·시트 열닫기·창 닫기처럼 **다시 그리는 계기가 없는 손짓**이 여럿이라,
  그 자리마다 `updateHint()` 를 부르는 대신 한 곳에서 반 초마다 다시 묻는다.
