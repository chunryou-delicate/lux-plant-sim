# 직업·남녀 분기 — «추후 분기»가 막히지 않게 길만 연다 (plan · 2026-10-10)

> 박사님(10-09 23:5x · 총괄 전달): *"옛날 기획한 대로 직업이랑 남녀별로 추후에 분기되도록도 해"*
> **지금 짓지 않는다.** 이 문서는 (1) 옛 «네 캐릭터»와 D59 «진로 셋»을 한 표로 맞추고 (2) 남녀 분기의 때·갈리는 것·안 갈리는 것을 정리하고 (3) 지금 코드가 막지 않게 할 최소 이음을 core 목록으로, (4) 그림·3D 주문을 char 목록으로 낸다. 값·재미가 갈리는 고르기는 §5 «박사님 몫».

## 0. 두 층 — «캐릭터»와 «진로» (plan-jobs-min §0 그대로)
- **캐릭터(새 판)**: 시작 집·돈·식구·목표가 갈리는 «게임의 종류»(GAME_PLAN §4 · data/balance/characters.json). 새로 시작할 때 고른다.
- **진로(엔딩 뒤 · 같은 판)**: 엔딩(내 집) 뒤 같은 사람이 «식물로 무엇을 하며 사나»를 고른다(D59 · 지금 식물 가게만 열림).
- 튜토·초보 스토리(반지하 → 원룸 → 내 집)는 **자취생 고정**(story_arc §0 · 박사님 확정). 성별은 그 안에서도 갈릴 수 있다(§2).

### 2-3. 안 갈리는 것
- **규칙 · 값 · 퀘스트 · 빛 · 자람 · 엔딩 · 진로** — 하나도 안 갈린다. 성별은 모습이다.
- **대사** — 지금 갈릴 줄이 없다(§2-4). 갈리게 쓰지 않는다(§3-5 검사).

### 2-4. 대사에서 성별이 드러나는 줄 — 세었다(dialogue.js · 10-10)
- 자취생 줄 273 · 몬이 줄 419 — **주인공 성별이 드러나는 줄 0.**
  - 어미: 자취생 혼잣말은 «…다 / …네»(성별 없음) · 몬이는 반말 «…야 / …자».

  - ⚠ 한 번 샜던 것: 손님 표 «콩나물 키우던 총각»(10-10 c13b4f0e 전에 «그 학생»으로 고침) — 그래서 검사로 막는다(§3-5).
- 주석·문서의 «자취녀»는 화면에 안 나간다(dialogue.js 주석 다섯 곳 · room_view 주석).

## 3. 지금 코드가 막지 않게 할 최소 이음 — [core] 목록 (지금은 'f' 그대로 · 길만)
1. **`S.hero = { gender: 'f' }`** — 세이브 칸 하나 · 옛 세이브는 'f' · 읽는 곳은 `heroGenderOf(S)` 하나(여러 곳에서 읽으면 반만 바뀐다).
2. **`story.job` 열거** — `'shop' | 'care' | 'breed'`(+ 뒤에 `'decor'` 자리) · 새 판 캐릭터는 따로 `S.character`(`'jachwi'|'gajang'|'jubu'|'researcher'` = characters.json id). 진로와 캐릭터를 한 칸에 섞지 않는다(한 낱말 두 방).
3. **초상** — FACE_FILE 찾기를 `who === 'jachwi'` 일 때 성별 앞말로: 'm' 이면 `jachwi_m_{키}` → 없으면 `jachwi_m_neutral`(+ 콘솔 경고 · 조용히 여자 얼굴로 떨어지지 않게). test_dialogue_coverage 의 «초상 파일이 있다» 검사를 성별마다 돌린다(남 모자란 키 목록이 곧 char 주문 — §4).
4. **3D·옷** — room_view `CHAR_ASSET`·v2_hero `HERO_URL`·`OUTFIT_FILES` 를 `heroGenderOf(S)` 로 고른다(남 파일이 없으면 'f' 그대로 + 경고). `?hero=m` 같은 깃발로 미리 볼 수 있게.
5. **대사는 손대지 않는다** — 갈릴 줄이 없다. 대신 plan 이 검사 한 칸을 둔다(§3-5).
- §3-5 [plan · 넣음] test_dialogue_coverage «주인공 성별 낱말 없음» — 자취생·몬이 줄과 손님 표 ask/thanks 에 «언니·오빠·누나·형·아가씨·총각·자취녀·자취남·그녀» 가 들어오면 빨강.
