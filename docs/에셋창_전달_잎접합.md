# [코드창 ↔ 에셋창] 잎 에셋 접합 검사

2026-07-26. **2판** — 1판의 검사 방식이 틀렸다는 지적을 받아 고쳤습니다.

---

## 먼저, 제 검사가 두 군데 틀렸습니다

에셋창 지적대로입니다. 두 오류가 겹쳐 **오탐 2건 · 미탐 2건**을 냈습니다.

**① 정점↔정점 거리로 쟀습니다.**
저폴리는 삼각형이 커서 면이 맞닿아 있어도 가장 가까운 *정점*은 멉니다.
겹쳐 박은 잎자루가 "끊김 0.079"로 나온 게 이 탓입니다. → **점↔면(point-to-surface) 거리**로 바꿨습니다.

**② 경계를 "폭이 3배 뛰는 지점"으로 잡았습니다.**
완만하게 넓어지는 잎에서는 어느 구간도 3배를 못 넘어 경계를 아예 못 찾고,
그걸 "잎자루 없음"으로 처리했습니다. **실버-물방울과 마블-크림그린이 이 오탐**이었습니다.
→ **최대폭의 40%를 처음 넘는 높이**로 바꿨습니다.

거기에 경계 아래 집합에 잎몸 조각이 섞여 들어가, 잎몸끼리의 거리를 재고 "연결됨"으로
잘못 넘긴 경우도 있었습니다(갤럭시-틸골드). 지금은 **축 근처의 가는 심만** 잎자루로 셉니다.

## 지금 쓰는 판별 기준

여러 방식을 교차 검증한 결과, 가장 깔끔하게 갈리는 건 이것입니다.

> **자루 끝 높이 vs 잎몸 시작 높이** — 둘이 같으면 붙은 것, 자루 끝이 아래에서 끊기면 뜬 것

| 에셋 | 자루 끝 | 잎몸 시작 | 차이 | |
|---|---|---|---|---|
| 기준잎 `monstera_leaf_mature` | 0.45 | 45% | **0** | 붙음 |
| `mon_galaxy_tealgold` (수정 후) | 0.35 | 35% | **0** | 붙음 |
| `monstera_leaf_fullalbo` | 0.33 | 40% | **0.07** | ★ 뜸 |
| `mon_zebra` | 0.15 | 28% | **0.13** | ★ 뜸 |

점↔면 거리는 보조로 씁니다(삼각형이 이음매를 걸치면 0으로 나와 단독으론 못 씁니다).

## 새로 나온 것 — 2건

1판에서 못 잡았던 것들입니다. 검사 방식을 고치고 나서 드러났습니다.

### 1. 변이-알보-전체흰중기 · `monstera_leaf_fullalbo.glb`
```
자루 끝 0.33  /  잎몸 시작 40%  →  0.07 떠 있음
자루 정점 73개 (기준잎 383개)
```
자루가 잎몸에 닿기 전에 끊깁니다. **중기 변이 1번**이라 화면에 자주 나옵니다.

### 2. 변이-제브라-그린흰 · `mon_zebra.glb`
```
자루 끝 0.15  /  잎몸 시작 28%  →  0.13 떠 있음
자루 정점 22개 (기준잎 383개)
```
더 심합니다. 자루가 잎 높이의 15%에서 끝나는데 잎몸은 28%부터 시작합니다.
자루 정점이 22개뿐이라 사실상 짧은 막대 하나만 있는 상태입니다.

둘 다 **`mon_fullalbo`에 쓰신 방식(자루 상단을 잎몸 안으로 파고들게)** 이면 해결됩니다.

## 답변 — `pothos_silver_droplet_v1`

**"잎자루 없음"은 제 오탐이 맞습니다.** 사과드립니다. 경계 검출이 실패한 것이었습니다.
말씀대로 **자루가 76%**입니다.

**형태는 바꾸지 말아주세요.** 다만 알아두실 게 있습니다 —
자루가 76%면 **잎몸이 25%**밖에 안 돼서, 같은 성장 단계의 다른 잎보다 잎몸이 절반 이하로 보입니다
(기준잎 잎몸 55%). 코드에서 전체 크기를 키워 맞추려면 2.2배가 필요한데,
그러면 자루가 잎 높이의 1.7배가 돼서 더 이상해집니다.

같은 문제가 **`heart_albo_2672_3_v1`(알보-크림민트, 잎몸 28%)** 에도 있습니다. 둘 다 포토스 계열이네요.

**판단은 박사님께 넘깁니다.** 선택지는 둘입니다.

- **그대로 둔다** — 원화의 "물방울 + 긴 대" 느낌 유지. 대신 그루 안에서 유독 잎이 작아 보임
- **자루를 45% 정도로 줄인다** — 다른 잎과 크기가 맞음. 대신 긴 대 느낌이 사라짐

## 파이프라인 규칙 (변경 없음)

- **가장 낮은 정점을 잎자루 끝으로 봅니다** — 잎몸이 자루보다 아래로 내려오면 엉뚱한 데가 줄기에 붙습니다
- **파일명이 바뀌면 반드시 알려주세요** — 코드가 404를 냅니다
- 무늬종은 **텍스처를 그대로 씁니다**(틴트 안 함). 무늬가 곧 텍스처라서입니다
