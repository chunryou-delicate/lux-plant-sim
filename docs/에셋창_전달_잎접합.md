# [코드창 → 에셋창] 잎 에셋 결함 4건 + 육안 확인 1건

2026-07-26. 등록된 잎 에셋 38종을 GLB 정점 단위로 전수 검사한 결과입니다.
**파일명 그대로 고쳐주시면 새로고침만으로 반영**됩니다. 코드는 손댈 필요 없습니다.

---

## 검사 방법

각 GLB를 **높이 1로 정규화**한 뒤(런타임과 같은 조건) 세로 50구간의 단면 폭을 재고,
폭이 갑자기 3배 넘게 넓어지는 지점을 **잎몸이 시작되는 높이**로 잡았습니다.
그 아래가 잎자루, 위가 잎몸입니다.

- **자루↔잎몸 끊김** — 자루 꼭대기 정점에서 잎몸 정점까지의 최소거리가 자루 반경의 1.5배를 넘으면 끊긴 것
- **눕혀짐** — 폭÷높이가 1.2를 넘으면 세워지지 않은 것
- **위아래 뒤집힘** — 위쪽 40% 구간이 아래쪽 40%보다 좁으면 잎이 아래를 향한 것
- **잎자루 짧음** — 잎몸 시작 높이가 15% 미만

## 고쳐주실 것 (4건)

### 1. 변이-마블-크림그린-쨍 · `pothos_cream_marble_v1.glb`
```
위아래 뒤집힘 · 눕혀짐(폭/높이 2.53) · 잎자루 2%
```
가장 심합니다. 잎이 **눕혀진 채로** 들어와 있어 폭이 높이의 2.5배입니다.
회전으로는 못 덮습니다 — 코드가 **"가장 낮은 정점"을 잎자루 끝으로 보고 원점에 스냅**하기 때문에,
에셋 자체가 세워져 있어야 합니다. 현재 **랜덤 풀에서 제외**해 뒀습니다.

### 2. 변이-스페클-민트흰점2 · `pothos_mint_dot_34.glb`
```
위아래 뒤집힘 · 잎자루 2%
```
잎자루가 사실상 없고 위아래가 뒤집혀 있습니다. 이것도 **풀에서 제외** 상태입니다.

### 3. 변이-실버-물방울-쨍 · `pothos_silver_droplet_v1.glb`
```
잎자루 없음
```
잎몸만 있고 자루가 붙어 있지 않습니다. 지금은 엽초(코드 생성)로 밑동을 가려 쓰고 있는데,
자루가 있으면 훨씬 자연스럽습니다. **풀에는 들어가 있습니다**(형태 자체는 쓸 만해서).

### 4. 변이-알보-전체흰 · `mon_fullalbo.glb`
```
자루↔잎몸 끊김 — 간극 0.067 / 자루 반경 0.037  (1.8배)
```
자루와 잎몸이 **떨어져 있습니다**. 높이를 1로 놓았을 때 0.067이니,
실제 화면에서 자루 굵기의 두 배쯤 벌어져 보입니다.
`_v1` · `_v2`도 같은 메시라 함께 고쳐집니다.
