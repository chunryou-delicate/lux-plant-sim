### B가 고친 것 — 겉과 속의 불일치

## ★ B가 드러낸 진짜 버그 — 근거리 샘플링

B를 켜자 온실 DLI가 **65.50**이 나왔다. 이건 물리적으로 불가능하다.

```
천공 휘도 L = Ev·τ/π = 25,000 × 0.85 / π = 6,764 cd/m²
반구 전체가 유리여도  E ≤ π·L = 21,250 lx
측정값                          106,540 lx   ← 상한의 5배
```

**원인**: `daylightAt`이 창을 고정 4×3으로 쪼개 각 조각을 **점광원**으로 취급했다
(`E = L·cosWin·cosP·dA/d²`). 작은 창을 1m 밖에서 볼 땐 충분하지만,
유리벽(4.9×2.7m)을 0.6m 앞에서 보면 **조각 하나가 1.2×0.9m인데 거리는 0.6m** —
점광원 근사가 완전히 깨진다. 작은 창만 쓰던 동안 드러나지 않던 버그다.

**수정**: 거리 적응 샘플링. 조각 한 변이 거리의 1/3을 넘지 않게 자동으로 쪼갠다.

```js
daylightAt(p, n, wins, { samples: 'auto' })
```

- 수정 후 온실 17,182 lx (< 21,250 상한 ✅), DLI 10.56
- **tool.html도 `'auto'`로 전환했다** — 파라미터 재조정·새 기준선은 **`docs/lux_sampling.md`** 참고.
  (옛 기준선 426/104/559는 창 없는 장면이라 자연광 경로를 아예 검증하지 못했다)

## ★ 설계 의도 — 온실은 "최고의 방"이 아니라 "성격이 다른 방"

온실이 **최고**면 엔드게임이라 **도달하면 끝**이다.
온실이 **성격이 다르면 분기**가 된다:

| | 아파트 | 온실 |
|---|---|---|
| 빛 | 적당 — 그냥 두면 됨 | **남아돎 → 차광이 관리 변수** |
| 비용 | 보통 | **난방비 폭발** (겨울) |
| 적합 식물 | 관엽 (몬스테라) | **고광종** (다육·허브·채소) |
| 플레이 | 안정적 | 빡셈 |

→ **"아파트에서 안정적으로 vs 온실에서 빡세게 고광종"** 이 선택이 된다.

그리고 이러면 **연구자가 온실에서 시작하는 게 말이 된다** —
쉬워서가 아니라 **다른 게임이라서**. 연구자 목표(희귀종·신품종)와도 맞는다.
고광종을 다루려면 빛이 남아도는 곳이 필요하고, 그 대가로 차광과 난방을 관리해야 한다.

온도 축(`temp`)이 들어오면 이 트레이드오프는 **저절로** 강해진다 — 유리는 단열이 최악이다.

## ⚠️ C(천창) 전에 차광이 필요하다

천창을 넣으면 온실 DLI가 20~40이 된다. 몬스테라 `max` 16 초과 = **과광**.
차광 수단이 없으면 온실은 **"들어가면 죽는 방"** 이 된다.
지금 버그(DLI 0으로 즉사)가 **반대 방향 버그(과광 즉사)로 바뀔 뿐**이다.

### 차광 방안 (권장: 유리 투과율 τ를 관리 변수로)

이미 모든 창이 `tau`(투과율)를 갖고 있고 조도식이 `L = Ev·τ/π`로 그걸 쓴다.
**새 물리가 필요 없다.** 차광 장치는 `tau`에 계수를 곱하는 것뿐이다.

| 장치 | 배율 | 비용 | 조작 |
|---|---|---|---|
| 없음 | ×1.00 | — | — |
| 발 (대나무) | ×0.55 | 싸다 | 수동 |
| 차광막 30% | ×0.70 | 보통 | 수동 |
| 차광막 50% | ×0.50 | 보통 | 수동 |
| 차광막 70% | ×0.30 | 비쌈 | 수동 |
| 자동 블라인드 | 가변 | 비쌈 | **자동** — 목표 DLI 유지 |

- 창(또는 유리벽)별로 따로 걸 수 있어야 한다 → **"동쪽만 가리고 서쪽은 열어둔다"** 가 가능
- 계절별로 바꿔 달아야 함 → 여름 차광 / 겨울 제거. 안 바꾸면 겨울에 부족해진다
- 자동 블라인드는 **비싼 편의 아이템** — 돈으로 관리 부담을 사는 것

**대안(천창 면적 조절)을 권하지 않는 이유**: 숫자를 맞추면 문제는 사라지지만
**플레이가 안 생긴다.** 차광은 온실에 성격을 주고 계절 대응을 만든다.

### C의 안전장치 (tool.html 이관 때와 동일)
1. 작업 전 `tool.html`·`daylight_lux.js` 백업
2. 수직창만 있는 방으로 회귀 — **오차 0.000000** 확인
3. `_dli_probe.html`로 4개 방 DLI 재측정 — 값이 **하나도 안 변해야** 함
4. 어긋나면 즉시 롤백
