## 이 문서를 쓰는 법

**한 대목 = 한 블록**이다. 블록은 아래 여섯 칸을 늘 같은 차례로 갖는다 —
`언제 / 알아야 하는 것 / 지금 나가는 문구 / 실측 / 판정 / 고칠 안`.
새 대목이 생기면 **진행 순서에 맞는 자리에** 블록을 통째로 끼우고 번호(`G-NN`)만 새로 준다.
번호는 순서표가 아니라 **이름표**다 — 중간에 끼울 때는 `G-04a` 처럼 붙이고, 번호를 다시 매기지 않는다
(다른 문서가 이 번호로 가리킨다).

칸의 뜻:

| 칸 | 무엇을 적나 |
|---|---|
| **언제** | 이 안내가 뜨는 조건. 화면 상태로 적는다("Day 4 이후"가 아니라 "시루를 놓았고 물을 안 준 동안") |
| **알아야 하는 것** | 플레이어가 **이 순간에** 몰라도 되는 것 말고, 모르면 막히는 것만 |
| **지금 나가는 문구** | 화면에 실제로 뜨는 글자 그대로 + `파일:줄`. 없으면 **「없음」이라고 적는다** |
| **실측** | 화면으로 본 것. 안 봤으면 「안 봤다」 |
| **판정** | ○ 충분 · △ 있는데 모자람 · ✕ 없음 · ⚠ 틀린 말을 한다 |
| **고칠 안** | 짧고 시키는 말. 길이 제한(§0)을 지킨 것만 |

★ **대사·서사는 이 대장이 아니다.** `dialogue.js` 가 내는 말은 다른 창이 본다.
여기 적는 것은 「이제 뭘 하지」를 없애는 안내뿐이다. 겹치면 그 자리에 「대사와 겹침」이라고만 적는다.

## §3 대장을 쓰는 사람에게 — 자주 틀리는 것

1. **같은 말이 여러 곳에서 나온다.** 아래 한 줄(`#quest`)은 [식물] 탭 맨 위(`#sheetQuest`)에 **그대로 복사**된다(`game.html:4089`). 한 곳만 고치면 두 곳이 갈린다.
2. **손가락은 「모르는 것」에만 쓴다.** [다음 날]은 첫 이틀만 가리킨다(2026-08-06 지시). 늘 켜 두면 장식이 된다.
3. **말풍선이 있으면 아래 버튼은 안 뜬다.** 같은 일을 두 번 말하지 않기로 돼 있다(`markSays`). 그래서 **말풍선 문구가 곧 아래 버튼 문구**다.
4. **숫자를 숨기기로 한 판이다.** 첫 플레이 동안 DLI·밝기순은 감춘다(`showDli()`). 새 문구에 숫자를 넣기 전에 그 함수를 먼저 본다.
5. **배너는 셋까지다.** `banners()` 가 같은 말을 접고, 넷째부터는 `…외 N개` 로 줄이고, 6초 뒤 또는 누르면 사라진다(`game.html:6864~6885`). **한 턴에 넉 줄 이상을 배너로 내면 넷째는 안 읽힌다.**
6. **`grep` 을 믿지 말 것.** `game.html` 에 널 바이트가 하나 있어(바이트 기준 6869줄) 검색이 **6870~7117줄을 통째로 건너뛴다.** 그 구간은 검수·자동 시뮬 코드라 지금은 안내가 없지만, 새 문구를 넣었다면 `Read` 로 확인해야 한다.
