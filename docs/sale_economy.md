## 0. ★ 먼저 — 계산이 전제를 뒤집었다

`food_economy.md` §5에서 "75일 탈출 = 판매순익 32,100원/일 필요"라고 적었다.
실제로 모주 회전을 재보니 **자릿수가 안 맞는다.**

`plant_grow.html`의 `ageOf()` 곡선 때문에 **몬스테라는 뒤로 갈수록 마디가 느려진다**:

| 마디 | 게임일 | 직전 마디에서 |
|---|---|---|
| 1번째 | 11.0 | — |
| 2번째 | 28.9 | 17.9일 |
| 4번째 | 75.7 | 24.9일 |
| 6번째 | 133.0 | **29.8일** |
| 12번째 | 348.3 | **39.6일** |

성숙한 모주가 **마디 하나에 30~40일**이다. 반지하 10슬롯(13 − 콩나물 3)을 전부
몬스테라 모주로 채워도 **하루 0.29개** 삽수. 삽수 12,000원이면 **3,430원/일**이다.
필요한 32,100원의 **9분의 1**이다.

게다가 씨앗부터면 첫 삽수 채취(잎 4장)까지 **75.7 게임일**이 걸린다.
그 사이 순지출 16,125원/일 → **76일에 122만원 소모, 시작 자금 100만원으로 파산.**

> **결론: 반지하에서 식물을 팔아 흑자를 내는 건 불가능하다.**
> 이건 밸런싱 실패가 아니라 **자취생 게임의 정체**다. 아래처럼 다시 짠다.

## 1. ★ 자취생 = 흑자 게임이 아니라 **타임어택**

```
매일 적자다. 시작 자금 100만원이 줄어든다.
콩나물은 그 감소 속도를 늦춰 '버티는 날짜'를 늘린다.
그 시간 안에 무늬를 뽑아 한 방으로 탈출한다. 못 뽑으면 파산.
```

**콩나물의 역할이 여기서 확정된다** — 돈을 버는 게 아니라 **데드라인을 미루는 것**이다.

| | 순지출/일 | 시작 100만원으로 |
|---|---|---|
| 콩나물 없음 | 20,000원 | **50일** |
| 콩나물 풀가동 | 16,125원 | **62일** |

**콩나물이 12일을 벌어준다 (+24%).** "안 사도 되니까 아끼는 작물"이 날짜로 환산된다.

## 2. ★★ 반지하가 무늬 재현에 **가장 유리한 방**이다

이건 물리에서 저절로 나왔고, 예상 못 한 결과다.

`fStable`(최근 14일 DLI 변동계수)을 방마다 재보면:

| 방 | 평균 DLI | **CV** | fStable | fLight | **varieProb** |
|---|---|---|---|---|---|
| 반지하 (자연광만) | 0.24 | 0.81 | 0.7 | **0** | **0%** |
| **반지하 + 클립등 1개** | 6.71 | **0.03** | **1.3** | 0.5 | **13.0%** |
| **반지하 + 클립등 2개** | 13.2 | **0.02** | **1.3** | **1.5** | **39.0%** |
| 원룸 | 2.04 | 0.80 | 0.7 | 0 | 0% |
| 아파트 발코니 | 3.57 | 0.80 | 0.7 | 0.5 | 7.0% |
| 온실 (그대로) | 5.58 | 0.80 | 0.7 | 0.5 | 7.0% |
| 온실 + 차광30% + 등으로 9.3 고정 | 9.3 | **0.00** | **1.3** | **1.5** | **39.0%** |

**자연광이 들어오는 방은 전부 CV 0.80이다.** 날씨(맑음↔흐림 ×0.25)와 계절(×0.55)이
DLI를 4~10배로 흔든다. 재현성 게임에서 이건 치명적이다.

**반지하는 자연광이 거의 0이라 식물등이 곧 전부다 → DLI가 완전히 고정된다.**
어두운 방이 "빛을 100% 통제할 수 있는 방"이 된다.

> 온실도 **차광 + 등으로 위아래를 다 잡아야** 1.3을 받는다. 연구자는 전기가 공짜라
> 그게 가능하다. `greenhouse_plan.md`의 "온실은 차광이 관리 변수"와 정확히 맞물린다.

### ★ 등 하나 더 사느냐 — 0.29 DLI가 확률을 3배로 가른다

클립등 1개면 DLI 6.71로 `fLight` 경계 **7.0에 0.29 못 미친다.**

| | DLI | varieProb | 등 추가비 | 전기 |
|---|---|---|---|---|
| 등 1개 | 6.71 | **13%** | — | 230원/일 |
| **등 2개** | 13.2 | **39%** | 슬롯당 25,000원 | 460원/일 |

10슬롯이면 **초기 투자 25만원 = 시작 자금의 25%.** 전기는 하루 230원 더.
확률 3배를 25만원에 사느냐가 자취생의 첫 결정이 된다.
**물리 계산에서 그냥 튀어나온 임계값**이지 손으로 잡은 게 아니다.

## 3. B-1 삽수 경제 — 몬스테라 말고 **포토스**로

몬스테라는 마디 30~40일이라 현금 회전이 안 된다. 실제 삽수 시장의 주력도 포토스·스킨답서스다.

**포토스는 덩굴이라 마디 간격이 일정하다** — `timeCurve` 감속을 태우지 않는 게 자연스럽다.
`spawnStep = 10일 등속`으로 잡는다. 10슬롯이면 **하루 1마디**.

### 가격표 (정가. 살 때는 ×1.4 = 상점 마진)

| 품목 | 정가 | 비고 |
|---|---|---|
| 몬스테라 씨앗 1립 | 1,500 | 콩 1시루와 같은 값 — "제일 싼 것"의 가격대 |
| **포토스 삽수(일반)** | **3,000** | 하루 회전의 기본 단위 |
| **포토스 삽수(무늬)** | **15,000** | 5배 |
| 포토스 성체(무늬, 마디 6) | 150,000 | 삽수 10개값 — **키우는 게 이득** |
| **포토스 희귀무늬 성체** | **800,000** | ★ 탈출권 |
| 몬스테라 삽수(일반) | 12,000 | 느리지만 단가 높음 |
| 몬스테라 삽수(알보) | 80,000 | |
| 몬스테라 성체(잎 6장) | 60,000 | |
| 몬스테라 알보 성체 | 400,000 | 주부의 시작 개체 |

### 자취생 62일 시나리오 (등 2개 세팅, 10슬롯)

```
초기      등 10개 추가 −250,000  →  잔액 750,000
수입      1마디/일 × 39% 무늬
            무늬 0.39 × 15,000 =  5,850
            일반 0.61 ×  3,000 =  1,830
                          합계 =  7,680원/일
지출      16,125 + 전기 460     = 16,585원/일
순유출                            8,905원/일
→ 데드라인 750,000 / 8,905 =     84일
```

**희귀 무늬 발생**: 0.39 × `matRare` 0.10 = **0.039개/일** → 84일에 **3.3개**

### ★★ 그래서 핵심 결정이 생긴다

| 선택 | 결과 |
|---|---|
| **삽수로 즉시 판다** | 희귀 삽수 80,000 × 3.3 = 264,000원. **오늘은 버티는데 탈출은 못 한다** |
| **키워서 성체로 판다** | 800,000 × 2 = **1,600,000원 → 탈출**. 단 60일 슬롯 점유 = 그동안 수입 감소 |

**"오늘을 버티려고 파느냐, 탈출하려고 키우느냐."**
희귀가 24일차 이전에 나와야 60일을 키워 84일 데드라인에 맞는다.
24일 × 0.039 = **0.94개** — 아슬아슬하게 하나. 긴장이 산다.

그리고 관리를 안 하면(등 1개, `fStable` 0.7):
varieProb 7% → 희귀 0.007/일 → 84일에 **0.6개**. **탈출 실패.**
→ **5.6배 차이가 정확히 "탈출이냐 파산이냐"를 가른다.**

## 4. B-5 연구자 대량 실생 — 온실 45슬롯의 존재 이유

씨앗 100개 심어 변이만 골라내는 **실제 육종 방식**. 삽수는 유전 복제라 재현이 안 되므로
(`researcher_track.md` §8) **대량 실생이 논문의 유일한 길**이다.

### 1회전 = 11 게임일

무늬는 **첫 잎에서 이미 판정**된다(`varie`는 어린잎 단계 확률). 첫 잎이 11 게임일.
→ 심고 11일 뒤 골라내고 나머지는 처분·판매. 이게 1회전이다.

| | 값 |
|---|---|
| 슬롯 | 45 (온실 DLI≥6 자리) |
| 씨앗값 | 45 × 1,500 = **67,500원/회전** = 6,136원/일 |
| varieProb (차광+등 안정화) | **39%** |
| 회당 무늬 | **17.6개** |
| 나머지 27개 판매 (묘목 5,000원) | 135,000원/회전 = **12,270원/일** |

**씨앗값 6,136 < 묘목 판매 12,270.** 실생 자체가 흑자다.
"연구비는 남는 묘목 팔아 충당한다" — 실제 대학원생이 그렇다.
월급 60만원은 식비(22.5만)에만 쓰면 되고, 연구는 자급된다.

### 논문 1편까지 몇 회전인가

재현은 **같은 무늬 ID 3개**여야 한다. 중기 무늬 풀은 `ALBO_MID_POOL` **33종**이다.
회당 17.6개가 33종에 흩어지므로 어떤 한 종이 3개 모이려면:

| 회전 | 누적 무늬 | 최빈종 |
|---|---|---|
| 1 | 17.6 | 2개 안팎 |
| **2 (22 게임일)** | 35.2 | **3~4개 → 재현 성립** |

→ **논문 1편 ≈ 22 게임일**, 졸업 3편 ≈ 66일 + 실패·조건 불일치 여유 → **100 게임일**.
`researcher_track.md` §6의 "1단계 100~150턴" 추정과 맞는다.

### ★ 여기서 플레이가 하나 더 생긴다

재현 조건은 "같은 무늬 ID **+ 같은 조건**(7일 평균 DLI ±20%)"이다.
온실 45슬롯은 DLI가 슬롯마다 다르다.
→ **비슷한 DLI 슬롯끼리 묶어 심어야 재현이 성립한다.**
"어디에 심느냐"가 논문의 성패를 가른다. 배치 게임이 그대로 연구 게임이 된다.

## 5. B-6 상점 — 고정가

**변동가를 넣지 않는다.**

`env_difficulty_axis.md` §3이 지역 날씨를 두고 정리한 논리와 같다:
**"플레이어가 대비할 수 없는 변동은 난이도가 아니라 소음이다."**
가격이 흔들리려면 시세 UI가 같이 있어야 하는데, 그러면 관리 변수가 하나 더 는다.

품목은 캐릭터별 접근이 **가격만으로 자연히 갈린다** — 별도 잠금이 필요 없다:

| 품목 | 정가 | 살 수 있는 사람 |
|---|---|---|
| 씨앗 | 1,500 | 전원 (자취생이 유일하게 살 수 있는 것) |
| 삽수(일반) | 3,000~12,000 | 자취생 후반 · 가장 |
| 성체 | 60,000~150,000 | 가장 · 주부 |
| **알보 성체** | **400,000** | **주부만** (`A-2` 시작 형태 = 돈으로 시간을 삼) |

## 6. 남은 것 — B-4는 측정이 필요하다

**반지하 슬롯 13개 중 DLI 0.3 미만이 몇 개인지 아직 모른다.** 콩나물 3개가 필요한데
실제로 몇 칸이 충분히 어두운지 확인 안 됐다(5~8개가 적당, 3개 미만이면 문제).

`_dli_probe.html`은 브라우저에서 돌아야 하고(`house.js`가 THREE 의존),
**지금 출력에 `<0.3` 칸 수가 없다** — `≥3` / `≥6`만 센다.

> **집/방 창 인계**: `_dli_probe.html` 69행 근처에
> `const nDark = ds.filter(x => x < 0.3).length;` 한 줄과 표 컬럼 하나를 추가하면 된다.
> 시루가 차광 용기라 뚜껑을 덮으면 어차피 DLI 0이므로(§`food_economy.md` §3)
> **급하진 않다.** 다만 "뚜껑 없이도 되는 자리가 몇 개냐"가 초반 편의를 정한다.
