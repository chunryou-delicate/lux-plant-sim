## 0. 이미 확정·설계된 것 (재론 금지)

### 캐릭터 (game_design_core.md)
- **4종**: 자취생 / 주부 / 가장 / 연구원 — 소득 구조가 곧 난이도
- **엔딩**: 자취생=반지하 탈출 / 주부=드림가든 / 가장=목표금액→온실 / 연구원=도감·신품종
- **다이얼 시스템**: 캐릭터 = json 설정값만 다름
- **이사 = 빛 환경 갱신** (반지하~온실 6등급)

### 육성 조건 구현 우선순위 (growth_conditions_map.md) ★로드맵
```
1단계 빛     — PPFD·파장·식물등·판정·성장   ← 있음
2단계 물     — 주기·과습·부족
3단계 경제   — 판매·구입·식물등값 (자취생 긴장)
4단계 번식   — 개체 늘리기 (수익·수집)      ← 박사님 관심사가 여기
5단계 병충해 — 이벤트·약
6단계 온·습도·영양
7단계 무늬·개화 (Lv2)
★ 빛이 항상 메인, 나머지는 조연. 각 단계 재미 확인 후 다음.
```

### 지출·수입 항목 (growth_conditions_map.md) — 이미 목록 있음
- **지출**: 식물·씨앗 / 화분·흙·비료 / **식물등·전기료**(빛 후크 직결, 자취생 긴장원) / 약 / 이사·집
- **수입**: 다 큰 식물 판매 / **번식으로 개체 늘려 팔기(핵심 수익원)** / 희귀·무늬종 고가 / 꽃·열매·수확물

### 킬러 콘텐츠 (세션요약_20260713.md) ★이미 설계됨
```
① 번식: 가지 꺾꽂이 → 물컵 수경재배 → 화분 이식 (개체 늘리기)
② 선별: 씨앗 왕창 발아 → 알보만 살리기 (희귀종 가챠)
→ "식물 하나 키우기" → "컬렉션 경영"으로 확장
```

### 게임 첫 루프 (game_first_loop_start.md)
```
A1 시간(하루 넘기기) → A2 성장상태(growth/health) → A3 시각 피드백
→ A4 말 피드백 → [여기까지 재미 확인선] → A5 경제
첫 프로토 캐릭터 = 자취생
```

### 방향 전환 (game_assets_first.md, 세션요약)
- **"에셋 70% + 로직 30%"** — 에셋 먼저, 그다음 로직·스토리
- 밋밋함의 정체 = "하루 넘기기 + 성장 숫자"만으론 시뮬레이터
- 아트: 파스텔 저폴리, 민트·세이지, 동물의숲st
- 레퍼런스: 가디언테일즈(캐릭터) / 레알팜(수확·판매) / 동물의숲(공간·정) / 냥냥리조트(수집·방치)

### 모듈형 성장 (modular_plant_growth.md)
- 1단계 통째 모델 → 2단계 모듈 시스템(킬러) → 3단계 타 종 확장
- 현재 **2단계 진행 중** (몬스테라 생장 엔진 = 모듈+알고리즘)

### 생장 엔진 (몬스테라_생장엔진_진행.md)
- 순서도가 정본 / 혹은 "잎이 중간잎 되는 순간" 랜덤 1개 / 변이 잎마다 20%
- 성장 3년(1095일) / **수경 번식 시 무늬 80% 계승**

## 1. 박사님이 새로 더한 디테일 (기존 설계의 구체화)

> 번식·선별 자체는 이미 있었음. **아래는 그 안의 구체 규칙**이 새로 나온 것.

### 1-1. 번식 디테일 ★순서도와 직결
- [ ] **분해 단위**: 마디 단위로 자름. 조각 가치 = 품은 예비혹 수?
- [ ] **물꽂이 생략 페널티**: 물병 없이 바로 화분 → **진행 지연** (며칠?)
- [ ] **개별 처리 보너스** ★신규: 하나씩 따로 하면 알보 싹의 **알보 확률 대폭 상승**
  - 기본 20% → 개별 시 몇 %?
  - "수고 ↔ 확률" 트레이드오프 = 순서도 취향 스펙트럼이 조작 레벨에서 재현
- [ ] 기존 "수경 번식 무늬 80% 계승"과 수치 정합
- [ ] 자르기 실패·고사 리스크?

### 1-2. 식용작물 = 지출 절감 ★관점이 새로움
> 기존 문서엔 "수확물 판매"만 있고, **식비 절감** 개념은 없었음.
- [ ] 어떤 작물이 얼마나 절감? (상추·바질·토마토 — care 필드에 채소 DLI 이미 있음)
- [ ] 경제 2단: **초반 식비 절감(생존) → 후반 희귀종 판매(성장)**
- [ ] 캐릭터별 의미 (자취생=생존 직결 / 주부=살림 보탬)

### 1-3. 자체 난이도 축 ★신규
> 기존은 "캐릭터=난이도" 하나뿐. 별도 축은 새로움.
- [ ] 무엇을 조절? (월세 압박 / **변이 확률** / 식물 까다로움 / 시간 압박)
  - 엔진 문서 "변이 20%, 난이도별 조정 예정"과 연결
- [ ] 캐릭터 × 자체난이도 조합표

### 1-4. 시작 스토리 4종
- [ ] 각 캐릭터 시작 상황 3~5줄 (엔딩에서 역산)
- [ ] 시작 자산 — characters.json 스키마에 필드 이미 있음(startCash 등)
- [ ] 첫 5분 동선

### 1-5. 가격표
- [ ] 시간·돈 단위 먼저 (하루=몇 분? 월세·식비 주기)
- [ ] **"며칠치 생활비"로 환산해 잡기** (절대금액은 나중에 뒤집힘)
- [ ] 가구 / 창호(프리셋 12~18종) / 설비(식물등) / 소모품 / 판매가
  - 참고: `growth_conditions_map.md`에 "실제 가격대 서칭" 항목 이미 있음

## 5. 권장 순서 (기존 로드맵에 맞춤)

> 헌법: **한 번에 하나씩, 재미 확인 후 다음.**
> 육성조건 로드맵(1빛→2물→3경제→4번식)과 첫 루프(A1~A5)를 합치면:

```
현재 위치: 1단계(빛) 있음 + 모듈 성장 엔진 2단계 진행 중

다음:
  ① 생장 엔진 튜닝 마무리 → 게임 루프 연결
     (엔진 문서의 "튜닝 확정 후 게임 루프 연결")
  ② 첫 루프 A1~A4 — 하루 넘기기·성장·피드백 → 재미 확인
     · 자취생 프로토
  ③ 재밌으면 → A5 경제 (3단계)
     · 이때 시간·돈 단위 확정 → 가격표
     · 식용작물 식비절감도 여기
  ④ 번식 (4단계, 킬러) — 마디 분해·물꽂이·개별처리 확률
  ⑤ 시작 스토리 4종 + 난이도 2축
  ⑥ 선별(알보 가챠) → 컬렉션 경영으로 확장
```

**주의**: 기획서(스토리·가격표)를 먼저 다 쓰려 하면 엔지니어 함정.
기존 문서들이 반복해 경고 — **재미 확인이 항상 앞**, 문서는 뒤따라옴.
