# 2. Day 4 — 첫 수확, 그리고 몬스테라가 온다

```
Day 0   열린 콩나물 트레이 1개를 받는다   → "어디 둘까"
Day 4   첫 수확                        → 품질이 자리로 갈린다
        ↳ 식물신 메시지 한 줄
        ↳ 어린 몬스테라 도착            → "이건 또 어디 둘까"
Day 4+3~7  새순 전개 / 새잎             → ★첫 플레이 종료
```

## 콩나물 첫 수확 — **기존 수치 그대로**

| DLI (판정값) | 품질 | 끼니 |
|---|---|---|
| 0 ~ 0.3 | 100% | **3끼** |
| 0.3 ~ 1.0 | 70% | 2끼 |
| 1.0 이상 | 40% | 1끼 |

- **4턴 수확** (변경 없음)
- **판정 이력이 7일 미만이면 지금까지 관측한 DLI의 평균**을 쓴다.
  Day 4면 4일치 평균이다. `dliAvg(7)`이 모인 만큼으로 내는 기존 동작 그대로다

### 첫 성공 수확의 값어치

```
3끼 = 7,500원어치 (= 하루 식비 전액)
수확 당일 또는 다음 정산에서 2끼 사용 (하루 상한)
→ 식비 7,500원 → 2,500원 · 1끼 잔여
```

**하루 식비 7,500원 · 하루 사용 상한 2끼**는 `food_economy.md` 그대로다.

# 3. 몬스테라 — 식물등이 아니라 **창가 높은 자리**

## ★ [정정] 식물등은 첫 플레이의 통과 조건이 아니다

> **이전**: 튜토 체크리스트 *"☐ 등을 켜고 갈라진 잎 1장"*
> **정정**: *"☐ 몬스테라를 창가 높은 자리에 두어 새순이 나온다"*

**식물등은 이후의 비싼 성장 가속·안정화 선택지로 내린다.**
첫 플레이에서 배울 것은 **"자리"** 하나다.

| | 첫 플레이 | 이후 |
|---|---|---|
| 몬스테라를 자라게 하는 법 | **높은 창가 자리** (자연광) | + 식물등(가속·안정화) |
| 보상 | **새순 전개 / 새잎** | 갈라짐 · 무늬 |

## ★ 보상은 **갈라짐이 아니라 새순/새잎**

갈라짐(`fenestrate` 6.0)은 반지하 자연광으로 **닿지 않는다.**
첫 플레이 보상은 **화면에서 눈으로 보이는 변화**여야 한다 —
새순이 펴지거나 잎이 하나 나는 것.

**도착 후 3~7턴 안에 화면상 새순 변화가 시작되는 것을 목표 구간으로 둔다.**
정확한 초기 생장 진행도는 **growth 측정 후 확정**한다(§5).

## 판정 — `peak`가 아니라 `dli7`

```
growth 판정 = 최근 DLI 이력의 평균 (dli7)
7일 미만   = 모인 만큼의 평균
novice     = 날씨·계절 고정이라 dli7이 그 슬롯의 peak 조건으로 수렴한다
```

## ⚠ real 모드에서는 보장되지 않는다 — **첫 플레이는 novice 전용**

| 라벨 | 값 | 판정 |
|---|---|---|
| `banjiha.space.peak_summer` (h=1.6m) | **3.74** | `min` 3.0 초과 → 성장 |
| `banjiha.space.avg7_summer` (real) | **2.40** | **`min` 3.0 미만 → 정체** |

**real 모드의 자연광만으로는 성장 재개가 보장되지 않는다.**
날씨·계절이 굴러가면 평균이 2.40으로 내려가기 때문이다.

→ **첫 플레이는 novice 전용으로 명시한다.** real 모드는 식물등이 필요하고,
그게 §3의 *"식물등은 이후의 선택지"* 와 맞는다.

# 4. 학습 통과 기준 — [정정]

> **이전**: *"아무도 시키지 않았는데 다시 옮긴다"*
> **정정**: 아래 한 줄

```
정답 위치를 직접 알려주지 않았을 때
플레이어가 콩나물은 어두운 자리, 몬스테라는 높은 창가 자리에 배치한다.
```

**두 작물의 요구가 정반대**라는 게 핵심이다 — 하나는 어두울수록 좋고 하나는 밝을수록 좋다.
같은 방 안에서 **자리를 나눠 쓰는 법**을 배우는 것이 첫 플레이의 학습 내용이다.

## 보조 관찰 — 통과 기준이 아니다

*"한 번 더 옮겨본다"* 는 **보조 관찰로만 유지**한다.
옮겨보는 행위 자체는 학습의 증거가 될 수 있지만, **통과 조건은 최종 배치**다.

# 5. ⚠ 지금 막혀 있는 것 — house 요청 필요

**`space` 기준 3.74인 자리가 `slots` 기준으로는 없다.**

| 라벨 | 값 |
|---|---|
| `banjiha.space.peak_summer` (h=1.6m) | 3.74 |
| **`banjiha.slots.peak_summer`** (현재 가구 배치) | **0.55** |

`space`는 **가구 없는 공간의 잠재력**이고, 화분은 **가구 위(`slots`)에만** 놓인다.
→ **지금 가구 배치에는 3.74짜리 자리가 존재하지 않는다.**

→ **house에 "반지하 창가 높이(1.6m)에 화분 슬롯"을 요청했다**(`plan-to-house.md` 10차).
그게 없으면 §3의 몬스테라 성장이 성립하지 않는다.
